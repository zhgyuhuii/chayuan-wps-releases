# 察元AI桌面单机版下载到出对话的完整路径 一台办公本就够

很多人对「单机版 AI 软件」的第一反应是配置麻烦，得装 Docker、得开端口、得熟悉命令行。我想用一段自己装的过程把这层心理障碍先拆掉。整个流程从下载到出第一句对话，时间不到二十分钟，机器是一台公司发的普通办公本，i5 加 16G 内存，没有独立显卡。

第一步是拿到包。chayuan-desktop 在 release 页面提供了 Windows、macOS、Linux 三套安装包。Windows 是 msi，macOS 是 dmg，Linux 是 deb 和 AppImage，国产 OS 比如麒麟、统信 UOS、openKylin 也有适配的 deb 包，文件名里带架构后缀。我那台是 Win11，下了 x86_64 的 msi，二百多兆。

第二步装包。msi 双击点过去，安装路径默认在 Program Files 下，安装本身只解开 Tauri 外壳和嵌入式 Python sidecar，不动数据目录。装完桌面会出现一个 察元AI.lnk 的快捷方式，这名字是品牌标识里写明的固定文案，不要自己改，重装的时候它还会回来。

第三步首次启动。双击图标会先看到一个 splash 画面，然后弹出 FirstRunSetup 向导。向导第一屏问数据目录放哪，也就是后面所有的资料、对话、模型钥匙、知识库索引会落到的根目录，环境变量名是 CHAYUAN_ROOT。我建议不要选系统盘的用户目录，挑一个独立分区，便于后期备份和迁移。第二屏问允不允许 Tauri 主进程拉起 sidecar，默认勾上就行。第三屏问首启动要不要预下载内嵌的 bge-m3 嵌入模型和 RapidOCR 模型，单机版有这两个东西做本地离线知识库的底层，建议留着。这一步走完，进度条一般在两三分钟内结束，机器风扇都不用转起来。

第四步等 sidecar 起来。Tauri 主进程会 spawn 一个嵌入的 Python sidecar 子进程，注入 CHAYUAN_ROOT 环境变量，监听 127.0.0.1:62581。前端 webview 通过这个端口跟后端讲话。如果你打开任务管理器，会看到一个 chayuan-desktop.exe 和一个 chayuan-server 子进程。健康探针通过之后，主界面打开。

第五步配模型。主界面右上的设置里有「模型供应商」这一栏。免费开源的AI软件 通常会在这里给一份长长的厂商列表，察元AI 也是。OpenAI 兼容路由这一项很重要：你自家用 vLLM、Ollama、LM Studio 部署的本地推理服务，全都可以以这个接口接进来。我现场塞了一个 DeepSeek 的 Key 进去，界面就自己拉了一次 /v1/models，把对话、嵌入、重排、视觉这些类别的默认候选自动填上了。这种自动探测在 chayuan-desktop 里是默认行为。

第六步出第一句对话。回到主界面，左上点新建对话，挑模型，发一句话过去。流式输出、reasoning 折叠、工具调用三层折叠，这些 UI 细节会让你感觉这是一台正式的产品，不是一个 demo。我顺手把一份产品手册 PDF 拖进对话窗口，它触发了察元智库的文档 RAG，引用气泡跟着回答出来。整个体验和后面要装的 chayuan-wps WPS AI 插件 是一致的：一边在桌面单机版里问，一边在 WPS 文字里问，背后是同一套知识库和模型配置。

二十分钟，两个安装包，三件该配的事，第一句对话出来。一台办公本是够的，没什么神秘的事情。
