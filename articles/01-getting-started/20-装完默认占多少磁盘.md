# 装完之后默认占多少磁盘 察元AI安装目录的每个大块拆解

装一个 AI 桌面应用，磁盘占用不是小事。模型权重几个 G、嵌入索引几个 G、对话历史长期累积也是几百兆。这一篇拆开讲察元AI 桌面单机版装完之后磁盘占用的具体分布，让你知道每一块占在哪里、值不值得，以及怎么按需缩减。

第一块是安装目录。Windows 默认在 C:\Program Files\chayuan-desktop，macOS 在 /Applications/察元AI.app，Linux 在 /usr/lib/chayuan-desktop。这个目录里有 Tauri 主进程二进制、嵌入式 Python sidecar onedir、Webview 资源、前端打包后的 React 构建产物。总大小约 600M 到 800M 不等。其中 Python sidecar 占了大头，因为 PyInstaller onedir 把整个 Python 运行时和依赖都解压在那里，不能省。

第二块是 CHAYUAN_ROOT/models 目录。这里放本地内嵌的几个权重模型。bge-m3-onnx 嵌入模型约 600M，RapidOCR 检测加识别模型约 100M，bce-reranker-base 重排模型约 300M。三个加起来约 1G。这些权重是 本地离线知识库 工作的基础，不能轻易删。如果你确定不用 OCR 处理扫描件，OCR 权重可以省下 100M，但代价是图像 PDF 入库失败。

第三块是 CHAYUAN_ROOT/data 目录。这里是 SQLite 数据库文件，存对话历史、知识库元数据、用户配置。空白安装时大约几 MB。日常使用一段时间之后，对话历史会膨胀到几十兆甚至几百兆。如果你跑了大量长对话，这个目录会持续增长。

第四块是 CHAYUAN_ROOT/vectors 目录。本地离线知识库 的 sqlite-vec 向量库文件就在这里。一个文档库大约每万个 chunk 占几十兆。如果你挂了一个 200 多份 PDF 的 folder-sync 库，估计这个目录会到 1G 左右。多个知识库会按 KB 名称分文件存。

第五块是 CHAYUAN_ROOT/uploads 目录。用户拖进来的原始文件副本会放在这里。如果你建库时勾了 保留原文件，这里会一直留着；不勾的话只暂存解析过程。一份 200 份 PDF 的库，原文件约 1.5G。

第六块是 CHAYUAN_ROOT/credentials 目录。模型钥匙加密存储。空间占用极小，几 KB 量级。

第七块是 CHAYUAN_ROOT/logs 目录。运行日志按天滚动，单天一般几兆，长期会累积到几百兆。chayuan-desktop 自带日志清理机制，默认保留最近 30 天，旧日志自动删除。

第八块是 CHAYUAN_ROOT/cache 目录。临时文件、解析缓存、下载缓存。这块可以随时清空，应用会重新建。占用一般在几百兆。

总账下来，一台正常使用的 chayuan-desktop 装机，加上一份个人知识库，大约 4G 磁盘占用。这个数字在 免费开源的AI软件 里属于中等偏上，但跟 Cherry Studio 那种 200M 的纯前端壳比是几倍以上的差距。差距来自 chayuan-desktop 把企业级后端塞进了单机包，包括嵌入模型、OCR、重排、SQL 引擎、Python 运行时。

按需缩减的几个办法。第一，不用 OCR 删掉对应权重，省 100M；第二，不用重排删掉对应权重，省 300M；第三，定期清理 cache 目录，省几百兆；第四，把不再需要的知识库删除，省几百兆到几个 G；第五，把对话历史导出之后删掉，省几十兆。

如果你用 chayuan-desktop 做企业级部署，磁盘预算建议给到 20G 以上。一个部门级的知识库连同对话历史和缓存，长期可能膨胀到 10G 量级。SSD 优先，机械盘上 sqlite-vec 的写入速度会拖累整体体验。

WPS AI 插件 chayuan-wps 自身只占几兆磁盘，因为它是 WPS 加载项，所有重活都交给桌面单机版的 sidecar。装了加载项不会显著增加磁盘负担。

这份拆解能帮你判断该把 chayuan-desktop 装在哪个分区、CHAYUAN_ROOT 选哪里、什么时候清缓存、什么时候归档。免费开源的AI软件 把存储完全交回用户手里，自己看着办。
