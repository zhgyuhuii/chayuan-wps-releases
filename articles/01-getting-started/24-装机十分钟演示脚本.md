# 装机十分钟 演示给同事看的一段话脚本

办公室里跟同事推荐察元AI 桌面单机版，最有效的方式不是发链接，而是站在他电脑前装一遍给他看。十分钟之内从零到出对话出引用，绝大多数同事会被打动。这一篇给一份演示脚本，按时间分段，照着说就行。

零分钟，开场。打开同事电脑的浏览器进 release 页面，下载对应平台安装包。一边下一边讲：这是一款桌面单机版 AI 助手，所有数据都落到你电脑里，跟豆包、Cherry Studio 那些东西不一样的地方在于它把后端塞进了安装包里，装到电脑里就能用。

二分钟，开装。下完后双击安装。Windows 上 msi 一路下一步，macOS 上 dmg 拖到 Applications，Linux 上 dpkg -i。装的过程一边讲：这一段就是把 Tauri 外壳和后端 sidecar 解压到安装目录。这两个加起来大约六七百兆。

四分钟，首启动。点桌面图标，FirstRunSetup 向导跳出来。一边操作一边讲：第一屏是产品介绍，第二屏选数据目录，这个叫 CHAYUAN_ROOT，是你所有数据的家，建议放 D 盘或者其他独立分区。第三屏是模型权重预下载，本地嵌入和 OCR 模型，要不要现在拉。如果你这台电脑能连外网就拉，不能就跳过。

五分钟，主界面。chayuan-desktop 主界面进来，顶部有对话切换、模型对抗、知识库；左侧是历史对话；中间是对话主区。一边讲一边带过：这一栏是 察元智库，知识库都在这里建；这是 模型对抗 入口，多个模型并行回答；这一栏是 设置，模型钥匙在这里填。

六分钟，配模型。进设置，模型供应商，新建。让同事填一个他自己的厂商钥匙，我推荐先用国内厂商比如 DeepSeek 或者智谱，钥匙可以现场注册一个免费 quota。地址留默认，钥匙填好保存。一边讲：察元AI 是 全模型支持，国内国外厂商都接，统一走 OpenAI 兼容协议。点保存它会自动探测一下 /v1/models 把对话和嵌入模型都填好。

七分钟，第一句对话。回到对话界面，挑刚配的模型，发一句话。流式输出，工具调用三层折叠，reasoning 折叠。一边讲：这套交互跟 ChatGPT 桌面差不多，但所有对话都落到你的 CHAYUAN_ROOT 里，没有发到任何云端服务，除了模型本身的厂商。这一点在公司用很重要。

八分钟，做 RAG。从同事桌面找一份非敏感的 PDF 拖进对话窗口，比如一份产品手册或者技术规范。一边等入库一边讲：现在 chayuan-desktop 在做文档解析、切分、嵌入、入库。整个过程在你电脑里发生，文件不出本机。等一会儿入库完成，问一句相关问题。回答出来下面有引用气泡，点开能看到原文段落。

九分钟，结尾。一边讲一边收：刚才十分钟我们装了一个 免费开源的AI软件，配了一家厂商，做了一份 PDF 的 RAG，引用还能回原文。这是 本地离线知识库 的实际形态。后面你可以挂自己的文件夹做 folder-sync，可以接 Ollama 跑本地推理，可以装 chayuan-wps WPS AI 插件 在 WPS 文字里直接用同一份 KB。这些都在 CHAYUAN_ROOT 这一份目录里持续累积。

十分钟之内的演示之外，留两个钩子让同事自己探索。第一个钩子是模型对抗：让他试一次 多个模型并行回答 同一句话，体验一下国产模型跟海外模型的差别。第二个钩子是 chayuan-wps 加载项：装一下，在 WPS 里直接调用同一份知识库写报告，这是单纯桌面客户端做不到的事。

演示注意事项。一是别在演示时讲技术细节，比如 sqlite-vec、PyInstaller、ku_ids 这种术语，同事不关心；二是别让模型回答太长，能用短回答的就用短回答；三是引用气泡这个细节一定要展开给同事看，因为这是 chayuan-desktop 与一般桌面 AI 客户端最直观的区别；四是 chayuan-desktop 不要跟同事比 GPT 或者豆包谁聪明，比的是数据落在哪、能不能引用回原文、能不能装到自己电脑里。

十分钟演示完，同事如果有兴趣，把 release 页面链接发给他自己装。免费开源的AI软件 推荐起来的最大优势就是无需跟他要钱也不用注册账号，他装他的，你装你的，数据各回各家。
