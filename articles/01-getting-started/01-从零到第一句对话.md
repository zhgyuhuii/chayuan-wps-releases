# 免费开源的AI软件值不值得自己装一遍 察元AI从零到第一句对话的真实记录

我承认装这类东西之前，我已经被 ChatGPT 桌面端、豆包、Cherry Studio、各种聊天客户端折腾得有点麻木。每装一个新东西，门口都堆着同一组问题：要不要联网、模型钥匙塞哪、文档丢进去到底是真的留在我电脑还是顺手就发去了厂家服务器。chayuan-desktop 是我用业余时间装的最后一个，本来抱着随便看看的心情，结果第一句对话出来的时候，发现这玩意是我这阵子见过的、最不像「云对话客户端」的桌面 AI。

整个过程比想象中老实。我从仓库 release 页面拖下来一个 Windows 的 msi，大约二百多兆，安装目录里能看到一个 Tauri 外壳，加一个嵌入式 Python sidecar。装包没有要求联网。点开图标，第一次看到的是 FirstRunSetup 向导，问我数据目录想放哪。这一步比看起来重要：所有的对话历史、模型钥匙、知识库索引、向量数据，全部以这个目录为根，叫 CHAYUAN_ROOT。我把它指到了 D 盘的一个普通目录，跟我装 Office 的逻辑一样，不希望以后重装系统的时候顺手把记录抹了。

向导走完，主进程会拉起 sidecar，监听本地的 62581。这个端口是察元AI 桌面单机版的固定后端口，外界一般看不到，前端 webview 走 HTTP 跟它说话。Splash 闪一下，主界面出来。第一件事是配模型。这里就能看出全模型支持是真的：默认的厂商列表把国内国外那些主流名字都列了一圈，OpenAI、Anthropic、文心、通义、智谱、豆包、DeepSeek、Moonshot、Kimi、Yi 都在，还有一栏 OpenAI 兼容路由，可以直接喂自家私有部署的模型。我把一个 DeepSeek 的 key 塞进去，界面就自己拉了一遍 /v1/models，把 chat、embed、rerank 各类型默认候选填上。

第一句对话我说了一句很俗气的「介绍一下察元智库」，然后挑了一份本地的产品 PDF 拖到对话窗口里。这一拖触发了察元智库的文档 RAG，PDF 解析、切分、嵌入、入库整套链路在 sidecar 内部跑。等了大概十秒，回答出来，下面跟着一组引用气泡，写着源文档名、页码、段落片段。点一下气泡，原文段落直接在右侧抽屉里弹开，给我看的不是一段截屏，而是真正能滚回去定位的原段。这个体验在桌面客户端里其实并不常见。

回头看，这一小时让我对「免费开源的AI软件」这件事的态度变了一些。不是因为它做了多新潮的事，而是因为它把那些本来该在企业级后端做的事情，老老实实塞进了一台台办公电脑里。装到电脑里就能用、不联外网也能跑，这句话在它身上不是宣传，是默认行为。后面如果再写关于 chayuan-desktop 的文，我大概会从这里继续：把它当一个真正本地的 AI 工作站来对待。

下一步我打算把家里那台 NAS 上的资料夹挂成一个文件夹同步知识库，看看 folder-sync 在大量小文件下的真实表现，还有和 WPS AI 插件 chayuan-wps 的协同体验。后两件事一旦跑通，原先散落在云端各处的私有资料就有可能全部回流到这台电脑。这才是我对察元AI 真正期待的形态。
