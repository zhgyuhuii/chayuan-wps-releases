# 装一台到家用台式 把工作笔记本的对话历史迁过去

工作笔记本上用察元AI 桌面单机版攒了几个月的对话历史和知识库，想在家用台式上接着用。chayuan-desktop 的数据都在 CHAYUAN_ROOT 目录里，迁移这件事看着简单，实际上有几个细节需要小心。这一篇专门讲跨电脑迁移的步骤。

先看哪些数据要迁、哪些不要迁。要迁的：对话历史、知识库索引、向量库、原始文件、自定义提示词、模型供应商配置。不要迁的：模型权重（在新电脑上重新下载更省事）、本地推理服务（Ollama 这种在新电脑单独装）、缓存日志（新电脑会自己生成）。

工作笔记本上准备阶段。第一，关闭 chayuan-desktop，确保 sidecar 进程已退出。任务管理器或者 ps 命令确认。第二，找到 CHAYUAN_ROOT 路径。如果你不记得在哪，打开 chayuan-desktop 设置里的 关于 页可以看到。第三，对 CHAYUAN_ROOT 做一次完整备份到外置硬盘或者 U 盘。压缩成 zip 或者 tar 都可以，注意别拷到 OneDrive 那种实时同步的目录。

家用台式上准备阶段。第一，先正常装 chayuan-desktop，跑一次 FirstRunSetup，CHAYUAN_ROOT 指到一个跟工作笔记本结构类似的目录，比如 D:\Chayuan。第二，跑通基础流程：新建对话发一句话，确认 sidecar 起来正常。第三，关闭 chayuan-desktop。

迁移阶段。把工作笔记本的 CHAYUAN_ROOT 内容覆盖到家用台式的 CHAYUAN_ROOT。注意有几个子目录需要特殊处理。

credentials 目录是密钥加密存储，密钥派生跟操作系统的用户绑定，从工作笔记本拷到家用台式之后解不开。表现是模型供应商列表都在，但点哪个发请求都 401。处置方法是把 credentials 删掉，进 chayuan-desktop 重新填一遍模型钥匙。这个不便利是为了换电脑场景下密钥不被无门槛拷走。

models 目录里的内嵌权重可以拷过去，避免重新下载几个 G。但如果家用台式架构不同，比如笔记本是 x86_64 笔记本，台式是 ARM 主机，ONNX 模型文件可以通用，但其他平台特定的二进制要换。

vectors 目录直接拷可以。SQLite 文件是平台无关的，但如果工作笔记本是大端字节序某种古怪平台，台式机是小端，会有问题。普通 x86 之间互拷没事。

data 目录里的 SQLite 文件直接拷可以，对话历史和知识库元数据全部跟着走。注意 SQLite 必须确保来源端 chayuan-desktop 已经关闭，否则文件可能处于不一致状态，目标端打开会报数据库损坏。

uploads 目录里是用户拖上来的原始文件副本。如果你建知识库时勾了 保留原文件，这里要拷过去，引用气泡的原文回链才能继续工作。

logs 和 cache 目录可以不拷，目标端会自己生成。

迁移完成之后启动 chayuan-desktop。打开主界面，左侧看历史对话是否还在；进设置看模型供应商列表是否在（钥匙需要重填）；进知识库列表看 KB 是否在；新建对话挑一个 KB 问问题，看引用气泡是否能展开原文。

跨电脑场景里几个常见问题。第一，模型钥匙没法迁，必须新电脑重填一遍。第二，本地推理服务的 base URL 要在新电脑上重新配置，因为 Ollama 装的位置变了。第三，folder-sync 知识库的源路径如果工作笔记本是 D:\Documents 而台式是 E:\Files，路径会失效，需要进 KB 设置里改成新路径，再触发一次完整重扫。

WPS AI 插件 chayuan-wps 单独装在新电脑的 WPS 上，配置 服务器地址 指向 chayuan-desktop 那台，认证模式 选 none。两边数据是同一份，加载项不需要再迁移什么。

跨电脑迁移的核心其实就一句话：CHAYUAN_ROOT 整个目录就是你 察元AI 在这台机器上的全部记忆。把它搬过去，按上面几个细节做对，新电脑就能接着用工作笔记本上的所有积累。免费开源的AI软件 的数据所有权回到了用户手里，迁移不靠云端账号同步。
