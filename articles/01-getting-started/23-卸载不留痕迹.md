# 卸载察元AI不留痕迹 用户目录里的数据怎么处理

软件用一阵子之后想换或者不用了，能不能干净卸载是衡量产品好坏的一个细节。商业软件常见的毛病是装的时候说装哪都行，卸的时候到处都是残留。chayuan-desktop 桌面单机版作为 免费开源的AI软件 在这件事上比较坦率，但仍然有几个角落需要你自己清。这一篇讲清楚怎么彻底卸载察元AI。

先列清楚装了之后会写到哪些位置。第一是安装目录，Windows 上是 Program Files 下的 chayuan-desktop，macOS 上是 Applications 下的 .app，Linux 上是 /usr/lib/chayuan-desktop。第二是 CHAYUAN_ROOT，这是你自己在 FirstRunSetup 选的位置，存所有数据。第三是配置目录，Tauri 主进程把自己的配置写在系统的 AppData 或 ~/.config 下，跟 CHAYUAN_ROOT 区分开。第四是少量注册表项（Windows）或 plist（macOS），主要是跟开机自启和文件关联有关。

第一步：关闭应用。任务管理器或 Activity Monitor 或 ps 命令确认 chayuan-desktop 和 chayuan-server 进程都没在跑。强制结束如果还有残留。

第二步：标准卸载。Windows 上控制面板 程序和功能 找到 chayuan-desktop 卸载。macOS 上把 /Applications/察元AI.app 拖进废纸篓。Linux 上 sudo apt-get remove chayuan-desktop（如果用 deb）或者 sudo rpm -e chayuan-desktop。这一步把安装目录清掉，但不动 CHAYUAN_ROOT。

第三步：清 CHAYUAN_ROOT。这一步是核心。如果你想保留对话历史和知识库以备将来再用，跳过这一步，备份 CHAYUAN_ROOT 整个目录。如果你确定不再用，直接删掉。注意备份要选离线介质，否则数据可能被同步软件传走。

第四步：清 Tauri 配置目录。Windows 上一般在 %APPDATA%\com.chayuan.desktop 或类似路径。macOS 上在 ~/Library/Application Support/com.chayuan.desktop。Linux 上在 ~/.config/chayuan-desktop。这个目录里存了 Tauri 主进程的窗口位置、上次打开时间、CHAYUAN_ROOT 的指向等信息，体积很小。删掉之后再装一次会重新走 FirstRunSetup。

第五步：清 webview 缓存。Tauri 的 webview 缓存会落在系统的另一个位置。Windows 上在 %LOCALAPPDATA%\com.chayuan.desktop\EBWebView 之类。这个目录可以直接删，下一次装包会自动重建。

第六步：清模型权重缓存。如果你装了本地 Ollama 等推理服务，对应的模型权重在 ~/.ollama 或者 vLLM 配置的目录下。这部分跟 chayuan-desktop 无关，按需自己处理。

第七步：清 WPS 加载项。如果你也装了 chayuan-wps WPS AI 插件，加载项的安装位置在 WPS 加载项目录下，需要在 WPS 设置里禁用并卸载。或者直接把对应 dll 从加载项目录删掉。

第八步：清快捷方式和图标。Windows 桌面上的 察元AI.lnk 通常会被卸载程序自动清掉，但偶尔残留。手动删掉。开始菜单的快捷方式同理。Linux 上 ~/.local/share/applications 下的 .desktop 文件检查一下。

第九步：清浏览器或终端环境变量。如果你之前用脚本设过 CHAYUAN_ROOT 环境变量到系统级，记得清掉。Windows 上 系统属性 高级 环境变量；Linux/macOS 上 ~/.bashrc ~/.zshrc 里搜一下 CHAYUAN_ROOT 删掉。

第十步：可选的彻底清理。如果你出于隐私或者合规要求需要彻底擦除数据，CHAYUAN_ROOT 的所在分区做安全擦除。Windows 上 cipher /w 命令，Linux 上 shred 命令。这种擦除对 SSD 不是百分百可靠，磁盘报废之后还要做物理销毁的话另说。

国产化支持下的几个变体。麒麟 UOS 上 apt remove 之后还要检查 /etc/systemd/user 下有没有残留 service 文件；龙芯发行包卸载后特定的目录可能残留几个二进制依赖，dpkg -L 查路径手动清掉。

整套卸载流程在十分钟内能走完。本地离线知识库 的优势之一就是数据真的在你手里，卸载之后没有云端历史拖着尾巴，只要本机清干净，所有跟察元AI 有关的痕迹就都消失。换电脑、换工作、把电脑给同事，这些场景下完整卸载都给你一个干净的状态。免费开源的AI软件 在这一点上比商业云服务清爽很多。
