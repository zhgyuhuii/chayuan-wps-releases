# 工具调用三层折叠展示 后端怎么把数据吐成那个样子

打开 chayuan-desktop 桌面单机版的对话窗口，让模型调用一次工具，比如 web search。回答区会出现一张折叠卡片：一行 summary、一段可展开的参数与输出、一个再展开的完整 JSON。这个三层结构不是前端瞎堆出来的，是后端按一份特定数据结构吐给前端的。这一篇讲后端怎么生成这份数据。

先看一次工具调用的数据流。用户发问，sidecar 把对话送给 LLM，LLM 回了一个 tool_calls 字段，里面是 web 工具的名字和参数。sidecar 根据这个调用真的执行 web 工具，拿到结果。然后把工具结果作为新一轮上下文喂回 LLM，让它生成最终答案。中间这个 工具调用 + 工具结果 的回合需要让用户看到，于是有了这个折叠卡片。

后端给前端推的数据结构。tool_call 事件携带几个字段。summary：一行字，描述工具调用的简短情况，比如 调用 web 搜索 chayuan-desktop。args：参数对象，结构化展示，比如 {query: "chayuan-desktop", limit: 5}。output：工具执行结果，可能是文本、JSON、表格等多种形态。raw：完整的原始数据，包括请求体、响应头、调用耗时等。status：状态，pending / running / success / error。

每个字段对应一层折叠。summary 是第一层，永远显示。args 和 output 是第二层，默认折叠，点开可见。raw 是第三层，再深一层折叠，开发者排查问题用。前端按这个结构渲染，用户按需展开。

summary 怎么生成。后端的工具 adapter 在执行完工具之后调一段 LLM（小模型，可以是同一个对话用的模型也可以是专门小模型）生成 summary。prompt 类似 给以下工具调用写一行不超过 30 字的中文摘要。Summary 是 LLM 生成的人话，不是机械堆字段。

args 的格式化。每个工具的参数 schema 在工具注册时声明，包括字段名、类型、描述。前端按 schema 渲染参数表格，每个字段一行，类型显示在右边。这种结构化显示比 直接 JSON 字符串 友好。

output 的格式化。工具返回值有几种形态。文本就直接渲染。JSON 渲染成可折叠的树形。表格用 markdown 表格渲染。图像直接显示缩略图，点开看原图。文件返回链接给用户下载。这种多形态渲染让不同工具的输出都能直观展示。

raw 字段的生成。包括完整的请求 URL、headers、body、响应 status code、headers、body、调用开始时间、结束时间、网络耗时。这些信息对开发者排查问题极有用。普通用户看不懂可以一直关着。

错误状态的处理。工具调用失败时 status=error，output 里携带错误信息。前端渲染一个红色边框的卡片，summary 改成 工具调用失败，args 仍然展示，output 显示错误信息和 traceback。raw 里有完整诊断。

并发工具调用。一个回合里 LLM 可能同时要调多个工具。每个工具是独立的 tool_call，并行执行。前端展示成多张卡片堆叠，每张独立折叠状态。完成顺序按各自完成时间排序。

工具调用确认。某些高风险工具默认要求用户确认才执行，比如 发邮件、调外部 API 改数据。这种工具的卡片在 args 显示后弹一个 确认 / 取消 按钮，用户点确认才真的执行。这个机制在工具注册时通过 require_confirmation 字段声明。

工具调用与 RAG 的协作。某些场景下工具调用的结果会作为 RAG 检索的输入。比如 web 工具拿回搜索结果之后，结果文本进 retrieval 走一遍重排再喂给 LLM。这种链式调用在折叠卡片里展示成 多次工具调用 + 一次 RAG 检索 的多卡片列表。

后端的工具调用日志。每次调用的 raw 数据除了推给前端展示，也会落到 CHAYUAN_ROOT/logs/tools 目录下，按调用时间归档。这是审计和故障回放的基础。免费开源的AI软件 在工具透明度上的要求是：所有调用都有迹可循，开发者能复现，用户能审计。

性能影响。生成 summary 要调一次小模型，多花几百毫秒。args/output/raw 的字段填充几乎不耗时。整体上每个工具调用比 不显示折叠卡片 多 0.3-0.5 秒延迟，是合理代价。

WPS AI 插件 chayuan-wps 共用同一份工具调用展示逻辑。在 WPS 文字里发起的对话调工具时，加载项里的折叠卡片跟桌面客户端一致。Vue 3 渲染层不同，但底层数据结构同源。

三层折叠这种 UI 设计在通用桌面 AI 客户端里不常见。Cherry Studio、Chatbox 之类的产品大多只显示一行 调用了 X 工具 就完事，不展示参数也不展示输出。chayuan-desktop 在这一点上更接近 OpenAI Console、Anthropic Workbench 的开发者体验，把 AI 行为做透明。
