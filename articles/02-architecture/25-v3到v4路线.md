# 路线图 chayuan-desktop从v3到v4架构会怎么演化

chayuan-desktop 桌面单机版当前在 v3.0 这一代。从架构角度看，v3 主要解决 把企业级后端塞进单机包 这件事，让本地离线知识库 加 全模型支持 加 国产化支持 三件事在一台电脑里能稳定跑。下一代 v4 在路上，这一篇梳理一下未来可能的演化方向。

先看 v3 这一代解决了什么。Tauri 2 + React 19 + Python sidecar 三层架构稳定下来；五类知识源（doc、structured、vector、office、web）的统一接口落地；ku_id 与 KnowledgeRef 成为合同主字段；retrieval/query 模块按 refs/authz/router/orchestrator 分清职责；模型网关接了 18+ 家厂商；MCP 协议双角色完整；模型对抗 arena 上线；与 chayuan-wps WPS AI 插件 v3.0 完成深度集成。

v3 还没完全做好的几件事。一是多模态本地推理。当前多模态主要走厂商 API，本地化程度不如对话和嵌入。Piper TTS 和 FunASR ASR 是 v3 末期才完整集成的，本地 T2I 和 T2V 仍以外部为主。二是离线模型对抗。模型对抗的常见用法是云端模型互比，本地模型纳入对抗的工程化还需要打磨。三是知识库的双向写入。当前 KB 主要是单向（用户上传，AI 检索），未来 AI 主动写入 KB（agent memory）需要新接口。

v4 路线方向一：多模态本地化。预期把更多多模态能力塞进单机包。本地 T2I（Stable Diffusion 量化版）作为可选下载模块，跟 bge-m3 一样在 FirstRunSetup 时让用户决定要不要装。本地视频帧分析、本地 OCR 增强、本地 ASR 实时流式都在演进中。这一步让 全模型支持 不只是覆盖厂商，本地能力也要对齐。

v4 路线方向二：agent memory。Agent 是当前 AI 工程的核心方向，agent 能持续学习、长期记忆、跨对话保留状态。chayuan-desktop 的 agent memory 设计预期把 KB 扩展为可写入的，agent 在对话过程中可以把重要信息写到一个特殊 KB 类型 mem:* 里，下一次对话能查到。这件事要解决记忆的精度、隐私边界、跨会话一致性。

v4 路线方向三：MCP 生态接入。当前 MCP 协议在 chayuan-desktop 里已经实现客户端和服务端，但生态对接还在早期。v4 预期：把 chayuan-desktop 自身作为 MCP server 暴露给 Claude Desktop 等客户端使用；在自带工具市场里集成更多 MCP 第三方工具；让 MCP 工具的安装、升级、卸载像浏览器扩展一样简单。

v4 路线方向四：自动选模型。当前用户在对话框里手动选模型，模型对抗 arena 用来辅助选型。v4 预期：根据问题类型、上下文长度、预算偏好自动选最合适的模型，让 全模型支持 从 用户挑 进化到 系统帮你挑。这件事需要建立模型能力画像和场景画像两套数据。

v4 路线方向五：folder-sync 智能化。当前 folder-sync 是定时扫描文件夹建库。v4 预期：增加 watch 模式实时响应文件变化、加上文件级别的智能分类（按内容自动分到不同 KB）、加上跨 KB 关联推断（同一份资料的不同版本自动归类）。这些让 本地离线知识库 更接近 智能资料管理。

v4 路线方向六：跨机协同。chayuan-desktop 是单机版，但用户经常在家用台式和工作笔记本之间切换。v4 预期：支持多台电脑的 KB 同步、对话历史同步、模型钥匙同步，且仍保持本地优先（同步通过用户掌控的私有云或局域网，不依赖厂商云）。这件事要把单机版的 数据所有权 扩展到 多机所有权。

v4 路线方向七：可观测性增强。当前 chayuan-desktop 有日志和 Langfuse 可选接入，但单机用户的可观测性偏弱。v4 预期：内置一个 dashboard 展示当前的资源使用、对话延迟、限速触发、错误率，让用户对系统状态有掌控感。

v4 路线方向八：国产化支持深化。麒麟、UOS、openKylin 当前覆盖较好，但飞腾、鲲鹏、龙芯架构上的性能优化还有空间。v4 预期：对国产 CPU 做专门 ONNX kernel 优化、对国产 GPU（昇腾、寒武纪）做接入支持、对国产数据库的 text2sql 进一步打磨。

v4 路线方向九：信创生态对接。预期跟更多国产软硬件厂商做认证适配，让 chayuan-desktop 进入更多政企采购清单。这件事是商业层面的工作，但工程上要做的是各种适配认证测试。

v4 不会动的几件事。Tauri 2 不打算换 Electron。React 19 不打算换其他框架。Python sidecar 仍然是后端形态。SQLite + sqlite-vec 仍然是默认嵌入式存储。AGPL-3.0 许可不变。这些是 chayuan-desktop 的核心定位，不会因为追新而动摇。

WPS AI 插件 chayuan-wps 跟着 chayuan-desktop 演化，重点放在 WPS 内的工具调用、多模态、模型对抗的入口集成。v4 时代两个产品的协同会更深入。

路线图本质是一份让团队和用户对齐预期的文档。免费开源的AI软件 的好处之一是路线图可见，用户能预判哪些场景什么时候有支持，避免错配期望。
