# 架构图怎么画才看得懂 给非工程师同事的通俗讲解

很多产品同事、销售同事、客户希望听人讲一遍 chayuan-desktop 桌面单机版到底是怎么搭的，但又不想被 sidecar、orchestrator、adapter 这堆词淹没。这一篇用通俗的方式讲一遍架构图，让没有工程背景的人也能听懂大概。

先讲产品定位。chayuan-desktop 是一款 装到电脑里就能用 的 AI 助手。跟豆包、Cherry Studio、ChatGPT 桌面这些客户端不同的地方在于：它把 AI 后端的所有重活都打包到了一台电脑里，不需要联网也能跑大部分功能。免费开源的AI软件 + 本地离线知识库 + 全模型支持 这三件事是它的标签。

从用户感知讲起。你双击桌面图标，看到一个像 ChatGPT 桌面那样的窗口。左边是历史对话列表，中间是对话框，右上是设置入口。装好之后第一次会让你选一个数据目录，叫 CHAYUAN_ROOT，所有数据都落在这里。这一切跟一般客户端没差。

差别从一打开就开始。你不需要登录账号，因为它是单机版，没有云端服务器要登。你看到模型供应商列表，里面有 OpenAI、Anthropic、文心、通义、智谱、豆包、DeepSeek 等十几家厂商。你填一个钥匙就能用对应厂商，所有钥匙加密存在你电脑里。

更不一样的是 知识库。你可以拖一份 PDF 进对话窗口，它会自动解析、切分、入库，几秒之后你问问题，AI 回答下面会有引用气泡，每个气泡能展开成原文段落。这就是 察元智库 的体验。

回答能引用原文这件事，背后的机制是这样：你拖进来的文件被切成若干小段，每一段被算一个 数学坐标（向量），存到本地的一个数据库（sqlite-vec）。你问问题时，问题也被算一个向量，去数据库里找跟它 坐标接近 的小段，把找到的喂给 AI 模型一起生成答案。这个流程叫 RAG。所有计算都在你电脑里，不发云端。

往下一层看技术结构。chayuan-desktop 像一个套娃。最外面是一个原生窗口，技术叫 Tauri 2。Tauri 是一个把 Web 应用包装成桌面应用的框架，类似 Electron 但更轻。Tauri 主进程负责窗口管理、文件对话框、系统托盘。

第二层是前端 UI，用 React 19 写。React 是一个流行的 Web 框架，跟微信小程序的写法有点像。这一层负责所有你看到的界面。

第三层是后端，叫 sidecar。这是一个用 Python 写的程序，被 PyInstaller 打包成一个独立的可执行文件塞进了 Tauri 安装包里。Tauri 启动时把这个 sidecar 当一个子进程拉起来，让它监听 127.0.0.1:62581 这个本地端口。前端 webview 通过这个端口跟 sidecar 讲话。

第四层是数据存储。sidecar 用 SQLite（一种嵌入式数据库）存对话历史、知识库元数据、用户配置；用 sqlite-vec（SQLite 的扩展）存向量数据。所有数据是文件，落在 CHAYUAN_ROOT 目录里。

为什么搞这么多层。第一层 Tauri 是为了跨平台原生窗口；第二层 React 是为了写 UI 顺手；第三层 Python 是为了用 AI 生态成熟的 Python 库；第四层 SQLite 是为了不依赖外部数据库服务。这四层合起来是 桌面单机版 这件事的具体实现。

跟 chayuan-wps WPS AI 插件 的关系。chayuan-wps 是另一个产品，它是 WPS Office 文字软件的加载项，跑在 WPS 内部。它本身不带 AI 能力，所有 AI 调用都通过 HTTP 调 chayuan-desktop 后端。所以你装了 chayuan-desktop 加 chayuan-wps 之后，在 WPS 文字里写报告时可以直接用同一份知识库、同一份模型钥匙、同一份对话历史。

跟豆包 Cherry Studio 这些产品对比的核心差。豆包是字节的产品，对话发到字节云端，数据在云上。Cherry Studio 是一个开源的多供应商客户端，对话还是发到各家厂商的云端，本地只存对话历史。chayuan-desktop 的核心差别是 把后端塞进了本地：知识库索引、文档解析、嵌入计算、向量检索、SQL 生成等等都在你电脑里完成，模型推理可以走云端厂商也可以走本地 Ollama。

数据落在哪。所有对话历史、知识库索引、上传的文件都在 CHAYUAN_ROOT 里。你随时可以备份这个目录、复制到另一台电脑、卸载之后清掉。免费开源的AI软件 + 本地离线知识库 这件事在数据可见性上做得很彻底。

未来怎么演化。chayuan-desktop 现在在 v3.0 这一代，主要是核心能力的稳定。未来 v4 路线图里有：多模态本地推理增强、企业级 governance 模块、MCP 协议生态对接、模型对抗自动选模型。这些都在保持单机版核心理念的前提下扩展。

讲完这套，你大致能跟非工程师讲清楚 chayuan-desktop 是什么、跟其他产品差在哪、值不值得装。技术细节留给工程师们慢慢看其他文。
