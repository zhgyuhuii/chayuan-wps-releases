# 工具与多模态的结合 图像工具的统一抽象

chayuan-desktop 桌面单机版的工具支持多模态。图像作为输入或输出有统一抽象。这一篇讲。

## 多模态工具的场景

场景一：图像理解。用户传一张图问 这图里说了什么。LLM 调 image_describe 工具。

场景二：图像生成。用户问 帮我画一只猫。LLM 调 image_generate 工具（DALL-E、Stable Diffusion）。

场景三：图表渲染。用户让分析数据。LLM 调 chart_render 生成图表（柱状、折线、饼图）。

场景四：截图操作。RPA 工具截图 + 图像理解。

## 输入图像的统一表示

不同来源的图像。

用户拖拽到聊天框。

引用 KB 里的 OCR 原图。

WPS 文档里的插图（chayuan-wps 上传）。

工具调用返回的图像（image_generate 输出）。

chayuan-desktop 内部统一表示。

```
{
  "type": "image",
  "url": "file:///path/to/img.jpg" or "data:image/jpeg;base64,...",
  "alt": "图像描述",
  "metadata": {"width": 1024, "height": 768}
}
```

## 工具传递图像

工具描述中支持图像参数。

```yaml
- name: image_describe
  parameters:
    - name: image
      type: image
      description: 要描述的图像
```

LLM 调用时把图像作为参数传给工具。chayuan-desktop 的网关把内部表示转成工具能接受的格式。

## 工具返回图像

工具能返回图像。

```python
def chart_render(data):
    img_path = generate_chart(data)
    return {"type": "image", "url": f"file://{img_path}"}
```

chayuan-desktop 把图像渲染到聊天界面。LLM 在后续回答里能引用 此图。

## 跟视觉 LLM 的协作

某些工具调用结果是图像。后续 LLM 可能要看这张图。

LLM 是视觉 LLM（GPT-4V、Qwen-VL 等）。

chayuan-desktop 把工具返回的图像作为下一轮 LLM 输入的图像消息。

```
对话历史：
  user: 帮我分析销售数据
  assistant: [tool_calls: chart_render]
  tool: [图像]
  user: [LLM 收到图像，分析]
  assistant: 这张图显示了 Q1-Q4 销售上升趋势...
```

## 图像处理工具

chayuan-desktop 内置基础图像处理工具。

image_resize。改尺寸。

image_crop。裁剪。

image_rotate。旋转。

image_compress。压缩。

调用方式跟其他工具一致。

## 图像识别工具

OCR（前面文章）。

物体识别（如果需要）。chayuan-desktop 集成 YOLO 或类似。

人脸识别（隐私敏感，默认不内置）。

## 图像生成工具

image_generate。基于 prompt 生成图像。

后端可选。

DALL-E 3。OpenAI。

Stable Diffusion 本地（chayuan-desktop 集成 sd-webui 或 ComfyUI）。

豆包文生图。火山引擎。

通义万相。阿里。

文心一格。百度。

chayuan-desktop 的网关统一调用。LLM 不需要关心后端。

## 图像存储

工具产生的图像存到 ~/.chayuan/cache/images/。按时间组织。

聊天历史引用图像时用相对路径。导出时打包图像一起。

## 国产化场景

党政军场景对图像理解和生成都需要。chayuan-desktop 集成国产视觉模型（Qwen-VL、文心 ERNIE-VL、通义万相等）。完全国产化。

## chayuan-server 的对应

chayuan-server 部署在 GPU 服务器跑大视觉模型。chayuan-desktop 单机能跑小视觉模型 + 调用云。

## WPS 加载项

chayuan-wps 在 WPS 里能处理 WPS 文档里的图像。chayuan-wps 提取图像传给 chayuan-desktop 的视觉工具。员工能问 这张图表表达什么。

## 总结

工具与多模态的结合是 chayuan-desktop 在 AI 完整能力上的工程整合。免费开源的AI软件 让 工具调用 + 图像处理 + 视觉 LLM 在统一抽象下协作。chayuan-desktop 的统一表示 + 多后端 + 工具统一调用让多模态自然落地。
