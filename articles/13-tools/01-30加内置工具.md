# 免费开源的AI软件能给多少把锤子 30+内置工具一览

chayuan-desktop 桌面单机版自带 30+ 内置工具。这一篇做个目录式概览。

办公类。

text2sql。结构化数据 SQL 生成跟执行。

doc_search。文档库 RAG 检索。

KB_query。统一知识库查询入口。

translate。中英日韩翻译。

summarize。长文摘要。

extract_entities。实体识别（人名、地名、组织）。

网络类。

web_search。Web 搜索（按用户配的搜索引擎）。

web_fetch。抓取 URL 内容。

arxiv_search。arXiv 论文搜索。

github_search。GitHub 仓库 / 代码搜索。

办公协作类。

dingtalk。钉钉消息、文档操作（需鉴权）。

feishu。飞书消息、文档操作（需鉴权）。

email。发邮件（IMAP/SMTP 配好）。

calendar。日历事件查询创建。

notion。Notion 页面读写。

数据类。

execute_sql。在已配 SQL 数据库跑只读查询。

mongodb_query。MongoDB 查询。

es_search。ES 搜索。

milvus_search。Milvus 向量搜索。

文件类。

file_read。在 CHAYUAN_ROOT 范围内读文件。

file_write。在 CHAYUAN_ROOT 范围内写文件（受确认）。

file_search。在文件系统搜索文件。

ocr。给图片做 OCR。

媒体类。

image_generate。文生图（接 SD 或厂商）。

image_describe。看图说话。

audio_transcribe。语音转文本。

text_to_speech。文本转语音。

代码类。

python_eval。安全沙箱跑 Python 代码。

shell_run。运行 shell 命令（受白名单）。

http_request。调任意 HTTP API（按 OpenAPI 定义）。

时间日期类。

current_time。当前时间。

date_calc。日期计算。

每个工具有自己的元数据（name、description、inputSchema）。LLM 按需调用。

工具的扩展。前面文章讲过，新工具可以通过 OpenAPI 自动导入或手动写 BaseTool。MCP 工具也能扩展。

WPS AI 插件 chayuan-wps 共用所有内置工具。

30+ 内置工具是 chayuan-desktop 给 LLM 的能力扩展。免费开源的AI软件 让 LLM 不只是聊天而是真能干活，靠的是这些工具。chayuan-desktop 的工具集覆盖办公主流场景。
