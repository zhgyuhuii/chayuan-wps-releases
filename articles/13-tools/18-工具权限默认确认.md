# 工具的权限 哪些工具默认要确认

chayuan-desktop 桌面单机版的工具权限默认值合理。哪些工具默认 auto_allow，哪些要 require_confirm。这一篇讲。

## 默认 auto_allow 的工具

只读工具默认 auto_allow。

web_search。搜索网页。

web_fetch。读取 URL 内容。

kb_search。检索知识库。

list_files。列文件名。

list_repos / get_repo。GitHub 只读。

read_email。读邮件。

list_issues / list_prs。

总之 看而不动 的工具。

## 默认 require_confirm 的工具

写操作工具默认要确认。

send_email。发邮件。

create_issue。创建 issue。

post_message（slack/discord）。发消息。

write_file。写文件。

run_shell。执行 shell。

create_repo / delete_repo。

模糊：某些工具看名字像只读但有副作用（比如 fetch_and_log，名字像只读实际写日志到外部）。chayuan-desktop 的判断规则不止看名字，看工具描述里的 destructive 标识或 capability 声明。

## 默认 deny 的工具

极敏感的默认禁用。

delete_user_data（如果有）。

drop_database。

format_disk。

某些 RPA 工具能完全控制鼠标键盘的极敏感操作。

用户必须主动启用。

## 工具描述里的 capability 标识

工具开发者声明工具能力。

```yaml
- name: send_email
  description: 发送邮件
  capabilities:
    - destructive: true
    - external_communication: true
    - cost: low  # 不花钱
```

chayuan-desktop 按 capabilities 自动决定默认权限。destructive=true → require_confirm。

## 用户的覆盖

设置 - 工具 - 权限。每个工具能调整默认。

```
github_mcp.list_repos: auto_allow ✓
github_mcp.create_issue: require_confirm ✓
github_mcp.delete_repo: deny ✓
```

精细控制。

## 总是允许 / 仅此次

弹确认框时。

```
LLM 想调用 send_email
  收件人: legal@corp.com
  主题: 合同条款

[允许此次] [总是允许此工具] [拒绝]
```

总是允许 后该工具自动 auto_allow。

## 危险参数的提示

某些工具调用本身合法但参数危险。

delete_repo(name="production-database")。

chayuan-desktop 检测参数关键词（production、main、master、important 等）弹特别警告。

```
您正在删除 "production-database"，此操作不可恢复！
请输入 "确认删除" 以继续：
[___________]
```

二次确认。

## 时间窗口的权限

某些场景用户允许工具在某段时间内自动调用。

```
允许 send_email 在接下来 1 小时内自动调用 5 次。
```

避免每次都要确认。但不无限期。

## 自动学习

chayuan-desktop 学习用户的确认习惯。

某用户对 read_email 一直拒绝。chayuan-desktop 提示 您是否要 deny read_email？让用户考虑改默认。

某用户对 list_repos 一直 总是允许。chayuan-desktop 不提示。

## 国产化场景

党政军场景对工具权限严格。chayuan-desktop 默认严，让管理员能进一步收紧。

某些等保场景所有工具调用都需要审计。chayuan-desktop 即使 auto_allow 也记审计日志。

## chayuan-server 的对应

chayuan-server 多用户场景下权限矩阵更精细（按角色 / 工具）。chayuan-desktop 单机简化。

## WPS 加载项

chayuan-wps 在 WPS 里发起的工具调用走相同权限规则。WPS 用户在 WPS 内得到确认弹窗。

## 总结

工具的权限默认值是 chayuan-desktop 在用户体验和安全平衡上的工程设计。免费开源的AI软件 让 只读自动 + 写操作确认 是合理默认。chayuan-desktop 的 capabilities 声明 + 用户覆盖 + 危险参数检测让权限管理 既不烦又安全。
