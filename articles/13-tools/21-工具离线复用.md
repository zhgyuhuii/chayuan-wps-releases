# 工具的离线复用 内网下也能调

chayuan-desktop 桌面单机版的工具在内网离线环境仍然能用。这一篇讲。

## 离线场景

党政军内网。

边远地区电脑。

出差时弱网。

测试或灾备环境。

每种都需要工具能用。

## 哪些工具能离线

完全离线工具。

kb_search。本地知识库检索。

ollama 本地推理。

filesystem。本地文件操作。

custom Python / Shell（白名单内）。

部分离线工具。

web_search 走本地缓存（如果之前查过）。

email_mcp 离线发到草稿箱（联网后发出）。

完全联网工具。

github_mcp。需要 api.github.com。

slack_mcp。需要 slack.com。

外部云 API。

## chayuan-desktop 的离线模式

设置 - 网络 - 离线模式 开关。

启用后。

所有 联网工具 显示禁用图标。

LLM 看到工具列表时联网工具被过滤掉。

避免 LLM 调不可用工具浪费时间。

## 缓存

某些联网工具的结果能缓存。短时间内同样查询走缓存。

```
web_fetch("https://example.com") 
  第一次：1.2 秒（联网）
  第二次（5 分钟内）：5ms（缓存）
```

缓存默认 5 分钟。设置里可调。

离线时缓存仍能查（前提是之前查过）。

## 内网替代品

某些公网工具有内网对应。

公网 GitHub → 内网 GitLab。

公网 Slack → 内网钉钉 / 飞书。

公网 OpenAI → 内网 vLLM 部署。

chayuan-desktop 的工具市场对每个工具标注 是否有内网版。员工能选合适的。

## 工具的混合

某些场景工具部分联网部分离线。

```
ai_search:
  - 内网 KB 检索（离线）
  - 公网 web_search（联网，可禁用）
```

chayuan-desktop 的混合工具能根据网络状态动态启用部分能力。

## 本地代理工具

某些团队搭内网代理网关。访问公网工具走代理。

```
chayuan-desktop 配置：
  http_proxy: http://proxy.corp.com:8080
```

代理网关做合规审查（哪些请求允许、哪些禁止）。

chayuan-desktop 的工具调用经过代理。

## 离线包

完全断网场景。chayuan-desktop 的工具要预装。

离线安装包含。

chayuan-desktop 主程序。

常用工具的 npm / pip 包。

模型权重。

预先在外网下载 + U 盘带进内网。

## 自动检测网络

chayuan-desktop 启动时检测网络状态。

完全断网 → 自动启用离线模式。

弱网 → 提示用户 网络较差，建议启用离线模式。

强网 → 正常。

## 离线时的 LLM

某些 LLM 是云模型（OpenAI、Claude）。离线不可用。

chayuan-desktop fallback 到本地 Ollama。

如果用户没装本地模型。提示 当前无可用模型，请配置本地推理或恢复网络。

## 国产化场景

党政军内网部署是常态。chayuan-desktop 的离线模式 + 内网替代 + 离线包是核心能力。

某些党政军场景一年都不联外网。chayuan-desktop 的全套能力都本地化。

## chayuan-server 的对应

chayuan-server 多用户场景下集中代理 + 工具集中部署。chayuan-desktop 单机本地。

## WPS 加载项

chayuan-wps 在 WPS 里也跟 chayuan-desktop 一起进入离线模式。员工能感知。

## 总结

工具的离线复用是 chayuan-desktop 在网络受限场景的工程能力。免费开源的AI软件 让 内网 / 弱网 / 完全断网 用户都能用。chayuan-desktop 的离线模式 + 缓存 + 内网替代 + 离线包让 网络不可靠 也能高效使用工具。
