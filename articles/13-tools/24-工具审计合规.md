# 工具的审计与合规 留痕的最小集

chayuan-desktop 桌面单机版的工具审计有最小留痕集。这一篇讲。

## 留痕的最小字段

每次工具调用至少记录。

时间戳。

调用方（chayuan-wps / 桌面 / 第三方应用）。

工具名。

输入摘要（脱敏）。

输出摘要。

执行结果（成功 / 失败）。

耗时。

用户身份（多身份场景）。

## 不必记录的

避免记敏感数据。

完整密码。

完整 API token。

完整用户 PII（除非合规要求）。

避免记重复数据。

LLM 已记的对话内容（已在聊天日志里）。

## 等保 2.0 三级要求

要求一：审计覆盖关键操作。chayuan-desktop 默认覆盖。

要求二：日志保留 6 个月。chayuan-desktop 默认 30 天，能调到 1 年。

要求三：审计日志不可篡改。chayuan-desktop 用哈希链。

要求四：异常告警。chayuan-desktop 内置规则。

## 个人信息保护法

要求一：明确告知用户哪些信息被处理。chayuan-desktop 隐私声明明确。

要求二：用户能查看自己的审计日志。chayuan-desktop 设置里能查。

要求三：用户能要求删除（在合规允许范围内）。chayuan-desktop 支持删除请求（带元审计）。

## 生成式 AI 备案

某些场景 AI 服务要备案。chayuan-desktop 在某些发行版（中国大陆）出厂带备案号。审计配合。

## 审计文件的存储

存到本地 SQLite。

```
~/.chayuan/audit/
  audit.db
  rotated/
    audit-2026-04.db.gz  # 按月归档
```

每月归档压缩。

## 审计的查询

设置 - 审计 - 查询。

按时间、工具、用户、状态过滤。

```
查询近 7 天 send_email 的失败调用：
  [2026-05-08] send_email failed (rate_limited)
  [2026-05-09] send_email failed (network_error)
  ...
```

## 审计的导出

CSV、JSON、Syslog。

```
[导出审计 2026-05]
保存为 audit-2026-05.csv
```

某些政企集成到企业 SIEM。chayuan-desktop 配 Syslog forward。

## 审计的离线交付

某些场景需要导出给监管或审计员。chayuan-desktop 支持。

```
[生成审计交付包]
时间范围：2026-01-01 至 2026-05-10
内容：审计日志 + 配置快照 + 工具版本清单
格式：zip 含数字签名
```

签名让交付方验证完整性。

## 审计成本

每条审计记录约 1KB。日活跃用户每天约 1000 条工具调用。每月日志约 30 MB。

存储成本可控。

## 审计的隐私边界

审计本身记录用户行为。审计日志泄露也是隐私问题。

chayuan-desktop 的审计存储加密（SQLCipher）。访问审计需要主密码。

## 国产化场景

党政军等保合规靠审计。chayuan-desktop 的审计实现满足等保 2.0 三级要求。

某些行业（金融、医疗）有更严格审计要求。chayuan-desktop 配置可调到更严。

## chayuan-server 的对应

chayuan-server 多用户场景下审计集中。chayuan-desktop 单机本地。两者协议一致便于聚合。

## WPS 加载项

chayuan-wps 在 WPS 里调工具记录到 chayuan-desktop 审计。target_app=wps 字段区分。

## 总结

工具的审计与合规是 chayuan-desktop 在政企采购上的工程基础。免费开源的AI软件 让 合规留痕 不只是文档说说。chayuan-desktop 的最小留痕 + 哈希链 + 导出 + 加密让审计在工程上有据可查。
