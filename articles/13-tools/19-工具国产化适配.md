# 工具的国产化适配 国产服务的接入清单

chayuan-desktop 桌面单机版的工具国产化适配是核心卖点。这一篇盘点国产服务接入清单。

## 即时通讯类

钉钉。dingtalk-mcp。发送消息、查询群组、待办。

企业微信。wechat-work-mcp。同上。

飞书。feishu-mcp。同上 + 飞书文档操作。

## 协作办公类

腾讯文档。tencent-docs-mcp。读写文档、表格。

WPS 文档。chayuan-wps 加载项本身就是。

腾讯会议。tencent-meeting-mcp。预定、查询、纪要。

## 云服务类

阿里云。aliyun-mcp。OSS、ECS、RDS API。

腾讯云。tencent-cloud-mcp。COS、CVM、TDSQL。

华为云。huawei-cloud-mcp。OBS、ECS。

百度智能云。baidu-cloud-mcp。

## 业务系统类

金蝶 ERP。kingdee-mcp。

用友 ERP。yonyou-mcp。

某些自家 OA / ERP。chayuan-desktop 的 OpenAPI 一键导入功能能接（前面文章）。

## 大模型 API

百度文心。文心一言 API。chayuan-desktop 直接接入（不需要 mcp，走网关）。

阿里通义千问。同上。

智谱 ChatGLM。同上。

字节豆包。同上。

腾讯混元。同上。

## 搜索引擎

百度搜索。baidu-search-mcp。

搜狗搜索。sogou-search-mcp。

DuckDuckGo（国际）。同样能用。

chayuan-desktop 内置 web_search 默认走多个搜索引擎聚合。

## 国产数据库

达梦 DM。dm-sql-mcp。

人大金仓 KingbaseES。kingbase-mcp。

南大通用 GBase。gbase-mcp。

通过 chayuan-desktop 的 text2sql 模块支持。

## 政务类

政务服务网。gov-services-mcp（路线图）。查询事项、状态。

国家政务平台。同上。

## 接入清单的打包

chayuan-desktop 的 国产化工具包。一键安装常见国产工具。

```
chayuan-desktop 设置 - 工具 - 国产化套装
[一键安装]
  ✓ dingtalk-mcp
  ✓ wechat-work-mcp
  ✓ feishu-mcp
  ✓ aliyun-mcp
  ✓ tencent-cloud-mcp
  ✓ baidu-search-mcp
  ✓ dm-sql-mcp
  ...
```

省去员工逐个找工具的麻烦。

## 鉴权方式

国产服务鉴权方式各异。

钉钉 / 企微 / 飞书：OAuth 2.0。chayuan-desktop 内置 OAuth flow。

阿里云 / 腾讯云：自家签名算法（v3）。chayuan-desktop 实现。

国产数据库：传统用户名密码。

每个工具自己处理。chayuan-desktop 提供 SDK 简化。

## 国产工具的质量

某些国产工具开源生态活跃（钉钉、飞书有官方 mcp）。

某些工具只能社区第三方实现（质量参差）。

chayuan-desktop 的工具市场标注质量等级。官方 / 社区认证 / 实验性。用户按需选。

## 离线场景

某些政企内网完全断网。国产工具大多需要联网（API 调用）。chayuan-desktop 配置允许的域名白名单。

完全断网场景这些工具不可用。chayuan-desktop 提示用户 当前网络受限，部分工具不可用。

## chayuan-server 的对应

chayuan-server 多用户场景下国产工具集中部署。员工 chayuan-desktop 通过 chayuan-server 调用。chayuan-server 维护 OAuth 状态。

## WPS 加载项

chayuan-wps 在 WPS 里调国产工具。员工写报告时调钉钉发消息、调阿里云查 OSS 文件等。日常工作场景。

## 总结

工具的国产化适配是 chayuan-desktop 在国产生态融入上的工程能力。免费开源的AI软件 让 国产服务 跟国外工具同样在 AI 里能用。chayuan-desktop 的国产化套装 + 鉴权适配 + 工具市场让 党政军场景 一键武装。
