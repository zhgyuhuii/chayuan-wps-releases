# 加载项未来 工具调用 多模态 模型对抗的入口

chayuan-wps 加载项的未来路线。这一篇讲未来。

## 当前能力

知识库检索（RAG）。

引用气泡 + 回链。

写回 WPS（插入 / 替换 / 批注）。

私库支持。

结构化数据查询。

## 短期路线（v3.x，2026 H2）

工具调用集成。

加载项侧栏集成 chayuan-desktop 的 MCP 工具。

```
工具调用：
  发邮件给法务 → email_mcp
  查 GitHub → github_mcp
  查 Jira → jira_mcp
```

WPS 内调用。员工不必切应用。

视觉对话。

加载项支持图像输入。员工把 WPS 文档截图、外部图片拖入加载项。

```
[拖入图]
[图缩略图]
请问：[输入框]
```

视觉 LLM 分析。

模型对抗入口。

加载项里的 [实验] 标签。让用户在 WPS 内做模型对抗。比如同问题让 GPT-4o vs Qwen 对比。

```
[Arena 模式]
Question: ...
[Run on multiple models]
```

## 中期路线（v4.x，2027）

完整 Agent 能力。

加载项里的对话不只是问答。是完整 Agent。

```
用户: 帮我审查这份合同并发法务批准
AI: 
  step 1: 审查合同 (RAG + LLM)
  step 2: 找出问题 (LLM)
  step 3: 调 email 工具发法务
  step 4: 等待法务回复
  step 5: 通知用户
```

多步自动执行。

实时协作。

多个员工在同一 WPS 文档协作。chayuan-wps 加载项跨用户协同。

```
张三：我加了一段
李四：AI 帮我们对比一下张三加的和模板的差异
AI: ...
```

WPS Office 已经支持多人协作。chayuan-wps 跟它整合。

桌面端深度同步。

加载项跟 chayuan-desktop 桌面端实时同步状态。

桌面端开会话 → 立即在 WPS 里看到。

WPS 里发起的 → 桌面端实时显示。

无需手动刷新。

## 长期路线（v5+，2028+）

完全融合的办公 AI。

WPS + chayuan-wps 不分。AI 是 WPS 的内置能力（金山如果合作的话）。

或 chayuan-wps 演化成 AI 优先的 WPS 替代。

具身智能。

某些场景（虚拟办公室）chayuan-wps 加载项扩展到 VR / AR。

跨应用集成。

不只是 WPS。Excel、PowerPoint、Word（金山版）等也有类似 chayuan-wps 加载项。

完全的办公 AI 生态。

## 不变的核心

无论怎么演化。chayuan-wps 的核心。

WPS 优先（不脱离 WPS 工作流）。

数据本地（KB、对话、文件本地）。

国产生态（国产 LLM、嵌入、OCR）。

开源（AGPL-3.0）。

## 跟金山的合作

chayuan-wps 是 WPS 的第三方加载项。

如果金山官方接纳。chayuan-wps 可能成为 WPS 的官方推荐 AI 加载项。或被 WPS 内置（合作模式）。

某些场景 chayuan-wps 跟金山自家 AI（WPS AI）协同。

## 国产化场景

党政军场景的 AI + 办公融合是趋势。chayuan-wps 的路线契合国家信创战略。

未来某天 用 WPS 写公文时 AI 是常态 而不是 装个加载项才能用。chayuan-wps 在这个进化中扮演关键角色。

## chayuan-server 的对应

chayuan-server 跟 chayuan-wps 协同演进。chayuan-wps 客户端的能力扩展跟 chayuan-server 服务端能力扩展同步。

## chayuan-desktop 的协同

chayuan-desktop 后端能力扩展直接惠及 chayuan-wps。共享所有底层能力（LLM、KB、工具、多模态）。chayuan-wps 是这些能力在 WPS 内的暴露。

## 总结

加载项未来路线是 chayuan-wps 在长期发展上的工程战略。免费开源的AI软件 让 WPS + AI 整合 越来越深。chayuan-wps 的工具 / 多模态 / 对抗 / Agent / 协作让办公场景的 AI 体验持续进化。WPS 是中国办公主力。chayuan-wps 是它的 AI 引擎。
