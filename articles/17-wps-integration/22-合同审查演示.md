# 加载项与 RAG 的最佳实践 一份合同审查的演示

chayuan-wps 加载项 + RAG 在合同审查场景的最佳实践演示。这一篇是实战。

## 场景

法务张三收到一份新供应商合同。需要快速审查。

KB 准备好。

doc:legal_templates。公司标准合同模板（30 份）。

doc:past_contracts。过去 3 年的合同（500 份）。

office:legal:flagged_clauses。法务标记的危险条款集（100 条）。

## 第一步 加载合同到 WPS

WPS 打开新供应商合同 NewSupplier_Contract.docx。

## 第二步 调起 chayuan-wps 加载项

侧栏点开。检测到当前是合同。

加载项自动推荐 KB。

```
智能推荐：
  ✓ doc:legal_templates
  ✓ doc:past_contracts
  ✓ office:legal:flagged_clauses
[确定]
```

## 第三步 总体审查

张三在加载项问。

```
帮我快速审查这份合同。重点关注与标准模板的差异。
```

加载项调 chayuan-desktop。

chayuan-desktop。

第一。把当前 WPS 文档全文 RAG 化（临时 KB）。

第二。检索 doc:legal_templates 找标准合同。

第三。LLM 对比当前合同 vs 标准合同，列出差异。

第四。检索 office:legal:flagged_clauses 看有没有匹配的危险条款。

第五。综合返回结果。

## 输出展示

```
合同审查报告：

主要差异（与标准模板对比）：
1. 第 3 条：付款方式从 30 天改为 60 天 [⚠ 不利]
2. 第 5 条：违约金条款宽松 [⚠ 不利]
3. 第 8 条：免责范围扩大 [⚠ 风险高]

危险条款匹配：
- 第 8 条 "免除一切因不可抗力外的责任"
  → 匹配 office:legal:flagged_clauses 中的 模糊免责 危险条款
  → 历史案例：2024-Q3 类似条款引发诉讼

引用：
[1] doc:legal_templates 标准合同 v3
[2] office:legal:flagged_clauses 危险条款 #45
[3] doc:past_contracts 案例 case_2024_03
```

完整审查。

## 第四步 详细看某条款

张三看了报告。想详细了解第 8 条。

```
详细解释第 8 条的风险，并给出修改建议。
```

加载项调 chayuan-desktop 深入分析。返回。

```
第 8 条：[原文]
"...除不可抗力外，本方不承担任何责任..."

风险：
- 表述模糊。"任何责任" 范围过宽。
- 排除了过失责任。法律上有效但对客户不利。
- 类似条款在 case_2024_03 中被法院判定为霸王条款。

建议修改：
"除因本方故意或重大过失外，对乙方因合同履行受到的间接损失不承担责任。"

[ 引用 1: 法律条款数据库 ]
[ 引用 2: 历史案例 case_2024_03 ]
[ 引用 3: 公司标准免责条款模板 ]
```

精准建议。

## 第五步 写回 WPS

张三接受 AI 建议。

加载项 写回 按钮。

```
插入选项：
  ✓ 替换当前选中（第 8 条）
  ✓ 加批注解释修改原因
  ✓ 链接批注指向 case_2024_03
[确认]
```

WPS 文档自动。

第 8 条被替换。

旁边出现批注 已基于 case_2024_03 修改免责范围。

批注链接指向案例库。

未来读合同的人能看到修改原因。

## 第六步 生成审查报告

张三让 AI 生成完整审查报告插入文档末尾。

```
帮我把审查结果整理成正式审查报告，放在文档末尾。
```

加载项生成。

```
─────────────────
合同审查报告
审查人：法务-张三 + chayuan-desktop AI
审查时间：2026-05-10
审查依据：
  - 公司标准合同 v3
  - 公司危险条款库
  - 法律案例数据库

主要差异：[列表]
建议修改：[列表]
风险等级：中（可签但需关注）
─────────────────
```

报告插入文档。

## 整体效率

审查耗时。

人工：4-8 小时。

AI 辅助：30 分钟（chayuan-wps + chayuan-desktop）。

效率提升 8-16 倍。质量更全（AI 不会漏对照）。

## 国产化场景

党政军和金融场景的合同审查是核心需求。chayuan-wps 的 RAG 在合同审查上的实战展示是采购卖点。

## chayuan-server 的对应

chayuan-server 模式下法务团队共享 KB（合同模板、案例库）。员工 chayuan-wps 走 chayuan-server。

## 总结

合同审查演示是 chayuan-wps + RAG 的实战最佳实践。免费开源的AI软件 让 法务工作 在 WPS 内 + AI 辅助 + 多 KB 协同下高效。chayuan-wps 的智能推荐 + 多步审查 + 写回让审查工作流自然顺畅。
