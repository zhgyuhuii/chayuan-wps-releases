# 加载项的全模型支持 不需要重新填一遍密钥

chayuan-wps 加载项不重复填 API Key，全模型支持都通过 chayuan-desktop 后端继承。这一篇讲。

## 不重复填的设计

某用户在 chayuan-desktop 配了 OpenAI、Claude、Qwen 等几十个 API Key。

加载项 chayuan-wps 安装到 WPS。

加载项不需要再填一遍 Key。

直接通过 chayuan-desktop 后端调用所有模型。

## 实现机制

chayuan-wps 走本地 chayuan-desktop 网关。

```
chayuan-wps → 127.0.0.1:62581/openai/v1/chat/completions
chayuan-desktop 后端用配置好的 Key 转发到实际厂商。
chayuan-wps 不需要 Key。
```

完全继承。

## 模型选择

chayuan-wps 加载项的模型选择器显示 chayuan-desktop 配的所有模型。

```
chat 模型: [▼]
  GPT-4o
  Claude 3.5 Sonnet
  Qwen-Plus
  DeepSeek-V2
  ollama:qwen2.5:7b
  ...
```

用户在 WPS 里能切换。

## 跟桌面端的同步

chayuan-desktop 加了新模型。chayuan-wps 自动看到。

chayuan-desktop 的默认模型变了。chayuan-wps 跟着变。

无需重新配置加载项。

## fallback 链共享

chayuan-desktop 的 fallback 链在 chayuan-wps 里同样生效。

chat 失败 → fallback 链 → 最终成功。chayuan-wps 用户感知就是 答案出来了。

## 路由共享

chayuan-desktop 的智能路由（前面文章讲）在 chayuan-wps 里同样工作。

```
chayuan-wps 用户问 帮我写代码
chayuan-desktop 路由 → 选 DeepSeek-Coder
chayuan-wps 看到回答（不感知后端切了模型）
```

## 隐私一致

chayuan-desktop 的隐私规则（私库不能上云、敏感内容确认等）在 chayuan-wps 里同样生效。

chayuan-wps 用户在 WPS 内问私库内容。如果走云模型 chayuan-desktop 弹用户确认（弹在 chayuan-wps 加载项里）。

## 配额共享

chayuan-desktop 的月度预算控制覆盖 chayuan-wps 的调用。

某用户月预算 ¥100。

桌面端用了 ¥30。

WPS 加载项用了 ¥50。

剩 ¥20。chayuan-desktop 知道这个总数。

避免 chayuan-wps 单独无限制烧钱。

## 审计共享

chayuan-wps 的调用记到 chayuan-desktop 的审计。

```
{
  "tool": "chat",
  "model": "gpt-4o",
  "called_from": "chayuan-wps",
  "wps_doc_path": "/path/to/contract.docx",
  ...
}
```

完整审计链。

## 多 chayuan-wps 实例

某用户同时开多个 WPS 文档。每个 WPS 文档都有 chayuan-wps 加载项。

所有加载项都连同一个 chayuan-desktop 后端。

不冲突。chayuan-desktop 的 session 区分。

## 国产化场景

党政军场景一台机器一个 chayuan-desktop。员工 WPS 加载项 自动用 chayuan-desktop 配的国产模型。

某些场景统一企业级 chayuan-server（chayuan-wps 连服务器）。员工不必各自配 API Key。

## chayuan-server 的对应

chayuan-server 模式下加载项连 chayuan-server。同样不重复填 Key。

## 总结

加载项的全模型支持不重复填 Key 是 chayuan-wps + chayuan-desktop 的工程便利。免费开源的AI软件 让 配置一次多端用。chayuan-wps 共享 chayuan-desktop 的完整模型配置 + fallback + 路由 + 配额 + 审计让加载项轻量但能力完整。
