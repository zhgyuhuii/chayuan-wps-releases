# 写回链路 插入 替换 批注 链接批注的实操

chayuan-wps 加载项支持把 AI 输出写回 WPS 文档。插入 / 替换 / 批注 / 链接批注。这一篇讲。

## 写回的几种方式

方式一：插入。在当前光标位置插入文字。

方式二：替换。替换当前选中的文字。

方式三：批注。给某段加一个批注（侧边的标记）。

方式四：链接批注。批注里挂一个 URL（点击跳转）。

每种用途不同。

## 插入

最常见。AI 生成内容直接添加到文档。

```js
const selection = WpsApplication.Selection;
selection.TypeText(content);
```

加载项调用。AI 生成完成后插入到光标位置。

适合：生成新段落、补充内容。

## 替换

用户选中某段不满意的文字让 AI 重写。AI 输出后替换。

```js
const selection = WpsApplication.Selection;
selection.Text = new_content;
```

适合：润色、重写、改写。

## 批注

加载项侧栏的回答能 转批注。

```js
const range = WpsApplication.Selection.Range;
const comment = range.Comments.Add(content);
```

侧边出现批注 气泡。读者能看到 AI 的注释。

适合：审阅意见、修改建议、解释。

## 链接批注

批注里加 URL。点击跳转。

```js
const comment = range.Comments.Add(text);
comment.Hyperlink = url;
```

适合：引用源文档、外部资源链接。

chayuan-wps 的引用气泡转链接批注：批注内容是引用文字，URL 指向原 KB chunk。

## 写回的格式保留

AI 输出的 Markdown 格式怎么处理。

加载项的策略。

转 WPS 格式。Markdown 的 **bold** 转 WPS 的粗体格式。# 标题 转 WPS 标题样式。

或纯文本。Markdown 符号去掉，纯文字插入。

用户选项。

```
插入选项：
[x] 保留格式（推荐）
[ ] 纯文本
```

## 表格的写回

AI 输出 Markdown 表格。加载项转 WPS 表格。

```js
const table = doc.Tables.Add(range, rows, cols);
// 填充每个单元格
table.Cell(1, 1).Range.Text = "...";
```

读者看到正常 WPS 表格。

## 图像的写回

AI 生成的图像（image_generate 工具的输出）能插入 WPS。

```js
const inlineShape = doc.InlineShapes.AddPicture(image_path);
```

图像内嵌到文档。

## 公式的写回

AI 输出 LaTeX 公式。加载项转 WPS 公式。

```js
// 用 OOXML 公式格式
range.OMaths.Add(latex_to_omath(latex));
```

WPS 渲染为公式。

## 撤销

写回操作可撤销。WPS 自身的 Ctrl+Z。

加载项不需要特别处理。WPS 自动维护撤销栈。

## 用户确认

写回前弹确认（如果设置开）。

```
即将插入：
[预览内容]
[插入] [取消] [让 AI 重写]
```

避免 AI 输出不合适直接污染文档。

让 AI 重写 让加载项再调一次 LLM 改进。

## 实战例子

员工写报告。

第一段写好了。

让 AI 写第二段。

加载项调 chayuan-desktop 生成。

预览。员工觉得不错。

点 插入。第二段加到光标位置。

继续写第三段。

完整工作流。

## 国产化场景

党政军写公文场景常用插入和批注。chayuan-wps 的写回让 AI 真正介入工作流。

## chayuan-server 的对应

chayuan-server 模式下写回链路一样（chayuan-wps 走 chayuan-server）。

## chayuan-desktop 的协同

chayuan-desktop 处理 LLM 调用。chayuan-wps 处理 WPS 操作。各司其职。

## 总结

写回链路的插入 / 替换 / 批注 / 链接批注是 chayuan-wps 在 WPS 工作流上的工程实操。免费开源的AI软件 让 AI 直接帮员工写文档而不是 看完手动复制。chayuan-wps 的多种写回方式让 AI 真正融入 WPS。
