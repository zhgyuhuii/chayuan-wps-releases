# 把桌面单机版当WPS的AI后端 同机直连127.0.0.1:62581

chayuan-wps 加载项默认连 chayuan-desktop 桌面单机版的 sidecar。最简配置是同机直连 127.0.0.1:62581。这一篇讲。

最简部署。

第一步：装 chayuan-desktop。FirstRunSetup 完成。sidecar 跑在 127.0.0.1:62581。

第二步：装 chayuan-wps 加载项。WPS Office 内 加载项 - 安装。

第三步：打开 WPS 文字。任务窗格出现 察元AI 选项卡。

第四步：在加载项设置里。服务器地址：http://127.0.0.1:62581。认证模式：none（chayuan-desktop 单机版默认关鉴权）。

第五步：发一句话测试。加载项调 sidecar 的 chat API，sidecar 调模型，回答流式回到加载项。

整套链路。WPS 文字 → chayuan-wps 加载项 → HTTP 调 127.0.0.1:62581 → chayuan-desktop sidecar → 模型 API（云端或本地 Ollama）。

为什么 127.0.0.1。本地 loopback 地址。意思是 加载项跟 sidecar 在同一台机器。绝对最简部署。

跨机器场景。如果用户希望 chayuan-desktop sidecar 跑在公司服务器，员工电脑只装 chayuan-wps 加载项。配置加载项的 服务器地址 = http://10.x.x.x:62581（内网 IP）。配置 chayuan-desktop sidecar 监听 0.0.0.0（不只 127.0.0.1）+ 打开鉴权。

加载项的请求格式。chayuan-wps 用 chayuan-desktop 自家 API（不是 OpenAI 兼容路由）。包括。

POST /api/v1/chat/completions。流式对话。

POST /api/v1/kb-query/search。KB 检索。

GET /api/v1/conversations/。对话历史。

GET /api/v1/kbs。KB 列表。

GET /api/v1/models。模型列表。

加载项跟桌面客户端共用同一组 API。差异在 UI 实现（Vue 3 vs React 19）。

性能。同机直连延迟极低。HTTP 调用 + sidecar 处理 1-2 秒（含流式开头）。整体体验跟桌面客户端一致。

故障处理。chayuan-desktop sidecar 挂了或 chayuan-desktop 没启动。chayuan-wps 加载项检测到连接失败，提示 后端服务未启动，请先启动桌面客户端。

WPS Office 升级。WPS Office 升级时加载项可能要重新启用。chayuan-wps 加载项支持 WPS 2024+ 版本。

国产化支持下的同机部署。麒麟 UOS 上 WPS Office Linux 版 + chayuan-wps 加载项 + chayuan-desktop 三件一起装。当前 WPS Linux 加载项支持仍在演进。

跟 chayuan-desktop 的版本兼容。chayuan-wps v3.0 跟 chayuan-desktop v3.0+ 兼容。chayuan-desktop 升级到 v4 时 chayuan-wps 也要升级（API 可能扩展）。

同机直连 127.0.0.1:62581 是 chayuan-desktop + chayuan-wps 组合的最简形态。免费开源的AI软件 想给个人用户最低使用门槛，这种 装两个东西就能用 是关键。
