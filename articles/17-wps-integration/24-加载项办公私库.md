# 加载项与办公私库 对接部门私有空间

chayuan-wps 加载项跟办公私库 office:* 的对接。这一篇讲。

## 场景

法务部门有内部知识库 office:legal:contracts。

部门成员通过 chayuan-wps 加载项在 WPS 里直接查询。

非法务部成员看不到这个 KB。

权限严格。

## 加载项里看到的私库

法务张三登录 chayuan-wps。

加载项 KbSelectorDialog 显示。

```
私库（你有权访问）：
  ✓ office:zhangsan:notes      (个人，仅你)
  ✓ office:legal:contracts    (部门，法务团队)
  ✓ office:legal:templates    (部门，法务团队)
```

非法务部门员工（如技术部）打开同一个对话框，看不到 office:legal:* 的 KB。

权限完全透明。

## 引用气泡的展示

法务在 WPS 里检索 office:legal:contracts。

回答里的引用气泡橙色（私库色）。

```
[橙色 锁图标]
合同条款 12.5：...
来源：office:legal:contracts/contract_2024_001.docx
```

颜色和图标提示用户 这是私库内容。

## 上云的提示

如果法务用云模型（GPT-4o）。chayuan-wps 检测引用是私库。弹提示。

```
您的查询命中 office:legal:contracts 私库。
该内容会随 prompt 发送给 OpenAI。
是否继续？
[继续] [改用本地模型] [取消]
```

防止私库内容无意中上云。

## 私库的特殊权限

office:legal:contracts 配置。

owners: [张三, 李四, 王五]  # 法务部三人能写
readers: []  # 没有额外只读
visibility: department_legal

加载项严格按权限过滤 KB 列表。

## 跨身份切换

某员工同一台电脑登录两个身份（chayuan-desktop 多身份）。

身份 A（法务）能看 office:legal:*。

身份 B（IT）看不到法务私库，但能看 office:it:*。

加载项自动按当前身份过滤。

## 私库的入库

法务通过 WPS 加载项入库。

```
[把当前 WPS 文档加入私库]
[选 office:legal:contracts]
[确认]
```

加载项调 chayuan-desktop API。文档解析 + 嵌入 + 入库。

之后该文档能被检索。

## 私库的更新

加载项支持更新私库。

```
[当前 KB 状态]
office:legal:contracts: 350 个文档
最近更新: 2 小时前

[添加新文档] [编辑] [批量管理]
```

法务在 WPS 里直接管理。

## 引用的二次创作

法务从私库引用某条款到当前 WPS 文档。

加载项 [插入引用]。

```
[复制原文][链接批注][脚注]
```

不同插入方式。链接批注让读者点击跳到原文档。

## 隐私警示

如果法务在 WPS 里把私库内容复制到聊天框分享给同事（错误使用）。chayuan-wps 检测到。

```
警告：您正在分享私库内容。
该聊天可能被发送给云 AI 服务。
[确认]
```

防止误操作。

## 国产化场景

党政军场景的部门私库（涉密、机要）需要严格权限 + 不出网。chayuan-wps 的 office:* + 本地处理满足。

某些场景甚至 不允许文档进入聊天上下文（仅引用气泡展示，不送给 LLM）。chayuan-wps 配置支持。

## chayuan-server 的对应

chayuan-server 模式下 office:* 私库集中。员工 chayuan-wps 通过 chayuan-server 检索。权限校验由 chayuan-server 处理。

## chayuan-desktop 的协同

chayuan-desktop 后端管理私库。chayuan-wps 通过后端检索。所有权限校验在后端。

## 总结

加载项与办公私库的对接是 chayuan-wps 在隐私敏感场景的工程能力。免费开源的AI软件 让 部门私有数据 也能在 WPS 里用 AI 查询，且权限严格。chayuan-wps 的颜色编码 + 上云警示 + 权限过滤让私库使用安全。
