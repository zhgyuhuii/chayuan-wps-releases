# 加载项的离线运行 桌面端不在时的降级

chayuan-wps 加载项在 chayuan-desktop 后端不在时的降级处理。这一篇讲。

## 后端不在的场景

场景一：chayuan-desktop 没启动。员工开 WPS 时 chayuan-desktop 还没开。

场景二：chayuan-desktop 崩溃。运行中后端突然挂了。

场景三：chayuan-desktop 升级中。临时不可用。

每种 chayuan-wps 都需要应对。

## 检测后端状态

chayuan-wps 启动时探测 127.0.0.1:62581。

```js
fetch("http://127.0.0.1:62581/api/v1/version")
  .then(... 后端在 ...)
  .catch(... 后端不在 ...)
```

定时（每 30 秒）重新探测。后端恢复时 chayuan-wps 自动接上。

## 后端不在时的 UI

chayuan-wps 加载项侧栏显示。

```
[未连接到 chayuan-desktop]
请启动 chayuan-desktop 后再试。
[启动 chayuan-desktop] [继续等待]
```

[启动 chayuan-desktop] 按钮调 OS 启动 chayuan-desktop（如果安装了）。

## 自动启动

chayuan-wps 检测后端不在 + chayuan-desktop 已安装。能自动启动。

```
chayuan-wps 配置：
  auto_start_backend: true
```

启用后 chayuan-wps 启动时如果检测到后端不在自动启动。

避免用户每次手动开两个应用。

## 降级到云模式

某些场景 chayuan-desktop 完全不装。chayuan-wps 直连云 API。

```
chayuan-wps 设置：
  backend: cloud
  cloud_provider: openai
  api_key: ...
```

chayuan-wps 直接调云 LLM。功能有限。

无 KB 检索（chayuan-desktop 才管 KB）。

无本地工具。

适合：完全不需要 KB 的轻量用户。

## 缓存模式

某些查询的结果之前缓存过。chayuan-wps 即使没后端也能返回缓存。

```
[离线模式]
没连接 chayuan-desktop。
显示之前缓存的回答：
"...."
[查看更多缓存] [尝试连接]
```

部分功能可用。

## 仅 WPS 操作模式

chayuan-wps 不调 LLM，只做 WPS 文档操作。

```
[基础模式]
某些 AI 功能不可用。但能：
  - 文档格式化
  - 选区高亮
  - 模板插入
[功能受限]
```

某些用户只需要 WPS 自动化也行。

## 错误诊断

chayuan-wps 探测失败时尝试诊断。

端口 62581 被其他进程占。提示用户。

chayuan-desktop 已运行但端口不通。可能防火墙拦截。

DNS 问题（不太可能 127.0.0.1 出 DNS 问题）。

让用户能修复。

## 异常重连

后端短暂断开。chayuan-wps 不立即弹错误。

等 5 秒重试。

仍失败 → 显示 重连中... 提示。

仍失败 30 秒 → 进入离线模式。

避免后端重启的几秒间断打断用户。

## 国产化场景

党政军场景对稳定性要求高。chayuan-wps 在 chayuan-desktop 偶发故障时仍提供基础功能让员工 不被卡住。

## chayuan-server 的对应

chayuan-server 模式下 chayuan-wps 同样需要后端不在的降级。chayuan-server 故障时 chayuan-wps 同样进入离线 / 缓存 / 受限模式。

## 总结

加载项的离线运行降级是 chayuan-wps 在工程鲁棒性上的设计。免费开源的AI软件 让 后端不在 不让 chayuan-wps 完全不可用。chayuan-wps 的多层降级（自动启动 / 缓存 / 云模式 / 受限）让用户体验稳定。
