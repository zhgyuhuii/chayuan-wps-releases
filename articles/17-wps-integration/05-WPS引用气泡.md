# 在WPS里调起察元智库 引用气泡的回链体验

chayuan-wps 加载项在 WPS 里调起察元智库的最佳体验是引用气泡 + 回链。这一篇讲。

场景。员工在 WPS 文字里写一份月度报告。需要引用一份历史合同的具体条款。打开 chayuan-wps 加载项，挑 doc:合同档案 KB，问 上次跟 X 客户签的合同里关于违约责任的条款是什么。chayuan-desktop sidecar 检索后给回答，下面是引用气泡。

引用气泡的展示。在加载项里的右侧抽屉（窄空间适配）。每个气泡显示。

文件名 + 页码。合同_v2.pdf 第 7 页。

预览片段。原文段落的前 80 字。

信任度（5 颗星）。

跳转按钮。

下载按钮（doc:* 来源支持）。

跳转的几种方式。

方式一：跳到 WPS 文档对应位置。如果命中的 chunk 来自当前 WPS 打开的文档（罕见但可能），加载项让 WPS 光标跳到对应段落。

方式二：打开外部 PDF 阅读器。命中来自一份 PDF，点击跳转用 OS 默认 PDF 阅读器打开 PDF 到指定页。

方式三：用 WPS 打开。如果命中是 docx 文件，加载项调 WPS 打开。

下载按钮。命中来自 doc:* 文档库且有原文件副本。点击下载按钮把原文件保存到本地。

引用回到 WPS 文档。

某些场景用户希望把引用直接插入到 WPS 文档作为脚注或批注。chayuan-wps 提供。

插入引用按钮。点击在光标位置插入 来自《合同_v2.pdf》第 7 页 这种引用文字。

批注形式。在 WPS 文档的某段加批注，批注内容是引用气泡的预览。

链接批注。WPS 特有的批注链接外部资源。chayuan-wps 用这个让批注能跳到 chayuan-desktop 的 KB 。
