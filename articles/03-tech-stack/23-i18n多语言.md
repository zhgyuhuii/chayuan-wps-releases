# i18n选react-i18next 单机版的字符串管理

chayuan-desktop 桌面单机版的多语言用 react-i18next。当前支持中文、英文、日文、德文、法文五种。这一篇讲清楚 i18n 在桌面应用上的几个特殊考虑。

先看 react-i18next 的好处。社区主流方案，文档全。支持命名空间分包加载、复数形式、嵌套引用、上下文区分。配合 React 用 useTranslation hook 简洁。

chayuan-desktop 的字符串组织。public/locales/zh-CN.json 中文、en.json 英文等。每个文件按命名空间组织（chat、kb、settings、tools、help），每个命名空间下是 key-value 对。

key 的命名约定。用层级化 key，比如 chat.input.placeholder、kb.create.title、settings.model.provider.add。命名清楚见名知意。这种约定让翻译者好工作，不需要懂代码就能填字符串。

字符串提取。chayuan-desktop 的源码用 t('chat.input.placeholder') 这种调用。i18next-parser 这种工具能扫描源码自动提取所有 t() 调用，更新 zh-CN.json 文件。这种 keys-from-code 的工作流让翻译同步不容易漏。

回退策略。如果某个 key 在某种语言里缺失（比如新功能加了 zh-CN 没加 fr），fallback 到 en。再没有就显示 key 本身。这种 graceful 回退让发布不会因为漏翻译被卡。

变量插值。t('chat.welcome', { name: 'zhang' }) 这种用法标准。chayuan-desktop 的字符串里大量用到，比如 设置里给 {0} 添加密钥、KB {0} 已建立。

复数形式。某些语言有复杂复数规则，i18next 用 plural form 处理。chayuan-desktop 里中英复数处理不太需要（中文几乎没有），但其他语言（德文、法文）有。

桌面应用的特殊考虑。一是没有 URL 路径切换语言的概念，得在应用内显式提供切换 UI。chayuan-desktop 的设置里有 语言 选项，五种语言切换。二是切换之后立即生效，不需要刷新页面。i18next 的 changeLanguage API 触发 React rerender。

字符串持久化。用户选的语言记录在 Tauri store 里。下次启动时按存的语言初始化 i18next。如果用户没选过，按系统 locale 自动选。

国产化支持下的中文。中文用 zh-CN（简体）。chayuan-desktop 当前不区分简繁，简体是默认。如果用户场景需要繁体（zh-TW），后期可以加。

字符串中的术语统一。chayuan-desktop 有一份术语表（terms.md）记录核心概念的固定翻译：chayuan-desktop 不译、察元AI 不译、知识库 = Knowledge Base = ナレッジベース、模型对抗 = Model Arena = モデルアリーナ。这种统一保证翻译一致性。

机器翻译的辅助。chayuan-desktop 的英文/日文/德文/法文翻译初稿用机器翻译生成，再由懂语言的人 review 修正。这种 machine + human 的工作流让覆盖速度跟得上。

字符串的字数差异。中文一般比英文短（同义内容字数比 1：1.5）。UI 设计时要预留宽度，避免英文字符串溢出 UI 边界。chayuan-desktop 的按钮、菜单都做了 max-width + ellipsis 处理。

字符串的 RTL 支持。阿拉伯文、希伯来文等是右到左排版。chayuan-desktop 当前不支持 RTL 语言。如果未来要加，CSS 的 dir 属性和 logical property 是关键。

错误消息的 i18n。chayuan-desktop 后端 sidecar 返回的错误码是英文（比如 'kb_not_found'），前端按错误码 lookup 翻译表展示给用户。这种 错误码作为 key 的设计让错误消息也参与 i18n。

帮助中心的 i18n。chayuan-desktop 内嵌的帮助中心是 markdown 文档，按语言分目录。help_zh-CN/、help_en/ 等。切换语言时加载对应目录的文档。这种 doc-level i18n 让帮助内容跟界面字符串都跟语言走。

WPS AI 插件 chayuan-wps 也支持 i18n，技术上用 vue-i18n。两边的字符串库相对独立，因为 UI 不共享。术语翻译参考同一份术语表保持一致。

i18n 在 chayuan-desktop 的工程化是 务实够用 的水平。免费开源的AI软件 想覆盖国际市场，i18n 这件事是基础工程。chayuan-desktop 当前的五种语言覆盖是逐步铺开的结果。
