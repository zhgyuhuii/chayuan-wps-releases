# 国产化支持下的政府公文格式 行文规范带来的解析挑战

国产化支持下的 chayuan-desktop 桌面单机版常常处理政府公文。这类文档有自己的行文规范（红头文件格式、标题层级、文件号、签发字段等），跟普通 Word 文档不太一样。这一篇讲清楚政府公文解析的挑战与应对。

先看政府公文的几个特征。第一行是发文机关（红头部分）。第二行往往是文件类型（通知/决定/通报等）。第三行是文件号（比如 京政发〔2026〕5 号）。然后是标题。然后是主送机关。然后是正文。最后是发文机关印章和签发日期。

红头部分。原始公文里红头是大字号、红色、居中的发文机关名称。chayuan-desktop 的 Word parser 拿到的是文字加 paragraph style metadata。如果 docx 里 红头 是用图片做的（很多 WPS 模板这么做），文字层就拿不到。chayuan-desktop 调 OCR 兜底处理这种图片型红头。

文件号识别。文件号有固定格式，比如 〔2026〕、第 X 号 等。chayuan-desktop 在公文 KB 里专门写了文件号识别规则，把文件号作为 metadata 字段提取。检索时能用文件号过滤。

标题层级。公文的标题用 黑体、宋体三号、四号 等字号区分层级。chayuan-desktop 在 docx parser 里识别这些字号差异，给 chunk metadata 加 heading_level。

主送机关。在标题之后，正文之前。chayuan-desktop 把主送机关作为 metadata 字段单独存。

正文段落。正文按段落切。中间有 一、二、三 这种序号的段落识别为列表项。

附件标记。某些公文末尾标注 附件：xxx，chayuan-desktop 把这部分作为 metadata 关联到主文档。

落款。发文机关印章 + 签发日期。chayuan-desktop 把 签发日期 作为 metadata，便于按时间检索。印章如果是图片，OCR 兜底但精度有限。

特殊处理。公文里的红头部分常用图片形式，chayuan-desktop 的 docx parser 在 image_run 上调 OCR。这种 选择性 OCR 比对整个文档 OCR 高效。

公文 PDF 的处理。某些机关用 PDF 发文。chayuan-desktop 的 PDF parser 加 RapidOCR 兜底处理。盖章页的印章识别精度有限，但章上的 公章 字样基本能识别。

引用气泡的展示。公文 chunk 的引用气泡展示 文件号 + 标题 + 段落。点击展开能看到原段落、原文件路径。这种展示让用户直接确认 这段答案来自哪份公文。

公文检索的特殊场景。

场景一：按文件号查。用户问 关于京政发〔2026〕5 号文件的内容。chayuan-desktop 通过文件号 metadata 精确命中。

场景二：按发文机关查。用户问 国务院最近发的关于教育的文件。chayuan-desktop 按 发文机关 + 主题 联合检索。

场景三：按时间范围查。用户问 2025 年下半年关于双减的政策。chayuan-desktop 按 签发日期 metadata 过滤。

场景四：跨文件比对。用户问 同一议题在两份不同公文里的差异。chayuan-desktop 多 KB 检索 + 模型综合分析。

公文密级。政府公文常分公开/内部/秘密/机密四级。chayuan-desktop 通过 confidentiality metadata 标记。检索时按用户身份过滤。

公文格式的差异。不同部门、不同地区、不同年代的公文格式有微差。chayuan-desktop 的 parser 不强求格式统一，按 通用规则 处理，覆盖大多数公文。极少数特殊格式可能需要自定义规则。

历史归档的批量入库。某个机关的几年历史公文打包入 chayuan-desktop 是常见场景。chayuan-desktop 的 folder-sync 加 OCR 加 metadata 提取一条龙完成。一份几千份公文的归档可能需要几小时入库，但一次完成后长期可查。

合规要求。政府公文的存储和访问通常有合规要求（比如不能跨网络分发、必须有审计日志）。chayuan-desktop 单机版的本地存储 + 不联外网 + audit_log 模块满足大多数要求。具体合规细节按客户单位规定。

WPS AI 插件 chayuan-wps 在政府办公场景下尤其有用。公文起草人在 WPS 里写文件草稿时，加载项查 doc:历史公文 KB 的相关内容做参考。引用气泡能精准跳到原公文段落。这种工作流跟传统 文件检索 + 手抄段落 比起来效率高很多。

政府公文格式的解析是 chayuan-desktop 国产化支持的一个具体落地。免费开源的AI软件 想真正服务政企客户，必须做到公文这种 专业格式 的处理深度。chayuan-desktop 在这一面的投入是国产化战略的一部分。
