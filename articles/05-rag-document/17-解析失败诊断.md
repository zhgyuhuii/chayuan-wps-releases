# 解析失败的诊断信息 给用户看的错误是怎么生成的

chayuan-desktop 桌面单机版的文档解析每次都跑成功是不可能的。损坏 PDF、加密文件、特殊格式、磁盘满、内存不够，各种原因都让解析失败。这一篇讲解析失败时 chayuan-desktop 给用户的诊断信息怎么生成。

先看用户能看到什么。在 KB 详情页有一个 解析状态 区，列出每个文件的状态：成功、警告、失败。失败和警告的展开能看到具体错误信息。这一组信息对用户排查很重要。

诊断信息的层级。

层级一：用户友好的描述。比如 该 PDF 已加密，请提供密码 或 该文件大小超过限制（200MB）。这是给非技术用户看的，简单明了。

层级二：技术错误码。比如 PDF_ENCRYPTED、FILE_TOO_LARGE、UNSUPPORTED_FORMAT。这是给开发者或客服用，定位问题精准。

层级三：完整 traceback。Python 的异常栈，给开发者排查 bug 用。

前端默认展示层级一。点开 详情 看层级二。再点 复制错误 复制层级三到剪贴板，方便发给社区或客服。

常见的失败类型。

类型一：文件损坏。PDF 文件 header 不对、SQLite 损坏、ZIP 损坏。错误码 FILE_CORRUPT。给用户提示 文件损坏，请检查原文件。

类型二：加密文件。PDF 加密、docx 加密、xlsx 加密。错误码 ENCRYPTED。给用户提示 文件已加密，请提供密码。chayuan-desktop 在 UI 上提供密码输入框。

类型三：格式不支持。比如 .doc 旧 Word 格式、.dps WPS 演示格式、.numbers Apple Numbers 格式。错误码 UNSUPPORTED_FORMAT。提示用户先转换成支持的格式。

类型四：文件太大。超过 KB 配置的单文件上限。错误码 FILE_TOO_LARGE。提示限制和当前大小。

类型五：磁盘空间不足。chayuan-desktop 写入 sqlite-vec 文件时磁盘满。错误码 NO_DISK_SPACE。提示用户清磁盘。

类型六：内存不足。OCR 一份大 PDF 时 OOM。错误码 OUT_OF_MEMORY。提示用户关其他应用或增加内存。

类型七：嵌入模型加载失败。比如模型权重文件损坏。错误码 EMBEDDING_MODEL_ERROR。提示重新下载模型。

类型八：OCR 服务不可用。RapidOCR 模型加载失败或者 ONNX Runtime 异常。错误码 OCR_SERVICE_ERROR。提示用户检查模型权重。

类型九：网络相关错误。比如外部 source 连接失败。错误码 EXTERNAL_SOURCE_UNREACHABLE。提示用户检查网络或外部服务。

类型十：文件锁。某些文件被其他程序占用（比如 OneDrive 同步中）。错误码 FILE_LOCKED。提示用户暂停同步软件或换路径。

诊断信息的写入位置。chayuan-desktop 把每次解析失败的诊断写到几个地方。

第一，KB chunk 表的 errors 字段。每个文件级别的状态记录。前端 KB 详情页直接展示。

第二，CHAYUAN_ROOT/logs/parser.log。详细日志含 traceback。开发者排查用。

第三，数据库的 audit_log 表。审计用。

错误恢复。多数解析失败可以用户主动重试。chayuan-desktop 的 重试 按钮重新触发该文件的解析。如果原因没解决，再次失败。

部分成功的处理。一份 100 页 PDF 中第 50 页解析失败（OCR 出错），其他 99 页正常。chayuan-desktop 入库 99 页的 chunk，标记第 50 页 部分失败。检索时不会因为这一页让整份文档不可用。

失败重试的退避。chayuan-desktop 不主动反复重试解析失败的文件，避免 失败循环 让 sidecar 一直忙。folder-sync 下次扫描时如果文件没变化（hash 一样）跳过；变化了再尝试解析。

诊断信息的国际化。chayuan-desktop 的错误消息按当前 i18n 语言展示。中文用户看到中文提示，英文用户看到英文。技术错误码（层级二）保持英文用于检索资料。

国产化支持下的诊断。某些国产格式（dps、et）chayuan-desktop 不支持时给出 国产化建议：请先用 WPS Office 另存为 PDF 或 docx 格式。这种贴近用户的提示对国产场景友好。

WPS AI 插件 chayuan-wps 在加载项里有简化的诊断展示。如果用户在 WPS 文字里上传一份解析失败的文件，加载项展示 该文件未能入库 提示，详情链接到桌面客户端的 KB 详情页。

解析失败诊断是 chayuan-desktop 用户支持的底盘。免费开源的AI软件 没有客服团队帮你排查每个问题，诊断信息越清楚用户越能自助。chayuan-desktop 在这件事上的投入对降低支持成本和提升用户体验都关键。
