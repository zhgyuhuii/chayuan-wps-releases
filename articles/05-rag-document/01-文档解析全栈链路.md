# 本地离线知识库的文档解析链路 PDF Word Excel PPT MD HTML 全栈

chayuan-desktop 桌面单机版的 文档 RAG 是用户用得最多的功能之一。一份 PDF 拖进对话窗口，几秒后回答出来还带引用气泡。这条链路看似简单，背后是一整套解析、切分、嵌入、入库的工序。这一篇全景式过一遍。

第一步：文件上传。用户拖文件到对话窗口或在 KB 详情页选文件。chayuan-desktop 把文件保存到 CHAYUAN_ROOT/uploads/KB名/ 目录下，文件名加时间戳前缀避免冲突。

第二步：文件类型识别。chayuan-desktop 用 magic（libmagic）识别真实 MIME 类型，不只看文件扩展名。这避免改名伪装的文件踩坑。识别出来的类型决定调哪个 parser。

第三步：选择 parser。PDF 走 PyMuPDF 加可选 RapidOCR。Word 走 python-docx。Excel 走 openpyxl。PPT 走 python-pptx。Markdown 走 markdown 库。HTML 走 beautifulsoup。txt 走原生读取。每个 parser 是 chayuan-desktop knowledge_source/document 模块下的独立文件。

第四步：文本抽取。每种 parser 把文件转成 Document 列表，每个 Document 含 文本片段 + 元数据（文件名、页码、段落、坐标）。这一步是文档 RAG 最关键，决定后续 chunk 质量。

PDF 抽取的双轨。PyMuPDF 先尝试提取文本层。如果文本层质量好（识别率 > 阈值）走文本层。如果文本层缺失或残缺（扫描件 PDF），走 RapidOCR 兜底，把每页渲染成图调 OCR。

Word 抽取。python-docx 把 docx 解析成段落。批注和修订作为独立 Document 携带，metadata 标记 来源 = 批注。

Excel 抽取。openpyxl 把每个 sheet 的每行转成一个 Document。如果数据列多，可能改走结构化 KB（src:*）路径。

PPT 抽取。python-pptx 把每个 slide 的每个 text frame 转成 Document。图片不直接抽，但记录位置。

Markdown HTML 抽取。markdown 渲染成结构化树，按 heading 分段。HTML 用 beautifulsoup 提取 main content（去掉导航栏、footer 噪声）。

第五步：切分（chunking）。Document 列表过 chunker 模块，按 chunk_size（默认 512 token）和 chunk_overlap（默认 50 token）切。chayuan-desktop 不只用滑动窗口，还有语义切分（按段落边界、句子边界）。

第六步：清洗。每个 chunk 过去 noise（去掉重复空白、统一全角半角、规范化 unicode）。OCR 结果还要做拼写纠错（轻量规则，不强）。

第七步：嵌入。每个 chunk 调嵌入模型（默认 bge-m3-onnx）生成 1024 维向量。批处理优化（batch size 32）让 CPU 上吞吐量好。

第八步：入库。chunk 文本 + 向量 + metadata 写到 sqlite-vec 文件。事务确保一致性，要么整批成功要么回滚。

第九步：标记完成。chayuan-desktop 在 KB 详情页更新统计：新增 X chunk，KB 总 chunk 数，最后同步时间。前端立即可见。

第十步：失败处理。任意一步失败时记录到诊断日志（CHAYUAN_ROOT/logs/parser.log），前端展示 X 个文件未成功入库 提示，点开看具体错误。

整个链路在 SSD 上一份普通 50 页 PDF 大约 30 秒到 1 分钟（含嵌入计算）。机械盘上慢一些。OCR 兜底的扫描件 PDF 慢得多。

国产化支持下的解析。WPS 生成的 docx、xlsx 格式偶尔跟 Microsoft Office 有差异。chayuan-desktop 用的 python-docx 和 openpyxl 对 WPS 兼容性不错，覆盖大多数实际场景。某些极端格式需要先在 WPS 里 另存为 docx 标准格式。

WPS AI 插件 chayuan-wps 在 WPS 文字里可以直接把当前文档作为 RAG 资料。加载项把文档内容发给 sidecar，走同一条解析链路入临时 KB。

文档 RAG 全栈链路是 chayuan-desktop 文档库的工程基础。免费开源的AI软件 在文档处理这一面的覆盖深度，决定它能不能 真的代替云端服务。chayuan-desktop 在 Office 全格式 + OCR + 多语种 上的覆盖让它在国产化办公场景里站得住。
