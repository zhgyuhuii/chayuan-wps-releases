# 把第三方MCP工具接进察元AI当客户端

chayuan-desktop 桌面单机版作为 MCP 客户端能用第三方 MCP 工具。这一篇讲对接。

MCP 工具生态。社区有大量 MCP server。比如。

filesystem-mcp：文件操作。

github-mcp：GitHub API。

slack-mcp：Slack 集成。

postgres-mcp：PostgreSQL 数据库。

git-mcp：Git 仓库操作。

browser-mcp：浏览器自动化。

calendar-mcp：日历集成。

新工具不断在加。

接入到 chayuan-desktop。设置 - MCP - 客户端配置。新增 MCP server。

stdio 模式示例。

```
{
  "name": "filesystem",
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-filesystem", "/home/user/Documents"],
  "transport": "stdio"
}
```

chayuan-desktop 启动这个子进程，发现工具。

SSE 模式示例。

```
{
  "name": "github",
  "url": "http://localhost:7000/sse",
  "transport": "sse",
  "headers": {"Authorization": "Bearer XXX"}
}
```

chayuan-desktop 连 SSE 端点。

工具发现。chayuan-desktop 拿到 MCP server 的工具清单后自动注册到自己的工具列表。LLM 在对话中能用。

实际用法。

例一：让 LLM 读你的本地文档目录。filesystem-mcp 接好后，LLM 能 ls 浏览目录、cat 文件。

例二：让 LLM 操作 GitHub。github-mcp 接好后，LLM 能创建 issue、提 PR、查 commit。

例三：让 LLM 跑 SQL 查数据库。postgres-mcp 接好后，LLM 能直接跑查询。

跟内置工具的关系。MCP 工具跟内置工具走同一接口。LLM 调用时不区分。引用气泡的 三层折叠 展示也一致。

工具的鉴权。MCP server 各自的 API key 在 chayuan-desktop 里加密存。

性能。MCP 工具调用比内置工具略慢（多一层 stdio/SSE）。但毫秒级，可接受。

工具市场。chayuan-desktop 路线图里有 MCP 工具市场，让用户在 GUI 里浏览安装 MCP server。当前需要手动配 JSON。

WPS AI 插件 chayuan-wps 在 WPS 里发起对话时也能调 MCP 工具（通过 sidecar）。

第三方 MCP 工具接入是 chayuan-desktop 给用户的能力扩展。免费开源的AI软件 不必所有功能都自己造，借助 MCP 生态扩展。chayuan-desktop 在这一面的开放让 工具能力 持续生长。
