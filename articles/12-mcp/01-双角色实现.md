# 免费开源的AI软件怎么接MCP 察元AI的双角色实现

chayuan-desktop 桌面单机版同时是 MCP 客户端和 MCP 服务端。这一篇讲 MCP 双角色。

先看 MCP 是什么。Model Context Protocol，Anthropic 发起的开放协议。让 AI 应用跟工具/数据源之间用统一协议通信。LLM 可以调外部 MCP server 提供的工具，外部 MCP client 也可以调本机 MCP server 暴露的能力。

chayuan-desktop 当 MCP 客户端。在设置 - MCP 工具 配置外部 MCP server。chayuan-desktop 启动 stdio 子进程或 SSE 连接，发现远端 server 暴露的工具。这些工具自动加进 chayuan-desktop 的工具列表。LLM 在对话中可以调用。

chayuan-desktop 当 MCP 服务端。chayuan-desktop sidecar 通过 stdio 或 SSE 暴露自己的能力作为 MCP server。Claude Desktop 等客户端能连进来，使用 chayuan-desktop 的 KB 检索、对话历史查询、本地文件操作等。

双角色的价值。

价值一：用户能选最合适入口。喜欢 Claude Desktop 的用户用 Claude Desktop 当客户端，chayuan-desktop 提供 KB 后端。喜欢 chayuan-desktop UI 的用户直接在 chayuan-desktop 里用所有功能。

价值二：生态融合。MCP 是开放协议，chayuan-desktop 接入 MCP 生态等于接入了所有 MCP 兼容工具。

价值三：扩展性。新工具不用 chayuan-desktop 团队开发，社区贡献的 MCP server 能直接接。

stdio 模式。chayuan-desktop 启动 MCP server 作为子进程，通过 stdin/stdout 通信。简单可靠。常用于本地工具。

SSE 模式。MCP server 跑在网络上，chayuan-desktop 通过 SSE 协议连接。常用于远程或多客户端共享场景。

chayuan-desktop 当 MCP server 暴露的能力。

KB 查询。让 Claude Desktop 等用户能查 chayuan-desktop 里的 KB。

对话历史检索。

文件操作（在 CHAYUAN_ROOT 范围）。

模型对抗触发。

工具列表。

跟内置工具的关系。chayuan-desktop 内置 30+ 工具（前面文章讲过）。MCP 工具跟内置工具走同一接口（BaseTool），LLM 调用时不区分来源。

WPS AI 插件 chayuan-wps 通过 sidecar 享受 MCP 工具。

MCP 双角色是 chayuan-desktop 在 AI 应用生态里的开放姿态。免费开源的AI软件 通过开放协议跟其他工具协作，让用户能选最合适的入口。
