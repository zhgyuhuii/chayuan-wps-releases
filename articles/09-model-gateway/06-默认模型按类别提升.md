# 默认模型按类别提升候选 chat embed image rerank

chayuan-desktop 桌面单机版的模型网关把众多模型按 类别 分组，新接入的模型自动晋升为对应类别的候选默认。这一篇讲。

## 类别的划分

chat。对话生成模型。GPT-4、文心、通义、Qwen 等。

embed。嵌入模型。bge-m3、text-embedding-3-small、智谱 embedding-2 等。

image。图像生成或理解模型。GPT-4V、Qwen-VL、文心 ERNIE-VL 等。

rerank。重排模型。bce-reranker、bge-reranker 等。

speech。语音识别和合成。Whisper、Paraformer 等（可选模块）。

每个类别独立维护候选列表。

## 自动晋升的逻辑

新厂商或新 Key 接入。chayuan-desktop 调 /v1/models 拉模型列表。

每个返回的模型按 ID 模式分类。

```
gpt-4 → chat
gpt-4-turbo → chat
gpt-4o → chat
text-embedding-3-small → embed
gpt-4-vision-preview → image
```

分类规则在 chayuan-desktop 的模型卡片配置文件里维护。

## 默认候选的提升

每个类别有一个 默认模型 字段。新接入模型如果用户没显式选默认，按规则自动提升。

提升规则一。chat 类别。优先用户配置的偏好厂商。其次 GPT-4o > Claude-3.5 > Qwen-Plus > 文心-4 等的预设排名。

提升规则二。embed 类别。优先国产开源（bge-m3 / bce-embedding）。其次 OpenAI text-embedding-3。理由：embed 调用频繁，本地国产模型成本低。

提升规则三。image 类别。优先有视觉的多模态模型。GPT-4V > Qwen-VL > 文心 ERNIE-VL。

提升规则四。rerank 类别。优先国产小模型。bce-reranker > bge-reranker。这俩是 ms-marco 评测里中文领先的。

## 用户覆盖

自动晋升只是 候选默认。用户能在设置里手动选其他模型作为类别默认。手动选的优先级最高。

UI 入口。chayuan-desktop 设置 - 模型 - 默认模型。每个类别一个下拉，列出该类别所有可用模型。

## 多 Key 同模型的处理

某些用户配了 OpenAI 多个 Key（用于轮换或速率分担）。同一个 gpt-4o 出现多次。chayuan-desktop 的 dedup 按 模型 ID + 厂商 去重，对用户呈现一个，调用时内部轮换 Key。

## 类别检测的失误

某些模型 ID 不规范，规则没法分类。chayuan-desktop 的 fallback 把这种模型归到 unknown 类别。用户在设置里看到 unknown 列表，能手动指认类别。

## 国产化场景

政企采购需要明确的 国产模型优先 配置。chayuan-desktop 的 类别默认 + 国产优先 是开箱即用的。embed 默认 bge-m3 满足国产化，rerank 默认 bce-reranker 同上。

## chayuan-server 协同

chayuan-server 也走相同的类别管理。chayuan-desktop 用了相同的模型卡片配置文件（共享 npm package 或 yaml）。一致性高。

## WPS 加载项

chayuan-wps 在 WPS 里调用 chayuan-desktop 的网关时按类别拉默认模型。chat 默认模型变了，WPS 里也跟着变。

## 总结

默认模型按类别提升是 chayuan-desktop 全模型支持下的工程便利。免费开源的AI软件 接入 18 家厂商，用户不可能手动管理几十个模型，自动晋升按类别分组让用户体验顺。chayuan-desktop 的国产优先策略也契合政企场景。
