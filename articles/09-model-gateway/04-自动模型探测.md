# 模型自动探测 填Key之后/v1/models的解析

chayuan-desktop 桌面单机版填模型 API Key 之后会自动拉一遍厂商的模型列表，把可用模型分类填进默认候选。这一篇讲清楚自动探测的机制。

先看为什么要自动探测。每个厂商都有几十甚至上百个模型版本（chat / embed / image / vision / reasoning）。让用户手动选费时间。chayuan-desktop 自动探测一次把所有模型按类别归到位。

探测的接口。OpenAI 协议有 /v1/models 接口返回模型列表。每条记录含 id 字段（模型唯一标识）。chayuan-desktop 调这个接口拿列表。

非标准协议的处理。某些厂商不完全 OpenAI 兼容（比如百度文心的认证格式不同）。chayuan-desktop 的 adapter 调对应厂商的接口，输出统一成 OpenAI 兼容的 model list 格式。

模型分类。chayuan-desktop 维护一份模型卡片库（model registry）。每条卡片含。

id：模型 ID（gpt-4o、deepseek-chat、qwen-max 等）。

provider：所属厂商。

category：chat / embedding / image / vision / rerank / audio / video。

context_length：上下文窗口大小。

supports_tools：是否支持工具调用。

supports_streaming：是否支持流式。

cost_per_1k_input：估算成本。

description：人类可读描述。

探测时的归类。chayuan-desktop 拿到 /v1/models 列表，对每个 id 在卡片库里查找。找到就用卡片信息。找不到的用启发规则。

启发规则。

含 embed / embedding 字样：embedding 类。

含 vision / vl / vlm 字样：vision 类。

含 image / dall / sd 字样：image 类。

含 rerank 字样：rerank 类。

含 audio / whisper / asr / tts 字样：audio 类。

其他默认 chat 类。

未识别的归到 unknown 类型，让用户手动指定。

默认候选的设置。每个类别下 chayuan-desktop 自动选第一个可用模型作为默认。前端切换默认模型时按列表展示。

实例。用户填 OpenAI 的 API Key。chayuan-desktop 调 /v1/models 拿到 30+ 模型。

gpt-4o（chat）。

gpt-4-turbo（chat）。

gpt-3.5-turbo（chat）。

text-embedding-3-large（embedding）。

text-embedding-3-small（embedding）。

dall-e-3（image）。

whisper-1（audio）。

tts-1（audio）。

chayuan-desktop 自动归类，前端显示分类列表。用户能切换默认 chat 模型从 gpt-4o 到 gpt-3.5-turbo。

错误处理。

错误一：API Key 不对。/v1/models 返回 401。chayuan-desktop 提示 凭据不正确，请重新输入。

错误二：网络不通。请求超时。chayuan-desktop 提示 无法连接，请检查网络。

错误三：模型列表为空。某些场景 /v1/models 返回空（账户无权限或额度耗尽）。chayuan-desktop 提示 该账户当前无可用模型。

错误四：协议不兼容。某些自家 LLM 服务不兼容 OpenAI /v1/models 接口。chayuan-desktop 让用户手动指定模型 ID。

国产化支持下的探测。文心、通义、智谱、豆包等的 /v1/models 协议略有差异。chayuan-desktop 的 adapter 处理。

WPS AI 插件 chayuan-wps 共用 chayuan-desktop 的模型卡片库。在加载项里的模型选择跟桌面客户端一致。

模型自动探测是 chayuan-desktop 给用户的便利。免费开源的AI软件 在多模型场景下让 配置 这件事尽量简单，靠的是这种自动化。chayuan-desktop 的卡片库 + 启发规则覆盖大多数场景。
