# 全模型支持下的模型卡片管理 名字描述上下文长度

chayuan-desktop 桌面单机版的模型网关给每个模型一份 模型卡片。卡片含展示名、描述、上下文长度、定价、能力标签等。这一篇讲。

## 模型卡片的字段

```yaml
id: gpt-4o
provider: openai
display_name: GPT-4o
description: OpenAI 多模态对话模型，支持视觉。响应快，质量高。
context_window: 128000
max_output: 16384
input_price: 2.5  # USD per 1M tokens
output_price: 10.0
capabilities:
  - chat
  - vision
  - tools
  - streaming
release_date: 2024-05-13
deprecated: false
```

每个模型一份。chayuan-desktop 内置基础 50+ 模型卡片，用户能扩展。

## 卡片的来源

来源一。chayuan-desktop 内置。打包时随客户端发布。覆盖 18 家厂商主流模型。

来源二。用户自定义。设置 - 模型 - 自定义卡片。新增 / 修改 / 删除。

来源三。线上更新。chayuan-desktop 启动时检查模型卡片更新（GitHub releases 或自架镜像），有新卡片自动拉。用户能关闭这个自动更新。

## 卡片的展示位置

模型选择器。聊天界面顶部的下拉。每个模型显示展示名 + 简短描述。hover 看完整卡片。

模型设置页。设置 - 模型 - 全部模型。表格形式展示卡片所有字段。能编辑。

模型对比页。设置 - 模型 - 对比。多个模型卡片并列对比。

## 上下文长度的作用

chayuan-desktop 用 context_window 字段决定。

聊天上下文截断。如果对话累积超过 context_window，按规则截断（保留最近、保留 system、保留引用）。

预估 Token。本地 tokenizer 算输入，跟 context_window 对比，超限提示。

文档输入。RAG 检索的 chunk 拼到 prompt 里前先按 context_window 限制总长度。

## max_output 的作用

某些模型 context_window 大但 max_output 小。比如 o1-preview 上下文 128k 但单次输出最多 32k。

chayuan-desktop 设置 max_tokens 时不超过 max_output。避免请求被厂商拒绝。

## 定价字段的来源

定价手动维护。每次厂商调价更新卡片。

chayuan-desktop 的卡片仓库（GitHub）公开。用户能 PR 更新最新定价。

某些便宜模型实际定价跟卡片有差。chayuan-desktop 的预估只是估算，最终账单看厂商。

## 能力标签

tools。支持原生工具调用。

vision。支持图像输入。

streaming。支持 SSE 流式。

reasoning。reasoning 模型（输出含 reasoning_content）。

multilingual。多语言能力强。

code。代码能力强。

按能力筛选。chayuan-desktop 设置里能 只看支持视觉的模型。

## 弃用标识

某模型被厂商弃用（gpt-3.5-turbo-0301 等）。卡片 deprecated=true。模型选择器里灰显，提示 已弃用，建议切换到 X。

## 自定义模型的卡片创建

私有部署的模型 chayuan-desktop 探测 ID 后自动创建基础卡片（默认值）。用户能完善描述、上下文长度等。

模板克隆。基于已有卡片克隆并修改。

## 国产化场景

国产模型卡片完整覆盖。文心、通义、智谱、豆包、Qwen、DeepSeek、Yi、Moonshot、阶跃等。每个有 国产 标签便于筛选。政企用户能 只看国产 一键过滤。

## chayuan-server 的对应

chayuan-server 共享同一份模型卡片仓库。一致性保证。

## WPS 加载项

chayuan-wps 在 WPS 里挑模型时也展示卡片。员工选模型时有完整信息。

## 总结

模型卡片管理是 chayuan-desktop 在多模型场景的元数据基础。免费开源的AI软件 接入 N 家厂商的几十个模型，没有结构化卡片管理用户没法选。chayuan-desktop 的卡片体系 + 内置 + 用户扩展 + 线上更新让 选模型 是看卡片就能决策的事。
