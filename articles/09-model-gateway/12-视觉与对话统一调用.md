# 视觉模型与对话模型的统一调用

chayuan-desktop 桌面单机版的模型网关把视觉理解模型和纯文本对话模型统一调用接口。这一篇讲。

## 视觉模型的特殊性

视觉模型接受图像输入。GPT-4V、Qwen-VL、Gemini-Pro-Vision 等。

输入格式不一致。

OpenAI 用 messages.content 数组里的 image_url 类型。

```json
{
  "type": "image_url",
  "image_url": {"url": "data:image/jpeg;base64,..."}
}
```

Anthropic Claude 用 messages.content 数组里的 image 类型。

```json
{
  "type": "image",
  "source": {"type": "base64", "media_type": "image/jpeg", "data": "..."}
}
```

Qwen 用 messages.content 数组里的 image 字符串字段。

各家不同。

## 统一封装的需求

chayuan-desktop 想让上层逻辑（聊天界面、知识库引用）一套代码处理所有视觉模型。所以网关层做统一封装。

## chayuan-desktop 的内部表示

中性表示。

```
{
  "type": "image",
  "url": "file:///local/path/img.jpg" or "https://...",
  "alt": "图像描述"
}
```

或者 base64 inline。

```
{
  "type": "image",
  "data": "<base64>",
  "mime": "image/jpeg"
}
```

## 网关的转换

针对每个厂商的格式映射。

调用 OpenAI 视觉模型时把内部表示转成 OpenAI 的 image_url 格式。

调用 Claude 时转 image base64 格式。

调用 Qwen 时转 image 字符串。

## 输入图像的来源

来源一。用户拖拽到聊天框的本地图片。chayuan-desktop 读为 base64 inline。

来源二。粘贴板的图片（截图工具 + Ctrl+V）。同上 base64 inline。

来源三。引用 KB 里的图像（src:* 图像 source）。chayuan-desktop 拉取图像或用图像 URL。

来源四。WPS 加载项发来的当前文档插图。chayuan-wps 提取图像传给 chayuan-desktop 网关。

## 图像大小处理

视觉模型对图像大小有限制。OpenAI 单图最大 20MB。

chayuan-desktop 上传前自动压缩。长边超过 1568 像素的缩放到 1568。JPEG 质量 85。

压缩后大小一般几百 KB。能容纳大多数模型。

## 多图输入

某些模型支持单次请求多图。chayuan-desktop 支持用户在聊天框拖入多张图。网关把多图转成对应厂商的多图格式。

OpenAI 的 messages.content 数组天然支持多 image_url。Claude 同上。Qwen 也支持。

## 输出统一

视觉模型的输出仍是文本（对图像的描述、分析、回答）。回答格式跟普通对话一致。chayuan-desktop 上层不需要区分。

## 文本+图像混合

某些回答里 LLM 可能引用图像（图像生成模型）。chayuan-desktop 当前只做视觉理解（图像作为输入），图像生成（DALL-E、Midjourney）是另一套逻辑。

## 路由判断

请求里如果有图像输入，chayuan-desktop 自动切到视觉模型。聊天里默认 chat 是 GPT-4o，但带图时切到 GPT-4V（如果用户没自定义视觉模型）。

如果当前默认 chat 模型本身就支持视觉（GPT-4o、Gemini-Pro），无需切换。

## 国产化场景

国产视觉模型 Qwen-VL、ERNIE-VL、ChatGLM-4V。chayuan-desktop 都接入。政企里员工传截图问 这截图里的报错怎么解，走国产视觉模型不出公司。

## chayuan-server 的对应

chayuan-server 模式下视觉模型调用同样统一。chayuan-desktop 单机版的实现跟 chayuan-server 共享网关代码。

## WPS 加载项

chayuan-wps 在 WPS 里发图像问问题（比如 这张图表示什么）。chayuan-desktop 网关收到图像统一处理。WPS 不感知用了哪个视觉模型。

## 总结

视觉模型与对话模型的统一调用是 chayuan-desktop 在多模态时代的工程基础。免费开源的AI软件 想覆盖政企办公场景必须支持图像问答。chayuan-desktop 的中性表示 + 厂商转换让视觉调用 跟普通对话一样简单。
