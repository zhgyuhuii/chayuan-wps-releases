# 模型权限 谁可以用哪个 单机版的简化

chayuan-desktop 桌面单机版的模型权限简化为 用户级 一刀切。这一篇讲模型权限模型。

## 多用户场景的模型权限

chayuan-server 多用户场景。

管理员能配置每个角色 / 用户能用的模型列表。

例如：实习生只能用 Qwen-Turbo（便宜），员工能用 GPT-4o，VP 能用 GPT-4。

权限按角色 + 模型 ID 矩阵。

## 单机版的简化

chayuan-desktop 单机假设。

通常一台电脑一个用户。配置模型 = 自己用模型。无需多角色。

最多支持 多身份切换（同一台电脑张三李四共用）。

简化为 当前身份 = 全部模型可用。

## 多身份场景的模型隔离

如果是真正的多身份场景（不同 OS 账号或同进程多身份）。

chayuan-desktop 给每个身份独立配置。每个身份自己的 Key、自己的默认模型、自己的 fallback 链。

身份 A 配置的 Key 身份 B 看不到。chayuan-desktop 用 Tauri Stronghold 加密存储，每个身份独立 keystore。

## 应用模式的模型权限

chayuan-desktop 暴露 OpenAI 兼容协议给本机其他应用。这些应用走 应用模式（HMAC 认证）。

应用模式可以配置 这个应用只能用哪些模型。

例如：某个开发者写的 工具应用 X 申请到 chayuan-desktop 的 API 访问，但只允许用 Qwen-Turbo（避免它无意中调用昂贵模型烧用户钱）。

```
应用 X：
  allowed_models: [qwen-turbo, ollama:qwen2.5:7b]
  daily_budget: ¥5
```

## 默认应用配置

chayuan-desktop 预置一些应用配置。

chayuan-wps（WPS 加载项）。默认能用所有模型。

第三方插件。默认禁用付费模型，只能用本地。用户能放开。

## 模型权限的可视化

设置 - 模型 - 权限。

```
应用列表：
  [chayuan-wps] 所有模型，无预算限制
  [开发者工具A] qwen-turbo, ollama:* 限本地，¥5/天
  [+] 添加应用
```

## API Key 范围

chayuan-desktop 给应用签发 API Key（HMAC 签名形式）时能附带 scope。

```
key: app_xyz
scope: models=[qwen-turbo, gpt-4o-mini], budget=10/day
```

应用拿这个 Key 调 chayuan-desktop 时只能调允许的模型。

## 临时降权

某用户怀疑自己的 Key 被泄露给某第三方应用。能在 chayuan-desktop 设置里 临时禁用 某个 Key 或 降低 scope。

```
临时操作：
  - 撤销应用 X 的 Key
  - 把应用 X 的预算降为 0
  - 把应用 X 的 allowed_models 改为只有本地
```

便于快速止损。

## 不需要 RBAC 的简化

单机版不引入复杂 RBAC 概念。不分 admin / editor / viewer 等角色。简单粗暴。

如果用户场景需要复杂 RBAC，升级到 chayuan-server。

## 国产化场景

政企单机部署对模型权限有简单要求（实习生别用贵的）。chayuan-desktop 的应用级权限够用。复杂场景升 chayuan-server。

## chayuan-server 的对应

chayuan-server 完整 RBAC + 角色。chayuan-desktop 单机版是这种 RBAC 的子集。便于将来升级时数据迁移。

## WPS 加载项

chayuan-wps 在 WPS 里调用走 chayuan-desktop 默认 chayuan-wps 应用 配置（所有模型可用）。如果用户想给 WPS 限制只能用便宜模型也行。

## 总结

模型权限单机简化是 chayuan-desktop 在桌面场景的合理取舍。免费开源的AI软件 不在单机版搞复杂 RBAC，把简单留给用户。chayuan-desktop 的 当前身份 = 全部 + 应用级 scope 模型让权限管理简单又灵活。复杂场景给 chayuan-server。
