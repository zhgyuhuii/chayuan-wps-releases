# 模型对比的字段口径 哪些指标在网关层就能给出

chayuan-desktop 桌面单机版的模型网关层能给出一部分模型对比指标，无需跑评测。这一篇讲。

## 网关层能给的指标

字段一：上下文长度。从模型卡片直接读 context_window。

字段二：max_output。从模型卡片读 max_output。

字段三：定价。input/output 单价。

字段四：响应延迟（首 token 延迟）。chayuan-desktop 历次请求的实测平均。

字段五：请求成功率。最近 100 次请求的成功率。

字段六：能力标签。是否支持 tools / vision / streaming / reasoning。

字段七：类别。chat / embed / image / rerank。

字段八：厂商。openai / anthropic / qwen 等。

这些不需要跑评测就能填。

## 网关层不能给的指标

需要评测才能给的指标。

质量分（MMLU、HellaSwag、GSM8K 等基准）。

中文能力分（C-Eval、CMMLU 等）。

代码能力分（HumanEval、MBPP）。

任务特定 ELO 评分（chayuan-desktop 的 Arena 给）。

幻觉率。

工具调用准确率。

这些走 chayuan-desktop 的 Arena 模块（专门评测）。模型卡片里能存评测结果的引用，但实际数据来自评测系统。

## 实测延迟的计算

chayuan-desktop 每次请求记录。

第一字延迟（TTFT）。从请求发出到第一个 token 返回的毫秒数。

每秒 token 速率（TPS）。流式中每秒平均输出多少 token。

总延迟。从请求到完整返回的毫秒数。

按模型分组聚合，取最近 100 次的平均。

## 实测成功率

成功定义。HTTP 200 + 非空 content。

失败包含。429、5xx、timeout、空响应等。

按模型分组算 100 次的成功比例。

## 模型对比页

设置 - 模型 - 对比。选择 2-4 个模型，并列展示。

```
| 字段        | gpt-4o    | claude-3.5 | qwen-plus |
| 上下文      | 128k      | 200k       | 32k       |
| 输入定价    | $2.5/M    | $3.0/M     | ¥0.4/M    |
| 输出定价    | $10/M     | $15/M      | ¥1.2/M    |
| 首字延迟    | 0.8s      | 1.2s       | 0.5s      |
| 成功率      | 99.5%     | 99.2%      | 98.8%     |
| 视觉支持    | 是        | 是         | 否        |
| Tools 支持  | 是        | 是         | 是        |
```

让用户基于实际指标选择。

## 评测结果的引入

chayuan-desktop 的 Arena 跑过的模型，对比页能展示 ELO 评分（用户盲评的 Bradley-Terry 排名）。

外部评测（C-Eval 官方榜）的结果作为参考链接，不直接展示数字（因为评测时点不同）。

## 用户主观评分

聊天界面每个回答下有 👍 👎 按钮（显示为文字 满意 不满意）。

这些主观评分按模型聚合。对比页能看到 用户主观满意度 字段。

## 对比的局限

不同任务最优模型不同。简单 chat gpt-4o 强，长文写作 claude 强，中文小语种 qwen 强。chayuan-desktop 的对比页只是数字，最终选择仍取决于用户实际任务。

chayuan-desktop 推荐 跑一两个真实任务再决策，不只看对比表。

## 国产化场景

政企用户对比国产模型时关心 国产 标签、合规备案、本地部署能力。chayuan-desktop 对比页有这些字段。

国产模型对比中文能力（C-Eval）特别有意义。chayuan-desktop 引用官方榜单数据。

## chayuan-server 的对应

chayuan-server 多用户场景下能聚合企业内所有用户的实测数据，得到更准的模型对比。chayuan-desktop 单机只能用本人的数据。

## WPS 加载项

chayuan-wps 在 WPS 里挑模型时按 chayuan-desktop 对比页的字段排序。员工能选 当前最快 或 最便宜 或 最准。

## 总结

模型对比的字段口径是 chayuan-desktop 在选模型决策上的工程支持。免费开源的AI软件 让用户基于数据选模型而不是靠厂商宣传。chayuan-desktop 的网关层指标 + Arena 评测 + 用户主观评分构成完整对比体系。
