# 默认模型按类别自动提升候选

chayuan-desktop 桌面单机版的 默认模型 概念让用户不用每次手动选。这一篇讲清楚默认模型的策略。

先看默认模型的几种类别。

chat 默认：对话用什么模型。

embedding 默认：嵌入计算用什么模型。

image 默认：图像生成用什么模型。

vision 默认：视觉对话（看图）用什么模型。

rerank 默认：重排用什么模型。

reasoning 默认：深度思考（o1、R1）用什么模型。

audio 默认：语音转文本用什么。

每个类别有自己的默认值。

自动提升候选的逻辑。

逻辑一：用户首次配置模型供应商时。chayuan-desktop 把用户配的第一个模型按类别设为默认。比如用户填了 OpenAI key，第一个 chat 模型 gpt-4o 自动成 chat 默认。

逻辑二：用户配置多个供应商。每次用户配新供应商，chayuan-desktop 比较新模型跟当前默认。如果新模型在 模型卡片库 里被标记为 优于 当前默认（比如更新版本），自动提升新模型。

逻辑三：手动设置。用户在设置里能 强制 默认某个模型。强制设置后自动提升不再覆盖。

类别归类。

文档对话主要用 chat 默认。

文档 RAG 入库用 embedding 默认。

模型对抗 arena 把多个 chat 模型并联。

视觉对话用 vision 默认。

复杂推理（链式思考）选 reasoning 模型。

跨类别协作。一次问答可能涉及多个类别。比如视觉对话先识别图片（vision）再 RAG 检索（embedding）再生成答案（chat）。chayuan-desktop 按需调对应默认模型。

默认模型的展示。前端在对话界面显示当前 chat 默认（用户能切）。其他类别的默认在内部使用，前端不直接显示。

切换默认的几种 UI。

UI 一：对话界面顶部模型选择器。改 chat 默认。

UI 二：设置 - 模型供应商 - 默认设置。可以一次设所有类别的默认。

UI 三：KB 设置 - 高级。某些 KB 可以指定专属 chat 模型（覆盖全局默认）。

实例。用户的 chayuan-desktop。

OpenAI 配好。

DeepSeek 配好。

Anthropic 配好。

智谱配好。

chat 默认。chayuan-desktop 选 deepseek-chat（用户偏好国产 + 低成本）。

embedding 默认。bge-m3-onnx（本地，零成本）。

vision 默认。gpt-4o（自动识别 vision 类）。

reasoning 默认。deepseek-reasoner（深度思考国产模型）。

不同 KB 的特殊默认。

doc:技术资料 KB 默认 chat 用 deepseek-chat（写技术内容好）。

office:zhangsan:legal KB 默认 chat 用 claude-3.5-sonnet（法律推理强）。

这种 per-KB 默认 让 一个 chayuan-desktop 同时服务多种场景。

如果默认模型不可用。比如 OpenAI 限速或账户欠费。chayuan-desktop 的 fallback 链路自动切到下一个可用模型。用户感知不到。

国产化支持下的默认。完全国产化场景下默认链路。

chat：deepseek-chat 或 qwen-max（国产）。

embedding：bge-m3-onnx（国产开源，本地）。

reasoning：deepseek-reasoner（国产）。

vision：qwen-vl-max（国产）。

整套默认完全不依赖海外厂商。

WPS AI 插件 chayuan-wps 共用 chayuan-desktop 的默认设置。在 WPS 里发起对话时按全局默认走，除非用户在加载项里临时切换。

默认模型按类别自动提升候选是 chayuan-desktop 用户体验的细节。免费开源的AI软件 不让用户每次都手动选模型，自动化默认让常规使用流畅。chayuan-desktop 的策略让 默认 这件事既智能又可控。
