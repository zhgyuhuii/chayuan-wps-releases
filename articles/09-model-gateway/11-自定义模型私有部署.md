# 自定义模型 OpenAI 兼容协议下的私有部署接入

chayuan-desktop 桌面单机版的模型网关支持接入任意 OpenAI 兼容协议的私有部署模型。这一篇讲。

## 私有部署的场景

场景一。公司内部部署 vLLM 跑 Qwen-72B，不出公司局域网。员工电脑想接入。

场景二。家庭服务器跑 Ollama 或 LM Studio。想从笔记本远程使用。

场景三。云上自部署 inference 服务（runpod、vast.ai）。

场景四。开源项目自架（FastChat、Text Generation WebUI）。

这些都需要 chayuan-desktop 接入。

## OpenAI 兼容协议

业界事实标准。POST /v1/chat/completions 接受 messages/model/temperature/stream 等字段。返回 choices/usage 字段。

vLLM、Ollama、LM Studio、FastChat 等开源框架都支持这个协议。

chayuan-desktop 对 OpenAI 兼容的请求方完全统一处理。所有这些后端在 chayuan-desktop 看来都是 OpenAI 兼容厂商。

## 配置方式

chayuan-desktop 设置 - 模型 - 添加自定义厂商。

```
name: 公司内部 vLLM
base_url: http://10.0.0.5:8000/v1
api_key: dummy-or-real
type: openai_compatible
```

base_url 填私有部署地址。api_key 如果服务端不校验填 dummy 即可。

## 模型探测

chayuan-desktop 调 base_url + /v1/models 拉模型列表。

```json
{
  "data": [
    {"id": "qwen-72b", "object": "model"},
    {"id": "deepseek-v2", "object": "model"}
  ]
}
```

把这些模型加入 chayuan-desktop 模型列表，归入对应类别（chat / embed 等）。

## 模型类别推断

私有部署的模型 ID 通常不规范。chayuan-desktop 按 ID 关键词推断。

```
qwen-72b → chat
qwen-vl → image
bge-m3 → embed
```

推断不准时用户能手动指认类别。chayuan-desktop 设置里能编辑每个模型的类别。

## 上下文长度

OpenAI 兼容协议没规定怎么报告上下文长度。chayuan-desktop 默认假设 4096。如果用户知道实际是 32k 或 128k 能在配置里覆盖。

```
qwen-72b:
  context_window: 32768
```

错误的上下文长度会导致 chayuan-desktop 截断输入或厂商报错 token 超限。

## 流式支持检测

并非所有 OpenAI 兼容服务都实现流式。chayuan-desktop 第一次请求时探测流式支持，存到模型卡片。后续请求按支持情况调用流式或非流式。

探测方法。stream=true 请求，看返回是 SSE 还是一次性 JSON。

## tools 调用支持

工具调用（function calling）是 OpenAI 比较新的扩展。私有部署里支持的不多。chayuan-desktop 默认假设不支持，工具调用走文本协议替代。

某些模型（DeepSeek-V2、Qwen-2.5）支持原生 tools，chayuan-desktop 配置里能开启。

## 自签证书

私有部署常用自签 HTTPS 证书。Tauri 默认拒绝。chayuan-desktop 设置里能 信任自签证书 把证书指纹填进去。或者关闭证书校验（不推荐）。

## 鉴权方式

OpenAI 是 Bearer Token。其他可能是 Basic Auth、x-api-key header。chayuan-desktop 配置里能选鉴权方式或自定义 header。

## 国产化场景

政企内部部署国产大模型（千问、文心、豆包等）走 OpenAI 兼容协议是主流。chayuan-desktop 直接支持接入。员工电脑装 chayuan-desktop 就能用公司内部模型。

## chayuan-server 的对应

chayuan-server 模式下私有部署接入更精细（认证、配额、审计）。chayuan-desktop 单机版简化但够用。

## WPS 加载项

chayuan-wps 在 WPS 里能选私有部署模型。员工写报告时选 公司 vLLM-Qwen-72B 走内网推理，不出公司。

## 总结

自定义模型私有部署接入是 chayuan-desktop 在企业场景的核心能力。免费开源的AI软件 让用户接入自己的模型而不只是 SaaS 厂商。chayuan-desktop 的 OpenAI 兼容协议封装让 私有部署 是 一行 base_url 的事。
