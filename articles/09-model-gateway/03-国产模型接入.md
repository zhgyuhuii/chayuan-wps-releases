# 国产化支持下接入文心通义智谱豆包的实操

chayuan-desktop 桌面单机版默认接入主要国产 LLM 厂商。这一篇讲怎么配各家。

第一家：文心一言（百度）。

申请。百度智能云开通 ERNIE Bot 服务，拿 API Key 和 Secret Key。

配置。chayuan-desktop 设置 - 模型供应商 - 新建 - 文心一言。填 API Key、Secret Key（百度的认证比较特殊，需要 Key+Secret 两段）。

可用模型。ernie-4.0-turbo、ernie-3.5、ernie-speed 等。

第二家：通义千问（阿里）。

申请。阿里云开通 DashScope 服务，拿 API Key。

配置。chayuan-desktop 选 通义千问 类型。填 API Key。

可用模型。qwen-max、qwen-plus、qwen-turbo、qwen-long、qwen-vl-max 等。

第三家：智谱清言。

申请。智谱清言开发者平台开通，拿 API Key。

配置。chayuan-desktop 选 智谱 类型。填 API Key。

可用模型。glm-4-plus、glm-4-flash、glm-4v、glm-3-turbo 等。

第四家：豆包（字节）。

申请。火山引擎开通豆包 API，拿 API Key 和 endpoint id。

配置。chayuan-desktop 选 豆包 类型。填 API Key、endpoint id。

可用模型。Doubao-pro、Doubao-lite、Doubao-vision 等。

第五家：DeepSeek。

申请。DeepSeek 开发者平台拿 API Key。

配置。chayuan-desktop 选 DeepSeek 类型或者 OpenAI 兼容路由（DeepSeek 用 OpenAI 协议）。base URL https://api.deepseek.com/v1。

可用模型。deepseek-chat、deepseek-coder、deepseek-reasoner 等。

第六家：Moonshot（Kimi）。

申请。Moonshot 平台拿 API Key。

配置。OpenAI 兼容路由。base URL https://api.moonshot.cn/v1。

可用模型。moonshot-v1-8k、moonshot-v1-32k、moonshot-v1-128k。

第七家：Yi（零一万物）。

申请。零一万物平台拿 API Key。

配置。OpenAI 兼容路由。base URL https://api.lingyiwanwu.com/v1。

可用模型。yi-large、yi-medium、yi-vision 等。

第八家：Minimax。

申请。Minimax 平台拿 API Key。

配置。专门 adapter（不是标准 OpenAI 协议）。chayuan-desktop 处理协议差异。

可用模型。abab6.5、abab6.5s 等。

通用流程。

第一步：在厂商平台开账户、充值（多数有免费额度试用）。

第二步：拿到 API key（复制保存好）。

第三步：在 chayuan-desktop 设置里新建供应商，选对应类型。

第四步：填 API key（chayuan-desktop 用 Stronghold 加密存）。

第五步：测试连接。chayuan-desktop 自动探测 /v1/models 列表。

第六步：选默认模型。每个类别（chat、embed、image 等）选一个默认。

WPS AI 插件 chayuan-wps 共用同一份模型供应商配置。在 WPS 里发起对话时直接用配置好的厂商。

国产模型的优势。

价格通常比 OpenAI/Anthropic 便宜（几分之一）。

中文场景表现优秀。

国产化合规。

延迟低（国内访问国内节点）。

劣势。

某些复杂推理任务可能稍弱于 GPT-4o / Claude-3。

国产模型接入是 chayuan-desktop 全模型支持的核心组成。免费开源的AI软件 把国产生态做齐，国产化场景才能完整落地。chayuan-desktop 在这一面的覆盖让 不靠海外厂商就能干活 这件事真的可行。
