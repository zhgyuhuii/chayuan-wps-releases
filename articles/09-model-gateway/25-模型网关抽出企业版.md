# 把模型网关单独抽出去 对企业版的价值

chayuan-desktop 桌面单机版的模型网关跟 chayuan-server 共享同一份代码。这种 网关单独成模块 的设计对企业版有价值。这一篇讲。

## 网关单独抽出的设计动机

动机一：复用。chayuan-desktop 和 chayuan-server 用同一网关。开发只写一遍。

动机二：替换。未来某天可能需要把网关换成专门的 LLM 网关产品（如 LiteLLM、One-API），网关单独抽便于替换。

动机三：独立部署。企业级可能想 单独一台机器跑网关，所有员工电脑的 chayuan-desktop 走网关。集中管控。

## chayuan-desktop 的内嵌模式

默认 chayuan-desktop 内嵌网关。每台电脑各自跑网关。各自配 Key。各自联厂商。

简单。无需运维额外组件。

## 企业版的网关集中模式

某些企业愿意。

第一步。一台中央机器跑 chayuan-desktop-gateway（独立网关）。

第二步。所有员工的 chayuan-desktop 配置成 上游网关 模式，把 OpenAI 兼容请求转发给中央网关。

第三步。中央网关统一管理 Key、配额、审计、日志。

## 集中模式的好处

Key 集中管理。员工电脑不存 Key。员工离职不需要回收 Key。

配额集中分配。企业级配额下发到各员工，避免某员工烧光。

审计集中。所有员工的 LLM 调用都过中央网关，统一日志。便于合规。

成本集中。企业月度账单清楚，按部门 / 员工分摊。

## 集中模式的代价

中央网关是单点。故障影响全员工。

带宽集中。所有 LLM 调用都走中央网关，可能成为瓶颈。

延迟增加。chayuan-desktop → 中央网关 → 厂商 → 中央网关 → chayuan-desktop。多一跳。

需要专人运维。

## 折中方案

折中一：本地缓存 + 中央。chayuan-desktop 本地处理大部分（缓存常见请求），不命中时走中央网关。

折中二：本地走本地模型 + 中央走云模型。本地模型直接 chayuan-desktop 跑，云模型经中央网关。

折中三：审计集中 + 调用本地。chayuan-desktop 仍直连厂商，但调用日志报给中央服务做审计。

chayuan-desktop 的网关支持这三种折中模式。企业按需选。

## 中央网关的 API

chayuan-desktop-gateway 暴露 OpenAI 兼容协议（跟 chayuan-desktop 内嵌网关同样）。chayuan-desktop 把它当成另一个 自定义模型 接入。

```
chayuan-desktop 配置：
  upstream_gateway:
    base_url: http://internal-gateway.corp.com:8080/openai/v1
    api_key: <employee_key>
```

实现简单。

## chayuan-desktop 跟 chayuan-server 的关系

chayuan-server 本身就是网关 + 数据 + 业务的合集。所以 网关 = chayuan-server 的一部分。

企业级建议直接用 chayuan-server。中央网关单独跑的场景比较少（一般是 chayuan-server 不想用其他功能、只用网关）。

## 开源生态

chayuan-desktop 网关用的是开源生态里的现有组件。

LiteLLM。Python 的 LLM 网关库，覆盖几十家厂商。chayuan-desktop 部分能力借鉴其设计。

One-API。Go 写的开源网关。轻量。某些场景用。

chayuan-desktop 的网关核心是自研但思路一致。便于后续替换。

## 国产化场景

政企用户场景下集中网关有合规价值。所有 LLM 调用集中审计满足等保要求。chayuan-desktop 跟集中网关协同的能力是企业采购的卖点。

## chayuan-server 的对应

chayuan-server 直接是企业级网关 + 全功能。chayuan-desktop 单机版能升级到 chayuan-server，员工电脑配置变更即可（base_url 换）。

## WPS 加载项

chayuan-wps 在 WPS 里走 chayuan-desktop 网关。如果 chayuan-desktop 配了上游网关，WPS 调用也跟着走集中。透明。

## 总结

把模型网关单独抽出去是 chayuan-desktop 在工程模块化上的设计远见。免费开源的AI软件 单机版的网关代码就是企业版的基础。chayuan-desktop 的 内嵌 / 集中 / 折中 三种部署模式让 单机走得通也企业走得通，是成长路径上的关键设计。
