# 全模型支持是个什么概念 18家厂商的统一网关

chayuan-desktop 桌面单机版的 全模型支持 是把 18 家以上 LLM 厂商在一个统一接口背后抹平。这一篇讲清楚网关层的覆盖。

接入的厂商列表。

国际厂商。OpenAI、Anthropic、Google（Gemini）、Mistral、Meta（Llama API）、Cohere、AI21、Together AI、Groq。

国内厂商。文心一言（百度）、通义千问（阿里）、智谱清言、豆包（字节）、DeepSeek、Moonshot（Kimi）、Yi（零一万物）、商汤、讯飞星火、Minimax、阶跃星辰。

加起来 18+。每家有自己的 API 协议、错误码、限速规则、模型分类。

统一接口的价值。

价值一：用户不用懂每家差异。在 chayuan-desktop 设置里填 base URL 加 API key。剩下的 chayuan-desktop 自己处理。

价值二：模型对抗多泳道。多个厂商的模型并行调用，前面 arena 文章讲过。

价值三：成本和性能比较。不同厂商在不同任务上表现不同，统一调用方便对比。

价值四：避免 vendor lock-in。某家厂商 API 变化，chayuan-desktop 在 adapter 层适配，业务代码不动。

OpenAI 兼容路由。chayuan-desktop 提供 /openai/v1/* 路径，让用户用 OpenAI 官方 SDK 直接连本机 chayuan-desktop。这种 把 chayuan-desktop 当 OpenAI 用 让现有 LLM 应用代码无缝迁移。

新厂商接入的流程。chayuan-desktop 的网关 adapter 设计让新增厂商容易。一个 adapter 大约 200-500 行 Python，包括协议翻译、错误处理、流式归一化。

用户视角。在设置 - 模型供应商 - 新建。选厂商类型（或者通用 OpenAI 兼容）。填 base URL、API key、其他必要信息。chayuan-desktop 自动探测可用模型。

模型自动探测。chayuan-desktop 调厂商的 /v1/models 接口拿模型列表，按规则归类（chat / embedding / image / rerank / vision）。归类的模型直接出现在前端选择器里。

WPS AI 插件 chayuan-wps 共用同一份网关。在 WPS 里发起对话时不感知背后哪家。

18 家厂商的统一网关是 chayuan-desktop 全模型支持 的工程基础。免费开源的AI软件 把多厂商抽象成同一接口，用户不用为每家模型学一遍 API。这是 chayuan-desktop 给用户的实在价值。
