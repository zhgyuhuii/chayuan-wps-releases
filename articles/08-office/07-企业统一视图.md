# 企业库的统一视图 多人单机的合并方案

某些政企客户的需求是 多个员工各自在自己电脑上用 chayuan-desktop 桌面单机版，但部门级别有一份 共享视图。这一篇讲多人单机场景下的合并方案。

场景。一个 50 人的部门。每个员工电脑装 chayuan-desktop。各自有自己的 office:zhangsan 个人库。但部门希望有一个 部门资料库 让所有员工都看到。

挑战。chayuan-desktop 是单机版，每个员工的 CHAYUAN_ROOT 物理隔离。怎么有 共享视图。

方案一：NAS 共享目录 + folder-sync。

部门级共享 NAS 上有一个 部门资料 目录（HR 维护）。

每个员工的 chayuan-desktop 用 folder-sync 同步这个 NAS 目录到自己的 office:dept_X KB。

每个员工本地有 part of dept_X 的索引。

新增的部门资料各员工自动同步到本地 KB。

删除的部门资料各员工同步删除（30 天软删后真删）。

优势。简单。零依赖额外服务。每个员工本地索引。

劣势。NAS 文件读权限要正确配。某些 NAS 不挂载在所有员工电脑。

方案二：定期 export/import。

部门管理员维护一台 master chayuan-desktop。给 office:dept_X 灌部门资料。

每周或每月用 export 工具导出一个 zip 包。

通过邮件、IM、内部网盘分发给员工。

员工 import 到自己的 chayuan-desktop。

优势。完全可控。每次更新人工选什么发。

劣势。频率低。人工操作。可能出现版本不一致。

方案三：内网 chayuan-server。

部门服务器装 chayuan-server 多用户版。

员工的 chayuan-desktop 客户端连远程 sidecar（Tauri 配置改成 external sidecar）。

部门级 KB 在 chayuan-server 上集中管理。

员工的个人 KB 在自己电脑上（如果分开）或在 chayuan-server 上（统一）。

优势。真共享。集中维护。版本一致。

劣势。需要部署多用户版服务。

方案四：Git/SVN 同步。

部门资料放 git 仓库。

每个员工 git pull 到本地某个目录。

chayuan-desktop folder-sync 这个目录到 office:dept_X KB。

优势。版本控制好。能审计变更。

劣势。员工要懂 git（或者用 GUI 客户端）。

什么场景选哪个。

20 人以下小部门。方案一 NAS 同步合适。简单可靠。

20-100 人中部门。方案三多用户版合适。集中管理。

100 人以上大部门。方案三必选。或者考虑分多个小部门各自方案一。

合规严格场景。方案三 + 审计完整。等保合规需要中央审计。

跨电脑同步个人 KB。员工在工作笔记本跟家用台式都装 chayuan-desktop，希望 office:zhangsan 同步。chayuan-desktop 当前不内置 P2P 同步。可以走方案二（手动 export/import）或自家 syncthing 同步 CHAYUAN_ROOT 子目录。

WPS AI 插件 chayuan-wps 在不同方案下行为一致。员工在 WPS 写报告查 office:dept_X KB，背后是哪种同步方案对加载项透明。

企业级统一视图的多人单机方案是 chayuan-desktop 给政企客户的灵活选项。免费开源的AI软件 不强求一种部署形态，按客户实际需要选。chayuan-desktop 的 NAS / export / 多用户 三条路径让 共享 这件事在不同规模都可达。
