# 国产化支持下的政企三层 部门项目组个人

政企组织有典型的层级结构。chayuan-desktop 桌面单机版的 office:* 命名空间映射到这种结构。这一篇讲政企三层的具体配置。

政企组织典型结构。

最上层：单位/公司。

中间层：部门 / 处室 / 司局。

下层：团队 / 项目组 / 课题组。

最下层：个人。

每层都有自己的资料。资料按密级分公开、内部、敏感、机密。

chayuan-desktop 的命名映射。

最上层资料：doc:public。所有员工可见。这一层用 doc:* 命名空间，不限定 owner。

部门资料：office:dept_X。比如 office:dept_finance、office:dept_legal、office:dept_research。部门成员可见。

部门下小组资料：office:dept_X:team_Y。比如 office:dept_finance:team_audit、office:dept_research:project_A。组成员可见。

个人资料：office:owner_name。每个员工自己的私有库。比如 office:zhangsan、office:lisi。

个人下分组：office:owner:group。员工自己的进一步分类。比如 office:zhangsan:work、office:zhangsan:personal。

权限矩阵。

公开资料：所有员工。

部门资料：本部门员工。office:dept_finance 只对财务部成员可见。

小组资料：组成员。office:dept_finance:team_audit 只对审计组成员可见。

个人资料：本人。office:zhangsan 只对 zhangsan 可见。

具体场景。

场景一：律师事务所。

doc:firm_public 公开资料（所有员工）。

office:dept_litigation 诉讼部资料。

office:dept_corporate 公司部资料。

office:dept_litigation:team_a 诉讼部 A 组。

office:lawyer_zhang 律师张三个人。

office:lawyer_zhang:case_2026_001 律师张三某个具体案件。

场景二：政府机关。

doc:agency_public 单位公开资料。

office:dept_general 综合处。

office:dept_legal 法规处。

office:dept_legal:section_review 法规处审查科。

office:user_zhangsan 某员工个人。

权限实施。

单机版。每个员工自己的 chayuan-desktop 上 owner 默认是当前 OS 用户。能看到 office:owner_name 和 office:owner_name:* 下面的 KB。其他 owner 的 KB 默认看不到（通过 RBAC 模拟）。

多用户版。chayuan-server 的 governance 模块按身份认证 + RBAC 严格控制。office:dept_X 对应的访问列表跟 IT 的人员管理系统对接。员工调动到新部门后访问权限自动跟着变。

部门资料的同步。某些场景部门资料是物理共享的（NAS 上一个目录）。chayuan-desktop 的 folder-sync 让 office:dept_X KB 持续同步那个目录。新增文件自动入库。

跨层级访问。

上级看下级。某些情况领导能看部门下所有组的资料。chayuan-desktop 多用户版支持配置 上级权限继承。

跨部门看不到。office:dept_finance 严格不让法务部成员看。

公开资料能升级。某份资料从 office:dept_finance 提升为 doc:public。chayuan-desktop 通过 KB 重命名 + ku_id 调整实现。

实施挑战。

挑战一：OS 用户跟身份系统映射。某些客户的 OS 用户不是真名（比如 user001），需要映射到身份系统。chayuan-desktop 支持配置 OS user → 身份 user 映射规则。

挑战二：人员变动。员工换部门，权限要跟着改。chayuan-desktop 支持从 LDAP/AD 同步身份和权限。

挑战三：审计。每次访问 office:* KB 写到 audit_log。审计员定期看 谁访问了什么。

国产化支持下的政企三层。中文命名（office:财务处:审计科）都支持。chayuan-desktop 在国产 OS（麒麟 UOS）上的多用户配合 PAM 认证。

WPS AI 插件 chayuan-wps 在政企场景下尤其重要。员工在 WPS 里写公文调起加载项，按身份过滤可见 KB。引用气泡严格按密级展示。

政企三层设计是 chayuan-desktop 在政企赛道的核心能力。免费开源的AI软件 想服务多人组织，组织结构的 native 支持是基本素质。chayuan-desktop 的命名空间体系跟政企组织契合好。
