# 国产化支持下的表与列白名单 多租户场景的最小可见集

chayuan-desktop 桌面单机版的 text2sql 安全模型核心是白名单：哪些表、哪些列允许 LLM 看到。这一篇讲白名单的设计和实操。

先看白名单为什么必要。生产数据库里有大量敏感信息：用户密码、身份证、手机号、银行卡、健康记录、财务数据。让 LLM 任意访问这些是合规灾难。白名单让用户主动决定 LLM 能看到什么。

表白名单。chayuan-desktop 在创建结构化 KB 时让用户从所有表里勾选哪些纳入。默认全不选，用户主动加。每个加进白名单的表都会在 KB 元数据里记录。

列白名单。每张白名单的表，列是次级粒度。用户能进一步勾选哪些列对 LLM 可见。比如 users 表纳入白名单，但 password_hash、id_card、phone 这三列不勾。LLM 在 schema linking 时看不到这三列。

schema linking 的实际行为。LLM 拿 query 想 怎么写 SQL，前提是知道有哪些表哪些列。chayuan-desktop 把白名单内容作为 schema 提示给 LLM。比如 表 users 字段 id, name, email, created_at（不含 password_hash, phone）。LLM 在生成 SQL 时只能用看到的字段。

如果 LLM 写 SQL 时硬要用 password_hash。AST 校验阶段会发现 password_hash 不在白名单，拒绝执行。这种 LLM 提示 + 执行校验 双层防护让敏感字段绝对不会被查到。

PII 自动识别。chayuan-desktop 在创建 KB 时扫描每张表的列名，对常见 PII 字段名自动建议不勾。比如包含 password、id_card、phone、email、address 这种字段名给提示 这是潜在 PII，建议不加白名单。

白名单的细粒度。

表级白名单。最粗粒度。整张表加进白名单。

列级白名单。中粒度。表加进白名单 + 哪些列可见。

行级白名单。最细粒度。哪些行的数据可以被查询。chayuan-desktop 当前不支持行级白名单（这是企业版能力）。如果需要，用户可以在 KB 创建时给一个 WHERE 子句作为 行过滤条件，LLM 生成的 SQL 自动加这个条件。

多租户场景的白名单。如果一台 chayuan-server 给多个用户用，每个用户可能看到不同表/列。chayuan-desktop 单机版没有用户概念，白名单是 KB 级别的。多用户版下白名单可以加 user_id 字段做隔离。

业务字段的脱敏。某些字段不能完全隐藏（比如手机号在客服场景需要部分可见）。chayuan-desktop 提供 字段脱敏 选项：列加进白名单，但读出来的值经过 mask 处理（13800001234 → 138****1234）。这种 部分可见 让业务能用同时保护隐私。

白名单的演化。KB 建好后白名单可以改。新增表、新增列时进 KB 设置加进白名单。撤销时从白名单删除。变更立刻生效。

白名单的审计。每次白名单变更写到 audit_log。这种记录在等保合规场景下是必要的。

白名单的脱敏例子。

users 表。白名单：id、username、created_at、status。不白名单：password_hash、id_card、phone、email。

orders 表。白名单：order_id、user_id、product_name、amount、created_at。不白名单：注释栏（可能含敏感信息）。

employees 表。白名单：employee_id、department、role、hire_date。不白名单：salary、social_security、emergency_contact。

国产化支持下的白名单。政府公文常涉及敏感字段（人员姓名、身份证号、家庭信息）。chayuan-desktop 的白名单机制让这些字段在 LLM 视野外。结合等保合规要求，白名单是必备工具。

错误处理。如果 LLM 因为白名单缺字段无法生成 SQL（用户问的事情确实需要那个字段），chayuan-desktop 会告诉用户 该问题需要访问 phone 字段，但当前 KB 的安全策略不允许。用户决定是否调整白名单。

国产数据库的白名单。达梦、金仓、Doris 的白名单机制跟 PG/MySQL 一致。chayuan-desktop 不区分数据库类型。

WPS AI 插件 chayuan-wps 在加载项里发起结构化查询同样受白名单约束。在 WPS 里写报告时不会因为加载项 用户身份不同 就拿到敏感字段。

表与列白名单是 chayuan-desktop text2sql 的合规底盘。免费开源的AI软件 想真正服务政企客户，白名单这种细粒度安全控制是基本能力。chayuan-desktop 在这一面比通用 AI 客户端深得多。
