# 结构化数据问答的完整端到端 一个客户案例

这一篇用一个真实风格的客户案例讲清楚 chayuan-desktop 桌面单机版的结构化 KB 在实际场景下怎么用。

客户背景。某省级公积金管理中心。员工约 200 人，主要业务系统在内部数据库（达梦 DM 集群）。员工日常需要查询公积金缴存数据、贷款数据、提取记录等。原工作流是问 IT 写 SQL 出报表，IT 一周出几十份报表，瓶颈明显。

需求。让普通业务员工能用自然语言查 公积金数据，无需写 SQL，无需联网。要求数据完全留在内网。

方案。chayuan-desktop 桌面单机版部署到员工电脑。chayuan-server 内嵌 sidecar 起来。接入达梦 DM 业务库（src:dm_provident）。配本地 Ollama 跑 DeepSeek-V3 7B（完全离线推理）。WPS Office 装好 chayuan-wps 加载项。

部署。

第一步。员工电脑装 chayuan-desktop（麒麟 UOS 版本，aarch64 架构）。

第二步。FirstRunSetup 选 CHAYUAN_ROOT 在 /home/user/chayuan。

第三步。配模型供应商。OpenAI 兼容路由指向内网部署的 Ollama 服务（http://10.0.x.x:11434/v1）。

第四步。建结构化 KB。src:dm_provident。填达梦 DM 连接信息。选业务表（缴存表、贷款表、提取表、用户表）。配字段白名单（敏感字段如身份证号设为 PII 默认 mask）。

第五步。装 chayuan-wps 加载项。配 服务器地址 = http://127.0.0.1:62581，认证 = none。

第六步。培训员工 5 分钟用法演示。

实际使用。员工的问题示例。

问题一：上个月本市的公积金缴存总额。chayuan-desktop 走 text2sql。生成 SELECT SUM(amount) FROM 缴存表 WHERE 月份 = '2026-04' AND 城市 = '本市'。30ms 跑完，返回 1234567890 元。LLM 总结：上个月本市公积金缴存总额是 12.34 亿元，比上月增长 X%。

问题二：贷款逾期的人数。SQL 生成 SELECT COUNT(*) FROM 贷款表 WHERE 状态 = '逾期'。返回 156。LLM 总结：当前贷款逾期人数为 156 人。

问题三：按行业分组的缴存额。SQL 生成 SELECT 行业, SUM(amount) FROM 缴存表 WHERE 月份 = '2026-04' GROUP BY 行业。返回 12 行结果。LLM 总结：上个月各行业缴存额排名前三的是 制造业、建筑业、信息技术业。

问题四：在 WPS 里写月度分析报告。员工新建 WPS 文档，调起 chayuan-wps 加载项。问 上月各类业务的关键指标，加载项调起 sidecar 跑混合查询，返回结构化数据 + 自然语言总结。员工点 插入到文档 把 AI 生成的段落直接放进 WPS。整个分析报告写作时间从 4 小时缩到 30 分钟。

效果数据（实施后 3 个月）。

每周 IT 收到的取数请求从 100+ 降到 30+。

业务员工自助查询占总查询的 70%+。

报告写作平均时间从 4-6 小时降到 1 小时。

数据完全在内网，没出域。

技术指标。

平均响应时间 2-3 秒（含 LLM 总结）。

text2sql 准确率 88%（业务员工的常规问题）。

用户反馈。

正面：取数不再求人。报告写作变快。学了点 SQL 知识（看 chayuan-desktop 生成的 SQL）。

负面：复杂 query 偶尔失败。某些业务术语 LLM 不识别（需要给 KB 加注释）。模型生成偶尔慢（本地推理 GPU 资源紧）。

后续优化。

优化一：给 KB 加 业务术语词典 元数据。LLM 看到术语对应的字段更准。

优化二：把高频 query 转成模板。模板覆盖 50% 的 query，剩下走 LLM。

优化三：加 GPU 服务器。本地推理速度提升 5 倍。

优化四：审计模块上线。给合规部门月度报告。

成本对比。

旧方案。IT 写 SQL 工时 + 报表平台许可。

新方案。chayuan-desktop 部署一次（开源，无许可费）。Ollama 服务器（一次性硬件采购）。员工电脑（已有）。

新方案 ROI 在 6 个月内回本。

国产化支持下的优势。完全离线、用国产数据库、用国产 LLM、AGPL 开源可审计。这套组合让公积金中心的领导和合规部门都满意。

WPS AI 插件 chayuan-wps 在这个客户场景下是写报告的核心工具。员工在 WPS 文字里直接调起 AI，写出有数据支撑的分析报告。

端到端客户案例展示 chayuan-desktop 的实际价值。免费开源的AI软件 不只是工程项目，是真业务问题的解决方案。chayuan-desktop 在政企场景的能力综合是用一个案例就能说明白的。
