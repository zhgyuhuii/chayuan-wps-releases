# 国产化支持下的达梦DM连接 驱动配置与实操

达梦 DM 是国产数据库代表，政企客户里覆盖率高。chayuan-desktop 桌面单机版作为国产化适配的一部分原生支持达梦。这一篇讲怎么在 chayuan-desktop 上接入达梦数据库。

先看达梦的特征。商用国产数据库（武汉达梦），SQL 方言接近 SQL Server + Oracle 的混合。客户端协议私有，需要专门驱动。在政企信创清单里位置很高。

接入达梦需要的几样东西。

第一样：达梦的服务地址和端口。一般是 IP + 5236（默认端口）。

第二样：用户名和密码。达梦的用户管理跟 Oracle 类似，有 SYSDBA 这种系统用户和业务用户。chayuan-desktop 用业务用户连，不用 SYSDBA。

第三样：模式名（schema）。达梦默认 schema 跟用户名同名。指定查询的 schema 让 SQL 生成更精准。

第四样：达梦的 Python 驱动。chayuan-desktop 用 dmPython 这种官方 Python 驱动。PyInstaller 打包时附带。

接入步骤。

第一步：在 chayuan-desktop 设置进入 知识库管理 - 新建知识库。类型选 结构化数据 - 外部数据库 - 达梦 DM。

第二步：填连接信息。host、port、user、password、schema、database_name。chayuan-desktop 的连接表单按达梦规范展示字段。

第三步：测试连接。chayuan-desktop 用填的信息试连一次，确认能通。失败原因有：网络不通、用户名密码错、达梦服务没启动、防火墙拦了。每种错误有具体提示。

第四步：选择要接入的表。达梦库里可能有几十几百张表，chayuan-desktop 让用户选哪些表纳入 KB。安全考虑，默认不接全部，让用户主动选。

第五步：确认表的字段白名单。每张选中的表，chayuan-desktop 列出所有字段，让用户勾哪些字段可以让 LLM 看到（用于 schema linking）。敏感字段（密码 hash、密级、PII）不勾，避免泄露给 LLM。

第六步：建立 KB。chayuan-desktop 把连接配置和表白名单存到 src:dm_xxx 命名空间的 KB 元数据里。

第七步：测试。新建对话挑这个 KB，问一个简单问题验证 text2sql 能跑通。

实际跑的 SQL 例子。问 上个月销售总额。chayuan-desktop 生成 SELECT SUM(金额) FROM 销售表 WHERE 销售日期 BETWEEN ADD_DAYS(CURRENT_DATE, -30) AND CURRENT_DATE。AST 校验通过（只读、表在白名单），通过 dmPython 执行，返回数字。

达梦的几个特殊处理。

字符集。达梦默认 UTF-8 但有 GB18030 配置。chayuan-desktop 在连接时显式指定 UTF-8 避免乱码。如果数据库本身是 GB18030 模式，用户在连接配置里指定。

中文表名。达梦支持中文表名（双引号包起来）。chayuan-desktop 的 SQL 生成正确处理中文标识符。

ROWNUM 替代。达梦支持 SQL Server 的 TOP 也支持 Oracle 的 ROWNUM。chayuan-desktop 的 LLM prompt 推荐用 TOP（ANSI SQL 风格更通用）。

锁机制。达梦的事务隔离级别默认 READ COMMITTED。chayuan-desktop 的查询都是只读，不需要担心锁问题。

连接池。chayuan-desktop 用 SQLAlchemy 连接池管达梦连接。默认 pool_size 5，max_overflow 5。够单机版用。

性能。达梦在中等数据量（几百万行）上的查询性能不错。chayuan-desktop 给每次查询 30 秒超时，超过的话返回超时错。复杂跨表 JOIN 在大表上可能超时，建议用户限定 WHERE 条件。

国产化部署。政企内网部署达梦，chayuan-desktop 接入时的连接 IP 是内网 IP。完全离线的政企场景下达梦数据库 + chayuan-desktop sidecar + chayuan-wps 加载项三层全在内网，符合等保合规。

许可。达梦本身是商业软件，需要正式许可。chayuan-desktop 的接入是技术对接，不涉及达梦许可问题。用户需要先有合法的达梦实例。

WPS AI 插件 chayuan-wps 在政企财务场景下非常有用。员工在 WPS 文字写报告时调起加载项，挑 src:dm_finance KB 问销售数字，引用气泡显示 SQL 和结果。这种 WPS + 达梦 + 察元AI 的组合在政企里是核心工作流。

达梦 DM 接入是 chayuan-desktop 国产化支持的重要一环。免费开源的AI软件 想真服务政企客户，国产数据库的对接深度是关键。chayuan-desktop 在达梦上的支持已经覆盖政企日常使用。
