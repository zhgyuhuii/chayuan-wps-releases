# 本地离线知识库不只是文档 17种SQL方言的text2sql实测

很多人认为知识库就是文档 RAG。chayuan-desktop 桌面单机版的本地离线知识库 包含一类被忽视但很重要的形态：结构化数据库。这一篇讲清楚 chayuan-desktop 支持的 17 种 SQL 方言以及 text2sql 在每种方言上的实际表现。

先看支持的方言列表。

国际数据库。MySQL、PostgreSQL、Oracle、SQL Server、SQLite、ClickHouse、Hive、MongoDB（用 SQL 风格查询）、Elasticsearch（用 ES SQL）。

国产数据库。达梦 DM、金仓 KingbaseES、Doris、StarRocks、TiDB、OceanBase。

云数据库。阿里云 RDS、腾讯云 TDSQL、华为云 GaussDB（这些大多兼容标准 PG 或 MySQL 协议）。

加起来支持 17 种主流方言。chayuan-desktop 通过 SQLAlchemy 的 dialect 机制接入。

text2sql 的具体实现。

chayuan-desktop 的 text2sql 不是黑盒丢给 LLM。流程包括：意图识别（这是聚合查询还是查找查询）、schema linking（query 提到的字段对应到哪些表和列）、SQL 生成（让 LLM 写 SQL）、AST 解析（用 SQLGlot 解析 SQL）、安全校验（只读校验、白名单校验）、执行（用 SQLAlchemy connection）、结果验证（行数合理、字段类型对）、自然语言总结。

每种方言的 SQL 差异。

MySQL 的 LIMIT 跟 PostgreSQL 一样。Oracle 用 ROWNUM 或 FETCH FIRST。SQL Server 用 TOP。chayuan-desktop 在生成 SQL 时按方言用对应语法。

日期函数。MySQL 的 DATE_SUB、PG 的 INTERVAL、Oracle 的 ADD_MONTHS、达梦的 DATEADD（兼容 SQL Server）。chayuan-desktop 的 prompt 里给 LLM 提示当前方言名，让它写正确语法。

字符串拼接。MySQL 用 CONCAT，PG 用 ||，SQL Server 用 + 或 CONCAT。

类型转换。CAST 标准，但 PG 的 :: 简写、Oracle 的 TO_NUMBER 等各家有差异。

聚合函数。COUNT、SUM、AVG 标准。但 GROUP_CONCAT（MySQL）、STRING_AGG（PG/SQL Server）、LISTAGG（Oracle）的方言差异 chayuan-desktop 在生成时按方言走。

实测精度。chayuan-desktop 在内部测试集上跑 text2sql 准确率。

简单聚合（SUM、COUNT、AVG 单字段）：95%+ 命中。

带 WHERE 条件的查询：90%+ 命中。

多表 JOIN：80% 命中。

子查询和窗口函数：70% 命中。

复杂业务逻辑（多层嵌套）：50-60% 命中，需要人工修正。

国产数据库的精度。

达梦 DM。语法接近 SQL Server 加 Oracle 的混合体。chayuan-desktop 的 LLM prompt 给达梦专门的语法提示。简单查询命中率跟 MySQL 接近，复杂查询稍低。

金仓 KingbaseES。基于 Postgres 的国产化版本。语法跟 PG 高度兼容。chayuan-desktop 当 PG 处理基本能用。

Doris。OLAP 分析数据库，支持 MySQL 协议。SQL 大多 MySQL 兼容。

StarRocks。类似 Doris，MySQL 协议兼容。

TiDB。MySQL 协议高度兼容。

OceanBase。MySQL 模式兼容。

text2sql 失败的处理。chayuan-desktop 在 SQL 生成失败、校验失败、执行失败时给出诊断信息。错误类型分 schema linking 失败（没找到对应表）、SQL 语法错误、安全校验失败（含写操作）、执行错误（连接失败、超时）、结果异常（行数 0 或者字段类型错）。每种错误前端有友好提示。

CLAUDE.md 里的硬要求。结构化数据问题不应该退化成文档 RAG 让 LLM 编答案。chayuan-desktop 的 router 严格判定意图，聚合问题必须走 SQL 路径。

WPS AI 插件 chayuan-wps 在 WPS 表格里的应用。用户在 WPS 表格里写销售分析报告，加载项调起察元AI，挑 src:dm_finance KB，问 上个月华南销售额，返回 SQL + 数字 + 自然语言总结。这种 WPS 加载项 + 结构化 KB 的组合在政企财务场景下尤其有用。

17 种 SQL 方言的覆盖是 chayuan-desktop 在结构化数据这一面的工程深度。免费开源的AI软件 想真覆盖企业实际场景，多方言 SQL 能力是必须。chayuan-desktop 在这一点上比通用桌面 AI 客户端强很多。
