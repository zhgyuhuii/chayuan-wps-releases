# 17 种 SQL 方言 谁支持几个

chayuan-desktop 桌面单机版支持 17 种 SQL 方言。这一篇是对比。

## chayuan-desktop 支持

国际主流。

PostgreSQL、MySQL、SQLite、Oracle、SQL Server。

OLAP / 大数据。

Doris、ClickHouse、Hive、Trino、Presto。

NoSQL（部分）。

MongoDB、Elasticsearch（通过 SQL 接口）。

国产数据库。

达梦 DM、人大金仓 KingbaseES、神通、南大通用 GBase、OceanBase。

时序数据库。

InfluxDB（部分支持）。

共 17 种。

## 其他产品支持

| 产品 | SQL 方言数量 |
|---|---|
| chayuan-desktop | 17 |
| AnythingLLM | 0-1（基础 SQL） |
| Cherry Studio | 0 |
| 通义桌面 | 1（阿里 RDS） |
| 豆包 | 0 |
| Vanna AI | 5-10（专业 text2sql） |
| LangChain | 多（开发库，不是产品） |

chayuan-desktop 在产品中支持最广。

## 方言差异的处理

不同方言的差异。

LIMIT vs ROWNUM。

字符串拼接 || vs +。

时间函数（NOW / SYSDATE / CURRENT_TIMESTAMP）。

存储过程语法。

每方言有 chayuan-desktop 的 SQL 模板。

## text2sql 的多方言

LLM 生成 SQL 时 chayuan-desktop 在 prompt 里指定方言。

```
你是 SQL 专家。生成达梦数据库（DM）的 SQL。
注意 DM 兼容 Oracle 语法。
```

LLM 按方言生成。

## 校验的多方言

chayuan-desktop 的 SQL 校验器（前面文章讲）用 sqlglot 解析。

sqlglot 支持 17+ 方言解析。

```python
parsed = sqlglot.parse_one(sql, dialect='dm')
```

## 国产数据库的特殊适配

达梦：兼容 Oracle 90%+。chayuan-desktop 用 Oracle 模板加部分修改。

金仓：兼容 PostgreSQL 95%+。chayuan-desktop 用 PG 模板。

OceanBase：兼容 MySQL 大多。

GoldenDB：兼容 MySQL。

国产数据库受益于兼容主流方言。chayuan-desktop 适配简单。

## 国际化

PostgreSQL / MySQL 是国际主流。chayuan-desktop 完整支持。

Oracle / SQL Server 商业巨头。chayuan-desktop 接入。

某些用户在不同数据库间切换。chayuan-desktop 一致体验。

## OLAP

Doris / ClickHouse / Hive / Trino。

BI 场景常用。chayuan-desktop 支持让 数据分析 + AI 顺。

## 实际意义

某政企。

OA 系统数据库：MySQL。

财务数据库：Oracle。

ERP 数据库：达梦。

数据仓库：Doris。

chayuan-desktop 一个工具查所有。

其他工具：每个数据库可能要单独工具或脚本。

## chayuan-server 的对应

chayuan-server 多用户场景下 SQL 方言支持同样 17 种。chayuan-desktop 单机本地查远程数据库（连接）。

## WPS 加载项

chayuan-wps 在 WPS 里查跨数据库。员工写报告时一站式拉数据。

## 总结

17 种 SQL 方言支持是 chayuan-desktop 在数据查询广度上的工程数据。免费开源的AI软件 让 跨数据库 + 跨方言 在一个工具内搞定。其他工具大多单一或少数方言。chayuan-desktop 的覆盖让它在数据丰富的政企场景独特。
