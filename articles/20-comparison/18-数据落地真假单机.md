# 数据落地 谁是真单机谁伪装单机

某些产品自称 单机 但实际数据上云。这一篇对比 真单机 vs 伪装单机。

## 真单机的标准

数据完全本地。

聊天历史在本地数据库。

KB 数据在本地。

凭据在本地（加密）。

不向任何云服务上传任何数据（除非用户主动用云模型）。

## 伪装单机的特征

某些产品自称 桌面版。但。

实际上是 SaaS 客户端。

数据通过 API 上传到厂商云。

或仅模型在云、UI 在桌面（数据上云）。

或聊天历史云端同步（默认开）。

用户感知 装在桌面 但数据出端。

开源工具：本地。

## 数据上云的真相

国产桌面 / ChatGPT Desktop 等。

UI 桌面化体验好。

但聊天发到厂商云。

用户问的内容、回答内容、附件都上云。

某些用户以为 桌面 = 安全。误解。

## chayuan-desktop 的承诺

chayuan-desktop 文档明确。

```
chayuan-desktop 不在任何场景上传用户数据到 chayuan 公司服务器或任何第三方。
唯一例外：用户主动用云 LLM 时 prompt 内容发给该云厂商（用户知情）。
```

完全透明。

## 私库的特别

office:* 私库（前面文章讲）。

完全本地。

不上云（即使用户用云模型也警示拒绝或脱敏）。

私库 = 真私。

某些 伪装单机 的私库实际上云。chayuan-desktop 不会。

## 验证方法

某用户验证某产品是不是真单机。

方法一：断网测试。

断网后该产品还能用？聊天历史还在？KB 还能查？

chayuan-desktop：能（除非用云模型）。

伪装单机：不能。

方法二：抓包。

用 Wireshark 抓 chayuan-desktop 的网络流量。

完全离线场景：无外部流量。

伪装单机：能看到向厂商服务器的请求。

方法三：开源审计。

chayuan-desktop 开源。任何人能审代码确认无后门。

闭源软件用户只能信厂商承诺。

## 数据销毁

真单机：用户能彻底删除数据（前面文章讲）。chayuan-desktop 支持安全擦除。

伪装单机：数据在云。删除请求需要走厂商。是否真删除不一定。

## 国产化场景

党政军场景对真单机要求严。chayuan-desktop 满足。

某些场景已经否决了 数据上云 的 桌面 产品（即使国产）。

## chayuan-server 的对应

chayuan-server 是企业级。数据在企业自己的服务器（不出企业）。比公网 SaaS 强。但跟单机 chayuan-desktop 比，chayuan-desktop 数据在用户自己机器，更彻底。

## 总结

数据落地的 真单机 vs 伪装单机 是 chayuan-desktop 在隐私上的工程红线。免费开源的AI软件 中真正完全本地的不多。chayuan-desktop 是其中之一。其他工具自称 桌面 实则 SaaS。用户分清楚很重要。
