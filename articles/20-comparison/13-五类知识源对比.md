# 五类知识源 谁支持几个

chayuan-desktop 桌面单机版支持 5 类知识源。其他工具支持几个对比。这一篇讲。

## 5 类知识源

1. doc:* 文档库（PDF / docx / md 等文本）。

2. structured:* 结构化（数据库 / xlsx）。

3. src:* 外部向量库（Milvus / Qdrant / Pinecone）。

4. office:* 办公私库（个人 / 部门私有）。

5. multimodal 多模态 KB（视频 / 音频 / 图像）。

chayuan-desktop 5 类全 ✓。其他不全。

## 各类的差异

doc:* 文档。

最常见。所有 RAG 工具都做。

差异在 chunk 切分、嵌入模型、引用回链等细节。

structured:*。

少数支持。chayuan-desktop / AnythingLLM 部分 / 通义部分。

text2sql + 17 SQL 方言是 chayuan-desktop 强项。

src:* 外部向量。

接 Milvus / Qdrant 等。少数支持。

chayuan-desktop 完整支持。

office:* 私库。

专门概念。chayuan-desktop 独有。

个人 / 部门私有 + 严格权限 + 不出端。

multimodal 多模态。

视频 / 音频 / 图像入 KB。

部分产品支持图像。视频较少。

chayuan-desktop 完整。

## 实际应用

某员工的工作场景。

公司文档 → doc:*。

个人笔记 → office:*。

ERP 数据 → structured:*。

某老 KB 在 Milvus → src:*。

会议录音 → multimodal。

5 类齐用。

只用 chayuan-desktop 一个工具。其他工具至少要 2-3 个组合。

## chunk 跨类型混合检索

chayuan-desktop 支持跨类型一次检索。

```
ku_ids=["doc:contracts", "office:zhangsan:notes", "structured:erp"]
```

返回的引用气泡有不同颜色（区分类型）。

其他工具一般不能跨类型混合。

## 设计哲学

chayuan-desktop：知识源是抽象的。任何来源都能成为 KB。

其他工具：只关注 文档 这种具体来源。

设计上 chayuan-desktop 更开放。

## 国产化场景

党政军场景的 5 类齐用。chayuan-desktop 独此一家完整支持。

某些场景没 office:* 是 dealbreaker（私库需求强）。

## chayuan-server 的对应

chayuan-server 多用户场景下 5 类同样支持。chayuan-desktop 单机简化但概念一致。

## 总结

五类知识源对比是 chayuan-desktop 在 KB 完整性上的对比数据。免费开源的AI软件 中只有 chayuan-desktop 5 类齐全。其他工具或单一类或部分。综合工作场景下 chayuan-desktop 优势明显。
