# 离线推理 谁原生 谁外挂

各产品对离线推理的支持。原生 vs 外挂。这一篇讲。

## 原生 vs 外挂

原生：产品自带推理引擎。开箱即用。无需配额外服务。

外挂：产品自己不做推理。靠外部服务（Ollama 等）。需要额外装。

## 各产品对比

| 产品 | 离线推理 | 方式 |
|---|---|---|
| chayuan-desktop | ✓ | 原生（内嵌 llama.cpp）+ 集成 Ollama |
| LM Studio | ✓ | 原生（内嵌） |
| Open WebUI | ✓ | 外挂 Ollama |
| AnythingLLM | ✓ | 外挂 Ollama |
| Cherry Studio | ✓ | 外挂 Ollama / vLLM |
| Chatbox | 部分 | 外挂 Ollama |
| ChatGPT Desktop | ✗ | 仅云 |
| Claude Desktop | ✗ | 仅云 |
| 豆包桌面 | ✗ | 仅云 |
| 通义桌面 | ✗ | 仅云 |

chayuan-desktop / LM Studio 原生。其他大多外挂或不支持。

## 原生的好处

开箱即用。不需要装 Ollama 等。

性能可控（产品自己优化）。

更省资源（不重复进程）。

## 外挂的好处

复用现有 Ollama。

灵活（可换其他推理引擎）。

## chayuan-desktop 的混合

chayuan-desktop 既原生又能集成 Ollama。

启动时如果检测到 Ollama 已在跑，复用（前面文章讲）。

如果没 Ollama，用自家内嵌 llama.cpp 跑。

灵活。

## 内嵌引擎的代价

chayuan-desktop 装后大（含推理引擎和默认模型）。

LM Studio 同样。

但安装和首次使用极简（不需要再装东西）。

## 推理引擎选择

chayuan-desktop 内嵌。

llama.cpp。GGUF 格式。CPU + GPU 混合。

ONNX Runtime。ONNX 格式（嵌入和小模型）。

llama-cpp-python。Python 绑定。

外挂支持。

Ollama。最常用。

LM Studio。OpenAI 兼容协议。

vLLM。GPU 高性能。

Xinference。多模型管理。

任意 OpenAI 兼容服务。

## 模型管理

chayuan-desktop 的模型目录。

```
~/.chayuan/models/llm/gguf/
  Qwen2.5-7B-Q4.gguf
  Qwen2.5-1.8B-Q4.gguf
  ...
```

跟 Ollama 共享（如果配置软链）。

## 离线 + 多模态

chayuan-desktop 离线场景下完整。

LLM：本地推理。

嵌入：bge-m3-onnx 本地。

OCR：RapidOCR 本地。

视觉：Qwen-VL 本地（如果显存够）。

ASR：FunASR 本地。

TTS：Piper 本地。

完全离线全功能。

LM Studio 只 LLM 离线。其他场景缺。

## 推理性能

某基准。Qwen2.5-7B-Q4。RTX 4060。

| 产品 | tokens/s |
|---|---|
| chayuan-desktop（内嵌 llama.cpp） | 38 |
| LM Studio | 40 |
| Ollama 直接 | 38 |

差不多。chayuan-desktop 不输专业推理工具。

## 国产 NPU

国产 NPU（昇腾、寒武纪）chayuan-desktop 路线图支持。

某些产品已支持（部分国产厂商定制版）。

## 国产化场景

党政军离线推理是核心需求。chayuan-desktop 原生支持 + 国产化栈让它在这种场景独特。

## chayuan-server 的对应

chayuan-server 部署在 GPU 服务器跑大模型。原生推理（vLLM）。chayuan-desktop 单机内嵌轻量推理。两者协同。

## 总结

离线推理的原生 vs 外挂展示各产品取舍。免费开源的AI软件 中 chayuan-desktop / LM Studio 原生。其他大多外挂。chayuan-desktop 的原生 + 集成 Ollama 双轨让用户灵活选。完全离线全功能 chayuan-desktop 独占。
