## 等保合规

党政军采购等保是硬要求。

chayuan-desktop：完整等保 2.0 三级。

Cherry Studio / Open WebUI：理论上可达三级但需要大量配置 + 难走测评流程（开源项目无人配合测评）。

豆包 / 通义：等保合规但绑定厂商云。

ChatGPT 类：完全不合规（数据出端 + 厂商境外）。

## 完全离线

涉密场景必须完全离线。

chayuan-desktop：完全离线（本地推理 + 本地嵌入 + 本地 OCR + 本地 ASR / TTS）。

LM Studio：本地推理但无 KB / OCR / ASR。

Cherry Studio：本地推理 + 简单 KB 但缺 OCR / ASR / 完整国产化。

Open WebUI / AnythingLLM：本地推理 + KB 部分。

豆包 / 通义 / ChatGPT：必须联网。

完全离线 chayuan-desktop 独此一家完整。

## 党政军采购

完整国产化栈 + 等保 + 完全离线 = 党政军采购首选。

chayuan-desktop 满足。其他产品补不齐。

## 商业上的意义

chayuan-desktop 在国产化场景独特。这是商业差异化。

国际项目（Cherry Studio、Open WebUI）做国产化代价大。chayuan-desktop 从设计就国产化优先。

## chayuan-server 的对应

chayuan-server 同样国产化栈。chayuan-desktop 单机 + chayuan-server 服务端组合让国产化部署完整。

## 总结

国产化跨产品对账让 chayuan-desktop 的优势清晰。免费开源的AI软件 中只有 chayuan-desktop 国产化全 ✓。其他产品或部分或缺失。在党政军 / 政企采购场景 chayuan-desktop 是合理选择。
