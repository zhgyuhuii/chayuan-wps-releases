# 模型对抗 多泳道是不是只有察元在做

chayuan-desktop 桌面单机版的 Arena 模式（多泳道模型对抗）。其他产品对比。这一篇讲。

## 模型对抗的概念

同一问题。多个模型并行回答。对比谁更好。

公开版：lmsys.org/lmarena 让全网用户对比。

桌面版：用户自己机器上跑对抗。

## 各产品支持

| 产品 | 模型对抗 |
|---|---|
| chayuan-desktop | ✓ 完整 Arena |
| Cherry Studio | ✓ 基础（多模型同时回答） |
| Open WebUI | ✓ 基础（多模型并排） |
| Chatbox | 弱（手动切换） |
| AnythingLLM | ✗ |
| LM Studio | ✗ |
| 豆包 / 通义 / 智谱 | ✗（单一模型） |
| ChatGPT Desktop | ✗ |

chayuan-desktop 是 完整 Arena。其他大多基础或无。

## 完整 Arena 的功能

chayuan-desktop。

多泳道（无上限）。同时跑 N 个模型（5-10 都行）。

ELO 评分。Bradley-Terry 算法。

盲评（用户看不到模型名）。

评测集（自带 + 自定义）。

任务分类（chat / code / 写作 / 视觉 / 工具）。

延迟 + 成本对比。

报告导出。

完整。

## Cherry Studio 的对抗

Cherry Studio 也支持多模型并排。但。

无 ELO（用户主观看）。

无评测集。

无报告。

基础。

## Open WebUI 的对抗

类似 Cherry Studio。基础并排。

社区扩展可能加更多但官方功能有限。

## chayuan-desktop 的独特

回归测试集成。模型升级前跑回归测对比。

A/B 测试。某模型试用一段。

主观评分汇总。

ELO 长期跟踪。

让对抗 不只是看一次结果，是工程化的选型。

## 对抗的应用

应用一：选默认模型。基于对抗结果选最佳。

应用二：发现退化。新版模型对比旧版。

应用三：成本优化。对抗能给 划算度 评分。

应用四：领域定制。专业领域对抗找最适合。

chayuan-desktop 的 Arena 让这些场景顺。

## 数据驱动选型

某政企采购前跑 chayuan-desktop Arena。

跑 3 个国产模型 + 2 个国外。

50 题代表性任务。

输出报告给决策层。

基于数据采购。比看厂商宣传 PPT 强。

## 国产化场景

党政军采购需要数据论证。chayuan-desktop 的 Arena 报告是采购材料。

多家国产模型间选。chayuan-desktop 实测最准。

## 跟 lmsys.org 的关系

lmsys 是公网 ELO 数据。

chayuan-desktop Arena 是本地实测（针对自己任务）。

两者互补。chayuan-desktop 不打算替代 lmsys，做本地版。

## chayuan-server 的对应

chayuan-server 多用户场景下 Arena 数据更全（多用户聚合）。chayuan-desktop 单机数据有限但够个人决策。

## 总结

模型对抗多泳道是 chayuan-desktop 在选型工程化上的独特。免费开源的AI软件 中只有 chayuan-desktop 做 完整 Arena。其他工具基础对比或无。chayuan-desktop 的 Arena 让 选模型有数据支持，是工程化决策工具。
