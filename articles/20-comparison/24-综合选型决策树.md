# 综合选型决策树 给你一张图自己挑

各产品综合选型决策树。这一篇给指南。

## 决策树

```
我需要 AI 助手
  │
  ├─ 主要场景？
  │   ├─ 仅聊天 + 云模型 → ChatGPT Desktop / 国产桌面
  │   ├─ 仅本地推理 → LM Studio
  │   ├─ 文档 RAG → AnythingLLM 或 chayuan-desktop
  │   ├─ 多模型对比 → Cherry Studio / Chatbox
  │   ├─ Ollama 前端 → Open WebUI
  │   └─ 综合办公 + KB + 国产化 → chayuan-desktop
  │
  ├─ 数据敏感度？
  │   ├─ 完全本地（涉密） → chayuan-desktop / LM Studio
  │   ├─ 国内合规（不出国）→ chayuan-desktop / 国产桌面
  │   └─ 不敏感 → 任意
  │
  ├─ WPS 集成？
  │   ├─ 需要 → chayuan-desktop（唯一）
  │   └─ 不需要 → 其他都行
  │
  ├─ 国产化场景？
  │   ├─ 党政军 → chayuan-desktop
  │   └─ 其他 → 任意
  │
  ├─ 预算？
  │   ├─ 免费 → chayuan-desktop / Open WebUI / Chatbox / Cherry Studio / LM Studio
  │   └─ 付费可 → ChatGPT / Claude / 商业产品
  │
  └─ 开源偏好？
      ├─ 完全开源 → chayuan-desktop / Cherry Studio / Open WebUI / AnythingLLM
      └─ 闭源可 → 国产桌面 / ChatGPT / Claude
```

## 推荐组合

需求一：党政军内网 + WPS + 国产化。

chayuan-desktop（唯一选择）。

需求二：开发者 + 多模型对比。

Cherry Studio + Open WebUI。

或 chayuan-desktop（带 Arena）。

需求三：纯本地 LLM 玩家。

LM Studio + Ollama。

需求四：办公场景 + KB。

chayuan-desktop（最全）。

或 AnythingLLM（轻量但 KB 单类）。

需求五：跨设备聊天。

ChatGPT Desktop / 豆包 / Kimi 桌面。

或 Chatbox（开源 + 多设备）。

## 综合得分

按 chayuan-desktop 的目标场景（中国办公）打分。

| 产品 | 综合得分 |
|---|---|
| chayuan-desktop | 95（完整 + 国产化 + WPS） |
| Cherry Studio | 75（开源 + 多模型但缺 KB / WPS / 国产化） |
| Open WebUI | 70（开源 + Ollama 但缺 KB / WPS） |
| AnythingLLM | 70（KB 强但缺其他） |
| LM Studio | 60（仅 LLM 推理） |
| Chatbox | 65（聊天客户端） |
| ChatGPT Desktop | 50（数据出端 + 收费 + 国外） |
| 国产桌面（豆包 / 通义 / 智谱等） | 60-70（数据上云 + 单一厂商） |

chayuan-desktop 在中国办公场景综合最强。

国际场景对比可能不同（chayuan-desktop 缺英文文档 / 国际推广）。

## 决策小贴士

贴士一：先想最关键需求。

数据敏感？WPS 集成？国产化？开源？

某一项是 dealbreaker 时直接筛。

贴士二：试用。

chayuan-desktop 免费下载。试 1 周。

跟当前用的对比。

贴士三：渐进迁移。

不必一次全换。chayuan-desktop 当 OpenAI 兼容后端。其他工具能继续用同时享受 chayuan-desktop 的 KB / 模型。

贴士四：社区。

chayuan-desktop GitHub issue + 论坛。问题能问。

## 国产化场景

党政军场景的决策简单。chayuan-desktop 是综合选项。

某些场景明确指定其他（如某厂商专项采购）。chayuan-desktop 跟它共存。

## chayuan-server 的对应

chayuan-server 是企业级。chayuan-desktop 是单机。决策。

个人 / 小团队：chayuan-desktop。

大团队 / 企业：chayuan-server。

## 总结

综合选型决策树是 chayuan-desktop 的对比工程总结。免费开源的AI软件 中没有 一个产品适合所有场景。chayuan-desktop 在中国办公 + 国产化 + 私库 + WPS 场景独特。其他场景看具体需求选。
