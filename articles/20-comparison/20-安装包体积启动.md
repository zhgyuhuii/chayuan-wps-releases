# 安装包体积与启动速度 一组实测

各产品安装包体积和启动速度的实测。这一篇讲。

## 测试环境

机器：Intel i7-13700H + 16GB + SSD + Windows 11。

测试方法：下载 → 装 → 首次启动 → 测时间。

## 安装包体积

| 产品 | 包大小 | 装后大小 |
|---|---|---|
| chayuan-desktop | 280 MB | 1.2 GB（含模型） |
| LM Studio | 480 MB | 600 MB |
| Cherry Studio | 130 MB | 250 MB |
| Open WebUI | 120 MB（Docker） | 1+ GB（Ollama 模型） |
| AnythingLLM | 200 MB | 400 MB |
| Chatbox | 100 MB | 180 MB |
| ChatGPT Desktop | 150 MB | 250 MB |
| 豆包桌面 | 80 MB | 120 MB |
| Kimi 桌面 | 70 MB | 110 MB |

chayuan-desktop 中等。装后大（含本地模型）。

豆包 / Kimi 等国产桌面体积小（多数功能在云）。

## 装后大小的差异

chayuan-desktop 装后 1.2 GB。

含 bge-m3-onnx（200MB）。

含 bce-reranker（300MB）。

含 RapidOCR（50MB）。

含 Python sidecar runtime。

含 LLM 推理引擎（llama.cpp）。

不含 LLM 模型权重（用户按需下）。

LM Studio 装后小但 LLM 模型用户单独下（GB 级）。

## 启动速度

| 产品 | 冷启动 | 热启动 |
|---|---|---|
| chayuan-desktop | 5-8 秒 | 2-3 秒 |
| LM Studio | 3-5 秒 | 1-2 秒 |
| Cherry Studio | 1-2 秒 | < 1 秒 |
| Chatbox | 1-2 秒 | < 1 秒 |
| ChatGPT Desktop | 1-2 秒 | < 1 秒 |
| 豆包桌面 | 1 秒 | < 1 秒 |

chayuan-desktop 较慢（启动 sidecar + 加载模型元数据）。

Electron 系（Chatbox 等）启动快。

## chayuan-desktop 启动慢的原因

第一。Tauri 启动 + WebView 初始化（1-2 秒）。

第二。Python sidecar 子进程启动（2-3 秒）。

第三。sidecar 加载 KB 元数据 + 模型卡片（1-2 秒）。

第四。UI 拉数据渲染（1 秒）。

总 5-8 秒。

## 优化方向

chayuan-desktop 路线图。

sidecar 启动并行（边启动边显示 UI）。

延迟加载（首次用某 KB 才加载）。

预加载（OS 启动时后台拉起）。

预计能优化到 3-4 秒冷启动。

## 启动速度的取舍

启动快 ≠ 功能多。

豆包 / Kimi 启动快但功能单一（聊天 + 云模型）。

chayuan-desktop 启动慢但本地推理 + KB + 多模态完整。

## 资源占用

启动后内存占用。

| 产品 | 内存（聊天空闲） |
|---|---|
| chayuan-desktop | 500-800 MB |
| LM Studio | 300-500 MB |
| Cherry Studio | 200-300 MB |
| Chatbox | 200-300 MB |
| ChatGPT Desktop | 200 MB |
| 豆包桌面 | 100-200 MB |

chayuan-desktop 中等。带本地推理时跳到 4-8 GB。

## CPU 占用

idle 时大多产品 < 5% CPU。

跑 LLM 推理时本地模型类（chayuan-desktop / LM Studio）100% CPU 短暂。

云模型类几乎不占（推理在云）。

## 笔记本续航影响

chayuan-desktop 跑本地推理耗电（30-60 分钟续航损失）。

云模型类影响小（仅 UI + 网络）。

## 国产化场景

党政军场景启动速度不是首要（功能完整 + 合规更重要）。chayuan-desktop 的略慢启动可接受。

## chayuan-server 的对应

chayuan-server 是服务端。启动速度不直接影响用户。chayuan-desktop 单机用户感知。

## 总结

安装包体积和启动速度的对比展示各产品的取舍。免费开源的AI软件 中 chayuan-desktop 体积中等启动慢但功能最完整。轻量产品功能少。用户按需选。
