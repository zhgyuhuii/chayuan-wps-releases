# 模型供应商数量 谁接得最多

各产品支持的模型供应商数量对比。这一篇讲。

## chayuan-desktop 接的厂商

国外。

OpenAI / Anthropic / Google Gemini / xAI / Mistral / Cohere。

国产。

百度文心 / 阿里通义 / 字节豆包 / 腾讯混元 / 智谱 GLM / DeepSeek / Yi（零一） / Moonshot Kimi / 阶跃 / MiniMax / 讯飞 / 商汤 / 浪潮 等。

本地。

Ollama / LM Studio / vLLM / Xinference / 自定义 OpenAI 兼容。

总共 18+ 厂商 / 30+ 模型组合。

## 各产品对比

| 产品 | 厂商数 |
|---|---|
| chayuan-desktop | 18+ |
| Cherry Studio | 30+（社区贡献多） |
| Chatbox | 30+ |
| Open WebUI | 10+（主要 Ollama + OpenAI 兼容） |
| LM Studio | 1（Ollama 类，但仅本地） |
| AnythingLLM | 8-10 |
| ChatGPT Desktop | 1（OpenAI） |
| 豆包桌面 | 1（豆包） |
| 通义桌面 | 1（通义） |
| 智谱清言 | 1（智谱） |

Cherry Studio / Chatbox 厂商最多。chayuan-desktop 略少但够用。

国产桌面单一厂商（绑定）。

## 厂商数量的意义

多厂商的好处。

灵活切换。某厂商出问题切其他。

成本优化。同任务找最划算的。

不被锁定。某厂商涨价 / 关停时不慌。

## chayuan-desktop 的策略

不追求最多。追求完整 + 优质。

主流厂商完整接入。

新厂商出来跟进（1-2 周内）。

实验性厂商（社区维护）选择性接入。

## 模型类型覆盖

不只是 chat。每个厂商。

chat（对话）。

embed（嵌入）。

rerank（重排）。

image（视觉理解）。

T2I（图像生成）。

ASR（语音识别）。

TTS（文本转语音）。

reasoning（推理 R1 类）。

每类都有覆盖。

## 本地模型支持

Ollama。最广。

LM Studio。OpenAI 兼容协议接入。

vLLM。私有部署。

Xinference。多模型。

GPT4All。少数支持。

llama-server。直接接入。

chayuan-desktop 的本地模型 OpenAI 兼容协议统一封装。

## 自定义厂商

chayuan-desktop 支持自定义任意 OpenAI 兼容厂商。

某用户自家训练的模型，部署成 OpenAI 兼容服务。chayuan-desktop 能接。

实际厂商数无上限。

## 接入成本

新厂商接入 chayuan-desktop。

如果 OpenAI 兼容：5 分钟（配置 base_url + api_key）。

如果自家协议：1-2 周开发 adapter。

chayuan-desktop 团队定期评估热门厂商接入。

## 国产化场景

国产厂商生态发展快。chayuan-desktop 紧跟。

某些场景客户希望某特定国产厂商。chayuan-desktop 能接。或客户 PR 加。

## chayuan-server 的对应

chayuan-server 共享网关代码。厂商支持一致。

## 总结

模型供应商数量是 chayuan-desktop 在选择性上的体现。免费开源的AI软件 中 Cherry Studio / Chatbox 厂商最多。chayuan-desktop 略少但更精选 + 国产化深。绑定单一厂商的国产桌面在多厂商场景受限。
