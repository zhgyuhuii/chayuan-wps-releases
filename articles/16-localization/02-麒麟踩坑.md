# 国产化支持下的麒麟桌面V10 踩坑总结

chayuan-desktop 桌面单机版在麒麟桌面 V10 上的部署有几个常见坑。这一篇汇总踩坑经验。

坑一：webkit2gtk 版本。麒麟 V10 SP1 自带 webkit2gtk-4.0，chayuan-desktop Tauri 2 需要 4.1+。处理：从麒麟开发者社区或者社区源装 4.1 版本。

坑二：glibc 版本。SP1 是 glibc 2.28，chayuan-desktop sidecar PyInstaller 二进制依赖 2.31+。处理：升级到 SP2 系统（glibc 2.31）或者从源码构建兼容版本。

坑三：字体渲染。麒麟默认字体集对部分 emoji unicode 显示不全。处理：装 fonts-noto-cjk。

坑四：sqlite-vec 加载。SELinux 拦截扩展加载。处理：调整 SELinux 策略（permissive 测试，正式部署写 audit2allow 策略）。

坑五：Tauri 主进程菜单。麒麟某些版本桌面环境对 Tauri 的菜单栏支持差。处理：用 chayuan-desktop 的 标题栏菜单 替代系统菜单。

坑六：托盘图标。麒麟某些 DE 环境（XFCE 老版本）不支持托盘。处理：chayuan-desktop 检测到不支持自动降级，不显示托盘图标。

坑七：高分屏 DPI。麒麟在 4K 屏上 chayuan-desktop 可能显示过小。处理：改 chayuan-desktop 的 zoom_factor 配置或者麒麟系统 DPI 设置。

坑八：输入法。麒麟用 fcitx5。Tauri 2 与 fcitx5 在某些版本有兼容问题（光标位置错）。处理：升级 chayuan-desktop 到最新（已修过这一类 bug）。

坑九：依赖软件包。某些依赖在麒麟源里版本旧。处理：从内部镜像或者社区源拿新版本。

坑十：签名。麒麟商店对未签名应用拦截。处理：企业部署用公司证书签名 deb 包。

部署流程。

第一步：确认麒麟版本。SP1 还是 SP2。

第二步：装依赖（webkit2gtk 4.1、libssl3、libsqlite3、fonts-noto-cjk 等）。

第三步：dpkg -i chayuan-desktop_x.y.z_arm64.deb 装包。

第四步：chayuan-desktop 启动。FirstRunSetup 选 CHAYUAN_ROOT。

第五步：处理首启动可能的小问题（字体、托盘等）。

第六步：测试基础流程。

实测机型。chayuan-desktop 团队验证过几款国产笔记本。

某品牌飞腾 D2000 麒麟笔记本：跑得动 chayuan-desktop + Ollama 7B 模型（CPU 慢但可用）。

某品牌鲲鹏 920 麒麟工作站：跑 chayuan-desktop 流畅。

某品牌龙芯 3A5000：chayuan-desktop 龙芯版包装好运行。

WPS AI 插件 chayuan-wps 在麒麟 WPS 上的支持仍在演进。当前在 Windows WPS 上稳定使用，麒麟版 WPS 的加载项支持视社区进度。

麒麟桌面踩坑总结是 chayuan-desktop 国产化部署的实战经验。免费开源的AI软件 在国产 OS 落地，每一台样机都可能有新坑。chayuan-desktop 的踩坑积累让后续部署更顺。
