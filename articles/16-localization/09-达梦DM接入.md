# 国产数据库 达梦 DM 的接入实操

chayuan-desktop 桌面单机版接入达梦 DM 数据库。这一篇讲实操。

## 达梦 DM 的地位

达梦数据库（DM）。武汉达梦开发。国产数据库代表。

党政军、金融、能源等关键行业广泛部署。

兼容 Oracle 语法（部分）。让 Oracle 应用迁移容易。

## chayuan-desktop 接入方式

方式一：通过 SQLAlchemy。chayuan-desktop 用 SQLAlchemy 抽象数据库。

```python
from sqlalchemy import create_engine
engine = create_engine("dm+dmPython://user:pass@host:port/db")
```

需要 dmPython（达梦官方 Python 驱动）。

方式二：通过 ODBC。

```
DSN=DM_PROD;UID=user;PWD=pass
```

跨平台但配置麻烦。

chayuan-desktop 默认推荐方式一。

## 配置示例

chayuan-desktop 设置 - 知识库 - 添加 - 类型 结构化数据 - 数据源 数据库。

```yaml
type: dm
host: 192.168.1.100
port: 5236
user: chayuan_user
password: <stored_in_stronghold>
database: BUSINESS
```

测试连接。chayuan-desktop 用 dmPython 拉 schema。

## SQL 方言适配

chayuan-desktop 的 text2sql 模块需要按 DM 方言生成。

DM 兼容 Oracle 大部分语法。

```sql
-- DM (Oracle 风格)
SELECT * FROM users WHERE rownum <= 10;

-- 而非 LIMIT
SELECT * FROM users LIMIT 10;
```

某些函数命名不同。

```
DM: SUBSTR (Oracle 兼容)
MySQL: SUBSTRING

DM: SYSDATE
MySQL: NOW()
```

chayuan-desktop 的 SQL 生成器有 DM 方言模板。LLM 生成 SQL 时指定方言。

## 类型映射

达梦类型 vs 标准类型。

NUMBER。约 Oracle 的 NUMBER。chayuan-desktop 映射成 numeric。

VARCHAR2。约 Oracle。映射 string。

DATE。带时分秒。映射 datetime。

CLOB / BLOB。大文本 / 二进制。映射成对应。

## 性能

DM 单机性能跟 Oracle 接近。

聚合查询。SELECT COUNT(*) FROM 表。秒级。

复杂 JOIN。优化器较好。

百万行。性能跟 Oracle 接近。

chayuan-desktop 的 text2sql 不需要特别优化（DM 自己会优化）。

## 鉴权

DM 支持。

用户名 / 密码。

LDAP / Kerberos。

国密算法（SM3 哈希）。

chayuan-desktop 的 stronghold 加密存储密码。

## 元数据获取

```sql
SELECT * FROM USER_TABLES;
SELECT * FROM USER_TAB_COLUMNS WHERE TABLE_NAME = 'USERS';
```

跟 Oracle 一致。chayuan-desktop 的 schema 提取直接用。

## 实战例子

某员工的 KB 接 DM 客户表。

用户问 我们公司有几个 VIP 客户。

LLM 决策 → 生成 SQL：

```sql
SELECT COUNT(*) FROM customers WHERE level = 'VIP';
```

DM 执行。返回 23。

LLM 包装：你们公司有 23 个 VIP 客户。

完整链路通。

## 国产化场景

党政军 + 金融场景大量用 DM。chayuan-desktop 接入 DM 是 KB 结构化查询的核心。

某些场景对 DM 有强制要求（不能用 Oracle / MySQL）。chayuan-desktop 的 DM 支持是采购前提。

## chayuan-server 的对应

chayuan-server 部署在 DM 服务器上跑。chayuan-desktop 单机连远程 DM。两者都支持。

## WPS 加载项

chayuan-wps 在 WPS 里查 DM 数据。员工写报告时直接拉 DM 数据生成图表。

## 总结

达梦 DM 接入是 chayuan-desktop 在国产数据库上的核心能力。免费开源的AI软件 让 DM 数据 也能用 AI 查询。chayuan-desktop 的 SQLAlchemy + dmPython + 方言适配让 DM 接入是配置即可的事。
