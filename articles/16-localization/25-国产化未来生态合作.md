# 国产化支持的未来 我们与生态的合作清单

chayuan-desktop 桌面单机版的国产化未来生态合作。这一篇讲。

## 已经合作的生态

OS 厂商。

麒麟。chayuan-desktop 在麒麟 V10 测试覆盖。提交兼容性问题反馈。

统信。同上。

openKylin。社区维护版。chayuan-desktop 跟进。

CPU 厂商。

华为鲲鹏。chayuan-desktop 在鲲鹏笔记本 / 服务器测试。

飞腾。同上。

龙芯。loongarch64 编译路径打通。

数据库厂商。

达梦。chayuan-desktop 接入 dmPython 驱动。

金仓。PG 协议直接兼容。

OceanBase。已接入。

LLM 厂商。

百度文心、阿里通义、字节豆包、智谱、DeepSeek、Yi、Moonshot。全接入。

## 计划合作的方向

CPU NPU。

华为昇腾。chayuan-desktop 集成 CANN 推理框架（路线图）。

寒武纪 MLU。同上。

天数智芯。同上。

国产 NPU 推理能力跟上后大模型本地推理性能更强。

CA 机构。

国家 CA。chayuan-desktop 用国家 CA 签名（路线图）。

省级 CA。某些省级采购要求。

第三方 CA（CFCA、GDCA 等）。

签名走国密 SM2 + SM3。

应用商店。

各省政务应用商店。chayuan-desktop 上架。

国家信创应用商店。同上。

各国产 OS 应用商店（麒麟、统信）。同上。

行业协会。

中国电子工业标准化技术协会。

中国信息技术应用创新工作委员会（信创工委会）。

参与标准制定。

## 合作的形式

技术合作。

兼容性测试。chayuan-desktop 在 OS / CPU / 数据库厂商的测试环境跑。

性能优化。共同优化在特定硬件上的性能。

接口对接。共同设计 API 让 AI 跟业务系统协同。

商业合作。

OEM。chayuan-desktop 给 OS 厂商定制化版本。

集成。chayuan-desktop 集成到 OEM 笔记本预装。

生态合作。

某些信创产品（数据库、中间件）厂商把 chayuan-desktop 推荐给客户。

参与中国信创联盟活动。

## 开源贡献

chayuan-desktop 开源（AGPL-3.0）。鼓励国产社区贡献。

国产开发者贡献功能。

国产用户反馈 bug。

国产文档翻译和补充。

某些贡献被合并到主线。chayuan-desktop 持续受益于社区。

## 开放协议

chayuan-desktop 推动开放协议。

MCP 协议。给 AI 工具生态。

KnowledgeRef 协议。给 KB 互操作。

某些政企的 OA / ERP 系统通过开放协议接入 chayuan-desktop。

不锁定客户。

## 国家战略

中国 国产化 / 自主可控 是国家战略。chayuan-desktop 是其中一员。

国家发改委、工信部对信创产品有政策支持。chayuan-desktop 申报相关资质。

通过国家测评机构认证。让党政军采购有合规依据。

## 国际合作（非国产但相关）

某些场景中国 + 一带一路国家。chayuan-desktop 也支持当地语种和合规。

俄语、阿拉伯语、波斯语等小语种支持（路线图）。

## chayuan-server 的对应

chayuan-server 跟随相同生态合作策略。chayuan-desktop 单机的合作经验复用。

## WPS 加载项

chayuan-wps 跟金山 WPS 深度合作。WPS 是中国办公软件主力。chayuan-wps 让 WPS 在 AI 时代更智能。

## 总结

国产化支持的未来生态合作是 chayuan-desktop 在长期发展上的工程战略。免费开源的AI软件 不孤立工作。chayuan-desktop 跟 OS / CPU / 数据库 / LLM / CA / 应用商店 等多方生态合作让国产化采购顺畅，让自主可控 AI 真正落地。
