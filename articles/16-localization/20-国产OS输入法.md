# 国产 OS 下的输入法 中文输入的边界

chayuan-desktop 桌面单机版在国产 OS 下的中文输入。这一篇讲。

## 国产输入法生态

iBus + 各引擎。麒麟、统信常用。

iBus + 拼音。

iBus + 五笔。

iBus + 手心 / 谷歌拼音 / 搜狗等。

fcitx + 各引擎。轻量内核。

fcitx + sogou。

fcitx + 五笔。

fcitx + RIME。

商业输入法。讯飞、搜狗（Linux 版）。

## chayuan-desktop 的输入兼容

Tauri 的 WebView。底层是 WebKit / WebView2。这些渲染引擎天然支持系统输入法。

chayuan-desktop 的输入框（chat、KB 名、设置等）跟系统输入法集成。

## 常见问题

问题一：输入法候选词浮窗位置。

某些 Linux 输入法在 Tauri WebView 上候选词浮窗位置不对（出现在屏幕左上角而不是输入框旁）。

原因：Wayland vs X11 + IBus / fcitx 实现差异。

解决：chayuan-desktop 启动时获取输入框坐标传给输入法。某些 OS 上仍有问题。chayuan-desktop 的兼容性测试覆盖。

问题二：中文标点切换。

输入法 Shift + 切换中英标点。某些场景 chayuan-desktop 抢键不让切。chayuan-desktop 不抢通用键。

问题三：长文输入卡顿。

某些 chat 框输入超长（5000+ 字）时卡。chayuan-desktop 的 textarea 优化。

问题四：复制粘贴含中文。

剪贴板兼容。chayuan-desktop 跟 OS 剪贴板正常交互。

## 输入法切换

用户在 chayuan-desktop 里切输入法（Ctrl + Space 默认）。

chayuan-desktop 不拦截 Ctrl + Space。让 OS 输入法切换正常。

## 表情符号

某些输入法支持 emoji。chayuan-desktop 的 chat 显示 emoji 完整。

某些政企 OS 不带 emoji 字体。chayuan-desktop 内嵌 emoji 字体作为 fallback。

## 五笔 / 速记

某些用户用五笔。打字快。chayuan-desktop 的输入框不影响。

某些用户用速记码（专业输入）。同样兼容。

## 中文 OS 路径

chayuan-desktop 支持中文 OS 路径（用户名 / 文件夹是中文）。

```
/home/张三/.chayuan/
```

底层文件操作用 UTF-8。Linux / macOS 默认 UTF-8。Windows NTFS UTF-16 转。

某些子进程（mcp 工具）对中文路径处理不好。chayuan-desktop 在调用前转 ASCII 或符号链接。

## RIME 的特殊场景

RIME 是高级 IME。允许用户自定义词库。

某些政企用户用 RIME 加专业词库（医学、法律等）。chayuan-desktop 兼容 RIME 输入。

## 国产输入法的 AI 增强

某些国产输入法（搜狗、讯飞）开始集成 AI（智能纠错、长句联想）。

chayuan-desktop 跟输入法不冲突。各自工作。

## 国产化场景

党政军采购国产 OS 自带输入法。chayuan-desktop 跟标配输入法兼容。

某些场景禁用第三方输入法（讯飞、搜狗）。chayuan-desktop 用 OS 自带输入法时也正常。

## chayuan-server 的对应

chayuan-server 是服务端无输入法问题。chayuan-desktop 单机版处理。

## WPS 加载项

chayuan-wps 是 WPS 加载项。WPS 自己处理输入法。chayuan-wps 不重复实现。

## 总结

国产 OS 下输入法是 chayuan-desktop 在中文输入完整性上的工程关注。免费开源的AI软件 不让 中文输入 成为门槛。chayuan-desktop 的 Tauri 兼容 + 候选词位置修复 + 中文路径让国产 OS 用户流畅输入。
