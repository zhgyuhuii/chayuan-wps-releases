# 飞腾鲲鹏龙芯三套CPU的实测

chayuan-desktop 桌面单机版在国产 CPU 上的实测表现。三款主流国产 CPU 跑得怎样。

飞腾 D2000。

8 核 aarch64。主频 2.0-2.6GHz。

实测：chayuan-desktop sidecar 启动 25-40 秒。前端渲染流畅。

CPU 跑 7B 模型 tokens/s 4-8。慢但能用。

bge-m3 嵌入：每 chunk 80-150ms（CPU）。

整体体验：用作日常对话客户端没问题。RAG 入库速度可接受（一份 100 页 PDF 入库约 5 分钟）。

鲲鹏 920。

64 核 aarch64。主频 2.6GHz。

实测：chayuan-desktop sidecar 启动 15-25 秒。

CPU 跑 7B 模型 tokens/s 8-15（多核 + AVX-like 指令）。

bge-m3 嵌入：每 chunk 50-80ms。

整体体验：服务器场景流畅。给团队共享后端用合适。

龙芯 3A5000。

4 核 loongarch64。主频 2.5GHz。

实测：chayuan-desktop 启动 30-60 秒（loongarch64 二进制略慢）。

CPU 跑 7B 模型 tokens/s 3-5。慢。

bge-m3 嵌入：每 chunk 100-180ms。

整体体验：基础办公能用，但响应感比 x86/ARM 略慢。

跟 x86 对比（i5-7400 笔记本）。

启动：15-20 秒。

7B 模型 tokens/s：6-10。

嵌入：30-60ms/chunk。

x86 处于飞腾跟鲲鹏之间。

性能差距的原因。

原因一：单核性能。国产 CPU 大多数单核性能弱于 Intel/AMD 同期产品。

原因二：指令集成熟度。x86 的 AVX2/AVX-512 指令在数学运算上有优化。aarch64 NEON 在某些场景效果接近，loongarch64 的 LSX 指令较新生态匹配滞后。

原因三：编译优化。chayuan-desktop sidecar 在 x86 上有充分优化的二进制（PyInstaller + ONNX Runtime + sqlite-vec），国产 CPU 上的二进制优化程度受社区进度影响。

GPU 选择。如果要追求性能，配 NVIDIA GPU（多数国产笔记本支持）。

加 RTX 3060：7B 模型 tokens/s 50-80。质变。

加 RTX 4090：跑 14B 70+ tokens/s 没问题。

国产 GPU。昇腾、寒武纪、摩尔线程等。chayuan-desktop 当前主要走 NVIDIA CUDA 加速。国产 GPU 通过 CANN/PaddlePaddle 等需要专门适配，社区推进中。

实战建议。

办公场景。飞腾笔记本跑日常对话和 RAG 没问题。模型选 7B 量化版本。

服务器场景。鲲鹏服务器跑 vLLM 给团队共享。

研发场景。x86 笔记本仍是 chayuan-desktop 开发主流。国产 CPU 上做最终适配测试。

WPS AI 插件 chayuan-wps 在国产 CPU 上跟 chayuan-desktop 一起部署。WPS 加载项的性能跟 chayuan-desktop sidecar 协同决定。

国产 CPU 实测是 chayuan-desktop 国产化的具体落地数据。免费开源的AI软件 给政企客户实际数据，让选型有依据。chayuan-desktop 在这一面持续投入测试覆盖。
