# 国产嵌入模型 BGE 与 GTE 的取舍

chayuan-desktop 桌面单机版选国产嵌入模型。BGE 和 GTE 系列的取舍。这一篇讲。

## 国产嵌入模型生态

BGE（智源 + 北大）。

bge-large-zh / bge-base-zh / bge-small-zh。

bge-m3（多语言，多功能）。

bge-reranker-v2-m3。

GTE（阿里）。

gte-large-zh。

gte-base-zh。

bce（网易有道）。

bce-embedding-base_v1。

bce-reranker-base_v1。

m3e（社区）。

m3e-base。

m3e-large。

每个有自家特点。

## 评测对比

中文检索任务（MTEB-zh）。

```
模型              准确率
bge-m3            76%
bge-large-zh      75%
gte-large-zh      72%
bce-embedding     74%
m3e-base          68%
text2vec-large    65%
```

bge 系列普遍领先。

## 多语种能力

bge-m3 支持 100+ 语言。中文 + 英文 + 日韩 + 阿拉伯等。

gte 主要中文 + 英文。

bce 中文为主。

m3e 中文。

多语言场景 bge-m3 是首选。

## 维度

bge-m3：1024 维。

bge-large-zh：1024。

gte-large：1024。

bce-embedding：768。

m3e-base：768。

bge / gte 默认 1024，bce 默认 768。chayuan-desktop 配置时按 KB 选。

## 模型大小

```
模型              参数        ONNX 大小
bge-m3            500M        700MB
bge-large-zh      326M        500MB
gte-large-zh      326M        500MB
bce-embedding     270M        380MB
m3e-base          110M        200MB
```

家用机器内存 16GB 都能跑任意。

## 推理速度

CPU 上单次嵌入。

```
模型              CPU
bge-m3            55ms
bge-large-zh      45ms
gte-large-zh      45ms
bce-embedding     35ms
m3e-base          20ms
```

m3e 最快。但精度差。bge 系列在精度和速度间平衡。

## chayuan-desktop 的默认

bge-m3-onnx-q8（INT8 量化）。约 200MB。

理由。

中文检索准确率最佳。

多语种支持。

ONNX 格式跨平台。

智源开源（无许可问题）。

## 何时换

场景一：中文专精。bce-embedding 在某些中文场景精度略胜。但失去多语种。

场景二：性能优先。m3e-base 速度快但精度差。仅特殊场景用。

场景三：升级到 bge-m3 之后版本。bge-m4（如果发布）chayuan-desktop 跟进。

## reranker 选择

bce-reranker-base。中文最佳。chayuan-desktop 默认。

bge-reranker-v2-m3。多语言。备选。

每个对中英文都行。中文场景 bce 略好。

## 商业 vs 开源

国产嵌入大多开源。bge、gte、bce、m3e 都是。

某些商业 embedding（智谱 embedding-2 等）chayuan-desktop 也接入但默认不用（出端 + 收费）。

## 国产化场景

党政军场景对嵌入模型也要国产开源。bge / gte / bce 都是国产开源。chayuan-desktop 的默认满足。

某些场景对模型来源严审。chayuan-desktop 的模型卡片标 origin: china + license: MIT/Apache。便于审批。

## chayuan-server 的对应

chayuan-server 部署在 GPU 服务器跑大嵌入模型。chayuan-desktop 单机用 ONNX 量化版。

## WPS 加载项

chayuan-wps 在 WPS 里检索走 chayuan-desktop 嵌入。模型选择对 WPS 透明。

## 总结

国产嵌入模型的取舍是 chayuan-desktop 在 RAG 国产化上的工程选择。免费开源的AI软件 让 嵌入也国产 不影响精度。chayuan-desktop 的 bge-m3 默认 + 多模型支持让国产嵌入生态全覆盖。
