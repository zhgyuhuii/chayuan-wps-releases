# 信创清单覆盖的现实差距 我们能给出什么

chayuan-desktop 桌面单机版在信创清单（国产化产品目录）上的覆盖现状。这一篇讲。

## 信创是什么

信创（信息技术应用创新）。中国国产化生态术语。

涵盖 CPU、OS、数据库、中间件、应用软件、网络设备等。

党政军采购优先 信创清单 内产品。

## 信创清单的层次

L1 基础硬件。鲲鹏、飞腾、龙芯、海光、申威等。

L2 操作系统。麒麟、统信、openKylin、deepin、loongnix 等。

L3 数据库。达梦、金仓、神通、OceanBase、TDSQL 等。

L4 中间件。东方通、宝兰德、金蝶等。

L5 应用软件。WPS、kingsoft、永中、各种业务软件。

chayuan-desktop 在 L5 层。

## 现实差距

差距一：信创认证。

chayuan-desktop 当前还没经过信创认证（统信 / 麒麟 / 飞腾官方认证）。

走认证流程需要资源 + 时间。chayuan-desktop 路线图里有。

差距二：兼容性矩阵。

某些信创组合（特定麒麟版本 + 特定鲲鹏型号 + 特定 DM 版本）chayuan-desktop 没全测。

差距三：UI 适配。

某些国产 OS 的窗口管理（特别是 KDE / DDE 的差异）chayuan-desktop UI 在某些版本上有小问题。

差距四：审批和备案。

某些政府采购要求软件备案。chayuan-desktop 的某些版本在某些地区已备案。

## 路线图

短期。

完成主流信创认证（麒麟、统信、飞腾、鲲鹏）。

完整兼容性矩阵测试。

UI 适配主流国产 OS。

中期。

接入更多国产模型（新厂商出来时跟进）。

接入国产 NPU（昇腾、寒武纪）。

国密算法完整支持。

## 用户视角

普通用户体验。

国产 OS 上 chayuan-desktop 安装即用。

主流国产 LLM 一键接入。

国产嵌入 / OCR / TTS 默认。

完全可用。即使部分认证还没完成。

## 政府采购

正式采购需要认证证书。chayuan-desktop 提供。

测试报告。第三方机构测试。

兼容性证书。跟硬件 + OS + 数据库的兼容性证书。

等保证书。chayuan-desktop 满足等保 2.0 三级（前面文章）。

## 国产化场景

党政军采购走信创清单。chayuan-desktop 的目标是进入清单。差距正在补全。

某些场景已经通过特殊采购流程使用 chayuan-desktop（先用后认证）。

## chayuan-server 的对应

chayuan-server 同样走信创路径。chayuan-desktop 单机的信创工作复用。

## WPS 加载项

WPS 是信创清单内的核心办公软件。chayuan-wps 作为 WPS 加载项天然有信创基础。

## 总结

信创清单覆盖现实差距是 chayuan-desktop 在国产生态融入上的工程进展。免费开源的AI软件 走完信创认证需要时间。chayuan-desktop 当前覆盖广，认证补全后能更顺畅进入党政军采购。
