# 政企内网部署 完全离线的工程化

chayuan-desktop 桌面单机版在政企内网完全离线部署的工程化。这一篇讲。

## 完全离线的定义

完全离线。chayuan-desktop 在内网。

不能访问 npmjs.org。

不能访问 GitHub / Hugging Face。

不能访问任何云 LLM API。

不能访问应用商店。

## 完全离线的必要

党政军、军工、重要部门内网。涉密。物理隔离。

某些金融、能源行业的核心区。同样断网。

人在内网，工具也只能在内网。

## chayuan-desktop 的离线包

chayuan-desktop 提供 完全离线安装包。

```
chayuan-desktop-offline-3.0.0-aarch64.tar.gz (4 GB)
  ├─ chayuan-desktop 主程序
  ├─ models/
  │   ├─ Qwen2.5-7B-Q4.gguf
  │   ├─ Qwen2.5-1.8B-Q4.gguf
  │   ├─ bge-m3-onnx-q8/
  │   ├─ bce-reranker-base-onnx/
  │   ├─ rapidocr/
  │   ├─ funasr-paraformer/
  │   ├─ piper-tts/
  ├─ runtime/
  │   ├─ python (PyInstaller frozen)
  │   ├─ ollama (binary)
  │   ├─ nodejs (for some MCP tools)
  ├─ mcp-tools/
  │   ├─ filesystem-mcp/
  │   ├─ ...
  └─ install.sh
```

一个包含全套。

## 安装流程

第一步。U 盘 / 光盘把离线包带进内网。

第二步。在目标机器解压。

```bash
tar -xzf chayuan-desktop-offline-3.0.0-aarch64.tar.gz
cd chayuan-desktop-offline
sudo ./install.sh
```

第三步。install.sh 部署。

```bash
# 复制主程序到 /opt/chayuan/
# 复制模型到 /var/lib/chayuan/models/
# 复制 mcp 工具到 /var/lib/chayuan/mcp/
# 创建桌面快捷方式
# 注册 systemd 服务（可选）
```

第四步。启动 chayuan-desktop。完全离线运行。

## 内网更新

新版本怎么更新到内网。

流程一。网管在外网下新版离线包。

流程二。流转到内网（按内网流程）。

流程三。员工电脑替换包。

```
chayuan-desktop 设置 - 升级 - 从离线包升级
[选择 chayuan-desktop-offline-3.1.0.tar.gz]
[升级]
```

chayuan-desktop 自动备份当前 + 替换。

## 内网知识库源

某些 KB 需要 公网知识 但内网没。

策略一。出口管理机定期下载（公网）→ 离线带入 → 内网员工电脑导入。

策略二。内网建一个全员共享的 KB（chayuan-server）。某些公开内容由网管定期更新。

## 内网模型源

模型权重定期更新。同样走离线流转。

某些政企搭内网 模型镜像（NAS 或 OSS）。chayuan-desktop 配置内网镜像 URL。员工电脑从这里拉。

## 内网 mcp 工具

mcp 工具的 npm / pip 包内网无法直接装。

策略一：完全离线包预装。

策略二：内网 npm 私服（Verdaccio）。

策略三：定期从外网导入到内网仓库。

## 离线运行验证

chayuan-desktop 启动时检查依赖。

```
[check] 模型: ✓ 完整
[check] 运行时: ✓ 完整
[check] 网络: 离线模式（已识别）
[check] 工具: ✓ 8 个本地工具可用
[ready] chayuan-desktop 已启动
```

让用户对环境有数。

## 离线场景的 UI

UI 上显示。

```
[离线模式]
当前可用：本地 LLM、本地 KB、内置工具。
不可用：联网工具、云 LLM。
```

避免用户误用云模型时浪费时间。

## 国产化场景

党政军部署的核心场景就是完全离线。chayuan-desktop 的离线包是采购的硬需求。

## chayuan-server 的对应

chayuan-server 多用户场景下也支持完全离线部署（部署文档跟单机类似）。chayuan-desktop 单机的离线流程经验复用。

## WPS 加载项

chayuan-wps 跟 chayuan-desktop 一起离线包。员工 WPS 里用 AI 完全本地。

## 总结

政企内网完全离线部署是 chayuan-desktop 在党政军场景的核心能力。免费开源的AI软件 让 完全断网 也能用 AI。chayuan-desktop 的离线包 + 内网更新 + 离线验证让完全离线在工程上落地。
