# 国产化支持下的安全审计 等保合规要点

chayuan-desktop 桌面单机版在等保 2.0 合规上的要点。这一篇讲。

## 等保 2.0 是什么

GB/T 22239-2019 信息安全技术 网络安全等级保护基本要求。

中国信息安全的国家标准。

按重要程度分 5 级。

一级。一般。

二级。重要。

三级。重大。

四级。重点。

五级。涉密最高。

党政军大多三级或更高。chayuan-desktop 重点支持三级。

## 三级要求覆盖

要求一：身份鉴别。

chayuan-desktop。多身份切换 + 主密码。满足。

要求二：访问控制。

chayuan-desktop。RBAC 简化版（owner / reader）。满足基础。

要求三：安全审计。

chayuan-desktop。完整审计日志。满足。

要求四：入侵防范。

chayuan-desktop。本地默认绑定 + 沙箱 + 异常检测。满足。

要求五：数据完整性。

chayuan-desktop。SQLite WAL + 定期备份 + 哈希校验。满足。

要求六：数据保密性。

chayuan-desktop。数据本地 + Stronghold 加密。满足。

## 实施清单

chayuan-desktop 给政企部署的等保实施清单。

第一项：账号管理。

主密码强度（12 位+ 含数字、字母、特殊字符）。

90 天密码更新（chayuan-desktop 提示）。

身份隔离（多身份场景）。

第二项：日志保留。

审计日志保留 ≥ 6 个月。

日志不可篡改（哈希链）。

每周日志归档。

第三项：备份恢复。

每天自动备份。

每周外部备份（NAS / 云盘）。

每季度恢复演练（用户测试）。

第四项：访问控制。

每个 KB 有明确 ACL。

工具调用按角色限制。

每次写操作用户确认。

第五项：数据加密。

KB 数据加密存储（SQLCipher 或类似）。

凭证 Stronghold 加密。

通信加密（HTTPS / TLS 1.2+）。

第六项：网络防护。

仅本机绑定（不暴露公网）。

防火墙配置。

异常访问检测。

## 合规审查工具

chayuan-desktop 内置合规自检。

```
设置 - 合规 - 等保自检
检查项：
  ✓ 主密码强度
  ✓ 审计日志启用
  ⚠ 备份未配置远程
  ✓ 数据加密
  ⚠ 防火墙配置
  
请处理标黄项后再次自检。
```

## 合规报告

chayuan-desktop 生成合规报告。

```
[合规报告]
  系统：chayuan-desktop 3.0.0
  等保级别：三级
  合规状态：12/15 项满足
  整改建议：
    - 配置远程备份
    - 启用防火墙
    - ...
```

提供给等保测评机构。

## 更新和补丁

chayuan-desktop 的安全补丁定期发布。

CVE 漏洞 7 天内补。

普通安全增强月度版本。

某些政企场景对补丁有审批流程。chayuan-desktop 的更新不强制（用户能延后）。

## 国密算法支持

某些场景要求国密算法（SM2、SM3、SM4）。

chayuan-desktop 的国密支持。

SM3 哈希。审计日志哈希链可选 SM3。

SM4 加密。本地数据加密可选 SM4。

SM2 签名。证书签名。

国密支持是路线图。当前 chayuan-desktop 用主流 AES + SHA-256。

## chayuan-server 的对应

chayuan-server 多用户场景下合规要求更高。chayuan-desktop 单机是基础。两者协同。

## WPS 加载项

chayuan-wps 跟 chayuan-desktop 共享合规框架。WPS 调用纳入审计。

## 总结

国产化支持下的安全审计是 chayuan-desktop 在党政军采购的硬要求。免费开源的AI软件 满足等保 2.0 三级。chayuan-desktop 的合规实施 + 自检 + 报告让等保通过有路径。
