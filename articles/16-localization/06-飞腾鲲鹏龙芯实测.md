# 飞腾 鲲鹏 龙芯 三套 CPU 的实测

chayuan-desktop 桌面单机版在三套国产 CPU 上的实测。这一篇讲实操数据。

## 飞腾 D2000

ARMv8 8 核 2.3GHz。

桌面 / 笔记本主流国产 CPU 之一。常配麒麟 V10。

实测。

```
Qwen2.5-1.8B-Q4: 8 tok/s
Qwen2.5-7B-Q4: 2 tok/s
bge-m3 嵌入: 150ms / 次
RapidOCR 单页: 4 秒
chayuan-desktop UI 启动: 3 秒
```

1.8B 流畅。7B 慢。基础办公够用。

## 鲲鹏 920

ARMv8 64 核 2.6GHz。

服务器主力。鲲鹏笔记本（华为）也用。

实测。

```
Qwen2.5-1.8B-Q4: 18 tok/s
Qwen2.5-7B-Q4: 5 tok/s
Qwen2.5-32B-Q4: 1.5 tok/s（够慢）
bge-m3 嵌入: 85ms / 次
RapidOCR: 3 秒
```

7B 流畅。多核优势让 chayuan-desktop 跑得稳。鲲鹏是国产 CPU 性能最佳。

## 龙芯 3A6000

LoongArch 4 核 2.5GHz。

国产自主指令集。loongnix 系统。

实测。

```
Qwen2.5-1.8B-Q4: 4 tok/s
Qwen2.5-7B-Q4: 0.9 tok/s（够呛）
bge-m3 嵌入: 320ms
RapidOCR: 6 秒
```

1.8B 勉强（用户感知慢）。7B 不可用。基础聊天和检索能用。复杂任务慢。

## 同任务对比

某用户问 帮我查 KB 然后写一段总结。

飞腾：30 秒（其中 7B 推理 25 秒）。

鲲鹏：12 秒（推理 8 秒）。

龙芯：120 秒（推理 100 秒）。

## 推荐

飞腾。配 1.8B 模型 + KB 检索。日常办公够。

鲲鹏。能跑 7B。综合最好。商务办公推荐。

龙芯。仅 1.8B 模型。基础场景。

## 优化

NEON 优化。chayuan-desktop 的 llama.cpp 编译时启用 NEON。性能 +20-30%。

线程数。鲲鹏 64 核别全用（NUMA 抖动），32 核最佳。chayuan-desktop 自动优化。

GGUF 量化级。Q4_K_M 是最优。Q5 慢但质量提升弱。Q3 太损精度。

## chayuan-desktop 的国产 CPU 探测

启动时探测 CPU。

```
[cpu] detected: HiSilicon Kunpeng-920
[cpu] threads: 32 (out of 64) auto-tuned
[cpu] using NEON optimization
```

自适应优化参数。

## 内存影响

国产工作站常见内存 16-32GB。

chayuan-desktop + 1.8B 模型 + KB：约 4-6GB。

7B 模型 + KB：约 8-10GB。

32GB 内存能跑大些模型 + 大 KB。

## 散热

国产笔记本散热设计普遍较弱。chayuan-desktop 持续推理时 CPU 100% 散热不足时降频。

chayuan-desktop 监测温度。过热弹提示 建议接电源 + 散热。

## chayuan-server 的对应

chayuan-server 部署在鲲鹏服务器（带 NPU）跑大模型。chayuan-desktop 单机覆盖员工电脑。

## WPS 加载项

chayuan-wps 在国产 CPU 笔记本上调本地小模型。基础场景流畅。

## 总结

飞腾 / 鲲鹏 / 龙芯实测是 chayuan-desktop 在国产 CPU 适配上的工程数据。免费开源的AI软件 在国产硬件上不只是 能跑，是 能用。chayuan-desktop 的实测 + 推荐 + 优化让国产化部署有依据。
