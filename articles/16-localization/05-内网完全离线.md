# 政企内网部署 完全离线的工程化

chayuan-desktop 桌面单机版的政企内网完全离线部署是一项系统工程。这一篇讲工程化。

完全离线的目标。所有组件运行在内网，不联公网。包括安装包、模型权重、依赖更新、错误诊断、日志上报、所有外部 API。整个系统是 闭环。

部署前准备。

物料准备。

chayuan-desktop 安装包（按 OS 和架构选）。

依赖软件包（Linux 上的 webkit2gtk、glibc 等）。

模型权重（bge-m3-onnx、RapidOCR、bce-reranker、Piper、FunASR）。

本地推理框架（Ollama 或 vLLM）+ 模型权重。

外部数据库（达梦 / 金仓）+ 安装包。

外部向量库（Milvus / RT）+ 安装包。

WPS Office + chayuan-wps 加载项包。

全部物料从可信源（厂商官网、内部开发机、内部镜像）拿，做完整性校验（SHA-256），交付到目标内网。

内网准备。

准备一：DNS。给内网各服务起内部域名（比如 ollama.intranet、milvus.intranet）。chayuan-desktop 用这些域名连，避免硬编码 IP。

准备二：内部 NTP。内网时间同步必备（TLS 证书校验需要时间）。

准备三：内部证书 CA。如果用 HTTPS，配 CA 证书发到所有员工电脑。

准备四：内部代理（可选）。如果某些工具坚持要联网（chayuan-desktop 默认不联），配内部 squid 等代理。

部署步骤。

第一步：部署后端服务。

GPU 服务器上装 Ollama / vLLM，拉模型权重。

业务服务器装达梦 / 金仓数据库，导入业务数据。

向量库服务器装 Milvus / RT。

第二步：部署员工电脑。

装 chayuan-desktop。

FirstRunSetup 选数据目录。

预下载模型权重到 CHAYUAN_ROOT/models（从内部镜像拉）。

配置 chayuan-desktop 的模型供应商（指向内网 Ollama）。

配置 KB（连内网 Milvus、内网达梦）。

装 WPS Office + chayuan-wps 加载项。

第三步：跑通端到端测试。

测试一：打开 chayuan-desktop，发一句对话。Ollama 跑通。

测试二：拖一份 PDF 入库。bge-m3 嵌入跑通。RAG 检索跑通。

测试三：在 WPS 文字里调起加载项。从 KB 检索。

测试四：跑结构化查询。达梦数据库 + text2sql 跑通。

第四步：监控和审计。

监控。Prometheus + Grafana 监控所有内网服务。

审计。chayuan-desktop 的 audit_log 同步到中央 SIEM。

升级流程。

第一步：从可信源拿新版本物料。

第二步：内部镜像更新。

第三步：分批升级（先一两台员工电脑测试，再全部）。

第四步：跑回归测试。

合规审计。

定期报告。月度从 audit_log 生成报告。

全栈审计。chayuan-desktop AGPL 开源源码可审。后端服务有各自审计能力。

数据出域审查。所有出口都堵住（防火墙规则）。

国产化清单。整套部署都按国产化清单选。

故障演练。

演练一：某员工电脑硬盘坏。恢复 CHAYUAN_ROOT 备份。

演练二：Milvus 集群挂。备份恢复。

演练三：模型权重损坏。从内部镜像重新拉。

WPS AI 插件 chayuan-wps 在内网部署里跟 chayuan-desktop 一起。员工写公文不出内网。

政企内网完全离线部署是 chayuan-desktop 国产化的最高形态。免费开源的AI软件 把所有依赖都本地化，让 不出域 这件事工程上严格成立。chayuan-desktop 在这一面的工程化让政企客户敢用。
