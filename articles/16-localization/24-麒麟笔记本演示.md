# 国产化支持的演示场景 一台麒麟笔记本的客户演示

某 chayuan 销售在客户现场演示 chayuan-desktop。一台麒麟笔记本。这一篇是演示场景。

## 演示设备

笔记本：联想昭阳 K4e（鲲鹏 920 + 16GB + 集成显卡）。

OS：麒麟 V10 SP3。

无网络（演示完全离线场景）。

预装：chayuan-desktop 3.0.0 + Qwen2.5-7B-Q4 + bge-m3 + bce-reranker + RapidOCR + FunASR + Piper。

## 演示开场（5 分钟）

销售：今天演示 chayuan-desktop 在国产硬件上完全离线运行的能力。

打开 chayuan-desktop。3 秒内启动。

```
[chayuan-desktop UI 加载]
版本：3.0.0
当前 KB：5 个
当前模型：Qwen2.5-7B（本地）
联网：否（完全离线）
```

客户：完全离线？

销售：是的。这台笔记本现在拔了网线，飞行模式。所有 AI 能力都在本地。

## 演示 1：知识库问答（3 分钟）

提前装入了客户的演示 KB（脱敏过的政策文件 100 份）。

销售对 chayuan-desktop 说话（按住麦克风按钮）。

```
"什么是新型基础设施？"
```

ASR 实时转字幕（FunASR）。chayuan-desktop 检索 KB。Qwen-7B 流式生成回答。Piper TTS 边生成边播。

```
"新型基础设施是指..."
来源：[政策文件_2024.pdf 第 5 页]
```

客户看到完整端到端语音对话。完全离线。

## 演示 2：合同审查（5 分钟）

销售把一份合同 PDF 拖入 chayuan-desktop。

```
"快速分析这份合同的关键条款。"
```

chayuan-desktop 解析 PDF（含 OCR 识别红章）→ 入临时 KB → LLM 生成关键条款摘要。

```
关键条款：
1. 合同金额：500 万元
2. 履行期限：6 个月
3. 违约金：合同金额的 20%
4. 争议解决：北京仲裁委
5. 关键风险：[标红] 第 8 条免责条款过宽，建议法务关注
```

客户：能识别风险？

销售：是的。LLM 跟我们的法律 KB 对照，识别异常条款。完全本地。

## 演示 3：多模态（5 分钟）

销售给 chayuan-desktop 一张办公场景照片（员工开会）。

```
"分析这张图，告诉我场景。"
```

视觉模型（用户安装的 Qwen-VL-7B 本地版本）。

```
图中是会议场景。约 5 人围坐。投影仪显示数据图表。氛围讨论积极。
```

完全离线视觉。

## 演示 4：工具调用（3 分钟）

销售展示 chayuan-desktop 调本地工具。

```
"帮我把客户名单整理成 Excel 表格"
```

chayuan-desktop 调内置工具。生成 .xlsx 文件保存到桌面。

```
[已生成] customers.xlsx
[5 列 100 行]
[在 WPS 表格中打开]
```

完全本地。无云。

## 演示 5：模型对抗（5 分钟）

销售启动 Arena。

```
[对抗] 同一问题给三个本地模型
  Qwen2.5-7B
  Qwen2.5-1.8B
  Llama3-8B
```

跑 10 题对比。结果展示。

```
Qwen2.5-7B 综合 88 分（最佳）
Llama3-8B 80 分
Qwen2.5-1.8B 72 分（最快）
```

客户看到模型评测能力。
