# aarch64 与 x86_64 的二进制双发布

chayuan-desktop 桌面单机版的 aarch64 / x86_64 双架构发布。这一篇讲。

## 两种架构的市场

x86_64。Intel / AMD 主流。Windows 笔记本 / 台式默认。中国内地 80%+ 桌面。

aarch64。ARM 服务器（鲲鹏）+ ARM 笔记本（华为 / 联想 / 苹果 M 系列）。增长快。

chayuan-desktop 必须双发布。

## CI/CD 流水线

GitHub Actions 或自建。

```yaml
matrix:
  os: [ubuntu-22.04, macos-14, windows-2022]
  arch: [x86_64, aarch64]

build:
  - rustup target add ${arch}-${os}
  - cargo tauri build --target ${arch}-${os}
  - upload artifact
```

每次 PR 触发所有架构编译。

## 交叉编译

某些场景在 x86 机器上交叉编译 aarch64 二进制。

```bash
rustup target add aarch64-unknown-linux-gnu
sudo apt install gcc-aarch64-linux-gnu
cargo tauri build --target aarch64-unknown-linux-gnu
```

需要 cross compiler。

跨编译速度慢于本机编译。chayuan-desktop CI/CD 用 ARM runner 直接本机编译。

## 二进制差异

x86_64 二进制约 80MB（chayuan-desktop 主程序）。

aarch64 二进制约 75MB（指令集稍紧凑）。

差异不大。

## 性能对比

同代次硬件。

i7-13700H（x86）vs M2 Pro（aarch64）。

LLM 推理。M2 Pro 约 90% i7 性能。

UI 响应。M2 Pro 更流畅（GPU 强）。

KB 检索。同等。

不同架构差不多。chayuan-desktop 在两种上都流畅。

## 平台特定优化

x86_64 上启用 AVX2 / AVX-512。

aarch64 上启用 NEON。

ONNX Runtime 自动选最佳。

llama.cpp 编译时指定。

## 安装包

deb / rpm / msi / dmg / appimage 等。

每个 + 架构 = 双倍安装包。

```
chayuan-desktop_3.0.0_amd64.deb
chayuan-desktop_3.0.0_arm64.deb
chayuan-desktop_3.0.0_amd64.rpm
chayuan-desktop_3.0.0_aarch64.rpm
chayuan-desktop_3.0.0_x64-setup.exe
chayuan-desktop_3.0.0_x64.dmg
chayuan-desktop_3.0.0_aarch64.dmg
```

发布页面让用户选。

## 自动检测下载

chayuan-desktop 官网检测访问者 OS 和架构，推荐对应安装包。

```
检测到您的设备：Linux x86_64
推荐：chayuan-desktop_3.0.0_amd64.deb
[下载]
```

避免用户下错。

## 升级链路

一旦装了 x86_64 版。升级时拉 x86_64 新版。chayuan-desktop 的自动升级保架构。

切换架构（用户换电脑）需要重新装。

## 模型权重的架构无关

模型权重（GGUF、ONNX）跟架构无关。x86 上下载的模型在 aarch64 上能用。

只有推理引擎（llama.cpp、ONNX Runtime）是架构相关的。chayuan-desktop 的不同架构二进制内嵌不同的引擎。

## 共享代码量

chayuan-desktop 的 95% 代码跟架构无关（Rust、TypeScript、Python）。

5% 是平台相关（C/C++ 推理库）。

维护成本主要在 5% 部分。

## 国产化场景

国产 CPU 大多 aarch64（鲲鹏、飞腾）。chayuan-desktop 的 aarch64 版是国产化采购的前提。

x86_64 版兼容海光（自主 x86 兼容指令集）。chayuan-desktop 在海光上跑通。

## chayuan-server 的对应

chayuan-server 同样双架构发布。chayuan-desktop 的 CI/CD 复用。

## WPS 加载项

chayuan-wps 是 WPS 加载项。WPS 在 x86 和 aarch64 都有版本。chayuan-wps 跟 WPS 兼容即可。

## 总结

aarch64 与 x86_64 双发布是 chayuan-desktop 在生态覆盖上的工程基础。免费开源的AI软件 让 国产 ARM + 主流 x86 双双兼容。chayuan-desktop 的 CI/CD + 二进制管理 + 自动检测让用户开箱即用。
