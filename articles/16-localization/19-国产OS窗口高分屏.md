# 国产 OS 下的窗口管理与高分屏

chayuan-desktop 桌面单机版在国产 OS 上的窗口管理和高分屏适配。这一篇讲。

## 国产 OS 的窗口管理

国产 OS 多基于 Linux。窗口管理器各异。

KDE Plasma。麒麟、统信用。

GNOME。openKylin、deepin 部分版本。

DDE（深度桌面）。deepin 自家。

UKUI（麒麟自家）。麒麟某些版本。

Wayland vs X11。

近期国产 OS 转向 Wayland。chayuan-desktop 兼容两者但 Wayland 下某些功能（系统托盘、全局快捷键）实现不同。

## chayuan-desktop 的窗口适配

主窗口大小。默认 1280x800。

最小窗口。800x600。低于这个 UI 元素挤。

最大化 / 全屏。Tauri 标准 API。各 OS 都行。

任务栏图标。chayuan-desktop logo（128x128 PNG）。各 OS 显示。

系统托盘。某些 OS 默认开（X11）。Wayland 下可能不可见，chayuan-desktop 有 fallback 通知。

## 高分屏适配

国产笔记本 1080p / 2K / 4K 都有。

chayuan-desktop 用 Tauri 的高分屏 API。自动按 OS DPI 缩放。

```
1080p (96 DPI): 默认大小。
2K (144 DPI): UI 自动放大 1.5x。
4K (192 DPI): UI 自动放大 2x。
```

字体、图标、按钮都适配。

某些国产 OS 的 DPI 设置不准。chayuan-desktop 让用户在设置里手动调缩放。

```
缩放比: [100% ▼ 125% 150% 200%]
```

## 字体渲染

国产 OS 默认字体。

麒麟：思源黑体 / 文泉驿等。

统信：自家 Source Han Sans 派生。

chayuan-desktop 默认用 OS 字体（系统调用）。某些 OS 字体不全（某些 Unicode 字符显示框框）。chayuan-desktop 内嵌备用字体（思源黑体）作为 fallback。

## 中文显示

某些 OS 默认 locale 不是中文。chayuan-desktop 启动时检测。如果系统 locale 是英文但用户选中文 UI，chayuan-desktop 强制用中文。

## 多显示器

chayuan-desktop 支持多显示器。

主屏幕跑 chayuan-desktop。

副屏跑 KB 详情面板（拖出来）。

某些用户喜欢 4 屏摆开。chayuan-desktop 的多窗口模式支持（路线图）。

## 输入法

国产 OS 输入法。

iBus + 拼音 / 五笔。麒麟、统信。

fcitx + 各种。openKylin 等。

Tauri 底层 webview 跟系统输入法集成。chayuan-desktop 的输入框天然支持。

某些场景输入法切换有 bug（特定 OS 版本）。chayuan-desktop 的兼容性测试覆盖。

## 暗色主题

国产 OS 大多支持暗色主题。chayuan-desktop 跟随系统主题。

```
chayuan-desktop 设置 - 主题:
  跟随系统 (默认)
  浅色
  深色
```

跟随系统时根据 OS 主题切换。

## 触屏支持

某些国产笔记本带触屏。chayuan-desktop 的 UI 元素（按钮）大小够手指点。

```
按钮最小 36x36 px。
```

## 国产化场景

党政军采购的笔记本主流是 麒麟 V10 + 飞腾 + 14 寸 1080p。chayuan-desktop 在这种主流配置上完全适配。

新一代国产笔记本（开始上 2K 屏）。chayuan-desktop 的高分屏适配覆盖。

## chayuan-server 的对应

chayuan-server 是服务端，无 UI。chayuan-desktop 单机版 UI 适配的工作不影响 chayuan-server。

## WPS 加载项

chayuan-wps 在 WPS 里展示。WPS 自己处理高分屏。chayuan-wps 跟 WPS 的样式约定一致。

## 总结

国产 OS 下的窗口管理和高分屏是 chayuan-desktop 在 UX 适配上的工程细节。免费开源的AI软件 不只能 装上跑，还要 用得舒服。chayuan-desktop 的 Tauri 跨平台 + DPI 适配 + 字体 fallback 让国产 OS 用户体验流畅。
