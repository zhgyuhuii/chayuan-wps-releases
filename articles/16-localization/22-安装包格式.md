# 国产化支持下的安装包格式 deb rpm 自家分发

chayuan-desktop 桌面单机版的安装包格式覆盖。这一篇讲。

## 主流 OS 的包格式

Linux deb（Debian 系）。Ubuntu、deepin、麒麟桌面 V10 部分版本、统信 UOS 个人版。

Linux rpm（Red Hat 系）。CentOS、RHEL、麒麟桌面 V10 部分版本、统信 UOS 服务器版、openEuler。

Linux AppImage。便携版（不依赖系统包管理器）。

Linux Flatpak / Snap。沙箱化（chayuan-desktop 路线图）。

Windows MSI / EXE。

macOS DMG。

不同发行版需要不同格式。chayuan-desktop 全打包。

## chayuan-desktop 的发布矩阵

```
chayuan-desktop_3.0.0_amd64.deb        # x86_64 Linux
chayuan-desktop_3.0.0_arm64.deb        # ARM Linux
chayuan-desktop_3.0.0_amd64.rpm        # x86_64 Linux RPM
chayuan-desktop_3.0.0_aarch64.rpm      # ARM Linux RPM
chayuan-desktop_3.0.0_loongarch64.rpm  # 龙芯
chayuan-desktop_3.0.0_amd64.AppImage   # 便携版
chayuan-desktop_3.0.0_x64-setup.exe    # Windows 安装包
chayuan-desktop_3.0.0_x64.dmg          # macOS Intel
chayuan-desktop_3.0.0_aarch64.dmg      # macOS Apple Silicon
```

每个 release 同步发布。

## deb 包的结构

```
chayuan-desktop_3.0.0_amd64.deb
  ├─ DEBIAN/
  │   ├─ control（元数据）
  │   ├─ postinst（安装后脚本）
  │   ├─ prerm（卸载前脚本）
  └─ usr/
      ├─ bin/chayuan-desktop
      ├─ share/applications/chayuan-desktop.desktop
      ├─ share/icons/.../chayuan-desktop.png
      └─ ...
```

control 含依赖声明。

```
Depends: libwebkit2gtk-4.1-0, libssl3, ...
```

apt / dpkg 自动处理。

## rpm 包的结构

类似 deb 但格式不同。

```rpm
Name: chayuan-desktop
Version: 3.0.0
Release: 1
Summary: ...
Requires: libwebkit2gtk, openssl, ...

%files
/usr/bin/chayuan-desktop
/usr/share/applications/chayuan-desktop.desktop
...
```

## 安装后脚本

postinst（deb）/ post script（rpm）。

```bash
# 创建用户数据目录
mkdir -p ~/.chayuan

# 注册桌面文件
update-desktop-database

# 创建 systemd 服务（可选）
...
```

让安装即可用。

## 卸载脚本

prerm。

```bash
# 不删用户数据（保留 ~/.chayuan）
# 提示用户：用户数据保留在 ~/.chayuan，如需彻底删除请手动 rm
```

避免误删用户 KB。

## 自家分发

某些政企内网不能访问公网。chayuan 公司提供自家分发。

国家信创应用商店。某些版本上架。

政府官方应用商店（如某省政务应用商店）。

公司直供。客户经理面交安装包。

每种渠道签名一致。

## 内网分发

某政企搭内部应用商店或 yum / apt 私服。

```
chayuan-desktop 配置：
  apt_source: http://apt.corp.com/debian
  rpm_source: http://yum.corp.com/centos
```

chayuan-desktop 升级时从内部源拉。

## 升级 vs 全新安装

deb / rpm 的升级。

```bash
sudo apt update
sudo apt install --only-upgrade chayuan-desktop
```

或

```bash
sudo dpkg -i chayuan-desktop_3.1.0_amd64.deb  # 直接覆盖
```

保留用户数据。

## 国产化场景

党政军采购的安装包格式要求各异。chayuan-desktop 的全格式覆盖让 各种采购流程都能用。

某些场景必须 .deb（统信 UOS 个人版）。某些必须 .rpm（麒麟服务器版）。chayuan-desktop 都给。

## chayuan-server 的对应

chayuan-server 也提供 deb / rpm 包。chayuan-desktop 单机的打包流程经验复用。

## WPS 加载项

chayuan-wps 是 WPS 加载项。WPS 加载项有自家分发格式（.wpsaddin 或 wps online plugin）。chayuan-wps 用对应。

## 总结

国产化支持下的安装包格式是 chayuan-desktop 在跨发行版兼容上的工程基础。免费开源的AI软件 让 一个软件覆盖所有国产 OS 是工程现实。chayuan-desktop 的全格式发布 + 内网分发 + 自动升级让安装部署顺畅。
