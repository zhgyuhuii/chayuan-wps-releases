# KB的元数据扩展字段怎么用 标签与自定义属性

chayuan-desktop 桌面单机版的 KB 有内置元数据字段（名字、类型、统计等），还预留了一个 metadata 字典让用户加自定义字段。这一篇讲怎么用这些扩展字段做更精细的管理。

先看 KB 自身的 metadata 字段。Pydantic schema 里 metadata 是 dict[str, Any]，默认空字典。用户可以往里加任意键值对。chayuan-desktop 不强制 schema，但常用的几个字段约定如下。

tags 字段。一个字符串列表。比如 ["技术", "v3.0", "内部"]。用于在 KB 列表里按标签过滤。前端 KB 管理页支持按 tag 多选过滤。

description 字段。一段自由文本。给 KB 加描述。在 KB 详情页展示。鼠标悬停 KB 名时也能看到摘要。

owner 字段。单机版下默认是当前 OS 用户。多用户版下是创建者。用于审计和权限。

confidentiality 字段。密级。可选值 public/internal/sensitive/confidential。用于政企场景的分级管理。

retention 字段。保留期限（天数或日期）。某些 KB 在指定时间后自动归档或删除。

source_type 字段。原始数据来源类型。比如 manual_upload、folder_sync、imap、jira_export。区分入库渠道。

last_review 字段。最后人工审视时间。对合规重要的 KB 定期审视，记录时间方便审计。

custom_fields。任意业务字段。比如 project_name、cost_center、department。

chunk 级别的 metadata。每个 chunk 也有 metadata 字段。常用约定如下。

source_file 字段。文件名 + 路径。用于回链。

page_number 字段。PDF 来源的页码。

paragraph_index 字段。原文档里的段落序号。

offset_start 和 offset_end 字段。chunk 在原文档的字符偏移。用于精确回链。

confidentiality 字段。每个 chunk 可独立标密级，覆盖 KB 级别。

tags 字段。chunk 级别的细标签。

created_at 和 modified_at。chunk 创建和修改时间。

custom_fields。业务字段。

metadata 在检索时的作用。

filter 过滤。检索时可以按 metadata 过滤。比如 找 confidentiality='public' 的 chunk，或者 找 tags 包含 v3.0 的 chunk。前端的 高级检索 面板支持这些过滤。

排序加权。某些 chunk 的 metadata 可以参与 score 加权。比如 last_modified 越新的 chunk 优先级更高。chayuan-desktop 在 results 模块支持自定义加权规则。

引用展示。引用气泡里的副信息从 metadata 取。比如 confidentiality 在气泡上显示 内部 标记。tags 显示成 chip。

API 操作 metadata。chayuan-desktop 的 /api/v1/kb/{kb_id} 接口支持 PATCH 更新 metadata 字段。增量改字段不影响其他字段。chunk 级别的 metadata 通过 /api/v1/kb/{kb_id}/chunks/{chunk_id}/metadata 接口操作。

metadata 的存储。KB 级别的 metadata 是 KB 表里的 JSON 列。chunk 级别的 metadata 是 chunk 表里的 JSON 列。SQLite 的 JSON1 扩展支持高效查询 JSON 字段。

不要把所有数据塞 metadata。metadata 是 supplementary，主要数据应该在 chunk 文本和向量里。把大量内容塞进 metadata 会让 SQLite 文件膨胀，且影响查询性能。

国产化支持下的 metadata 用法。政企客户常用 confidentiality 和 retention 字段做合规管理。chayuan-desktop 内置这些字段的标准化值，避免每个客户各自定义不同表达。

WPS AI 插件 chayuan-wps 在 KB 选择器里展示 tags 和 confidentiality，让 WPS 用户也能感知 KB 的属性。引用气泡同样按 metadata 展示。

未来的扩展。chayuan-desktop 可能在新版本里把某些常用 metadata 字段提升为顶级字段（schema 化），减少 ad-hoc 用法。这种演化在保持兼容性前提下做。

metadata 扩展字段是 chayuan-desktop 给用户的灵活度。免费开源的AI软件 不预设所有可能的 KB 属性，让用户按业务需要自己加。这种 extensible 设计让 chayuan-desktop 能适配差异巨大的客户场景。
