# 本地离线知识库的跨机迁移 把全部知识库搬到新电脑

换工作电脑、家用台式接力、临时去客户现场演示，都需要把 chayuan-desktop 桌面单机版的 KB 搬到另一台机器。这一篇讲跨机迁移 KB 的几种方式。

先看简单情况。如果两台机器同 OS 同架构（比如都是 Win11 x86_64），直接拷 CHAYUAN_ROOT 是最干脆的做法。前面 21-跨电脑迁移 讲过完整流程。简言之：关 chayuan-desktop，拷整个 CHAYUAN_ROOT，新机改 Tauri 配置指向新位置，重新填模型钥匙。

复杂情况一：跨平台。从 Windows 搬到 macOS 或者 Linux。

数据文件兼容。SQLite 文件、sqlite-vec 文件、ONNX 模型权重都是平台无关的二进制格式，跨平台直接用没问题。

路径处理。Windows 路径用反斜杠，Linux/macOS 用正斜杠。chayuan-desktop 内部 pathlib 自动处理，但是 metadata 里如果存了绝对路径（比如 folder-sync 的源目录），跨平台就失效。新机上要进 KB 设置改源路径再重扫。

权限差异。Windows 上的文件权限模型跟 Linux/macOS 不同。拷过去后可能需要 chmod 调整权限让 sidecar 能读写。

Tauri 配置位置。Windows 是 %APPDATA%\com.chayuan.desktop，macOS 是 ~/Library/Application Support/com.chayuan.desktop，Linux 是 ~/.config/chayuan-desktop。新机上的 chayuan-desktop 用对应位置。

复杂情况二：跨架构。从 x86_64 搬到 ARM 或者 loongarch64。

数据文件兼容。SQLite 和 sqlite-vec 文件大端小端字节序在主流架构（x86_64、ARM64、loongarch64）上都是小端，互通。ONNX 模型权重也跨架构通用。

二进制依赖差异。chayuan-desktop 的安装包是按架构构建的，新架构上要装对应架构的发行包。这个不是数据迁移问题，是装机步骤。

性能差异。x86_64 笔记本上的嵌入计算比 ARM 笔记本快或慢取决于具体型号，但不影响数据有效性。

复杂情况三：用 export/import 工具。

export 操作。在源机器 chayuan-desktop 设置 - 备份与导出 - 导出，选 KB 列表，输入加密密码，生成 chayuan-export-时间戳.zip 文件。

传输 zip。把 zip 拷到新机器（U 盘、网盘、内网 SCP 都行）。

import 操作。新机器 chayuan-desktop 设置 - 从备份恢复，选 zip 文件，输入密码。chayuan-desktop 把 KB 解压到 CHAYUAN_ROOT，更新元数据。

import 跟原数据合并。如果新机器已经有同名 KB，import 时会问 覆盖 / 跳过 / 改名 import 三个选项。这种 conflict resolution 让用户控制合并策略。

复杂情况四：跨命名空间。某个 KB 想从 doc:个人 改成 office:zhangsan:work。chayuan-desktop 不支持直接改命名空间，因为 ku_id 决定了 KB 类型和很多内部行为。变通办法是新建 office:* KB 把数据 copy 过去，旧 KB 删除。这种 重新分类 不是常见操作。

跨机迁移的几个潜在坑。

坑一：钥匙不能跟着走。credentials 目录的密钥派生跟 OS 用户绑定，新机器解不开。新机器要重新填一遍模型钥匙。

坑二：folder-sync 源路径失效。原电脑 D:\Documents 在新电脑可能是 E:\Documents 或者 /home/user/Documents。进 KB 设置改路径再重新触发同步。

坑三：本地推理服务地址变化。原电脑 Ollama 在 127.0.0.1:11434，新电脑可能没装 Ollama 或者装了但端口不同。重新配 OpenAI 兼容路由供应商。

坑四：CHAYUAN_ROOT 路径不一致。原电脑 D:\Chayuan，新电脑可能想放 /Volumes/Data/Chayuan（macOS）。跑完 FirstRunSetup 之后改 Tauri 配置指向正确位置。

国产化支持下的跨机迁移。从 Windows 搬到麒麟 UOS 是常见跨平台场景。chayuan-desktop 的发行包对应国产 OS，数据迁移流程跟通用 Linux 一样。

WPS AI 插件 chayuan-wps 单独装在新电脑的 WPS 上，配 服务器地址 指向新机器的 chayuan-desktop。两边数据一致。

跨机迁移 KB 是 chayuan-desktop 单机版用户的常见需求。免费开源的AI软件 用户拥有数据所有权，迁移这件事既是权利也是责任。chayuan-desktop 把工具准备到位，剩下的是用户的工作流程。
