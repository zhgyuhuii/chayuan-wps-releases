# 本地离线知识库的演示最小集 给客户演示前要装多少

给客户演示察元AI 桌面单机版的时候，时间通常很紧（30 分钟到一小时）。你不能现场建库，得提前装好演示最小集。这一篇讲清楚演示前要准备什么。

先看演示的几个目标。让客户看到 chayuan-desktop 真的能装到电脑上，本地离线知识库 真的在跑，全模型支持 真的覆盖国产，引用气泡真的能回原文。这几件事覆盖了 chayuan-desktop 的核心差异面。

第一项：装好 chayuan-desktop。一台演示机（最好是国产化机器，比如麒麟 UOS 或者 Win11）装好 chayuan-desktop 桌面单机版。CHAYUAN_ROOT 选独立分区。FirstRunSetup 跑完进主界面。

第二项：配两到三个模型供应商。一个国产厂商（DeepSeek 或文心或通义）展示 全模型支持 的国产覆盖。一个海外厂商（OpenAI 或 Anthropic）展示同时也覆盖海外。一个本地推理（Ollama 跑 qwen2.5:7b）展示 完全离线 也能跑。三个之间能切换。

第三项：建三个文档库。一个产品手册（doc:产品手册），一个技术规范（doc:技术规范），一个市场分析（doc:市场分析）。每个 KB 内 30-100 份 PDF 或 Word 文档。建议规模在中型，避免演示时检索太慢。

第四项：建一个结构化 KB。准备一份示例 CSV，比如 模拟销售数据 1000 行。chayuan-desktop 自动转 SQLite 表，用作 src:* 结构化演示。

第五项：建一个外部数据库连接（可选）。如果客户对外部数据源接入感兴趣，配一个 src:postgres_demo 或者 src:dm_demo 指向演示数据库。这个不是必演项，但能加分。

第六项：装 chayuan-wps WPS AI 插件。配置 服务器地址 指向当前机器的 chayuan-desktop。打开 WPS 文字，确认加载项能正常调起。这是 chayuan-desktop 加 chayuan-wps 协同的演示。

第七项：准备演示问题清单。

文档 RAG 演示问题：产品手册里关于 V3.0 的核心改进有哪些。期望命中 doc:产品手册 几段，引用气泡能展开原文页码。

结构化演示问题：上个月华南地区的总销售额。期望走 src:* 跑 text2sql，返回数字加 SQL 展示。

混选演示问题：结合最新销售数据和市场分析报告，给一份本月业绩简报。期望同时调 src:* 和 doc:市场分析，模型综合两边内容。

模型对抗演示。把同一个问题（写一段产品宣传文案）发给三个模型并行，看不同模型的输出风格。

WPS 联动演示。在 WPS 文字里写一段报告草稿，调起 chayuan-wps 加载项，挑 doc:市场分析 KB 提问，引用插入到 WPS 文档里。

第八项：准备演示数据。所有用于演示的 PDF、CSV、模拟数据库都不能含真实客户敏感信息。建议用 Lorem Ipsum 风格的虚构数据，或者自己公司的公开资料。

演示时的几个注意。

注意一：网络。如果演示包含云端模型（DeepSeek、OpenAI），确保现场网络畅通。最好提前配本地 Ollama 兜底。

注意二：电池和电源。演示笔记本电池要够，最好接电源。chayuan-desktop 跑模型对抗时 CPU 高负载。

注意三：屏幕分辨率。演示笔记本屏幕够大（15 寸以上）让客户看得清楚。

注意四：术语。给客户讲解时不要堆 sidecar、orchestrator、ku_id 这些技术词，用 后端、检索引擎、知识库标识 这种通俗表达。

注意五：现场建库慎演。现场拖一份 PDF 进对话窗口建 KB 看起来酷，但万一这份 PDF 解析出问题就很尴尬。建议用提前建好的 KB。

第九项：准备失败兜底。万一某个模型现场限速或者某个外部 API 超时，要能快速切换到本地 Ollama 演示，不让演示卡死。

第十项：演示后的 followup。给客户留一份 演示用的 chayuan-desktop 安装包 或者 release 链接，让他自己装试。给一份 chayuan-wps 加载项安装说明。给一份 联系方式 方便后续支持。

国产化支持下的演示。给政企客户演示时强调几个点：完全离线、数据不出域、麒麟 UOS 适配、达梦数据库支持、AGPL-3.0 开源可审计。这些是 chayuan-desktop 在国产化场景的核心卖点。

演示最小集的准备时间通常 1-2 小时（不算装机）。一旦准备好，就能反复演示给不同客户看。免费开源的AI软件 销售路径上的演示效率，靠的是这种 复用最小集 的策略。
