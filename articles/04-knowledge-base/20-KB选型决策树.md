# 本地离线知识库的选型决策树 一张图判断你需要哪种源

chayuan-desktop 桌面单机版的五类知识源给用户多种选择，但选错的代价是检索结果不准或者操作复杂。这一篇用决策树的方式讲清楚不同场景该选哪种 KB 类型。

第一个分叉。你的数据是文档（自然语言文本为主）还是数据（数字、表格、字段为主）。

文档场景。你的资料以文章、报告、合同、规章、笔记为主。每份资料的核心是文字内容，不是数字。这种走 doc:* 文档库 或者 office:* 办公私库。

数据场景。你的资料以表格、记录、字段为主。比如客户清单、订单台账、销售数据、财务报表。这种走 src:* 结构化数据库。

混合场景。既有文字也有数据。常见。这种是 同时建两种 KB，问答时一起勾上。

第二个分叉（在文档场景里）。资料是公开还是私密。

公开或部门级共享。建 doc:* 文档库。比如 doc:技术资料 doc:政策法规。所有员工都能查。

个人或团队私密。建 office:* 办公私库。比如 office:zhangsan office:dept_finance。按 owner 隔离。

第三个分叉（在数据场景里）。数据规模和数据库形态。

小规模 CSV 或 SQLite。chayuan-desktop 内嵌结构化 KB 直接处理。把 CSV 上传，自动转成本地 SQLite 表。问答走 text2sql。这是最简单的数据场景方案。

中等规模有现成数据库。MySQL、Postgres、Oracle、SQL Server 这些。chayuan-desktop 通过 src:* 外部连接器接入。配连接信息，跑 text2sql 直接查。

大规模或国产数据库。达梦 DM、金仓 KingbaseES、Doris、ClickHouse、Hive、MongoDB、Elasticsearch。chayuan-desktop 通过 src:* 外部连接器接入，方言适配在内部。

第四个分叉（在向量库场景里）。需不需要外部专业向量库。

不需要。chayuan-desktop 内嵌的 sqlite-vec 默认存所有 doc:* KB 的向量。百万级以下不必额外接外部。

需要。如果你已有 Milvus、Chroma、Zilliz 等集群，且数据规模超百万 chunk 或需要 HNSW 等高级算法，通过 src:* 外部连接器接入。

第五个分叉。需不需要混选。

不需要。一次问答只查一个 KB，简单场景。

需要。一次问答勾上多个 KB（不同类型），让 chayuan-desktop 多源并联检索后聚合。常见场景如 查公司财务数据 + 看对应分析报告。

把上面分叉串起来的决策示例。

示例一：员工日常资料管理。文档为主，公开级别。建 doc:技术资料 doc:产品资料 doc:运营资料 几个 folder-sync KB，对应的本地文件夹自动同步。

示例二：销售部数据问答。数据为主，规模中等，已有 PG 数据库。建 src:postgres_sales 外部连接，问销售数字走 text2sql。同时建 doc:销售文档 装一些销售指南，混选用。

示例三：政府公文处理。文档为主，分级敏感。按密级建 doc:公开 office:dept_finance office:dept_finance:office_a 等 KB，按身份过滤。

示例四：研究人员资料管理。混合场景。论文 PDF 走 doc:论文库 folder-sync。实验数据 CSV 走 src:experiments 结构化。同时挂上做混选检索。

示例五：政企内网部署。完全离线，国产 OS。doc:* 配 sqlite-vec 完全本地。src:* 接达梦或者金仓内网数据库。office:* 按部门隔离。模型走内网 Ollama 或者私有部署的国产 LLM。

不该选什么的反向决策。

数据问题不要塞文档库。比如 有几个客户 这种聚合问题如果走文档库，模型可能编造或者数错。必须走结构化 KB。

公开资料不要塞 office:*。office 是私库，跨用户不可见。如果资料应该全员可见，用 doc:*。

临时资料不要建 folder-sync。一次性的资料用单文件上传到通用 KB 或者临时 KB，省得管理目录。

国产化支持下的决策树。国产场景下数据库选型多用国产（达梦、金仓、Doris），chayuan-desktop 通过 src:* 接入。文档库用 doc:* 配本地 sqlite-vec 完全离线。OS 走国产麒麟 UOS。这种组合在 chayuan-desktop 上完整支持。

WPS AI 插件 chayuan-wps 共用桌面客户端建好的所有 KB。在 WPS 里写报告时按场景勾选合适的 KB。决策树跟桌面端一致。

KB 选型决策树是 chayuan-desktop 用户的导航地图。免费开源的AI软件 想让用户少踩坑，把复杂的选择简化成一系列二选一是务实做法。
