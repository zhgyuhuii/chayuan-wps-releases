# 多模态结果的引用 图像引用的回链

chayuan-desktop 桌面单机版的多模态结果引用回链跟文本一样精确。这一篇讲。

## 图像 chunk 的引用

KB 里的图像（OCR 后入库的扫描件、用户上传的截图、视频抽帧）作为 chunk。LLM 答题命中后引用。

引用气泡含。

图像缩略图。

来源（KB 名）。

页码 / 帧时间戳。

bbox（在原图中的位置）。

## 点击跳转

点击图像引用。

```
原始来源 → 打开原图（原 PDF 第 N 页 / 视频该时间点）→ 高亮 bbox 区域
```

让用户验证 LLM 引用是否准。

## 视频引用的回链

视频 chunk 引用。

```
"张三：销售提升..."
来源: meeting.mp4 [00:00-00:05]
[▶ 播放该片段]
```

点击视频片段从该时间点播放。播放器只播放 5 秒（或用户设置的窗口）。

## 音频引用

ASR 出的音频 chunk。

```
"客户说他对 X 不满意"
来源: customer_call.mp3 [02:34-02:50]
[▶ 播放]
```

跟视频类似。点击播放音频片段。

## 跨多媒体的引用

某用户问综合性问题。LLM 引用文本 + 图 + 视频片段。

```
回答：
张三在 [文本引用] 提到要提升销售。
具体方案见 [图像引用] 销售改进图。
他在 [视频引用] 进一步解释了方法。
```

UI 上每种引用气泡视觉不同。

## 引用的可用性

某 chunk 引用了一张图。如果原图被删（用户清理或文件丢失）。引用气泡变灰。

```
[此图像已不可用]
```

LLM 答题时如果只命中已不可用的引用，回答里加提示。

## 聊天导出时的引用

导出 PDF / docx 时引用气泡转成。

文本：脚注引用。

图像：内嵌图 + 来源说明。

视频：截图 + 链接说明（PDF 不能播放视频）。

```
[图 3 来自 contract.pdf 第 5 页]
```

让导出文档完整保留来源信息。

## 引用的搜索

历史聊天里的引用气泡能搜索。

设置 - 历史 - 搜索。按引用类型过滤（图像、视频、文本）。便于回查 之前那张图在哪个会话。

## 引用的反向链接

某图被多次引用。点击图能看到 这张图被哪些会话引用过。

```
contract_p5_table.png:
  - 会话 #42 (2026-04-15): "合同条款"
  - 会话 #58 (2026-05-01): "回顾合同"
  - 会话 #71 (2026-05-10): "合同到期"
```

便于追踪。

## 国产化场景

党政军场景对引用回链是审计基础。chayuan-desktop 的多模态引用让 AI 答案的图像 / 视频来源 都可追溯。

## chayuan-server 的对应

chayuan-server 多用户场景下引用网络更大（多用户引用同图像）。chayuan-desktop 单机本地。

## WPS 加载项

chayuan-wps 在 WPS 里展示引用气泡。WPS 用户能在文档里看到 AI 引用的图。

## 总结

多模态结果的引用回链是 chayuan-desktop 在 RAG 完整性上的工程能力。免费开源的AI软件 让 多模态的 AI 答案 跟文本一样可追溯可验证。chayuan-desktop 的图像 / 视频 / 音频引用气泡让多模态 RAG 像文本 RAG 一样可信。
