# 多模态路线图 单机版未来支持哪些

chayuan-desktop 桌面单机版的多模态路线图。这一篇讲未来计划。

## 短期（v3.x，2026 H2-2027 H1）

完善视觉 LLM 接入。

更多国产视觉模型。

视觉 LLM 跟 RAG 更深结合。

视觉评测完善。

完善文生图。

更多 T2I 模型接入。

inpainting / outpainting 工具集成。

ControlNet 集成。

完善 ASR / TTS。

更多语音模型接入。

实时流式优化。

声纹分离基础支持。

## 中期（v4.x，2027 H2-2028 H1）

文生视频。

集成本地 / 云 T2V 模型（Sora、可灵、混元视频等）。

短视频生成（5-10 秒）。

视频编辑工具。

3D 内容。

3D 模型生成（Point-E、Shap-E 类）。

3D 模型查看器集成 chayuan-desktop。

某些场景（产品设计、建筑）的 AI 辅助。

实时视频流处理。

直播流处理优化。

会议视频实时分析。

监控视频实时检测。

## 长期（v5+，2028+）

多模态统一模型。

不再分文本 / 视觉 / 视频 / 音频 模型，一个模型全包。

类似 GPT-4o、Gemini 2.0 已经在做。

chayuan-desktop 跟随。

具身智能。

机器人控制。AI 不只回答，还能操作物理世界。

某些家用机器人接入 chayuan-desktop。

虚拟世界。

VR / AR 集成。chayuan-desktop 在 VR 里展示。

多媒体生成进入 3D 空间。

## 单机版的边界

单机版不会做的。

复杂的视频后期编辑（专业软件领域）。

3D 渲染（专业 GPU 工作站）。

大规模多媒体处理（云服务领域）。

实时高质量视频生成（需要服务器）。

边界基于 单台桌面机能跑。超出的是 chayuan-server 范围。

## 国产模型的紧贴

国产生态发展快。chayuan-desktop 紧跟。

新模型出来 1-3 个月内适配。

国产模型评测纳入 Arena。

国产开源模型本地部署支持。

## 开源生态的协作

跟 ComfyUI 等开源生态协作。chayuan-desktop 不重复造轮子。

ComfyUI 的工作流能在 chayuan-desktop 内调用。

Stable Diffusion WebUI 的 API 兼容。

## 用户社区的反馈

多模态需求很大程度由用户驱动。chayuan-desktop 的反馈通道。

GitHub Issues。

社区论坛。

某些场景调研。

按需调整路线图。

## 国产化场景的特别考虑

党政军场景。

视觉模型完全离线（不联网）。

水印 + 元数据强制。

NSFW 检测严格。

合规审查工具集成。

教育场景。

家长监管模式（限制某些内容生成）。

学习辅助多模态（解题、批改）。

医疗场景（路线图）。

医学影像 AI 辅助。

涉密医学数据完全本地处理。

## chayuan-server 的对应

chayuan-server 跟随相同路线但更激进（服务器算力更强）。chayuan-desktop 单机版精简版本。

## WPS 加载项

chayuan-wps 在 WPS 里享受多模态进化的红利。WPS 文档处理越来越智能。

## 总结

多模态路线图是 chayuan-desktop 的长期愿景。免费开源的AI软件 不只满足当下，要为未来准备。chayuan-desktop 的短期完善 + 中期扩展 + 长期统一让多模态在桌面单机长期可演进。
