# 视觉对话 把图片丢给GPT-4V的统一封装

chayuan-desktop 桌面单机版支持视觉对话（看图说话）。用户上传图片，LLM 看图回答。这一篇讲。

视觉模型选择。

GPT-4o（OpenAI）。视觉能力强。

Claude 3.5 Sonnet。视觉能力强。

通义千问 VL（阿里）。中文场景好。

文心一言 4.0 Vision（百度）。

智谱 GLM-4V。

豆包视觉（字节）。

LLaVA / Qwen-VL（本地开源）。

chayuan-desktop 的统一封装。前端在对话框旁有 加图片 按钮。用户上传图片后，按当前 vision 默认模型走 OpenAI Vision 协议或对应厂商协议。

实际用法。

例子一：识别截图里的内容。用户截一张表格的截图。问 这个表格的数据是什么。LLM 看图后用文字描述表格内容。

例子二：分析图表。用户上传一张销售曲线图。问 这个趋势怎么样。LLM 解读图表。

例子三：OCR 替代。某些场景 vision 模型当 OCR 用。质量比 RapidOCR 略低但能理解上下文。

例子四：架构图分析。用户上传系统架构图，问 这个架构有哪些组件。LLM 看图描述。

例子五：界面截图调试。用户截一张应用 UI 截图问 这里有什么 bug 风险。LLM 看图分析。

跟 RAG 的协作。某些场景视觉对话结果回流入 KB。比如截图里的关键信息被识别后，作为 chunk 入库。后续可检索。

视觉模型的成本。Vision API 调用比纯文本贵几倍。一张图片视为几千 token 算钱。chayuan-desktop 在前端展示成本估算让用户心里有数。

本地视觉模型。Qwen-VL 7B 本地部署需要 GPU。chayuan-desktop 接本地 vision 模型走同一接口。完全离线场景下用本地。

性能。

云端 vision API 调用。3-10 秒（含图片上传 + 模型推理）。

本地 Qwen-VL。GPU 上 5-15 秒。

中文场景的视觉模型。

GPT-4o 中英文都好但偏英文。

通义 VL、文心 Vision 中文场景优秀。

国产化部署优先国产视觉模型。

国产化支持下的视觉。完全国产化场景下用通义 VL 私有部署或本地 Qwen-VL。chayuan-desktop 都支持。

WPS AI 插件 chayuan-wps 在 WPS 里支持插入图片让 AI 分析。比如用户在 WPS 里粘贴架构图，让 AI 分析后写注释。

视觉对话是 chayuan-desktop 多模态的常见场景。免费开源的AI软件 想覆盖 看图 这种自然交互，视觉模型必须接。chayuan-desktop 的统一封装让用户切换模型不感知差异。
