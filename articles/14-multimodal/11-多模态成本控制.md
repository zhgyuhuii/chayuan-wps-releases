# 多模态请求的成本控制

chayuan-desktop 桌面单机版对多模态请求的成本控制。这一篇讲。

## 多模态的高成本

文本聊天每次约 0.001-0.05 元。

视觉调用每次约 0.1-0.5 元（图大时更贵）。

T2I 文生图每次约 0.5-2 元。

T2V 文生视频每次约 5-30 元。

ASR 长音频每次几角到几元。

成本累积快。

## 成本预估

每次多模态调用前 chayuan-desktop 显示预估。

```
此次调用预估成本：
  GPT-4V 视觉: ¥0.18
  Image generation (DALL-E 3): ¥0.32
  总计: ¥0.50
[继续] [取消]
```

让用户知情决策。

## 单次成本上限

设置里能配单次调用上限。

```yaml
multimodal_cost_limit:
  per_request: 5  # 单次不超 ¥5
  per_day: 50    # 每日不超 ¥50
  per_month: 500 # 每月不超 ¥500
```

超限时 chayuan-desktop 弹提示让用户确认或拒绝。

## 自动用本地

chayuan-desktop 的智能路由优先尝试本地。

视觉理解能用本地 Qwen-VL 不用 GPT-4V。

T2I 能用本地 Stable Diffusion 不用 DALL-E。

ASR 能用本地 FunASR 不用云。

只有本地不够好时才走云。用户能在设置调倾向。

## 图像压缩

发图给视觉 LLM 前压缩。1024x1024 压缩到 512x512 token 数大幅降。

chayuan-desktop 自动按 LLM 推荐尺寸压缩。

某些场景需要高精度（OCR、细节识别）。chayuan-desktop 弹提示 当前压缩可能损失细节，是否原图。让用户选。

## 缓存复用

同一张图问同样问题。命中缓存。

```
用户：这图什么意思 + [img_abc]
[5 分钟前已查过，复用缓存结果]
```

不重复花钱。

## 批量优惠

某些云厂商对批量调用有优惠（OpenAI batch API 半价）。

chayuan-desktop 在某些场景能批量。

```
用户上传 100 张图问 每张是什么。
chayuan-desktop 提示：使用 batch 模式预计耗时 24 小时但成本减半。
```

让用户选 实时贵 或 慢但便宜。

## 月度预算控制

chayuan-desktop 的统一预算系统（前面文章讲）覆盖多模态。

接近预算时提示。100% 暂停所有付费多模态调用，只让本地继续。

## 跟踪历史

监控面板。

```
多模态成本：
  本月：¥234
  视觉调用 78 次：¥45
  图像生成 23 次：¥56
  ASR 12 次：¥133（音频长）
```

让用户看大头在哪。

## 国产化场景

国产模型 API 大多比国外便宜。chayuan-desktop 推荐国产优先（成本和合规双赢）。

某些场景完全本地（无 API 成本）。chayuan-desktop 的本地多模态优势。

## chayuan-server 的对应

chayuan-server 多用户场景下成本按用户分摊。chayuan-desktop 单机用户全负担。

## WPS 加载项

chayuan-wps 在 WPS 里发起多模态请求经过 chayuan-desktop 网关。预算和成本控制对 WPS 透明。

## 总结

多模态请求的成本控制是 chayuan-desktop 在用户体验上的工程必要。免费开源的AI软件 让 用户用得起多模态 + 用得放心。chayuan-desktop 的预估 + 上限 + 自动本地 + 压缩 + 缓存让成本可控。
