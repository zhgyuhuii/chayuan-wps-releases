# 多模态评测 给生成图像打分

chayuan-desktop 桌面单机版的多模态评测功能。这一篇讲。

## 多模态评测的难度

文本评测有客观指标（精度、召回、BLEU、ROUGE 等）。

多模态特别是生成式（文生图、文生视频）很难客观评测。

某图美不美？某视频符不符合 prompt？

主观性强。

## 评测的几个维度

维度一：技术质量。

清晰度（无模糊）。

无明显瑕疵（多余手指、扭曲文字）。

色彩自然。

维度二：prompt 一致性。

生成内容是否符合 prompt 描述。

主体、动作、场景准确。

维度三：美学质量。

构图。

光影。

色彩搭配。

维度四：安全合规。

无 NSFW（成人内容）。

无暴力血腥。

无侵权（生成名人脸等）。

每维度独立打分。

## 自动评测方法

CLIP score。CLIP 模型算图像和 prompt 的语义相似度。客观但简单。

VQA score。问 VQA 模型 这图里有 X 吗，验证 prompt 一致性。

NIMA / MUSIQ。审美评分模型。客观但训练数据偏。

DreamSim。专业图像质量评测模型。

chayuan-desktop 的 Arena 集成这些自动评测。

## 用户盲评

最准的评测是人盲评。

chayuan-desktop UI。

```
两张图的 prompt 都是 "一只在森林里的红色狐狸"
A: [图]
B: [图]
您觉得哪张更好？
[A] [B] [一样]
```

足够多盲评后用 Bradley-Terry 算 ELO。

## 多模型对比

chayuan-desktop 的 Arena 让用户对比多个文生图模型。

```
prompt: "公司年会现场"
DALL-E 3: [图]
通义万相: [图]
Stable Diffusion: [图]
Midjourney: [图]
```

并排展示。用户选最满意。

## 评测的成本

每次评测可能调多个模型生成图。每个生成 0.5-2 元。100 题 4 模型 = 400 次生成 = 200-800 元。

chayuan-desktop 提示用户成本预估让决定。

某些评测能用本地 SD 跑省钱。

## 评测结果的应用

应用一：选默认模型。基于评测选最适合的。

应用二：发现退化。新版模型对比旧版看是否退化。

应用三：调参。同模型不同 cfg_scale、steps 试。

## 视频评测

视频评测更难。除了图像维度还要考虑。

时间一致性。前后帧是否连贯。

动作合理性。

声画同步（如果有音频）。

chayuan-desktop 的视频评测目前是基础版。复杂评测需要专业工具。

## ASR 评测

ASR 评测客观。WER（Word Error Rate）。chayuan-desktop 自动计算。

```
ground_truth: "我觉得这个方案挺好"
asr_result:   "我觉这个方案挺好"
WER: 5%
```

## 国产化场景

国产生成模型对比有意义。chayuan-desktop 的 Arena 让用户基于自己场景选国产或国际模型。

某些场景必选国产（合规）。chayuan-desktop 的评测让用户在国产模型间选最佳。

## chayuan-server 的对应

chayuan-server 多用户场景下评测数据更多更准。chayuan-desktop 单机基础版。

## WPS 加载项

WPS 内不直接做评测。但 WPS 用户用 chayuan-desktop 评测后的最佳模型生成报告插图。

## 总结

多模态评测是 chayuan-desktop 在选模型决策上的工程支持。免费开源的AI软件 不让用户被厂商宣传忽悠。chayuan-desktop 的自动评测 + 用户盲评 + Arena 对比让多模态选型有数据支持。
