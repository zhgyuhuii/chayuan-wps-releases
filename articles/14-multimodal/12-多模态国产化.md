## 接入方式

chayuan-desktop 的网关层（前面文章讲）统一封装。每个国产模型有对应的 adapter。

```
adapters/
  qwen.py
  glm.py
  ernie.py
  doubao.py
  hunyuan.py
  ...
```

每个 adapter 把模型 API 转成 chayuan-desktop 内部表示。

## 鉴权方式

国产 API 鉴权各异。

阿里云 (DashScope)。AccessKey + Secret 签名。

智谱。API Key + JWT。

百度文心。API Key + Secret + Token 换取。

字节豆包。API Key + Secret + V4 签名。

腾讯混元。Secret ID + Secret Key + V3 签名。

讯飞。AppID + APIKey + APISecret。

每个签名算法不同。chayuan-desktop 的 adapter 内置实现。用户只填 Key 即可。

## 模型卡片标识

chayuan-desktop 的模型卡片标 origin: china 字段。设置里能 国产优先 一键过滤。

## chayuan-server 的对应

chayuan-server 部署在国产 GPU 服务器跑国产视觉模型。chayuan-desktop 单机能跑小模型 + 调云。
