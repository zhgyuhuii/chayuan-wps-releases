# T2I文生图 接入SD系与厂商API的双轨

chayuan-desktop 桌面单机版的文生图（T2I）支持本地 Stable Diffusion 系跟厂商 API 双轨。这一篇讲两条路径。

本地 SD 路径。

部署方式。装 ComfyUI 或 Automatic1111 web UI。chayuan-desktop 通过这些工具的 API 调用。

模型权重。SDXL、SD 1.5、Flux 等。从 civitai 或 modelscope 下载。

性能。RTX 4060+ GPU 跑 SDXL 1024x1024 约 10-30 秒/图。CPU 太慢不实用。

成本。一次性 GPU 投入。后续零成本。

控制度。用户能调 prompt、negative prompt、CFG scale、steps、seed 等参数。

适合场景。

频繁生成。每天大量图。

隐私敏感。prompt 不上传。

定制化高。要用 LoRA、ControlNet 等扩展。

厂商 API 路径。

OpenAI DALL-E 3。质量高，遵循 prompt 好。每图几毛钱（按 size 计费）。

文心一格（百度）。中文 prompt 友好。

通义万相（阿里）。集成阿里云。

字节豆包文生图。新接入。

腾讯混元文生图。国产代表。

性能。云端 API 5-15 秒/图。

成本。按 image 计费，每图 0.1-0.5 元。

控制度。比本地 SD 略弱。但厂商有自己的高级选项（DALL-E 3 的 hd vs standard）。

适合场景。

偶尔生成。每月几百张内。

要求质量。某些厂商比本地 SD 质量更好。

不想运维 GPU。

chayuan-desktop 的统一调用。

```
client.images.generate(
    model="dall-e-3",  # 或 sdxl-local、wanxiang
    prompt="一只猫坐在窗户边看夕阳",
    size="1024x1024"
)
```

切换 model 字段就切后端。其他参数（quality、style）按厂商支持转换。

混合用法。chayuan-desktop 让用户配多个 T2I 后端。日常用本地 SD（成本低），重要场合用 DALL-E 3（质量好）。

跟 LLM 的协作。LLM 在对话里调用 image_generate 工具时按 default image 模型走。用户在对话框可以临时切换。

WPS AI 插件 chayuan-wps 在 WPS 里能让 AI 生成图。直接插入到 WPS 文档。

T2I 的双轨设计是 chayuan-desktop 给用户的灵活度。免费开源的AI软件 不强求用户走某一路径。本地或云端都行，按场景选。chayuan-desktop 在这一面的支持让 文生图 真正可用。
