# 多模态的提示工程 视觉提示与文本提示的搭配

chayuan-desktop 桌面单机版的多模态提示工程跟纯文本不同。这一篇讲。

## 视觉 prompt 的特点

视觉 LLM 看图 + 看 prompt 一起决策。prompt 写得好让模型聚焦关键。

```
不好：这图什么意思
好：请描述图中的图表，重点关注 X 轴和 Y 轴的趋势
```

明确指引让回答更精准。

## 任务定向

不同任务不同 prompt 模式。

描述任务：详细描述图中所有元素，包括人物、物体、背景、文字、颜色。

OCR 任务：提取图中的所有文字，按从上到下从左到右顺序。

理解任务：图中的图表说明了什么趋势？请用一句话总结。

诊断任务：图中是否有异常？比如错别字、逻辑错误、格式问题。

## 多步引导

某些复杂分析需要多步。

```
第一步：识别图中的所有图表元素。
第二步：读取每个数值。
第三步：分析趋势。
第四步：给出洞察。
```

CoT（Chain of Thought）让模型按步骤来。

## 上下文增强

某些场景给视觉 LLM 加文本背景。

```
背景：这是某公司 2026 年 Q1 销售月报。
图：[销售数据图]
请告诉我哪个月销售最好以及原因（结合公司近期事件）。
```

视觉 + 文本上下文 LLM 回答更准。

## 视觉提示

prompt 里能引导模型看图的某部分。

```
请关注图的右下角的小字部分，那里有重要信息。
```

模型更聚焦。

## prompt 模板

chayuan-desktop 给常见多模态任务提供模板。

```yaml
templates:
  ocr_extract:
    prompt: "请提取图中所有可见文字，保持原文语言和顺序。如有表格请用 markdown 格式。"
  chart_analysis:
    prompt: "分析图表：1) 类型 2) 主要变量 3) 趋势 4) 关键洞察"
  document_summary:
    prompt: "总结图中文档的核心内容，5 句话内"
```

用户能选模板或自己写。

## 文生图的 prompt

文生图 prompt 也很重要。

```
不好：画个猫
好：A photorealistic image of a fluffy orange tabby cat sitting on a windowsill, soft afternoon sunlight, detailed fur texture, shallow depth of field
```

详细 prompt 出图质量翻倍。

## prompt 扩展

LLM 帮助扩展简洁 prompt。

```
用户：画个猫
LLM 内部：扩展 prompt 为详细描述
LLM：调 image_generate(prompt="<扩展版>")
```

用户体验简单。LLM 内部做提示工程。

## 多语言 prompt

视觉 LLM 在中英文 prompt 上表现可能不同。

某些视觉 LLM 中文 prompt 较弱。chayuan-desktop 自动翻译成英文 prompt 提升质量。

某些视觉 LLM（Qwen-VL）中文 prompt 优于英文。chayuan-desktop 保留中文。

模型卡片里标注每个模型的 prompt 语言偏好。

## 国产化场景

国产视觉模型大多中文 prompt 强。chayuan-desktop 鼓励中文 prompt（不必先翻译）。

## chayuan-server 的对应

chayuan-server 多用户场景下提示模板由管理员预置。chayuan-desktop 单机用户级。

## WPS 加载项

chayuan-wps 在 WPS 里调多模态时使用 chayuan-desktop 的 prompt 模板。员工写报告时 AI 给的视觉分析质量稳定。

## 总结

多模态的提示工程是 chayuan-desktop 在 AI 输出质量上的工程关键。免费开源的AI软件 让 多模态调用 不只调通，是 调好。chayuan-desktop 的模板 + 多步引导 + LLM 自动扩展让多模态提示质量稳定。
