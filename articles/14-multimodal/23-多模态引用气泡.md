# 多模态的引用气泡 图片片段怎么标注

chayuan-desktop 桌面单机版的多模态引用气泡跟文本气泡同等重要。这一篇讲细节。

## 图像引用气泡的字段

```json
{
  "type": "image_citation",
  "kb_id": "doc:contracts",
  "source_file": "contract_2026.pdf",
  "page": 5,
  "bbox": [100, 200, 800, 400],
  "thumbnail_url": "...",
  "alt": "合同关键条款图表",
  "score": 0.92
}
```

含完整溯源信息。

## bbox 的意义

bbox = [x1, y1, x2, y2]。在原图中的左上角和右下角坐标。

LLM 引用某个具体表格 / 图表。bbox 让用户跳转后高亮该区域。

不只是 这页有这内容，是 这页这位置有这内容。

## 缩略图渲染

引用气泡显示原图的缩略图（200x200）+ bbox 高亮框。

```
[原图缩略图 + 红色框圈出 bbox]
来源: contract_2026.pdf 第 5 页
[查看原图]
```

让用户一眼看出引用的是什么。

## 跳转行为

点击 查看原图。

PDF。chayuan-desktop 内置 PDF 查看器或调外部 PDF Reader。打开第 5 页。如果 PDF Reader 支持锚点，跳转到 bbox 附近。

WPS 文档。chayuan-wps 加载项接管。打开 docx 跳到对应段落。

视频。播放器从 bbox 对应时间点播放。

## 多个图像引用

某次回答引用多张图。chayuan-desktop UI 横向排列。

```
回答内容...

引用：
[图 1] [图 2] [图 3] [图 4]
```

每个图独立缩略图 + 跳转。

## 视频片段引用气泡

```json
{
  "type": "video_citation",
  "video_file": "meeting.mp4",
  "start_time": 0.0,
  "end_time": 5.0,
  "thumbnail_frame": "...",
  "transcript": "张三：销售提升...",
  "score": 0.88
}
```

含转写文字 + 关键帧 + 时间窗口。

## 音频片段引用气泡

```json
{
  "type": "audio_citation",
  "audio_file": "call.mp3",
  "start_time": 154.0,
  "end_time": 170.0,
  "transcript": "客户说他对 X 不满意",
  "speaker": "客户A",
  "waveform_preview": "..."
}
```

含波形预览 + 转写 + 说话人。

## 引用气泡的颜色

跟前面文章讲一致。

doc:* 蓝色。

src:* 紫色。

office:* 橙色。

多模态在颜色基础上加图标区分。

📄 文本。

🖼 图像。

🎬 视频。

🎵 音频。

让用户一眼看出引用类型。

## 引用的导出

聊天导出 PDF。引用气泡转。

文本：脚注。

图像：内嵌图 + 引用说明。

视频：截图 + 链接说明。

音频：图标 + 链接说明。

完整保留来源信息。

## 引用的可信度

引用 score（重排后的相关度）显示在气泡上。

```
引用气泡：
  [图 1] (相关度 0.92)
  [图 2] (相关度 0.78)
```

让用户对引用质量有数。

## 引用的可访问性

某些用户视力障碍。引用气泡支持。

alt 文字（屏幕阅读器读出）。

键盘导航（Tab + Enter 跳转）。

高对比度模式。

无障碍合规。

## 国产化场景

党政军场景对引用追溯严格。chayuan-desktop 的多模态引用气泡含完整溯源。等保审计场景能输出。

## chayuan-server 的对应

chayuan-server 共享前端引用气泡组件。chayuan-desktop 单机版的引用气泡跟 server 版一致。

## WPS 加载项

chayuan-wps 在 WPS 里展示引用气泡。多模态引用同样视觉一致。

## 总结

多模态的引用气泡是 chayuan-desktop 在 RAG 完整性上的工程细节。免费开源的AI软件 让 多模态 AI 答案 跟文本 AI 答案 同样可追溯。chayuan-desktop 的彩色 + 图标 + 缩略图 + bbox + 时间窗口让多模态引用直观可信。
