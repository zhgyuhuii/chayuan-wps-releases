# 多模态工具调用 让模型自己生成图

chayuan-desktop 桌面单机版让 LLM 通过工具调用生成图像。这一篇讲。

## 场景

用户问 帮我画一只猫。LLM 不直接画（LLM 是文本模型），调用 image_generate 工具。

工具调用 DALL-E / Stable Diffusion / 通义万相。返回图。

LLM 在回答里展示图。

## 工具的描述

```yaml
- name: image_generate
  description: |
    根据文本描述生成图像。
    适合用户想看可视化、概念图、艺术创作等场景。
  parameters:
    - name: prompt
      type: string
      description: 详细的图像描述
    - name: style
      type: string
      enum: ["realistic", "anime", "sketch", "oil_painting"]
      default: "realistic"
    - name: size
      type: string
      enum: ["512x512", "1024x1024", "1024x1792"]
      default: "1024x1024"
```

## LLM 的提示

工具调用前 LLM 需要把用户简洁的描述扩展成详细 prompt。

```
用户：画一只猫
LLM 生成 prompt: A photorealistic image of a fluffy orange cat sitting on a wooden floor, soft natural lighting, high resolution, detailed fur texture
```

详细 prompt 出图质量更好。

## 后端选择

chayuan-desktop 的 image_generate 工具背后能调多种后端。

DALL-E 3（OpenAI）。质量好，贵。

Stable Diffusion（本地）。免费，本地部署。

通义万相。国产，便宜。

Midjourney（通过 Discord bot 桥接）。质量极好但配置麻烦。

用户在设置选默认后端或让 LLM 按场景选。

## 多步生成

某些复杂场景多步。

第一步：LLM 生成基础 prompt。

第二步：image_generate 出图 v1。

第三步：用户反馈 颜色不对。

第四步：LLM 修改 prompt 加颜色描述。

第五步：image_generate 出图 v2。

每步是独立的工具调用。

## 图像编辑

某些后端支持基于已有图编辑（DALL-E 3 的 inpainting、SD 的 image-to-image）。

工具描述。

```yaml
- name: image_edit
  parameters:
    - name: source_image
      type: image
    - name: edit_prompt
      type: string
```

LLM 调用时给原图 + 编辑指令。

## 失败处理

生成失败（内容过滤、模型异常）。chayuan-desktop 弹错误。

LLM 看到错误能调整 prompt 重试。

```
DALL-E 拒绝："涉及人物形象，无法生成"
LLM 调整：去掉具体人物，改成抽象表达
```

## 国产化场景

党政军场景对 AI 生成内容有合规要求（特别是涉及人物、政治敏感等）。chayuan-desktop 优先国产模型（合规审查更适配中国法规）。

某些场景完全禁用图像生成（避免合规风险）。chayuan-desktop 配置能禁用。

## chayuan-server 的对应

chayuan-server 部署在 GPU 服务器跑本地 SD。chayuan-desktop 单机能跑小型 SD 但慢。

## WPS 加载项

chayuan-wps 在 WPS 里能让 AI 生成图像插入文档。员工写报告时一句话生成插图。

## 总结

多模态工具调用让 chayuan-desktop 的 AI 能 画 不只是 说。免费开源的AI软件 让 文生图 集成到工作流。chayuan-desktop 的工具抽象 + 多后端 + LLM 提示扩展让图像生成自然落地。
