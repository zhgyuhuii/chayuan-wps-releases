# 多模态结果在 UI 上的展示 图像 视频 音频

chayuan-desktop 桌面单机版的多模态结果在 UI 上展示。这一篇讲。

## 图像展示

聊天界面显示图像直接 inline。点击放大查看。

```
LLM: 这是 Q1-Q4 销售趋势图：
[图像缩略图]
点击全屏 / 下载 / 复制
```

懒加载。仅当图进入视图时加载。

## 缩略图

大图先显示缩略图（200x200）。点击加载原图。

避免聊天历史滚动时大图卡顿。

## 视频展示

视频在聊天里嵌入式播放器。

```
LLM 引用了一段会议视频：
[视频播放器 - meeting_2026_05_10.mp4 - 00:00-00:05]
[▶ 播放]
```

播放器小尺寸。点击全屏。

## 音频展示

音频 inline 播放器。

```
[音频播放器 - 张三的发言 - 30 秒]
[▶ 播放] [波形图]
```

支持加速 1.5x、2x。

## 视频片段

LLM 引用视频的某片段。播放器从该时间点开始。

```
"张三：我觉得这个季度销售可以再提升"
来源: meeting_2026_05_10.mp4 [00:00-00:05]
[▶ 仅播放该片段]
```

点击只播放引用的几秒。

## 多媒体的 thumbnail 缓存

每个图像 / 视频的缩略图缓存到本地。

```
~/.chayuan/cache/thumbnails/
  abc123_thumb.jpg
  def456_thumb.mp4.jpg
```

聊天历史滚动时秒级加载。

## 引用气泡的多模态

引用气泡支持图像引用。

引用气泡含。

预览缩略图。

来源（KB 名 + 文件路径）。

时间戳（视频/音频）。

bbox（图像中的位置）。

点击跳转到完整资源。

## 下载和导出

每个多媒体右上角下载按钮。一键保存到本地。

聊天导出（PDF / docx）时多媒体打包到 zip。

## 多媒体的尺寸控制

某些用户希望聊天界面紧凑。多媒体尺寸调小。

某些用户希望大尺寸（视觉处理）。

设置里调。

## 暗黑模式

多媒体在暗黑模式下。

图像加暗角避免太亮。

视频播放器整体暗。

UI 适配。

## 屏幕共享

某些场景用户在 chayuan-desktop 内屏幕共享或截图（路线图）。chayuan-desktop 的多媒体展示扩展。

## 国产化场景

党政军场景多媒体使用率不低。会议视频、扫描件、图表。chayuan-desktop 的展示让多媒体内容能流畅访问。

## chayuan-server 的对应

chayuan-server 多用户场景下多媒体集中存储。chayuan-desktop 单机本地。

## WPS 加载项

chayuan-wps 在 WPS 里展示多媒体引用。WPS 文档插入图像引用气泡 + 跳转链接。

## 总结

多模态结果在 UI 上的展示是 chayuan-desktop 在用户体验上的工程关键。免费开源的AI软件 让 图像视频音频 不只是文件，而是聊天里能交互的内容。chayuan-desktop 的播放器 + 缩略图 + 缓存让多模态体验流畅。
