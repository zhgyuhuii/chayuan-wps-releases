# 多模态对硬件的要求 一台普通笔记本的边界

chayuan-desktop 桌面单机版的多模态对硬件有要求。普通笔记本的边界在哪。这一篇讲。

## 内存要求

视觉模型 Qwen-VL-7B Q4。占 4-5GB。

ASR FunASR Paraformer。占 1-1.5GB。

TTS Piper。占 200MB。

加上 chayuan-desktop 主程序 + 知识库。

总内存需求约 12-16GB。

普通办公本 8GB 不够。16GB 起步。

## 显存要求

集成显卡。够跑 ASR + TTS（CPU 路径）。视觉模型本地跑慢但能。

独立显卡 4GB。Qwen-VL-7B Q4 + ASR/TTS。流畅。

独立显卡 8GB+。能跑视觉 + LLM 同时。完整本地化。

## CPU 要求

任何近 5 年的 CPU 都能跑（Intel i5、AMD R5 起）。

国产 CPU（鲲鹏、飞腾）也能跑（参考前面文章）。

CPU 跑视觉慢（每帧几秒）。GPU 路径必备多模态流畅体验。

## 硬盘

模型权重总量约 5-10GB。

多媒体缓存可能占几 GB-几十 GB。

总建议 SSD 100GB+ 自由空间。

机械硬盘也能跑但慢（模型加载几十秒）。SSD 强烈建议。

## 网络

完全离线场景。无要求。

混合云模型。需要稳定上行带宽（视觉调用上传图）。

直播流处理。需要稳定下行（处理直播流）。

## 普通笔记本的能跑组合

i5 + 16GB + 集显。

ASR 流畅。

TTS 流畅。

视觉 LLM 慢（每图 5-10 秒）。

文生图慢（每图 30-60 秒，本地 SD）。

图像生成建议走云。

i7 + 16GB + RTX 4060 (8GB)。

全多模态流畅。

视觉 LLM 每图 1-2 秒。

文生图每图 5-10 秒。

ASR 接近实时。

旗舰本（i9 + 32GB + RTX 4090 mobile）。

完美。本地全多模态。

## 笔记本散热

多模态持续推理 GPU 满载。笔记本散热不够会降频。

实测某轻薄本跑视觉 5 分钟后 GPU 频率降 20%。

chayuan-desktop 监测温度。过热时弹通知 建议接电源 + 抬高笔记本散热。

## 续航

电池单跑多模态。

集显笔记本：3-4 小时。

独显笔记本：1-2 小时。

外接电源时不限制。

chayuan-desktop 设置 - 省电 - 电池模式自动降级。视觉转 ASR 走 CPU + 用更小模型。

## 完全不能跑的场景

老笔记本（i3 + 4GB + 集显）。多模态基本不行。建议走云模式（chayuan-desktop 当前端，云模型）。

旧 Mac（Intel x86 + 8GB）。多模态有限。可以跑 ASR/TTS。视觉 / 生成走云。

## 国产化场景

国产笔记本（鲲鹏 / 飞腾 / 龙芯）。

ASR/TTS 流畅。

视觉模型可跑但慢。

文生图基本不跑（NPU 推理框架还在完善）。

建议国产笔记本配公司 chayuan-server 走云端多模态。

## chayuan-server 的对应

chayuan-server 部署在 GPU 服务器解决硬件问题。员工笔记本只是客户端。

## WPS 加载项

chayuan-wps 在普通笔记本上能用基础 ASR/TTS/视觉。复杂处理走 chayuan-desktop 后端 / 云。

## 总结

多模态对硬件的要求是 chayuan-desktop 的工程现实。免费开源的AI软件 让 主流硬件能用基础多模态。chayuan-desktop 的实测数据 + 自动降级让用户对设备能力心中有数。完全本地多模态需要中高配。
