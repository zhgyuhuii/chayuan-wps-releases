# 多模态结果的二次编辑 怎么把图片再交给模型

chayuan-desktop 桌面单机版支持把生成的图再交给模型做二次编辑。这一篇讲。

## 二次编辑的需求

第一次生成的图。

颜色不对。

某细节缺失。

整体布局想换。

某些元素想替换。

每种都需要二次处理。

## 编辑的几种方式

方式一：调整 prompt 重生。

```
LLM 修改 prompt 加颜色描述。重新调用 image_generate。
```

完全新图。原图丢弃。

方式二：image-to-image。

```
基于原图 + 修改指令生成新图。
新图保留原图的整体布局和构图。
```

更多控制。

方式三：inpainting。

```
用户在图上画一个区域。仅在该区域内重新生成。
```

精准编辑。

方式四：outpainting。

```
扩展图像（往外画）。原图保留，新部分基于原图风格延伸。
```

## chayuan-desktop 的工具支持

工具一：image_edit_global。基于 prompt 修改整体（image-to-image）。

工具二：image_inpaint。基于 mask 修改局部。

工具三：image_outpaint。扩展图像。

工具四：image_remove_object。移除某物（用 SAM + inpaint）。

工具五：image_replace_object。替换某物。

每个工具有清晰描述。LLM 按场景选。

## 工作流示例

用户：我想要一张猫的图，但要橙色的。

LLM 调 image_generate(prompt="A cat")。出图（默认灰色）。

用户：要橙色的。

LLM 调 image_edit_global(image=<上图>, prompt="make the cat orange")。出新图（橙色）。

用户：背景太暗了，换成森林。

LLM 调 image_edit_global(image=<上图>, prompt="orange cat in a forest")。

每次基于上一版编辑。chayuan-desktop 的对话历史保留每版图。

## 版本管理

每次编辑生成新版。chayuan-desktop 的 UI 显示版本历史。

```
v1: A cat
v2: orange cat
v3: orange cat in forest
```

用户能回到任一版本继续编辑。

## 局部编辑的 UI

某些场景需要在图上画 mask。chayuan-desktop 的画布工具。

```
点击图像 → 进入编辑模式
画笔工具：标记要修改的区域
LLM prompt：在文本框输入
[应用编辑]
```

mask + prompt 发给 inpaint 工具。

## 编辑的成本

每次编辑相当于一次新生成。成本叠加。

chayuan-desktop 提示用户当前已编辑 N 次，总成本 X。让用户对成本有数。

## 国产化场景

党政军场景的图像编辑（修官方海报、调整宣传图）需求。chayuan-desktop 让本地 SD 跑 inpaint，免费且合规。

## chayuan-server 的对应

chayuan-server 部署 GPU 跑大型 SD 模型支持复杂编辑。chayuan-desktop 单机能跑基础。

## WPS 加载项

chayuan-wps 在 WPS 里能基于文档里的图编辑。比如 把这截图的某区域模糊。chayuan-wps 调 chayuan-desktop 的 image_inpaint。

## 总结

多模态结果的二次编辑是 chayuan-desktop 在创作场景的工程能力。免费开源的AI软件 让 AI 出图 不只是一次性，能反复打磨。chayuan-desktop 的多种编辑工具 + 版本管理让图像创作流畅。
