# 多模态接入的最小代码量 开发者体验

chayuan-desktop 桌面单机版让开发者用最小代码量接入多模态。这一篇讲。

## 视觉对话的最小代码

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:62581/openai/v1",
    api_key="dummy"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{
        "role": "user",
        "content": [
            {"type": "text", "text": "这图什么意思"},
            {"type": "image_url", "image_url": {"url": "data:image/jpeg;base64,..."}}
        ]
    }]
)
print(response.choices[0].message.content)
```

10 行代码。完整视觉对话。chayuan-desktop 路由到底层视觉模型。

## 文生图的最小代码

```python
response = client.images.generate(
    model="dall-e-3",
    prompt="A cat in the forest",
    size="1024x1024"
)
print(response.data[0].url)
```

完全 OpenAI 兼容接口。chayuan-desktop 路由到 DALL-E 或本地 SD。

## ASR 的最小代码

```python
audio_file = open("audio.mp3", "rb")
transcript = client.audio.transcriptions.create(
    model="whisper-1",
    file=audio_file
)
print(transcript.text)
```

OpenAI Whisper 接口。chayuan-desktop 路由到本地 FunASR 或云。

## TTS 的最小代码

```python
response = client.audio.speech.create(
    model="tts-1",
    voice="alloy",
    input="Hello, world"
)
response.stream_to_file("output.mp3")
```

完整 TTS。

## 视频处理的最小代码

视频 chayuan-desktop 提供专门接口（OpenAI 没有原生视频）。

```python
import requests

response = requests.post(
    "http://127.0.0.1:62581/v1/video/process",
    json={"video_url": "file:///path/to/video.mp4"}
)
```

返回视频的 chunk + 索引。

## 本地模型的接入

切换底层模型只改 model 参数。

```python
# 用本地 Qwen-VL
response = client.chat.completions.create(
    model="ollama:qwen-vl:7b",
    messages=[...]
)
```

不改代码。chayuan-desktop 内部路由。

## 流式接收

```python
stream = client.chat.completions.create(
    model="gpt-4o",
    messages=[...],
    stream=True
)
for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="")
```

流式跟非流式只差一个参数。

## 错误处理

```python
try:
    response = client.chat.completions.create(...)
except Exception as e:
    if "rate_limited" in str(e):
        # 重试或换模型
        ...
```

chayuan-desktop 用 OpenAI 标准错误码。开发者熟悉。

## 第三方应用接入

LangChain、LlamaIndex 等框架天然支持 OpenAI 兼容协议。改 base_url 即可。

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    base_url="http://127.0.0.1:62581/openai/v1",
    api_key="dummy",
    model="gpt-4o"
)
```

LangChain 的所有功能都能通过 chayuan-desktop 访问底层。

## 国产化场景

国产开发者用 chayuan-desktop 做本地 AI 服务。配 OpenAI SDK 直连本地。代码跟用 OpenAI 一致。学习成本低。

## chayuan-server 的对应

chayuan-server 同样 OpenAI 兼容协议。chayuan-desktop 单机版的代码能直接迁到 chayuan-server。改 base_url。

## WPS 加载项

chayuan-wps 内部就是用 OpenAI SDK 调 chayuan-desktop。开发者看 chayuan-wps 源码学接入。

## 总结

多模态接入的最小代码量是 chayuan-desktop 的开发者友好性核心。免费开源的AI软件 让 开发者用 10 行代码接入完整多模态 AI。chayuan-desktop 的 OpenAI 兼容协议 + 多模态扩展让开发简单。
