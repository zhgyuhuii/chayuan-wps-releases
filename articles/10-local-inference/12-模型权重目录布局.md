# 模型权重的目录布局 升级时不重新下载

chayuan-desktop 桌面单机版的模型权重存放有约定的目录布局。便于升级时不重复下载。这一篇讲。

## 默认目录

```
~/.chayuan/
  models/
    embeddings/
      bge-m3-onnx-q8/
        model.onnx
        tokenizer.json
        config.json
    rerankers/
      bce-reranker-base-onnx/
        ...
    llm/
      ollama-models -> /usr/share/ollama/models  # 软链
      gguf/
        Qwen2.5-1.8B-Instruct-Q4_K_M.gguf
        Qwen2.5-7B-Instruct-Q4_K_M.gguf
    ocr/
      rapidocr/
        det.onnx
        cls.onnx
        rec.onnx
    asr/
      funasr-paraformer-large-onnx/
        ...
    tts/
      piper/
        zh_CN-huayan-medium.onnx
```

每类模型在自己的子目录。

## 模型版本

每个模型目录里有 manifest.json。

```
{
  "name": "bge-m3-onnx-q8",
  "version": "1.0.0",
  "size": 207000000,
  "sha256": "abc...",
  "downloaded_at": "2026-04-15",
  "source": "https://modelscope.cn/..."
}
```

chayuan-desktop 升级时检查版本。一致就不重下。

## 升级时的处理

chayuan-desktop 1.0.0 → 1.1.0 升级。

第一步。chayuan-desktop 1.1.0 启动时检查需要的模型清单。

第二步。对比当前 ~/.chayuan/models/ 已有的。

第三步。已有版本一致 → 复用。

第四步。已有版本过旧 → 提示用户升级（不强制，避免重复下载几 GB）。

第五步。完全没有 → 下载。

## 升级时的兼容性

旧版 chayuan-desktop 的模型基本能在新版用。chayuan-desktop 保证向前兼容（不换模型路径或格式）。

模型本身有大版本变化时（如 bge-m3 → bge-m4，向量维度从 1024 → 2048），chayuan-desktop 会提示用户 模型升级会让现有 KB 索引失效，是否一键重建索引。

## 软链支持

某些用户不想模型放 ~/.chayuan/。比如想放 D 盘或外挂硬盘。chayuan-desktop 支持软链。

```bash
# Linux/Mac
ln -s /mnt/external/models ~/.chayuan/models

# Windows (管理员命令行)
mklink /D %USERPROFILE%\.chayuan\models D:\models
```

## Ollama 模型共享

如果用户已安装 Ollama 跑过模型，那些模型不重下。chayuan-desktop 自动检测 Ollama 模型目录（默认 ~/.ollama/models/），软链到自己的 llm 目录下。

避免相同模型存两份占磁盘。

## LM Studio 模型共享

LM Studio 模型默认在 ~/.cache/lm-studio/models/。chayuan-desktop 同样自动检测共享。

## 多用户共享

某些场景一台电脑多用户（家庭共用）。每个 OS 账号有自己的 ~/.chayuan/。模型重下浪费。

chayuan-desktop 支持系统级模型目录。

```bash
# Linux
sudo mkdir -p /var/lib/chayuan/models
sudo chown -R chayuan-users:chayuan-users /var/lib/chayuan/models

# 把每个用户的 ~/.chayuan/models 软链到这里
ln -s /var/lib/chayuan/models ~/.chayuan/models
```

所有用户共享。空间省。

## 删除清理

chayuan-desktop 设置 - 模型 - 已下载模型。

列表显示每个模型大小。能 删除按钮 一键删。

也支持 自动清理 30 天未用的模型。

## 模型校验

每次启动时校验模型 SHA256。损坏的模型自动重下。

避免坏文件导致推理崩溃。

## 国产化场景

党政军内网部署。chayuan-desktop 的模型仓库支持配 国内镜像 或 本地 NAS。所有模型从内网拉，不联外网。

```
chayuan-desktop 设置：
  model_mirror: http://nas.corp.com/models
```

## chayuan-server 的对应

chayuan-server 模式下模型在服务器。员工 chayuan-desktop 不下模型，按需走服务器接口。

## WPS 加载项

chayuan-wps 不直接管模型。所有模型由 chayuan-desktop 维护。WPS 只调 chayuan-desktop 接口。

## 总结

模型权重的目录布局是 chayuan-desktop 在长期使用的工程基础。免费开源的AI软件 让 升级不重下 + 多软件共享模型 + 自定义路径 三件事兼顾。chayuan-desktop 的目录约定 + manifest 校验 + 系统级共享让 模型管理 在工程上整洁。
