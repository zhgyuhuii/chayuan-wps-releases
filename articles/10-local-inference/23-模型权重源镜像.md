# 模型权重源 Hugging Face 镜像与本地复用

chayuan-desktop 桌面单机版的模型权重来源除了 Hugging Face 还有镜像。这一篇讲。

## Hugging Face 的痛点

Hugging Face 是 AI 模型主流仓库。但在国内访问。

痛点一：网络慢。从国内拉模型动辄几小时。

痛点二：偶尔断流。被墙或 GFW 影响。

痛点三：政企内网无法直连外网。

需要镜像。

## 国内镜像源

镜像一：ModelScope（阿里达摩院）。中文模型最全。speed 快。免费。

镜像二：HF-Mirror。社区维护。Hugging Face 完整镜像。

镜像三：国家深度学习开源开放创新平台。某些政府推荐。

镜像四：百度 Gitee AI。某些模型有。

chayuan-desktop 默认配置 ModelScope 作为首选源。HF-Mirror 作为备份。

## 配置方式

chayuan-desktop 设置 - 模型 - 模型源。

```yaml
sources:
  primary: modelscope
  fallback: hf-mirror
custom_mirror: https://nas.corp.com/models  # 内网镜像
```

下载模型时按顺序尝试。

## 政企内网镜像

某些政企单位完全断网。chayuan-desktop 的 模型源 配置成内网 NAS 或对象存储。

```
custom_mirror: http://internal-nas.corp.com/chayuan-models/
```

NAS 上预放模型权重。chayuan-desktop 启动时从 NAS 拉。

模型权重的同步流程。某个内网管理机能联外网拉模型。然后 rsync 到 NAS。员工电脑从 NAS 拉。

## 校验完整性

每个模型有 SHA256 哈希。chayuan-desktop 下载完校验。哈希不一致重下。

避免 镜像被污染或文件损坏 导致推理崩溃。

## 增量下载

chayuan-desktop 的模型源支持断点续传。下到一半网络断开，重启时续传不重头。

某些大模型（72B FP16 几百 GB）必须支持续传。

## 多源并行

chayuan-desktop 下大模型时能从多个源并行拉。一个文件分块从不同源拉，最后拼。

加速大模型下载。

## 跟其他工具共享

如果用户已用 Hugging Face Hub 命令行（huggingface-cli）下过模型，chayuan-desktop 自动检测复用。

```
~/.cache/huggingface/hub/  # HF 默认目录
~/.cache/modelscope/hub/   # ModelScope 默认目录
```

chayuan-desktop 启动时扫描这些目录的模型，软链到自己 models/ 目录。

## 本地复用

某员工已下了 Qwen2.5-7B 模型。其他员工想用同款。chayuan-desktop 的 LAN 内模型共享 功能。

```
chayuan-desktop 设置 - LAN 共享：
  enable: true
  shared_models_dir: D:\public\chayuan-models
  discoverable: true
```

启用后局域网内其他 chayuan-desktop 实例能发现这台机器有的模型。下载时优先从局域网拉（速度快）。

不开启时不广播。用户隐私优先。

## 模型卡片同步

模型权重之外，模型卡片（描述、上下文长度、定价等）也要同步。chayuan-desktop 的模型卡片仓库（GitHub）也有镜像（gitee 或自架）。

## 国产化场景

党政军单位完全断网。chayuan-desktop 的内网镜像方案成熟。常见做法。

第一步。一台外网管理机下载模型到外接硬盘。

第二步。硬盘带到内网 NAS 上传。

第三步。员工电脑 chayuan-desktop 配 NAS 镜像。

完整闭环。chayuan-desktop 的官方文档有这种部署的详细步骤。

## chayuan-server 的对应

chayuan-server 模式下模型直接由服务器管理。员工 chayuan-desktop 不下模型，调 chayuan-server 接口推理。

## WPS 加载项

chayuan-wps 不直接管模型。所有模型由 chayuan-desktop 维护。镜像配置对 WPS 透明。

## 总结

模型权重源镜像与本地复用是 chayuan-desktop 在网络环境复杂场景的工程支持。免费开源的AI软件 让国内用户、政企内网用户都能拿到模型。chayuan-desktop 的多源 + 镜像 + LAN 共享让 拉模型 在各种网络条件下都能搞定。
