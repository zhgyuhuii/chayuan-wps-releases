# 国产化支持下的飞腾鲲鹏龙芯推理性能实测

chayuan-desktop 桌面单机版在国产 CPU 上的本地推理性能。这一篇给实测数据。

## 测试机型

机型一。鲲鹏 920（华为）。ARMv8。64 核 2.6GHz。麒麟 V10 SP3。

机型二。飞腾 D2000（飞腾科技）。ARMv8。8 核 2.3GHz。统信 UOS V20。

机型三。龙芯 3A6000（龙芯中科）。LoongArch64。4 核 2.5GHz。loongnix。

机型四。海光 7280（海光信息）。x86_64。32 核 2.0GHz。openEuler。

对比机型 Intel i7-13700H（笔记本，参考）。

## 测试模型

Qwen2.5-1.8B-Q4_K_M。约 1GB。基础对话。

Qwen2.5-7B-Q4_K_M。约 4GB。日常问答。

bge-m3-onnx（嵌入）。约 200MB。

## 推理后端

llama.cpp（基于 CPU）。chayuan-desktop 内嵌的本地推理后端。支持 ARM、x86、LoongArch。

llama.cpp 在 ARM 上有 NEON 优化。在 x86 上有 AVX2 / AVX-512 优化。LoongArch 用基础 SIMD。

## Qwen2.5-1.8B 实测

每秒 token 速率（解码阶段）。

| CPU | tokens/s |
|---|---|
| 鲲鹏 920 | 18.2 |
| 飞腾 D2000 | 8.5 |
| 龙芯 3A6000 | 4.3 |
| 海光 7280 | 22.1 |
| Intel i7-13700H | 35.4 |

首字延迟（prompt 100 token）。

| CPU | TTFT (ms) |
|---|---|
| 鲲鹏 920 | 320 |
| 飞腾 D2000 | 580 |
| 龙芯 3A6000 | 1200 |
| 海光 7280 | 240 |
| Intel i7-13700H | 180 |

结论：鲲鹏 920 和海光 7280 接近 Intel 性能。飞腾 D2000 慢一倍。龙芯 3A6000 慢得多但能用。

## Qwen2.5-7B 实测

| CPU | tokens/s |
|---|---|
| 鲲鹏 920 | 5.2 |
| 飞腾 D2000 | 2.1 |
| 龙芯 3A6000 | 0.9 |
| 海光 7280 | 6.8 |
| Intel i7-13700H | 11.3 |

7B 模型在国产 CPU 上 跑得动 但流畅度有差。鲲鹏和海光接近可用。飞腾够用但慢。龙芯 1 token/s 仅勉强够用（适合后台批处理）。

## 嵌入模型实测

bge-m3-onnx 单次嵌入耗时（输入 256 token）。

| CPU | ms |
|---|---|
| 鲲鹏 920 | 85 |
| 飞腾 D2000 | 150 |
| 龙芯 3A6000 | 320 |
| 海光 7280 | 70 |
| Intel i7-13700H | 55 |

嵌入比 LLM 推理便宜得多。各国产 CPU 都能流畅做嵌入。建索引时 1 万 chunk 花鲲鹏 14 分钟，飞腾 25 分钟，龙芯 53 分钟，能接受。

## 内存占用

llama.cpp 在 ARM 上的内存占用跟 x86 接近。

Qwen2.5-1.8B-Q4。约 1.5GB（模型 1GB + KV cache 500MB）。

Qwen2.5-7B-Q4。约 5GB（4GB + 1GB）。

国产工作站典型配置 16GB 内存够跑 7B。

## 优化建议

建议一：用 Q4 量化。Q4_K_M 是质量和速度的甜蜜点。Q5 慢 30% 质量提升微弱。

建议二：调 thread 数。llama.cpp 默认用全部核心。鲲鹏 920 有 64 核，实际用 32 核效果更好（避免 NUMA 抖动）。chayuan-desktop 自动探测优化。

建议三：开 mmap。模型权重不全加载内存，按需 page。慢但省内存。

建议四：避免 7B 模型在飞腾 D2000 跑。还是 1.8B 流畅。

## chayuan-desktop 的自适配

启动时探测 CPU 类型。

发现 ARM CPU。启用 NEON。提示用户 已识别 ARM 架构。

发现 LoongArch。提示性能可能慢。建议优先用 1.8B 模型。

发现 x86 + AVX-512。启用最快路径。

## 国产化场景

党政军单位采购国产工作站，跑 chayuan-desktop 是主流场景。chayuan-desktop 的本地推理在国产 CPU 上的性能数据是采购评估的关键。

鲲鹏 920 + 16GB 内存的工作站跑 chayuan-desktop + Qwen2.5-7B 流畅可用。基本达到 Intel 水平。

## chayuan-server 的对应

chayuan-server 部署在国产服务器（鲲鹏服务器）上，跑 vLLM 类型 GPU 推理框架。chayuan-desktop 是 CPU 单机推理。

## WPS 加载项

chayuan-wps 在 WPS 里调用本地模型走 chayuan-desktop 推理引擎。国产工作站上 chayuan-wps 体验跟 Intel 笔记本接近。

## 总结

国产 CPU 推理性能实测是 chayuan-desktop 给政企采购的硬数据。免费开源的AI软件 跑在飞腾鲲鹏龙芯上的可行性靠这种实测说话。chayuan-desktop 的 NEON 优化 + 1.8B 默认推荐让 国产化推理 真正可用。
