# 本地推理的安全边界 不要把推理端暴露到公网

chayuan-desktop 桌面单机版的本地推理只对本机或局域网开放，不对公网。这一篇讲安全边界。

## 暴露公网的风险

如果用户把 Ollama 或 chayuan-desktop 的 OpenAI 兼容端点暴露到公网。

风险一：被刷算力。陌生人发现接口免费用，疯狂调用消耗你 GPU。电费暴涨。

风险二：被钓鱼。攻击者发奇怪 prompt 让模型生成有害内容，记到日志栽赃。

风险三：模型被探测。攻击者通过返回内容推断你跑的是什么模型，配合其他信息搞社工。

风险四：服务被攻击。DDoS 让服务挂掉，影响日常使用。

不暴露公网是基本原则。

## chayuan-desktop 的默认配置

监听 127.0.0.1:62581。只对本机。

外部任何 IP 访问被拒绝。即使在防火墙打开 62581 端口，chayuan-desktop 服务还是只 bind 在 127.0.0.1，外部 IP 连不到。

避免新手用户误开公网访问。

## Ollama 的默认配置

Ollama 默认监听 0.0.0.0:11434。这是一个潜在风险。如果电脑直接连公网（家庭宽带不带路由的极少场景或公网服务器），Ollama 暴露到公网。

chayuan-desktop 检测后自动改 OLLAMA_HOST=127.0.0.1，避免暴露。

## 局域网共享

某些场景用户希望家里其他设备能访问 chayuan-desktop（手机、平板）。需要让 chayuan-desktop 监听局域网。

chayuan-desktop 设置 - 网络 - 局域网共享 开关。

```yaml
listen:
  bind: 0.0.0.0  # 局域网
  cors_origins: ["http://192.168.1.0/24"]  # 仅允许局域网 IP
  require_token: true  # 强制 token 认证
```

启用后局域网设备能访问。但只有局域网，不出公网。

## 防火墙配置

启用局域网共享时 chayuan-desktop 提示用户配置防火墙。

Windows。Windows Defender Firewall 添加 chayuan-desktop 入站规则，仅本地子网。

macOS。系统防火墙允许 chayuan-desktop。

Linux。iptables 或 ufw 添加规则。

```bash
sudo ufw allow from 192.168.1.0/24 to any port 62581
```

## 暴露到公网的合法场景

少数合法场景。

场景一：用户自架 chayuan-desktop 给团队用。这种应该用 chayuan-server，不用 chayuan-desktop 单机。

场景二：远程办公需要从外网访问家里的 chayuan-desktop。

第二种推荐方案。

方案一：VPN。家里架 VPN（WireGuard、ZeroTier 等），员工连 VPN 后访问 chayuan-desktop。

方案二：SSH 隧道。员工 SSH 到家里机器，把 62581 端口转发到本地。

不直接对公网开放。

## 强制认证

如果 chayuan-desktop 检测到自己监听 0.0.0.0 或公网 IP。强制启用 token 认证。

任何请求必须带 Authorization: Bearer <token> header。token 由 chayuan-desktop 生成（强随机），用户在设置里看。

不允许匿名访问。

## 速率限制

公网或局域网模式开启速率限制。每个 IP 每分钟最多 60 次请求。超过返回 429。

避免被刷算力。

## 审计加强

公网模式下每次请求记审计。来源 IP、token 哈希、prompt 哈希、时间戳。便于追溯异常调用。

## 数据出端的二次确认

公网模式下用户对话内容如果要发给 OpenAI（联网模型）。chayuan-desktop 弹双重确认。

```
您正在远程访问 chayuan-desktop。
当前请求会把对话发给 OpenAI。继续？
```

防止远程访问中误把数据上云。

## 国产化场景

党政军单位严禁把内部服务暴露公网。chayuan-desktop 的默认本机绑定符合等保规定。

某些场景 VPN 远程办公。chayuan-desktop 跟 VPN 配合。

## chayuan-server 的对应

chayuan-server 是企业级服务，从设计就暴露给团队访问。带完整认证授权。chayuan-desktop 单机不该承担这个角色。

## WPS 加载项

chayuan-wps 在本机访问 chayuan-desktop 走 127.0.0.1，不走公网。安全。

## 总结

本地推理的安全边界是 chayuan-desktop 的工程红线。免费开源的AI软件 不能因为方便就让用户的算力暴露到互联网。chayuan-desktop 的默认本机绑定 + 局域网开关 + 强制 token + 审计 + 速率限制构成完整安全模型。
