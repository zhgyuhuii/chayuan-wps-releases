# 本地推理的可观测 token/s 时延 错误

chayuan-desktop 桌面单机版的本地推理收集 tokens/s、时延、错误率等指标。这一篇讲。

## 收集的指标

每次本地推理记录。

```json
{
  "timestamp": "2026-05-10T14:23:11Z",
  "model": "ollama:qwen2.5:7b",
  "ttft_ms": 567,
  "duration_ms": 12450,
  "input_tokens": 250,
  "output_tokens": 480,
  "tokens_per_sec": 38.6,
  "gpu_memory_used_mb": 4520,
  "cpu_percent": 80,
  "status": "success" | "failed",
  "error": null | "OOM" | "timeout" | ...
}
```

按模型聚合。

## tokens/s 的意义

每秒输出 token 数。衡量推理速度。

家用 RTX 4060 + Qwen-7B-Q4。约 35-50 tok/s。流畅。

家用集成显卡 + Qwen-1.8B-Q4。约 15-25 tok/s。流畅。

CPU 跑 Qwen-7B-Q4。约 5-10 tok/s。慢但能用。

## 首字延迟（TTFT）

从请求到第一个 token 的耗时。包含 prompt 处理时间。

GPU 推理 prompt 100 token：约 100-300ms。

CPU 推理同样：约 500ms-2s。

prompt 越长 TTFT 越大（线性增长）。

## 监控面板

设置 - 监控 - 本地推理。

显示。

实时 tokens/s（最近一次推理）。

最近 24 小时各模型平均 tokens/s。

最近 24 小时 TTFT 分布。

最近 24 小时错误率。

GPU 显存历史曲线。

## 错误类型

错误一：OOM。显存不够。chayuan-desktop 提示 显存不足，建议关闭其他 GPU 应用 或 切换到更小模型。

错误二：模型加载失败。模型文件损坏。chayuan-desktop 校验 SHA256，失败时重下。

错误三：推理超时。某些请求长时间没响应（5 分钟以上）。chayuan-desktop 强制中断。

错误四：CUDA 错误。CUDA toolkit 版本不匹配或 N 卡驱动过旧。chayuan-desktop 提示用户检查驱动。

错误五：tokenizer 不匹配。模型和 tokenizer 文件版本不一致。chayuan-desktop 重下模型。

每种错误都有具体提示。

## 性能基线

chayuan-desktop 内置每个模型在常见硬件上的基线性能。

```
Qwen2.5-7B-Q4 baseline:
  RTX 4090: 80 tok/s
  RTX 4060: 35 tok/s
  M2 Pro: 28 tok/s
  CPU i7-13700H: 11 tok/s
```

实测低于基线 50% 时 chayuan-desktop 提示 性能异常，建议检查后台占用。

## GPU 占用监控

chayuan-desktop 调 nvidia-smi（N 卡）或 macOS Metal Performance HUD（Apple）拿 GPU 利用率。

利用率长期 100%。说明 GPU 持续吃满。性能瓶颈。

利用率忽高忽低（30%-100%）。可能 CPU 瓶颈或 IO 瓶颈。chayuan-desktop 给优化建议。

## CPU 占用

CPU 推理时关注 CPU 利用率。

满负载（每核 100%）。正常。

低负载（30%）。可能 thread 数没配好。

chayuan-desktop 自动调 thread 数。

## 内存监控

模型加载后内存占用稳定（不应该一直增长）。

发现内存泄漏（持续增长）。chayuan-desktop 记录到日志，建议用户重启服务。

## 可观测的导出

监控数据导出 JSON / CSV。某些用户想自己分析。

某些政企场景需要把推理日志归集到企业 SIEM。chayuan-desktop 支持配 Syslog 或 Elasticsearch。

## 国产化场景

党政军单位对 AI 服务可观测有要求（保障运维）。chayuan-desktop 的内置监控满足基础需求。复杂场景集成到企业监控平台。

## chayuan-server 的对应

chayuan-server 模式下监控更完善（多用户聚合）。chayuan-desktop 单机版是入门版。共享指标定义。

## WPS 加载项

chayuan-wps 在 WPS 里发起的请求也记入监控。便于看 WPS 调用占总推理的比例。

## 总结

本地推理的可观测是 chayuan-desktop 在工程透明度上的工程支持。免费开源的AI软件 让用户对推理性能心中有数。chayuan-desktop 的指标 + 基线 + 异常告警让 推理 不再是黑盒。
