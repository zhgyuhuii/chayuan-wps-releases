# 模型缓存目录共享 给多用户共用的策略

chayuan-desktop 桌面单机版的多用户场景下模型缓存目录共享避免重复下载。这一篇讲策略。

## 多用户的场景

场景一。家庭共用台式机。爸爸、妈妈、孩子各有自己的 OS 账号。

场景二。办公室共用工作站。多名员工不同时段使用。

场景三。教学机房。一台机器多个学生用。

每人都跑自己的 chayuan-desktop。如果各自下模型每个 OS 账号占 5-10GB 磁盘。浪费。

## 共享的方案

方案一：系统级共享目录。

```
/usr/share/chayuan/models/      # Linux
/Library/Application Support/Chayuan/models/  # macOS
C:\ProgramData\Chayuan\models\  # Windows
```

每个用户的 ~/.chayuan/models/ 软链到这个共享目录。

方案二：单一用户主导。

某一个用户（admin）下载模型到自己的 ~/.chayuan/models/。其他用户软链过来。

方案三：网络共享。

家里 NAS 挂载到每台机器作为模型源。

## chayuan-desktop 的安装时设置

安装 chayuan-desktop 时询问。

```
[?] 模型存储位置
  > 用户独立 (默认 ~/.chayuan/models/)
    系统共享 (/usr/share/chayuan/models/)
    自定义路径
```

选系统共享时 chayuan-desktop 自动配置软链。

## 权限管理

系统共享目录的权限。

读权限。所有用户。每个用户都能读模型推理。

写权限。有限。某个 admin 用户能写（下载新模型）。其他用户只读。

避免普通用户误删模型影响其他人。

## 模型下载锁

多用户场景下两个人同时点 下载某模型。chayuan-desktop 需要 lock 避免重复下载。

```
~/.chayuan/models/.locks/model_name.lock
```

第二个用户看到 lock 直接等待第一个下载完成，不重复下。

## 模型清理

某个用户删模型时检查是否其他用户在用。

chayuan-desktop 维护引用计数（每个用户用过的模型记录）。最后一个用户停用时模型才物理删除。

避免某用户清理破坏其他人。

## 跨平台的共享路径

Linux：/var/lib/chayuan/models/。属 chayuan-users 组。

macOS：/Library/Application Support/Chayuan/models/。属 staff 组。

Windows：C:\ProgramData\Chayuan\models\。属 Users 组。

## 用户级覆盖

某些用户想自己下特定模型不影响其他人。chayuan-desktop 设置里能加用户级模型路径。

```yaml
model_paths:
  shared: /var/lib/chayuan/models
  user: ~/.chayuan/private_models
```

chayuan-desktop 启动时合并两个目录的模型，user 级优先级更高。

## 教学场景

学校机房的实战。

机器装 chayuan-desktop。系统共享目录预下基础模型（bge-m3、Qwen-1.8B、Qwen-7B）。

每个学生 OS 账号登录 chayuan-desktop 直接能用。无需各自下模型。

学生想试新模型，教师 admin 账户下载到共享目录，所有学生秒级看到。

## 国产化场景

党政军教学机房或共用工作站常见。chayuan-desktop 的共享目录方案省磁盘、省带宽（一次下，多用）、便于管理。

某些等保场景禁止用户自己下模型（避免下到敏感模型）。chayuan-desktop 配置里能 锁定 共享目录，禁止用户级自下。

## chayuan-server 的对应

chayuan-server 多用户共享一个模型库（服务器端）。chayuan-desktop 单机多用户场景的简化版本。

## WPS 加载项

chayuan-wps 不直接管模型。所有模型由 chayuan-desktop 维护。共享目录对 WPS 透明。

## 总结

模型缓存目录共享是 chayuan-desktop 在多用户场景的工程优化。免费开源的AI软件 不让多用户重复下模型浪费资源。chayuan-desktop 的 系统共享 + 用户级覆盖 + 下载锁 + 引用计数 让多用户的模型管理整洁。
