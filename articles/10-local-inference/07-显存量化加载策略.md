# 显存不够时怎么办 量化与加载策略

chayuan-desktop 桌面单机版的本地推理常遇到 显存不够 的痛点。这一篇讲应对。

## 显存瓶颈的来源

LLM 推理对显存吃紧。Qwen2.5-7B FP16 占 14GB 显存。家用 RTX 4060（8GB）跑不动。

笔记本集成显卡（Intel UHD、AMD Radeon Vega）共享系统内存，能用但慢。

国产显卡（华为昇腾 Atlas、寒武纪 MLU）显存按型号有差。

## 量化是降显存的主要手段

FP16 → INT8 量化。显存减半。质量略降（多数任务感知不到）。

FP16 → INT4 量化。显存减到 1/4。质量降明显但小模型仍可用。

更激进的 INT2 量化。显存减到 1/8。质量损失大，仅特定场景。

chayuan-desktop 默认推荐 Q4_K_M（INT4 的一个变种）。质量和速度甜蜜点。

## 量化模型的来源

GGUF 格式（llama.cpp）。社区有大量预量化模型。Hugging Face 上 TheBloke、QuantFactory 等团队维护。

chayuan-desktop 默认从国内镜像（modelscope、www.modelers.cn）拉量化模型。避免 Hugging Face 不稳。

## 量化的对比

| 量化级 | 显存 | 速度 | 质量 |
|---|---|---|---|
| FP16 | 100% | 1x | 100% |
| INT8 | 50% | 1.5x | 99% |
| Q5_K_M | 35% | 1.7x | 98% |
| Q4_K_M | 25% | 2x | 96% |
| Q3_K_M | 20% | 2.2x | 92% |
| Q2_K | 15% | 2.5x | 85% |

Q4_K_M 是日常用户最佳。Q3 适合显存极度紧张。Q2 几乎不推荐（除非死也要跑）。

## CPU 卸载

部分层放 GPU，部分放 CPU。llama.cpp 支持。

模型 Qwen2.5-7B Q4 显存 4GB。GPU 6GB 能全放。

模型 Qwen2.5-14B Q4 显存 8GB。GPU 6GB 不够。卸载几层到 CPU。chayuan-desktop 自动算需要卸载多少层。

CPU 部分推理慢，所以 GPU+CPU 混合慢于纯 GPU。但能跑就好。

## 内存映射（mmap）

模型不全加载到 RAM。按需 page 进来。

```
chayuan-desktop 配置：
  inference:
    use_mmap: true
```

慢一些（每次需要的数据要从磁盘读）但极省内存。SSD 系统上影响不大。

## 上下文长度的取舍

KV cache 占显存。上下文越长占越多。

Qwen2.5-7B 4k 上下文 KV cache 约 1GB（FP16）。32k 上下文约 8GB。

显存有限时缩短 max_context。chayuan-desktop 设置里能改默认上下文长度。从 32k 改到 4k 显存省 7GB。

## 多模型同时加载

家用 8GB 显存。同时加载 1.8B + bge-m3-onnx 还能放下。

显存不够时 chayuan-desktop 按需切换模型。聊天用 1.8B，需要 embedding 时 unload 1.8B 加载 bge-m3，结束后再换回。

切换有几秒延迟。chayuan-desktop UI 显示 加载模型中... 提示。

## 推理框架选择

llama.cpp。CPU + GPU 混合。最灵活。chayuan-desktop 默认。

Ollama。基于 llama.cpp 包装。简单。chayuan-desktop 集成。

LM Studio。GUI 版。chayuan-desktop 通过 OpenAI 兼容协议接入。

vLLM。专注 GPU。性能高但显存要求严。家用一般跑不动。

## 国产 GPU 适配

华为昇腾 Atlas 300。chayuan-desktop 通过 MindSpore Lite 支持（还在路线图）。

寒武纪 MLU。同上。

国产 GPU 上量化方案跟 N 卡有差。chayuan-desktop 内置默认参数适配主流国产 GPU。

## 总结建议

家用 8GB 显存。Qwen2.5-7B-Q4_K_M。日常对话流畅。

笔记本集显（4GB）。Qwen2.5-1.8B-Q4_K_M。基础够用。

工作站 24GB 显存。Qwen2.5-32B-Q4 或 Qwen2.5-72B-Q3。大模型本地。

服务器 80GB 显存。Qwen2.5-72B FP16。给团队共享。

## 国产化场景

党政军用国产工作站经常 16-32GB 内存 + 集成显卡或低端独显。chayuan-desktop 的 Q4 量化 + CPU 推理 + 1.8B 默认让 国产硬件 + 本地 AI 能跑。

## chayuan-server 的对应

chayuan-server 在带 GPU 的服务器上跑大模型。chayuan-desktop 在显存有限的桌面上跑量化小模型。两者协同覆盖各种场景。

## WPS 加载项

chayuan-wps 在 WPS 里调本地模型走 chayuan-desktop。chayuan-desktop 显存策略对 WPS 透明。

## 总结

显存不够时的量化与加载策略是 chayuan-desktop 在硬件多样性下的工程能力。免费开源的AI软件 不只能在豪华工作站跑，也要在家用机和国产硬件跑。chayuan-desktop 的 Q4_K_M 默认 + CPU 卸载 + mmap 三层让 显存有限场景 都能用 AI。
