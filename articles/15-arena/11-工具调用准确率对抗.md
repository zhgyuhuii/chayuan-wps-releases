# 工具调用准确率的对抗

chayuan-desktop 桌面单机版 Arena 评测工具调用准确率。这一篇讲。

## 工具调用准确率的几个层次

层一：是否调工具。该调时不调（漏调）或不该调时硬调（误调）。

层二：调对工具。从几十个工具里选对那个。

层三：参数正确。参数填的值符合 schema。

层四：参数语义。参数值实际有意义（不是瞎填）。

层五：多步规划。多个工具串联起来逻辑对。

## 评测题

题 1：用户问 我有几个 GitHub repo。期望调 list_repos。

题 2：用户问 帮我列出某用户的所有提交。期望调 list_commits 而非 list_repos。

题 3：用户问 看下这个 PR 的状态。需要从用户问题里提取 PR 编号填参数。

题 4：用户问 把张三的合同发法务并设置截止日。多步：检索 + 发邮件 + 调 calendar。

每题难度递增。

## chayuan-desktop 的评测

每题给所有参赛模型。看每个模型决策。

```
题 1: 我有几个 GitHub repo
GPT-4o: 调 list_repos ✓
Claude: 调 list_repos ✓  
Qwen: 调 list_repos ✓
DeepSeek: 调 list_repos ✓
文心: 答 我看不到 ✗ (漏调)
```

文心未调工具拿不到答案。失败。

## 复杂题

题 4 需要多步。

```
GPT-4o: 调 search_kb → send_email → create_calendar_event ✓
Claude: 调 search_kb → send_email （漏 calendar）✗
Qwen: 调 send_email 但没先 search （顺序错）✗
```

复杂题模型差距大。

## 准确率统计

```
            层一    层二   层三   层四   层五
GPT-4o      98%    92%    95%    90%    85%
Claude      97%    93%    96%    91%    87%
Qwen-Plus   90%    85%    88%    80%    65%
DeepSeek-V2 92%    87%    91%    84%    72%
文心 4.0    85%    78%    82%    72%    55%
```

工具调用是 GPT 和 Claude 强。

## 国产模型的提升空间

国产模型工具调用相对弱。chayuan-desktop 的对抗显示具体差距。

某些原因。

国产模型工具调用训练数据较少。

国产模型上下文较短，工具列表长时溢出。

某些国产模型 OpenAI tools 协议支持不完整。

预期国产模型 2026-2027 跟上。

## 对话 vs 单轮

某些工具调用需要多轮对话。chayuan-desktop 的对抗也评测。

```
用户: 帮我开个 issue
模型: 哪个仓库？
用户: chayuan-desktop
模型: 标题是什么？
用户: 性能优化
模型: 调 create_issue ✓
```

需要模型记住上下文。某些模型在长对话中工具调用退化。chayuan-desktop 评测覆盖。

## 工具列表长度的影响

工具列表 5 个时所有模型都准。

工具列表 30 个时某些小模型选错。

chayuan-desktop 的评测按工具数量分组。让用户知道模型在不同 KB 复杂度下的表现。

## 国产化场景

党政军场景对工具调用的合规、审计、可追溯有要求。准确率高的模型让工具调用更可信。chayuan-desktop 的对抗帮用户选。

## chayuan-server 的对应

chayuan-server 多用户场景下工具调用对抗数据更多。chayuan-desktop 单机基础。

## WPS 加载项

chayuan-wps 在 WPS 里需要工具调用准确（写报告时调对工具）。chayuan-desktop 推荐准确率高的模型给 WPS 用。

## 总结

工具调用准确率的对抗是 chayuan-desktop 在 Agent 时代的工程关键。免费开源的AI软件 让 工具调用 选有保障的模型。chayuan-desktop 的多层次评测 + 复杂题让工具调用模型选型 客观。
