# 模型对抗的延迟与成本 哪个最划算

chayuan-desktop 桌面单机版 Arena 评测延迟和成本。这一篇讲。

## 延迟的几个维度

首字延迟（TTFT）。从发请求到第一个 token 出来的时间。

每秒 token 速率（TPS）。流式时每秒输出多少字。

总延迟。从发到完整回答的总时间。

## 实测延迟

短回答（100 token）。

```
GPT-4o: TTFT 0.6s, 总 1.5s
Claude: TTFT 1.0s, 总 2.0s
Qwen-Plus: TTFT 0.5s, 总 1.4s
DeepSeek: TTFT 0.4s, 总 1.2s
本地 Qwen-7B (CPU): TTFT 1.2s, 总 8s
```

国产模型延迟普遍较低（服务器在中国 +API 优化）。

长回答（2000 token）。

```
GPT-4o: 总 12s
Claude: 总 15s
Qwen-Plus: 总 10s
DeepSeek: 总 9s
```

## 成本对比

每千 token 成本（输入 + 输出）。

```
GPT-4o: $2.5 + $10 = ¥87/M token
Claude 3.5 Sonnet: $3 + $15 = ¥125/M
Qwen-Plus: ¥0.4 + ¥1.2 = ¥1.6/M
DeepSeek-V2: ¥0.14 + ¥0.28 = ¥0.42/M
文心 4.0 Turbo: ¥0.03 + ¥0.06 = ¥0.09/M（极便宜）
```

国产模型便宜 50-100 倍。

## 划算度计算

chayuan-desktop 的对抗给 划算度 评分。

```
划算度 = 质量分 / (延迟分 + 成本分)
```

```
模型           质量  延迟  成本  划算度
GPT-4o         95    80    50    1.46
Claude         96    75    40    1.67
Qwen-Plus      88    85    90    3.43
DeepSeek-V2    85    88    95    4.21
文心 Turbo     78    82    98    7.06
本地 Qwen-7B   75    50    100   5.0
```

文心 Turbo 划算度最高（极便宜，质量也行）。

## 任务匹配

不同任务最划算的模型不同。

简单聊天 → 文心 Turbo / Qwen-Turbo（便宜够用）。

复杂推理 → DeepSeek-V2（性价比好）。

精确任务 → Claude（质量优先）。

视觉任务 → Qwen-VL（国产视觉强）。

## 用户预算的影响

用户月预算 ¥100。

全用 Claude 能处理 1000 次请求。

全用 Qwen 能处理 60000 次请求。

差 60 倍。重度用户必看成本。

## 缓存复用

某些请求结果能缓存。chayuan-desktop 的缓存功能。

5 分钟内同样问题命中缓存。0 成本 + 0 延迟。

某些场景缓存命中率 30%+。实际成本 / 延迟少 30%。

## 流式 vs 非流式

流式让用户感知更快（首字快）。但总延迟差不多。

某些场景非流式更适合（脚本调用）。chayuan-desktop 让用户选。

## 国产化场景

党政军场景预算有限。chayuan-desktop 的对抗推荐国产高性价比。文心 Turbo 月度预算友好。

## chayuan-server 的对应

chayuan-server 多用户场景下成本按用户分摊。chayuan-desktop 单机用户全负担。成本敏感度更高。

## WPS 加载项

chayuan-wps 在 WPS 里高频调用。成本敏感。chayuan-desktop 的对抗让 WPS 选高性价比模型。

## 总结

模型对抗的延迟与成本是 chayuan-desktop 在性价比上的工程考量。免费开源的AI软件 让用户基于数据选最划算的。chayuan-desktop 的延迟 + 成本 + 划算度让选模型 不只看质量。
