# 模型对抗的反作弊 提示泄漏与缓存命中

chayuan-desktop 桌面单机版 Arena 防止某些 作弊 让对抗结果失真。这一篇讲。

## 作弊的几种形式

形式一：提示泄漏。某模型见过测试集（训练数据污染）。直接背答案。

形式二：缓存命中。第一个模型答完，缓存了。第二个模型直接复用缓存（实际没跑）。

形式三：标签泄漏。评测集的答案在 prompt 里被泄漏。

形式四：环境差异。某模型用 GPU 跑（快），其他用 CPU（慢）。延迟对比不公。

形式五：参数差异。某模型用 temperature=0（确定），其他用 0.7（随机）。质量不可比。

每种都让对抗失真。

## 提示泄漏检测

某些公开评测集（C-Eval、HumanEval）训练数据包含。模型直接背。

chayuan-desktop 的对抗用 自定义集 + 私有题。

```
对抗题源：
  - chayuan-desktop 自带题（已混淆，避免污染）
  - 用户自定义题（每用户独有）
  - 时间敏感题（含 2026 最新事件，2024 训练的模型不可能背过）
```

## 缓存隔离

chayuan-desktop 的对抗模式独立缓存。不复用日常对话缓存。

每次对抗每个模型独立调用。绝不复用其他模型的输出。

## 答案隐藏

测试集的答案在评测前隐藏。模型答完后才对比。

某些场景模型可能 推断答案在 prompt 哪里。chayuan-desktop 的 prompt 设计避免泄漏（不写 答案是 X）。

## 公平的执行环境

所有模型在相同环境跑。

API 模型：相同时间窗口（避免某模型在低峰期更快）。

本地模型：相同 batch size、相同 thread 数。

参数固定（temperature 等）。

避免环境差异影响公平性。

## 多次取均值

每题跑 N 次取平均。降低单次随机的影响。

```
GPT-4o 跑同题 5 次：
  92, 90, 95, 88, 93
平均: 91.6
```

抹平随机性。

## 盲评

某些主观评测让用户盲选。chayuan-desktop 隐藏模型名。

```
回答 A: ...
回答 B: ...
您觉得哪个更好？[A] [B] [一样]
```

避免用户对厂商的偏见影响评分。

## 评测集的更新

每月更新评测集。淘汰被广泛训练的题。加入新题。

让模型不能靠 多刷题 占优势。

## 数据泄漏的检测

chayuan-desktop 的实验性功能。检测某模型是否见过题目。

```
方法：把题目截一半给模型让它续写后半部分。
如果模型续写跟标准答案高度一致（> 0.9 BLEU），说明很可能见过原题。
```

发现疑似数据泄漏时 chayuan-desktop 警告 该模型在此题集可能有训练污染，结果仅供参考。

## 国产化场景

国产模型某些场景用中文公开数据集训练。某些 C-Eval 题可能见过。chayuan-desktop 鼓励用户用 自家数据 测让结果更可靠。

## chayuan-server 的对应

chayuan-server 多用户场景下数据更难泄漏（每个用户的私有数据）。chayuan-desktop 单机本地。

## WPS 加载项

WPS 不直接做对抗。但 WPS 用户的真实使用数据可作为防泄漏的对抗样本。

## 总结

模型对抗的反作弊是 chayuan-desktop 在 Arena 公平性上的工程严谨。免费开源的AI软件 让 对抗结果可信。chayuan-desktop 的私有题 + 缓存隔离 + 公平环境 + 多次取均值 + 盲评让模型对抗结果有公信力。
