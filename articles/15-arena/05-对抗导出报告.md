# 模型对抗的导出报告 一键给老板

chayuan-desktop 桌面单机版的模型对抗能一键导出报告。这一篇讲。

报告用途。

用途一：内部技术评估。给 IT 决策者。某模型在我们场景下表现如何。

用途二：客户演示。给政企客户看 国产模型确实够用。

用途三：选型记录。决定用某个模型时存根。

报告内容。

第一段：基本信息。对抗时间、参与模型、测试 query 数量。

第二段：每个 query 的结果。query 文本、每个模型的回答、用户评分。

第三段：性能对比表。模型名、平均延迟、平均长度、错误率、平均评分。

第四段：ELO 排名。当前每个模型的分数。

第五段：建议。chayuan-desktop 根据数据给出推荐使用建议。

导出格式。

格式一：Markdown。最简单。每段对话清晰展示。可以直接发邮件或贴到文档。

格式二：HTML。带样式。打印或在线查看。

格式三：PDF。正式报告。导出后可以直接发给领导。

格式四：Excel。每行一次对抗，每列一个模型。便于做透视分析。

格式五：JSON。原始数据。给开发者做二次处理。

操作。chayuan-desktop arena 界面有 导出报告 按钮。选格式后保存到本地。

可定制。

定制一：选要不要含 query 全文。某些场景 query 涉及业务敏感信息，可以脱敏。

定制二：选要不要含每个模型完整回答。回答很长时可以只保留摘要。

定制三：选 ELO / 性能 / 成本三类指标的哪些。

定制四：自定义评分维度。chayuan-desktop 支持用户加 准确度、流畅度、合规性 等评分维度。导出时按这些维度展示。

报告样例。

```
# 模型对抗报告
日期：2026-05-10
参与模型：gpt-4o, deepseek-chat, qwen-max, ernie-4.0-turbo, doubao-pro
测试 query：50 个

## 排名（基于 ELO）
1. gpt-4o：1620
2. deepseek-chat：1580
3. qwen-max：1530
4. ernie-4.0-turbo：1490
5. doubao-pro：1470

## 性能对比
| 模型 | 平均延迟 | 平均长度 | 准确率 | 成本（每 1M） |
|---|---|---|---|---|
| gpt-4o | 1.5s | 350 字 | 92% | 35 元 |
| deepseek | 0.8s | 320 字 | 90% | 1 元 |
| qwen-max | 1.2s | 300 字 | 88% | 4 元 |

## 建议
日常 chat 使用 deepseek-chat（成本低 + 中文好）。
重要决策使用 gpt-4o（准确率最高）。
代码场景考虑 deepseek-coder。
```

这种结构化报告让决策者一眼看清。

国产化支持下的报告。某些政企客户要 国产模型对比报告，chayuan-desktop 的导出直接成材料。

WPS AI 插件 chayuan-wps 不直接生成对抗报告（在桌面端做）。但可以在 WPS 里引用导出的报告。

模型对抗导出报告是 chayuan-desktop 给用户的 决策工具。免费开源的AI软件 不仅给能力，还给用 数据驱动决策 的工具。chayuan-desktop 的 arena 加上导出，让模型选型这件事有依据。
