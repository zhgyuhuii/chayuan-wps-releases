# 表格生成的模型对抗 结构化输出谁强

chayuan-desktop 桌面单机版 Arena 测试模型在表格 / 结构化输出上的能力。这一篇讲。

## 结构化输出的场景

场景一：把文本转表格。"上面这段员工档案整理成表格"。

场景二：从 KB 提取数据成表格。

场景三：JSON / YAML 等结构化数据生成。

场景四：Markdown 表格。

每种都需要严格的格式。

## 评测维度

维度一：格式正确。Markdown 表格语法正确？JSON 能 parse？

维度二：数据完整。所有数据都提取？没漏掉？

维度三：列对齐。表头跟数据列一致？

维度四：类型正确。日期是日期，数字是数字，不混。

维度五：转义正确。含特殊字符的数据正确处理。

## 实测

prompt: 把以下员工信息整理成 Markdown 表格。

```
张三财务部2020年1月15日入职 王五法务部2021年3月20日入职 赵六技术部2019年7月8日入职
```

模型 A 输出：

```markdown
| 姓名 | 部门 | 入职日期 |
|---|---|---|
| 张三 | 财务部 | 2020-01-15 |
| 王五 | 法务部 | 2021-03-20 |
| 赵六 | 技术部 | 2019-07-08 |
```

完美。

模型 B 输出：

```
姓名：张三 部门：财务部 入职日期：2020 年 1 月 15 日
姓名：王五 ...
```

不是表格。失败。

模型 C 输出：

```markdown
| 姓名 | 部门 | 入职日期 |
| 张三 | 财务部 | 2020/1/15 |
| 王五 | 法务部 | 2021/3/20 |
```

漏了表头分隔行。Markdown 表格不渲染。失败。

## 分数对比

```
GPT-4o: 95% （9.5/10 题完美）
Claude: 96%
Qwen-Plus: 88%
DeepSeek: 90%
文心: 82%
GLM-4: 85%
```

GPT 系和 Claude 在结构化输出最稳。

## JSON 输出

某些任务要求 JSON。

```
模型必须输出严格 JSON 不带额外文字
```

模型容易加 这是结果： 类前缀。chayuan-desktop 的 严格 JSON 模式（OpenAI structured outputs）让某些模型保证输出 JSON。

```
GPT-4o (structured outputs): 100% JSON 正确。
Claude (json_mode): 99%。
Qwen (无 structured): 85%（偶尔加前缀文字）。
```

## schema 一致

某些任务要求 JSON 符合特定 schema。

```json
{
  "type": "object",
  "properties": {
    "name": {"type": "string"},
    "age": {"type": "integer"}
  }
}
```

chayuan-desktop 的对抗用 jsonschema 校验。

## 嵌套结构

某些任务输出复杂嵌套。

```json
{
  "departments": [
    {"name": "财务", "members": [{"name": "张三", "role": "经理"}]}
  ]
}
```

复杂度高时模型差距大。

## 用途

哪个模型在你的结构化场景最强。基于对抗结果选默认。

```
chayuan-desktop 设置：
  default_for_structured_tasks: GPT-4o
  default_for_creative_writing: Claude
  default_for_chinese_chat: Qwen
```

按任务路由。

## 国产化场景

国产模型对中文表格生成支持好。chayuan-desktop 对抗让用户对比国产模型间。

## chayuan-server 的对应

chayuan-server 多用户场景下结构化任务集中。chayuan-desktop 单机本地。

## WPS 加载项

chayuan-wps 在 WPS 表格里调 AI 整理数据。chayuan-desktop 用最稳的模型生成表格内容。

## 总结

表格生成的模型对抗是 chayuan-desktop 在结构化输出上的对比工程。免费开源的AI软件 让 选适合的模型 不靠拍脑袋。chayuan-desktop 的格式校验 + 数据完整 + schema 一致评测让结构化场景选模型 有据。
