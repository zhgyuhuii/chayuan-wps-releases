# 模型对抗的评测样本 自带集与自定义集

chayuan-desktop 桌面单机版的 Arena 模式（模型对抗）评测需要样本。这一篇讲。

## 自带评测集

chayuan-desktop 内置常用评测集。

通用问答集。100 题。覆盖事实、推理、写作。

中文知识集。50 题（来自 C-Eval 简化版）。

代码生成集。50 题（HumanEval 简化）。

数学推理集。50 题（GSM8K 简化）。

工具调用集。30 题。

视觉理解集。20 题（带图）。

总共约 300 题。开箱即用。

## 自定义集

用户上传自己的评测集。

CSV 格式。

```csv
prompt,reference_answer,category
"什么是 RAG","RAG 是检索增强生成...",knowledge
"写个 Python 函数判断质数","def is_prime(n)...",code
```

或 JSON 格式。

```json
[
  {"prompt": "...", "reference": "...", "category": "..."},
  ...
]
```

chayuan-desktop 解析后导入。

## 用户场景集

某用户的真实使用场景。

"chayuan-desktop 让用户在聊天历史里筛选满意 / 不满意的回答自动收集成评测集。"

后续模型对抗用这个集评测。比公开评测集更贴近实际使用。

## 评测集的隐私

某些评测集含敏感信息（公司机密 prompt）。chayuan-desktop 默认本地存储不上传。

跨用户共享评测集需要用户主动操作。chayuan-desktop 提示导出前脱敏。

## 评测集的版本

评测集会迭代。某题答案过时。某些新题加入。chayuan-desktop 维护版本。

```
self_collected_eval:
  v1.0: 100 题（2026-04 收集）
  v1.1: 110 题（2026-05 加 10 个 + 修 3 个）
```

跑评测时锁定版本。便于对比同一基准。

## 评测集的标签

每题打标签。

任务类型：knowledge / code / math / tools / vision。

难度：easy / medium / hard。

领域：legal / medical / tech / general。

评测时按标签筛选。某用户只关心 medium-hard 的 code 任务。

## 评测集的导入分享

某团队整理了金融领域评测集。导出 zip 给同事。

```
finance_eval_v2.zip:
  - eval.csv
  - metadata.json
  - examples/
```

接收方导入到自己的 chayuan-desktop。

某些评测集开放在 GitHub。chayuan-desktop 的评测集市场提供。

## ground truth 的来源

某题的 reference_answer。来源。

人工标注。最准但慢。

LLM 生成。chayuan-desktop 用某 高质量模型 生成参考答案。便利但有偏差。

实际数据。某些场景有标准答案（数学题、SQL 查询）。

## 评测集的扩展

chayuan-desktop 让用户在已有评测集上扩展。

```
基于 100 题让 LLM 生成 100 个相似题。用户审核后加入评测集。
```

快速扩集。但质量看 LLM。

## 国产化场景

党政军场景的专业评测集（公文写作、政策问答）。chayuan-desktop 提供模板让用户填充自家数据。

C-Eval、CMMLU 等中文评测集 chayuan-desktop 内置或一键拉。

## chayuan-server 的对应

chayuan-server 多用户场景下评测集集中（部门共享）。chayuan-desktop 单机本地。

## WPS 加载项

WPS 不直接做评测。但 chayuan-wps 用户的真实使用数据可作为 chayuan-desktop 评测集。

## 总结

模型对抗的评测样本是 chayuan-desktop 在 Arena 准确性上的工程基础。免费开源的AI软件 让 自带集 + 自定义集 + 自动收集 三管齐下。chayuan-desktop 的评测集体系让模型对抗有数据支撑。
