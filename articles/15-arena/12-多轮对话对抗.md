# 多轮对话的对抗 谁记得住

chayuan-desktop 桌面单机版 Arena 在多轮对话场景的对抗。看哪个模型 记得住。这一篇讲。

## 多轮对话的难点

模型在多轮中需要。

记住前面说过的事实。

记住用户的偏好。

保持人物 / 风格设定。

不前后矛盾。

随对话推进。

10 轮、20 轮、50 轮对话考验上下文管理。

## 评测设计

设计长对话题。

```
轮 1: 我叫张三，住在北京，喜欢喝茶。
轮 2: 我们聊聊烹饪。最简单的红烧肉怎么做？
轮 3: 不错。再说说工作。我是程序员，写 Python。
... (中间 15 轮无关讨论)
轮 20: 我还记得我说过我喜欢什么吗？
```

期望答案：喝茶。

某些模型在第 20 轮已经 忘了 第 1 轮。

## 实测

```
模型           轮数限制    准确率
GPT-4o         128k 上下文  98%（基本不忘）
Claude 3.5     200k 上下文  99%
Qwen2.5-1M     1M 上下文    97%
DeepSeek-V2    128k         95%
Qwen-7B (本地)  32k          85%（轮数多时忘）
Qwen-1.8B (本地) 8k          70%
```

上下文长度强相关。

## 上下文压缩的影响

某些场景对话超过模型上下文。chayuan-desktop 的策略。

策略一：截断。保留最近 N 轮。

策略二：压缩。LLM 自己摘要历史。

策略三：RAG 化。把历史对话当 KB 检索。

每种策略影响 记得住 的程度。chayuan-desktop 的对抗考虑这些。

## 一致性测试

```
轮 1: 我喜欢咖啡。
轮 5: 给我推荐一杯饮料。
期望: 推荐咖啡（基于偏好）。
```

某些模型轮 5 直接说 茶吧 (忘了偏好)。chayuan-desktop 评测。

## 矛盾检测

模型自己前后矛盾。

```
轮 1: 我说 "Python 是脚本语言"。
轮 10: 用户问 编程语言分类。
模型: "Python 是编译语言..."（自相矛盾）
```

chayuan-desktop 检测前后回答的事实矛盾。

## 风格保持

```
系统: 你是一只猫，每句话末尾加 "喵"
轮 1: 模型: 你好喵
轮 5: 模型: 让我想想喵
轮 20: 模型: 这道题挺难的（漏了喵）
```

风格漂移。chayuan-desktop 评测。

## 长上下文模型的优势

长上下文模型（Claude 200k、Qwen 1M）多轮对话明显更稳。

但长上下文模型贵。chayuan-desktop 的对抗给出性价比对比。

```
日常聊天（< 20 轮）：4k 上下文模型够用，便宜。
长对话（50+ 轮）：必须长上下文模型。
```

## 国产化场景

某些国产模型上下文长（Qwen2.5-1M、DeepSeek-V3 128k）。chayuan-desktop 让用户对比。

某些政企场景对话很长（一天工作记录）。chayuan-desktop 的对抗结果指引模型选型。

## chayuan-server 的对应

chayuan-server 多用户场景下多轮对抗数据更多。chayuan-desktop 单机本地。

## WPS 加载项

chayuan-wps 在 WPS 里支持多轮（员工跟 AI 多轮讨论文档）。chayuan-desktop 的对抗让 WPS 用稳的模型。

## 总结

多轮对话的对抗是 chayuan-desktop 在长对话场景的工程评测。免费开源的AI软件 让 选记忆好的模型 有数据支持。chayuan-desktop 的轮数评测 + 一致性 + 矛盾检测 + 风格保持让多轮选型更准。
