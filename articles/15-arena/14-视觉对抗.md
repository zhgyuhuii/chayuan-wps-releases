# 视觉对抗 一张图丢给五个模型

chayuan-desktop 桌面单机版 Arena 在视觉场景的对抗。一张图喂多个视觉 LLM。这一篇讲。

## 视觉对抗的场景

场景一：图表理解。给一张销售曲线图，问 哪个月销售最好。

场景二：OCR。给扫描件，要求提取文字。

场景三：场景描述。给一张普通照片，描述场景。

场景四：图像分类。给图，分类（猫 / 狗 / 鸟）。

场景五：异常检测。给监控图，看是否有异常。

每种都要测。

## 实测对抗

图：销售柱状图（Q1-Q4，分别 100、120、150、180 万）。

问：哪个季度销售最好？

```
GPT-4o: Q4 销售 180 万最好。✓
Claude 3.5 (vision): Q4 销售最好，180 万。✓
Qwen2.5-VL-72B: Q4 最好，180 万。✓
ERNIE-VL-3.5: Q4 销售最好。✓
GLM-4V Plus: Q4 销售 180 万最高。✓
```

简单场景所有模型都行。

## 复杂图

图：复杂的产品架构图（含 30+ 模块和箭头）。

问：核心模块是哪几个？

```
GPT-4o: 识别出 5 个核心模块。✓
Claude: 识别出 4 个核心模块（漏 1）。
Qwen-VL-72B: 识别出 5 个。✓
ERNIE-VL: 识别出 3 个。漏多。
GLM-4V: 识别出 4 个。
```

复杂图模型差距大。

## OCR 对抗

图：中文扫描件。

```
RapidOCR: 99% 准确（专业 OCR）。
GPT-4V: 95%。
Qwen-VL: 96%。
Claude: 94%。
```

专业 OCR 比视觉 LLM 强（OCR 是优化的）。

视觉 LLM 在理解 OCR 内容的语义上强。chayuan-desktop 推荐 RapidOCR 提取 + 视觉 LLM 理解。

## 多图对抗

某些任务多图。

```
prompt：对比这两张图找出差异
图 1: [产品 v1]
图 2: [产品 v2]
```

模型需要同时分析两张图。某些模型多图能力弱。chayuan-desktop 的对抗让用户对比。

## 时间敏感

某些图含时间信息（日期、时间戳）。模型理解。

```
GPT-4o: 准确读出日期。
Qwen-VL: 准确。
某些小模型: 经常读错日期格式。
```

## 评分维度

视觉评分多维度。

事实正确性。识别 / 描述是否对。

完整性。重要信息有没有漏。

精确性。数值是否准（图表里的数字）。

理解深度。能否给出洞察（不只是描述）。

## 国产化场景

国产视觉模型的对抗。

Qwen-VL 系列。整体强。

ERNIE-VL。中文场景好。

GLM-4V。综合不错。

豆包视觉。商业 API 强。

chayuan-desktop 的对抗让国产视觉模型在政企场景能选最优。

## chayuan-server 的对应

chayuan-server 部署 GPU 服务器跑大视觉模型。chayuan-desktop 单机能跑小视觉模型 + 调云。

## WPS 加载项

chayuan-wps 在 WPS 里发起视觉问答。chayuan-desktop 用对抗最佳的视觉模型。

## 总结

视觉对抗是 chayuan-desktop 在多模态评测上的工程能力。免费开源的AI软件 让 视觉 AI 选型 基于实测。chayuan-desktop 的多模型多任务对抗让视觉模型 选哪个 有数据支持。
