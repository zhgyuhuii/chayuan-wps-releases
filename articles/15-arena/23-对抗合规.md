# 模型对抗的合规 不要让对抗结果对外发布

chayuan-desktop 桌面单机版的 Arena 对抗结果有合规约束。这一篇讲。

## 合规约束

约束一：厂商许可。

OpenAI 和 Anthropic 等厂商的服务条款可能限制 把对比结果发布。

```
OpenAI Terms of Service:
  您不得将服务用于开发与 OpenAI 服务竞争的模型...
```

广义解读包括用对抗数据帮厂商外人选模型。

约束二：评测集泄漏。

某些评测集的题目本身有版权（C-Eval 等开源不限制；某些评测集需要授权）。

公开发布对抗结果可能泄漏评测集。

约束三：误导。

对抗结果可能因为 chayuan-desktop 的特定配置导致。其他用户不一定能复现。公开后误导他人采购决策。

## chayuan-desktop 的策略

策略一：默认本地。对抗结果默认存本地，不上传。

策略二：导出警示。导出报告时弹提示。

```
您即将导出对抗报告。
请注意：
- 部分 API 厂商的服务条款限制公开对比结果。
- 评测集可能含您的私有数据。
- 公开发布前请确认合规。
[继续导出] [取消]
```

策略三：水印 / 免责声明。导出报告自动加。

```
本报告基于 chayuan-desktop 在 [日期] [配置] 下的实测结果。
仅供个人 / 内部决策参考。
不构成对任何模型的官方评价。
公开发布前请确认遵守相关 API 厂商条款。
```

## 内部使用

对抗结果在 公司内部 使用一般合规。

公司选模型决策。

公司内部论证文档。

跟特定厂商商务谈判（基于实测谈价）。

不上公网。

## 公开发布的风险

某博主把 chayuan-desktop 对抗截图发上 X / 微博。可能。

OpenAI 警告：违反服务条款。

被诉：如果有商业损失。

被反驳：对方拿其他配置说你测得不公平。

降低风险。

打码模型名。

只放总分不放细节。

明确标 个人测试，不构成评价。

## 厂商关系

某些厂商欢迎用户实测。chayuan-desktop 的对抗对他们是营销机会。

某些厂商不喜欢公开对比（他们排名靠后时）。

chayuan-desktop 中立。不偏向任何厂商。

## 学术使用

学术研究里发布对抗结果一般 OK（合理使用）。但仍要遵守条款。

chayuan-desktop 的对抗能配合学术规范（保留原始数据 + 可复现实验配置）。

## 国产化场景

国产厂商对自家排名敏感。某些场景把国产排名靠前作为营销点。

党政军采购公开对比可能政治敏感。chayuan-desktop 的内部使用模式更适合。

## 合规自检

chayuan-desktop 的合规检查工具。

检查报告是否含厂商敏感信息。

检查是否符合厂商条款（chayuan-desktop 维护各厂商条款摘要）。

发现问题提示用户。

## chayuan-server 的对应

chayuan-server 多用户场景下对抗集中。合规风险更大。chayuan-server 有更严格的导出审批。chayuan-desktop 单机用户决策。

## WPS 加载项

WPS 不直接跟对抗合规相关。chayuan-wps 用 chayuan-desktop 推荐的模型，对抗结果不外泄。

## 总结

模型对抗的合规是 chayuan-desktop 在工程严谨上的提醒。免费开源的AI软件 让用户能对抗 但不让 对抗结果 失控公开。chayuan-desktop 的本地默认 + 导出警示 + 免责声明 + 合规检查让对抗使用合规。
