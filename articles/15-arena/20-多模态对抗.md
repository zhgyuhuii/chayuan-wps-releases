# 多模态对抗 图像生成谁更稳定

chayuan-desktop 桌面单机版 Arena 在多模态生成上的对抗。这一篇讲图像生成。

## 图像生成的稳定性

稳定性。同一 prompt 多次生成结果质量是否一致。

某模型出图忽好忽差。某模型每次都稳。

稳定性影响实际可用性。

## 测试方法

每个 prompt 跑 5 次。看 5 次的方差。

```
prompt: "A cat on the moon"
DALL-E 3 5 次质量分: 9, 9, 9, 8, 9 - 方差小，稳定。
SD 1.5 5 次: 6, 8, 5, 9, 7 - 方差大，不稳。
通义万相 5 次: 8, 8, 9, 8, 8 - 中等稳。
```

DALL-E 3 最稳。

## 多 prompt 多次

100 个 prompt × 5 次 = 500 次生成。统计每模型的。

平均质量分。

方差（稳定性指标）。

最差案例（极端值）。

```
模型           平均   方差    最差
DALL-E 3       8.5    0.3    7
通义万相        8.0    0.5    6
文心一格        7.2    0.8    5
SD 1.5         7.0    1.5    3
```

## 类别对比

不同类别擅长不同。

人像。Midjourney > DALL-E > SD > 通义万相。

风景。SD（基于 Lora 训练）> Midjourney > 通义。

抽象。DALL-E > Midjourney > 其他。

中国元素。通义 / 文心 > DALL-E（DALL-E 中式不准）。

chayuan-desktop 按类别分组对抗。

## 安全合规

某些 prompt 各模型反应不同。

```
prompt: "天安门广场"
DALL-E: 拒绝（合规策略）
Midjourney: 生成
通义万相: 生成（中国合规处理过）
SD: 生成（无审查）
```

合规场景选国产更适合。

## prompt 一致性

模型按 prompt 生成的程度。

```
prompt: "穿红裙子的女孩在森林里"
模型 A: 红裙子的女孩，森林背景。✓
模型 B: 蓝裙子（颜色错）。✗
模型 C: 女孩穿红裙子，但在城市背景。部分错。
```

prompt 一致性是核心指标。

## 美学评分

NIMA 等审美模型打分。但人评更准。chayuan-desktop 让用户参与盲评。

## 视频生成对抗

T2V（文生视频）也能对抗。

```
模型           可用度   连贯性   美学
Sora           9        9        9
可灵 1.5       8        8        8
混元视频       7        7        7
SVD (开源)     6        5        7
```

T2V 还在快速演进。chayuan-desktop 跟进对抗。

## 速度对抗

生成速度也算指标。

```
DALL-E 3: 8 秒
通义万相: 5 秒
文心一格: 6 秒
SD 1.5 (本地 RTX 4060): 12 秒
SD-XL (本地): 25 秒
```

实时性场景速度重要。

## 国产化场景

国产 T2I/T2V 在中国元素 + 合规上有优势。chayuan-desktop 的对抗让国产模型在政企采购更有说服力。

## chayuan-server 的对应

chayuan-server 部署 GPU 服务器跑 SD 等本地图像生成。chayuan-desktop 单机能跑小模型。

## WPS 加载项

chayuan-wps 在 WPS 里用图像生成插入文档。chayuan-desktop 推荐稳定的模型。

## 总结

多模态对抗特别是图像生成稳定性是 chayuan-desktop 在视觉 AI 选型上的工程数据。免费开源的AI软件 让 出图谁更稳 客观可比。chayuan-desktop 的多 prompt × 多次 + 类别分组让多模态对抗有 entitled 数据。
