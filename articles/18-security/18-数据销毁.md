# 数据销毁 卸载时的彻底删除

chayuan-desktop 桌面单机版卸载时彻底删除数据。这一篇讲。

## 卸载的两种方式

方式一：保留数据卸载。

删除主程序但保留 ~/.chayuan/。

用户后续重装 chayuan-desktop 时数据还在。

适合：升级 / 临时卸载。

方式二：彻底卸载。

删除主程序 + 删除 ~/.chayuan/。

数据完全消失。

适合：换电脑前清理 / 不再使用。

## chayuan-desktop 的卸载

deb 卸载。

```bash
sudo apt remove chayuan-desktop  # 保留数据
sudo apt purge chayuan-desktop   # 彻底（含配置但不一定含 ~/.chayuan）
```

某些场景 ~/.chayuan/ 在用户主目录。purge 不动它。

chayuan-desktop 的特别 chayuan-uninstall 命令。

```bash
chayuan-desktop --uninstall --purge
```

把 ~/.chayuan/ 也删掉。

## 彻底删除的步骤

第一。chayuan-desktop 主进程退出。

第二。子进程（sidecar、Ollama、mcp）停止。

第三。删除 ~/.chayuan/ 整个目录。

KB 数据。

聊天历史。

模型权重。

设置文件。

凭据（Stronghold）。

第四。删除主程序文件（/opt/chayuan、/usr/bin/chayuan 等）。

第五。删除 OS 注册（桌面快捷方式、systemd 服务等）。

完全清理。

## 安全擦除

某些等保场景要求 不可恢复 删除。

普通 rm 只删 inode。磁盘上的数据 forensics 工具能恢复。

```bash
shred -u file  # 多次覆写后删除
```

chayuan-desktop 提供 安全擦除 模式。

```bash
chayuan-desktop --uninstall --secure-erase
```

每个文件覆写多次（DoD 5220.22-M 标准 - 7 次）。

慢。但不可恢复。

适合涉密机器卸载。

## 保留数据的卸载

保留 ~/.chayuan/。

主程序删除。

桌面快捷方式删除。

但数据在。

用户能后续重装恢复。

## 加密磁盘

某些政企机器全盘加密（LUKS、BitLocker）。chayuan-desktop 数据自然在加密磁盘上。

即使物理硬盘被偷，没有解密密钥读不到数据。

chayuan-desktop 不替代全盘加密。是补充（应用级加密）。

## 卸载时的提示

UI 弹卸载向导。

```
您正在卸载 chayuan-desktop。
是否同时删除以下数据？
  □ KB 数据 (5 个 KB, 2.3 GB)
  □ 聊天历史 (450 条)
  □ 设置和凭据
  □ 模型权重 (4.5 GB)
[确定]
```

让用户清楚知道删什么。

## 误删恢复

如果保留方式卸载 + 用户后悔。

数据还在 ~/.chayuan/。重装 chayuan-desktop 即可恢复。

如果彻底卸载（含 ~/.chayuan/）。

数据没了。但备份可能有（如果用户开了远程备份）。

恢复用备份。

如果安全擦除。

完全没救。这是用户的明确选择。

## 临时停用

某些场景用户不想删但临时不用。

chayuan-desktop 设置 - 停用。

主进程停止。

不开机自启。

数据保留。

让用户随时能重新启用。

## 国产化场景

党政军换电脑或销毁场景对数据销毁严格。chayuan-desktop 的 安全擦除 满足合规。

某些场景需要销毁证明（哪些数据被销毁、什么时候、谁操作）。chayuan-desktop 的销毁审计满足。

## chayuan-server 的对应

chayuan-server 多用户场景下销毁是集中操作（管理员）。chayuan-desktop 单机用户级。

## 总结

数据销毁是 chayuan-desktop 在数据生命周期管理上的工程能力。免费开源的AI软件 让 卸载也是安全的。chayuan-desktop 的多级删除（保留 / 彻底 / 安全擦除）让用户对数据销毁有完全控制。
