# 国产化支持下的等保合规要点

chayuan-desktop 桌面单机版的等保合规要点详细。这一篇讲。

## 等保 2.0 二级 vs 三级

二级。一般重要系统。

三级。重大重要系统。党政军多三级。

四级。重点系统。

chayuan-desktop 主测三级。三级满足，二级自然过。

## 三级要求覆盖

要求一：身份鉴别 (S3)。

主密码 + 多因素（可选 OTP）。

定期更换密码。

锁定连续失败用户。

chayuan-desktop 满足。

要求二：访问控制 (S3)。

最小权限原则。

owner / reader / none 简易 RBAC。

某些场景更细粒度（升级 chayuan-server）。

满足三级基础。

要求三：安全审计 (S3)。

完整审计日志。

哈希链不可篡改。

保留 6 个月+。

满足。

要求四：入侵防范 (S3)。

仅本机绑定。

沙箱隔离工具。

异常行为检测。

满足。

要求五：恶意代码防范 (S3)。

代码签名校验。

供应链审计。

合作 OS 防病毒（Linux 防病毒不强制但有）。

基础满足。

要求六：可信验证 (S3)。

启动时验证主程序签名。

升级前校验签名。

满足。

要求七：数据完整性 (S3)。

KB 数据校验和。

定期备份。

哈希链审计。

满足。

要求八：数据保密性 (S3)。

数据本地存。

凭证 Stronghold 加密。

通信 TLS。

满足。

要求九：剩余信息保护 (S3)。

卸载时彻底删除。

删除 chunk 真正释放磁盘。

满足。

要求十：备份恢复 (S3)。

每天自动备份。

异地备份（NAS / 云盘）。

满足。

## 实施清单

chayuan-desktop 部署时配置项。

```
# 等保三级配置
[security]
audit_retention_days = 180
require_master_password = true
auto_lock_minutes = 15
allowed_inbound = "127.0.0.1"
encrypted_storage = true

[backup]
auto_backup = daily
remote_backup = enabled
remote_target = "//nas/backups/chayuan"

[network]
external_models_warning = true
data_export_warning = true
```

## 测评机构

国内等保测评。

公安部第三研究所等。

第三方测评机构（公安部认证）。

走流程。

提交申请。

测评机构审核。

满足要求颁发证书。

chayuan-desktop 配合测评机构进行。

## 测评的实操

测评通常包含。

文档审查。chayuan-desktop 的设计文档、安全说明。

配置审查。chayuan-desktop 的实际部署配置。

渗透测试。模拟攻击 chayuan-desktop 看防护。

漏洞扫描。

人员访谈。chayuan-desktop 团队回答测评问题。

## 持续合规

等保不是一次性。

每年回测。

漏洞修复要求快（CVE 7 天内补）。

变更管理（升级走审批）。

chayuan-desktop 的开发流程贴合。

## 国产化场景

党政军 chayuan-desktop 部署等保是必经。chayuan-desktop 的合规实施 + 测评配合让政企采购顺。

## chayuan-server 的对应

chayuan-server 多用户场景下等保更严（影响范围大）。chayuan-desktop 单机简化版本。

## WPS 加载项

chayuan-wps 跟 chayuan-desktop 共享合规框架。WPS 调用纳入审计。

## 总结

国产化支持下的等保合规要点是 chayuan-desktop 在政企采购上的硬要求。免费开源的AI软件 满足等保 2.0 三级。chayuan-desktop 的合规实施 + 测评配合 + 持续合规让等保通过有路径。
