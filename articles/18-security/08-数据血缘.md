# 数据血缘 lineage 跟踪到列与行

chayuan-desktop 桌面单机版的数据血缘跟踪。某条 AI 答案的依据从哪。这一篇讲。

## 数据血缘是什么

某 AI 答案。

引用了 chunk_a 和 chunk_b。

chunk_a 来自 doc:contracts/2024_001.pdf 第 5 页。

该 PDF 由谁谁谁在某时间上传。

chunk_b 来自数据库查询结果（SQL: SELECT...）。

完整数据来源链。

## 为什么需要血缘

合规审计。某次回答的依据是什么。可追溯。

错误溯源。AI 给了错误答案。哪个数据源错了。

数据更新。某个上游数据变了。哪些 AI 答案受影响。

权限验证。某用户看到的引用。是否在权限内。

## chayuan-desktop 的血缘记录

每个 chunk 入库时记录。

```json
{
  "chunk_id": "abc",
  "text": "...",
  "source": {
    "type": "document",
    "file_path": "/path/to/contract.pdf",
    "page": 5,
    "uploaded_by": "zhangsan",
    "uploaded_at": "2026-04-15",
    "kb_id": "doc:contracts"
  }
}
```

每次生成 chunk 时记 uploader、时间、来源。

## 列级和行级血缘

文档 chunk：到段落级（前面文章 paragraph_index）。

结构化数据：到列和行级。

```json
{
  "chunk_id": "row_42",
  "source": {
    "type": "structured",
    "kb_id": "structured:erp",
    "table": "orders",
    "row_id": 42,
    "columns": ["customer_name", "amount", "date"]
  }
}
```

精细度：哪一行哪些列被引用。

## SQL 查询的血缘

LLM 生成的 SQL 查 数据库。返回结果作为 chunk。

血缘记。

```json
{
  "chunk_id": "sql_result_xxx",
  "source": {
    "type": "sql_query",
    "kb_id": "structured:erp",
    "sql": "SELECT customer_name, amount FROM orders WHERE ...",
    "executed_at": "2026-05-10",
    "row_count": 5
  }
}
```

任何引用结构化数据的回答能追溯到 SQL。

## 链路可视化

某 AI 答案的血缘链路。

```
[AI 答案: 客户 X 的合同金额是 100 万]
  ↓ 引用
[chunk_a: 文档 contract_X.pdf 第 5 页]
  ↓ 来源
[文档 contract_X.pdf]
  ↓ 上传者
[zhangsan 在 2026-04-15 上传]

  ↓ 引用
[chunk_b: SQL 结果]
  ↓ 来源
[SQL: SELECT amount FROM contracts WHERE id=X]
  ↓ 表
[contracts 表]
  ↓ 数据库
[structured:erp 数据库]
```

完整链。

## UI 展示

chayuan-desktop 的引用气泡 hover 展示血缘。

```
[引用气泡]
hover →
来源：contract_X.pdf
上传：zhangsan 于 2026-04-15
KB：doc:contracts
```

点击 [完整血缘]看链路图。

## 血缘的查询

设置 - 血缘 - 查询。

```
查询：某用户上传的所有文档
查询：某 KB 在 2026 Q1 的上传记录
查询：某 SQL 表被引用了几次
```

便于审计和分析。

## 国产化场景

党政军合规对数据来源可追溯严格。chayuan-desktop 的血缘满足。

某些等保场景要求血缘日志保留 6 个月+。chayuan-desktop 默认 30 天可调。

## chayuan-server 的对应

chayuan-server 多用户场景下血缘聚合更全（多用户上传 + 引用关系）。chayuan-desktop 单机基础。

## 总结

数据血缘是 chayuan-desktop 在合规和可追溯上的工程基础。免费开源的AI软件 让 AI 答案的依据 完全可追溯。chayuan-desktop 的列级 / 行级血缘 + 链路可视化让数据源透明。
