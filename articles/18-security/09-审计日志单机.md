# 审计日志 单机版默认怎么存

chayuan-desktop 桌面单机版的审计日志默认存储方案。这一篇讲。

## 审计日志的内容

每次重要操作记。

时间戳。

用户身份。

操作类型（chat、search、create_kb、export 等）。

参数（脱敏后）。

结果（成功 / 失败）。

来源（chayuan-desktop UI / chayuan-wps / API）。

trace_id（关联）。

## 存储位置

```
~/.chayuan/audit/
  audit.db (SQLite 数据库)
  rotated/
    audit-2026-04.db.gz
    audit-2026-03.db.gz
```

主库 audit.db 含最近数据。

按月归档（gzip 压缩）。

## SQLite 表结构

```sql
CREATE TABLE audit_log (
  id INTEGER PRIMARY KEY,
  timestamp TEXT NOT NULL,
  user_id TEXT,
  action TEXT NOT NULL,
  target TEXT,
  params TEXT,
  status TEXT,
  duration_ms INTEGER,
  trace_id TEXT,
  hash TEXT  -- 哈希链
);

CREATE INDEX idx_timestamp ON audit_log(timestamp);
CREATE INDEX idx_user ON audit_log(user_id);
CREATE INDEX idx_action ON audit_log(action);
```

便于查询。

## 哈希链

每条记录含 hash 字段。

```
hash_n = SHA256(prev_hash + record_n)
```

任何篡改某条记录都让后续 hash 不一致。能检测出来。

某些政企场景要求审计不可篡改。哈希链满足。

## 加密

某些场景审计含敏感信息。chayuan-desktop 用 SQLCipher 加密 audit.db。

```
解锁 audit.db 需要主密码。
```

避免审计日志被偷看。

## 默认保留期

30 天。

设置可调。

```yaml
audit_retention_days: 30  # 默认
audit_retention_days: 365  # 等保三级要求
```

## 自动归档

每月 1 号凌晨 chayuan-desktop。

复制 audit.db 到 audit-YYYY-MM.db。

gzip 压缩。

清理 audit.db 中超期的记录。

归档保留按 retention 配置（默认 12 个月）。

## 查询接口

设置 - 审计 - 查询。

```
按时间过滤：[起] [止]
按用户：[user]
按操作：[chat / search / ...]
按状态：[success / failed]
[查询]
```

返回结果列表 + 详情查看。

## 导出

支持 CSV / JSON / Syslog forward。

某些政企集成到企业 SIEM 系统。chayuan-desktop 配 Syslog endpoint。

## 异常检测

chayuan-desktop 内置规则。

短时间内大量请求。

非常用时段访问。

频繁失败操作。

每条规则触发时弹通知。也写入审计（事件类型 anomaly_detected）。

## 删除请求

某些场景用户希望删某段审计（个人隐私）。

chayuan-desktop 支持删除但记 元审计。

```
{
  "action": "audit_deletion",
  "deleted_range": "2026-04-01 to 2026-04-15",
  "reason": "用户隐私要求",
  "operator": "..."
}
```

合规和隐私平衡。

## 跨用户场景

多身份场景每个身份的审计独立。

身份 A 的审计在 audit_userA.db。

身份 B 的审计在 audit_userB.db。

互不可见（除非 admin 配置）。

## 国产化场景

党政军等保 2.0 三级要求审计日志保留 6 个月+。chayuan-desktop 默认 30 天，等保部署调到 365 天。

某些场景要求审计日志的 完整性 和 不可否认性。chayuan-desktop 的哈希链 + 加密满足。

## chayuan-server 的对应

chayuan-server 多用户场景下审计集中（PostgreSQL 等数据库）。chayuan-desktop 单机本地 SQLite。共享审计字段定义。

## 总结

审计日志单机版默认存储是 chayuan-desktop 在合规和实用性上的工程平衡。免费开源的AI软件 让 单机版 也有完整审计。chayuan-desktop 的 SQLite + 哈希链 + 加密 + 归档让审计在工程上完整可用。
