# 网络边界 单机版只监听本地

chayuan-desktop 桌面单机版的网络边界。只监听本地。这一篇讲。

## 默认绑定

```
监听: 127.0.0.1:62581
```

只对本机进程开放。其他机器即使知道 IP 也连不到（OS 拒绝）。

避免新手用户误开公网。

## 为什么本地

本地用户用 chayuan-desktop UI（同一进程）。

本机其他应用通过 OpenAI 兼容协议连。

WPS 加载项通过本机连。

都不需要监听公网。

## 暴露公网的风险

如果监听 0.0.0.0 公网。

被陌生人发现 → 用 chayuan-desktop 算力。

被刷请求 → 烧用户 API 配额。

被 DDoS → 服务挂掉。

被探测内部数据。

风险大。

## 局域网模式

某些用户希望家里其他设备能访问 chayuan-desktop。

设置 - 网络 - 局域网共享。

```
listen:
  bind: 0.0.0.0
  cors_origins: ["http://192.168.0.0/16"]
  require_token: true
```

启用后局域网设备能访问。但要求 token 认证。

不开公网（IP 仅局域网，不出路由）。

## 防火墙配合

启用局域网时 chayuan-desktop 提示用户配防火墙。

仅允许局域网 IP 访问 62581 端口。

不允许公网 IP。

## token 认证

强制 token。任何请求必须带 Authorization: Bearer <token>。

token 由 chayuan-desktop 生成（强随机），用户在设置里看。

匿名访问拒绝。

## 速率限制

公网 / 局域网模式下速率限制。

每 IP 每分钟最多 60 次。

每 token 每分钟最多 100 次。

超过返回 429。

防止刷算力。

## 仅本地 vs 局域网 vs 公网

chayuan-desktop 默认仅本地。

某些用户开局域网（家里多设备）。chayuan-desktop 支持。

公网 强烈不推荐。chayuan-desktop 的设置里没有公网选项。如果用户硬要公网，自己改 nginx 反代。chayuan-desktop 不支持也不阻拦。

## 远程办公的方案

某员工在家想用公司 chayuan-desktop。

方案一：VPN。员工连公司 VPN。访问公司机器的 127.0.0.1 失败（VPN 不能访问别人的 localhost）。

方案二：SSH 端口转发。

```
ssh -L 62581:127.0.0.1:62581 user@office.machine
```

家里 127.0.0.1:62581 转发到办公室机器。chayuan-desktop UI 在家里能用。

方案三：chayuan-server 部署。直接是网络服务，员工远程访问。

不推荐改 chayuan-desktop 直接监听公网。

## 端口可调

某些场景 62581 跟其他服务冲突。chayuan-desktop 设置可改。

```yaml
listen_port: 62582
```

主机其他端口也行。

## IPv6

chayuan-desktop 也监听 ::1（IPv6 的 localhost）。

如果用户禁用 IPv6 chayuan-desktop 自动跳过 ::1 仅用 IPv4。

## 国产化场景

党政军内网场景默认仅本地。某些场景（部门共享）开局域网。从不公网。

## chayuan-server 的对应

chayuan-server 是网络服务。监听公网（HTTPS）。带完整认证授权。chayuan-desktop 单机不该承担这个角色。

## WPS 加载项

chayuan-wps 在本机访问 chayuan-desktop 走 127.0.0.1。安全。

## 总结

网络边界只监听本地是 chayuan-desktop 的工程红线。免费开源的AI软件 不能因为方便就把单机暴露公网。chayuan-desktop 的本地默认 + 局域网开关 + 强制 token + 速率限制让单机网络安全。
