# 自建向量库的零外网部署 内网拓扑

chayuan-desktop 桌面单机版接自建向量库（Milvus、Qdrant、自建 RT 等）的政企场景常常要求零外网。这一篇讲完全离线的内网拓扑。

先看一个典型政企内网部署。

第一层：员工电脑。chayuan-desktop 桌面单机版（麒麟 UOS 或 Win11）。WPS Office 加 chayuan-wps 加载项。员工电脑不直接连外网。

第二层：内网应用服务器。Milvus 集群（自建）、Ollama 推理服务（跑国产 LLM）、ES 集群（日志分析）。这些服务在内网某个段。

第三层：内网数据库。达梦 DM 集群、金仓 KingbaseES。业务数据在这一层。

第四层：内网存储。NAS 或对象存储。chayuan-desktop 的 CHAYUAN_ROOT 不放在这里（性能不行），但备份可能放这里。

第五层：内网管理。Prometheus、Grafana、SIEM 系统。给运维看的监控。

整套内网拓扑特征：所有数据流在内网内部，不出公网。

部署步骤。

第一步：内网准备。

确认内网带宽（chayuan-desktop 跟 Milvus 之间最好千兆以上）。

确认 DNS 解析（如果用主机名访问内网服务）。

确认时间同步（NTP 服务，TLS 证书校验靠时间）。

第二步：Milvus 集群部署。docker-compose 或 k8s 在内网某台服务器起 Milvus。预分配磁盘和内存。

第三步：模型服务部署。Ollama 起在 GPU 服务器，预拉取模型权重（从内部镜像）。

第四步：员工电脑装 chayuan-desktop。安装包从内部镜像拿，预下载嵌入模型权重到 CHAYUAN_ROOT/models。

第五步：员工电脑配 chayuan-desktop。模型供应商指向内网 Ollama URL。外部源指向内网 Milvus、达梦等。所有 URL 都是内网 IP。

第六步：员工电脑装 chayuan-wps 加载项。配 服务器地址 = 127.0.0.1:62581。

第七步：跑通端到端测试。

数据流。员工在 WPS 里写报告，调起 chayuan-wps 加载项。加载项发请求给本机 chayuan-desktop sidecar。sidecar 调内网 Milvus 跑 ANN 检索，调内网达梦跑 SQL，调内网 Ollama 跑 LLM。所有数据流不出内网。

容灾考虑。

容灾一：Milvus 高可用。Milvus 集群配 replica，单节点宕机不影响检索。

容灾二：Ollama 多副本。多台 GPU 服务器跑 Ollama，前面挂个 nginx 做负载均衡。chayuan-desktop 配 nginx URL，单台 Ollama 宕不影响整体。

容灾三：达梦集群。达梦原生支持高可用，配主备。chayuan-desktop 连主，主挂自动切到备。

容灾四：员工电脑独立。每个员工电脑是独立 sidecar。某个员工电脑挂了不影响其他人。

监控。

监控一：chayuan-desktop sidecar。每个员工电脑的 sidecar 状态（启动时间、内存、CPU）。可选上报到 SIEM。

监控二：Milvus 集群。Prometheus 收集 metrics，Grafana 看 dashboard。延迟、QPS、错误率。

监控三：Ollama。GPU 利用率、tokens/s、请求数。

监控四：达梦。慢 SQL、连接数、空间。

合规审计。

审计一：chayuan-desktop 的 audit_log。每次 KB 访问、模型调用、工具调用都记录。

审计二：员工电脑日志同步。某些场景把 sidecar 的 audit_log 同步到中央 SIEM。

审计三：Milvus 访问日志。每次 collection 查询的客户端 IP、时间、query。

审计四：定期合规报告。从各组件汇总日志生成月度合规报告。

升级流程。

升级一：chayuan-desktop。从内部镜像拿新版本 deb/msi，分发到员工电脑。alembic 自动 migrate。

升级二：Milvus。先停服务、备份、升级、启动、验证。Milvus 的滚动升级支持。

升级三：模型权重。新模型版本上传到内部镜像，员工电脑通过 chayuan-desktop 自动下载。

国产化清单。完整国产化部署至少应包括。

OS：麒麟 UOS / openKylin。

CPU：飞腾 / 鲲鹏 / 龙芯。

数据库：达梦 / 金仓 / Doris。

向量库：RT / Relyt / 自建 Milvus。

LLM：DeepSeek / 通义 / 文心（私有部署）。

应用：chayuan-desktop AGPL 开源。

WPS AI 插件 chayuan-wps 的内网部署跟 chayuan-desktop 一起。员工的 WPS 写文档时不出内网。

自建向量库的内网拓扑是 chayuan-desktop 在政企场景的实际落地形态。免费开源的AI软件 加上整套国产化栈，让 完全自主可控 这件事真的可行。chayuan-desktop 在这种部署里的位置是 整合各组件的中枢。
