# 向量库与办公私库的命名隔离 src:* 与 office:*

chayuan-desktop 桌面单机版有 src:* 向量库和 office:* 办公私库两种命名空间。看起来都是私有数据，区别在哪。这一篇讲清楚两个命名空间的隔离。

先看两个命名空间各自的定位。

src:* 向量库。外部数据源接入，包括 Milvus、Qdrant、Chroma、ES、pgvector 等。数据在外部系统里，chayuan-desktop 只读访问。

office:* 办公私库。本地或部门级的私有资料，按 owner 和可选 group 隔离。chayuan-desktop 自己管数据。

权限模型差异。

src:* 权限。基于外部系统的连接凭据。chayuan-desktop 用某个用户名密码连 Milvus，能看到那个用户被授权的 collection。

office:* 权限。基于命名空间隔离。office:zhangsan 只对 zhangsan 可见。office:dept_finance 只对该部门成员可见。多用户版下严格按身份过滤。

数据所有权差异。

src:* 数据。在外部系统。chayuan-desktop 不主动管数据生命周期。

office:* 数据。在 chayuan-desktop 自己的存储。chayuan-desktop 完整管理（创建、更新、删除、备份）。

适用场景差异。

src:* 适合。已有外部数据系统的复用。比如公司已有 Milvus，chayuan-desktop 接进来。或者已有 ES 日志系统，chayuan-desktop 检索。

office:* 适合。chayuan-desktop 内 created 的私有资料。比如个人笔记、部门文档、项目记录。这些资料不在外部系统，chayuan-desktop 直接管。

混合用法。一个 chayuan-desktop 可以同时有 src:* 和 office:* 库。比如用户的个人笔记走 office:zhangsan，公司的 Milvus 知识库走 src:milvus_corporate。一次问答可以勾两个一起检索。

UI 上的区分。chayuan-desktop 的 KB 选择器按命名空间分组展示。

文档库（doc:*）。蓝色图标。

外部源（src:*）。紫色图标。子分类按类型（Milvus、Qdrant 等）。

办公库（office:*）。橙色图标。

办公库的细分。office:* 命名空间下还有进一步分隔。

office:owner。个人库。owner 是 OS 用户名或自定义身份。

office:owner:group。个人下的组。比如 office:zhangsan:work 是 zhangsan 的工作组，office:zhangsan:personal 是个人组。

office:dept_X。部门库。多用户版下按部门隔离。

office:dept_X:team_Y。部门下团队库。

跨命名空间引用。一次问答的 ku_ids 可以混合多种命名空间。chayuan-desktop 的 router 不区分命名空间分别派给对应 adapter。引用气泡按 kind（src 还是 office）渲染。

权限校验链。

doc:* 单机版下默认全开。

src:* 取决于外部系统的连接配置。chayuan-desktop 不在自身做额外权限。

office:* 单机版下按 owner 隔离（owner 是当前 OS 用户）。多用户版下严格按授权。

数据迁移。

src:* 数据迁移。在外部系统里操作（pg_dump、Milvus backup 等）。chayuan-desktop 这边只改连接配置。

office:* 数据迁移。在 chayuan-desktop 内部，通过 export/import 工具。

混合迁移。如果用户从 chayuan-desktop A 搬到 B。office:* 数据通过 export 携带。src:* 在 B 上重新建连接（连接到同一外部系统）。

国产化支持下的命名隔离。政企场景常用 office:dept_finance 这种部门级命名。chayuan-desktop 严格按命名空间隔离让 部门数据 不会跨边界。

实战示例。某个员工的 chayuan-desktop 配置。

doc:技术资料。folder-sync 同步本地技术目录。

doc:合同档案。folder-sync 同步本地合同目录。

src:dm_finance。达梦财务库（外部 SQL）。

src:milvus_corporate。公司 Milvus 公共知识库。

office:zhangsan。个人笔记库。

office:zhangsan:work。工作专用笔记。

六个 KB 三种命名空间。检索时按需勾选。

WPS AI 插件 chayuan-wps 在加载项里 KB 选择器同样按命名空间分组。用户在 WPS 里能精准挑哪种来源。

src:* 跟 office:* 的命名隔离是 chayuan-desktop 在 多源管理 上的精细设计。免费开源的AI软件 不只接入数据，还要让数据按 来源 + 私有性 多维度组织。chayuan-desktop 的命名空间体系是这种组织的具体落地。
