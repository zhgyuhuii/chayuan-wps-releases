# Elasticsearch当向量库 与全文检索一锅出

chayuan-desktop 桌面单机版可以把 Elasticsearch 当向量库用。ES 8+ 支持 dense_vector 字段和 kNN 查询，让 ES 既是全文搜索引擎又是向量库。这一篇讲清楚。

先看 ES 的向量能力。ES 8.0 引入 dense_vector 字段类型，支持 cosine 和 L2 距离。8.4 引入 ANN 算法（HNSW），让大规模向量查询性能跟上 Milvus 这种专业库。

ES 当向量库的优势。

优势一：复用现有 ES。公司已经在用 ES 做日志分析或全文搜索，加上向量能力直接复用，不用单独部署 Milvus。

优势二：全文 + 向量混合。ES 强在全文检索（BM25），加上向量能力之后能做 hybrid search：query 同时跑 BM25 和向量召回，结果加权聚合。chayuan-desktop 接 ES 时支持这种 hybrid 模式，精度比纯向量召回高。

优势三：metadata 过滤强。ES 的 query DSL 表达力强，复杂 metadata 过滤（嵌套字段、范围、正则）都支持。

劣势。

劣势一：ANN 性能不如专业向量库。在亿级以上数据上 HNSW 性能略低于 Qdrant、Milvus。中等规模差别不大。

劣势二：部署复杂。ES 集群配置比 Milvus 还复杂，对 JVM 调优需求高。

劣势三：成本。ES 集群资源占用比向量库专门设计的库高。

接入到 chayuan-desktop。

步骤一：确认 ES 版本 8+。低版本不支持 dense_vector ANN。

步骤二：建 index 含 dense_vector 字段。例 PUT /chunks { mappings: { properties: { content: { type: "text" }, embedding: { type: "dense_vector", dims: 1024, index: true, similarity: "cosine" } } } }。

步骤三：往 ES 灌 chunk 数据。chayuan-desktop 不主动灌，用户自己用 elasticsearch-py 或其他工具。

步骤四：chayuan-desktop 设置 - 知识库 - 新建 - Elasticsearch 类型。填 host、port、index、embedding_field。

步骤五：测试连接。chayuan-desktop 用 elasticsearch-py 客户端 ping。

步骤六：建 src:es_xxx 命名空间的 KB。

实际查询。chayuan-desktop 用 ES 的 kNN search。

GET /chunks/_search
{
  "knn": {
    "field": "embedding",
    "query_vector": [...],
    "k": 10,
    "num_candidates": 100
  },
  "_source": ["content", "metadata"]
}

ES 返回 top-K 命中。chayuan-desktop 后续走重排和 LLM 总结。

hybrid search 模式。如果用户开了 hybrid，chayuan-desktop 同时发 BM25 query 和 kNN query，结果按 RRF（Reciprocal Rank Fusion）算法聚合。这种 双路召回 在某些 query 模式下精度比纯向量高。

filter 过滤。ES 的 filter DSL 跟 kNN 配合：

GET /chunks/_search
{
  "knn": {...},
  "query": {
    "bool": {
      "filter": [
        {"term": {"department": "finance"}},
        {"range": {"created_at": {"gte": "2026-01-01"}}}
      ]
    }
  }
}

这种细粒度过滤是 ES 的强项。

性能。chayuan-desktop 实测 ES 8.5 在百万 chunk 上 kNN 查询延迟 30-100ms。比 sqlite-vec 略好但不如 Qdrant。

跟纯文档 ES 的差别。某些用户在 ES 里只用全文检索（不用向量），chayuan-desktop 把这种 ES 当 doc:* 文档源处理。如果同一 ES 里既有 BM25 也有向量，可以建两个 KB（一个 doc:* 一个 src:vec）也可以一个 KB 配 hybrid 模式。

国产化支持下的 ES。某些政企客户用 OpenSearch（ES fork）替代 ES。chayuan-desktop 通过同样的协议接入，体验一致。easysearch、星河 ES 等国产 fork 也支持。

WPS AI 插件 chayuan-wps 不感知后端是 ES 还是其他。

ES 当向量库是 chayuan-desktop 多源支持的扩展。免费开源的AI软件 把 ES 这种 半结构化 + 全文 + 向量 三合一 工具纳入 KB 抽象，让 复用现有 ES 的用户能轻松接入察元 AI。
