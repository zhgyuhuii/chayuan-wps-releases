# 一份重排实验报告 加了重排带来多少召回提升

某用户在 chayuan-desktop 桌面单机版上跑了重排对比实验。这一篇是报告。

## 实验设置

数据集。用户的本地 KB，约 5000 chunk。覆盖技术文档、会议纪要、工作笔记。

测试 query。50 条，由用户从历史聊天中筛选（实际工作中用过的真实问题）。

每个 query 有 用户认可的最佳答案（用户标记的某个 chunk）。

## 评测指标

Recall@K。前 K 个候选里包含 ground truth 的比例。

MRR（Mean Reciprocal Rank）。最佳答案的排名倒数的平均。

NDCG@K。考虑排序的归一化折损累积增益。

## 实验组

组 A：仅召回。bge-m3-onnx 召回 top 50。

组 B：召回 + 重排。bge-m3-onnx 召回 top 50 → bce-reranker rerank 取 top 10。

组 C：召回 + 重排（large）。改用 bce-reranker-large。

组 D：仅召回 + 高维。换 bge-m3-large（2048 维）。

## 结果

```
                 Recall@5  Recall@10  MRR    NDCG@5
仅召回 (A)        72%       86%        0.58   0.62
召回+重排 (B)     85%       91%        0.74   0.78
召回+重排-large (C)  87%    92%        0.77   0.81
仅召回-高维 (D)   76%       88%        0.62   0.66
```

## 分析

发现一：重排显著提升精度。Recall@5 从 72% 提升到 85%，13 个百分点。MRR 从 0.58 提升到 0.74。说明重排在 top 排序上贡献明显。

发现二：高维召回提升有限。bge-m3-large 比 bge-m3-base 召回 Recall@5 提升 4%。不如重排。

发现三：重排 large 边际效益有限。bce-reranker-large 比 base 提升 2%。但延迟翻倍。性价比一般。

## 延迟数据

```
                 平均延迟（CPU i7-13700H）
仅召回           80ms
召回+重排（base） 580ms (+500ms)
召回+重排（large） 1280ms (+1200ms)
```

加重排 base 延迟增加 500ms。用户可感知但能接受。

加 large 延迟增加 1.2 秒。明显慢。

## 推荐配置

基于实验。

家用单机：召回 + 重排 base。精度好，延迟可接受。

延迟敏感场景（实时聊天）：仅召回。够用。

精度优先（重要查询）：召回 + 重排 large。值得等。

chayuan-desktop 默认 召回 + 重排 base 是最佳通用选项。

## 不同任务的差异

实验细分。

事实查询（如 张三的电话）。重排提升 18%。明显。

模糊查询（如 关于 X 项目的讨论）。重排提升 8%。一般。

复杂推理（如 跨多个文档分析）。重排提升 5%。有限。

结论。重排在精确事实命中场景最有价值。模糊查询本身受嵌入语义影响大，重排帮助不大。

## chunk 长度的影响

短 chunk（< 100 token）。重排提升 16%。

中 chunk（100-300 token）。重排提升 13%。

长 chunk（> 300 token）。重排提升 8%。

短 chunk 在召回阶段 score 不稳定，重排帮助大。长 chunk 召回已经准。

## 多 KB 混合场景

实验加上跨 KB 检索（5 个 KB 共 1 万 chunk）。

```
仅召回：Recall@5  68%
召回+重排：Recall@5  82%
```

跨 KB 时重排作用更明显（因为不同 KB 的 score 不可比，重排统一打分能纠正）。

## 重排模型选择

chayuan-desktop 内置 bce-reranker-base。

实验也试了。

bge-reranker-v2-m3：跟 bce-reranker-base 接近。

cross-encoder/ms-marco-MiniLM-L-6-v2：英文好但中文差。

国产场景 bce-reranker 是最佳选。

## 用户主观满意度

20 个用户使用一周后调查。

仅召回模式：6/20 表示 经常找不到要的。

召回+重排模式：17/20 表示 检索结果比较准。

主观满意度跟客观指标一致。

## 国产化场景

党政军用户运行类似实验。结果一致。重排在中文场景下效果显著。chayuan-desktop 默认开重排是合理选择。

## chayuan-server 的对应

chayuan-server 多用户场景下重排集中跑（GPU）。chayuan-desktop 单机本地跑。延迟差距小。

## WPS 加载项

chayuan-wps 在 WPS 里检索默认开重排。员工感知到 检索更准。

## 总结

重排实验报告是 chayuan-desktop 在 RAG 精度上的实证支持。免费开源的AI软件 给用户具体数据指导配置选择。chayuan-desktop 的 召回 + bce-reranker base 默认配置经实验验证最佳。
