# 自训练嵌入模型的接入 行业语料的小步快跑

chayuan-desktop 桌面单机版支持接入自训练嵌入模型。某些行业（医疗、法律、金融）有领域专业语料，自训练嵌入更准。这一篇讲。

## 为什么自训练

通用嵌入模型（bge-m3）在通用语料训练。某些行业术语效果一般。

医疗例子。bge-m3 看到 心衰 跟 心脏衰竭 距离接近，但跟 急性失代偿性心力衰竭 距离稍远。医生其实希望这三个等距。

法律例子。专业术语 合同解除 vs 合同终止 vs 合同撤销 法律含义有差。bge-m3 看着相似。

行业语料微调能解决。

## 微调的常见方法

方法一：对比学习。给模型一对相似句子和一对不相似句子。让模型学会区分。

方法二：领域 MLM 继续预训练。在领域语料上再跑一段 masked language modeling。

方法三：硬负样本挖掘。从领域语料挖出 表面相似但语义不同 的句子作为负样本。

## 微调的成本

100 万领域语料对。

GPU（RTX 4090）：约 1-2 天。

GPU（A100）：约半天。

CPU：跑不动。

家庭机器一般跑不动微调。需要工作站或租云 GPU。

某些 LoRA 微调更便宜。8GB 显存能跑。

## chayuan-desktop 的微调支持

当前 chayuan-desktop 不内置微调能力。把微调留给外部工具（sentence-transformers 训练脚本、FastEmbed 等）。

chayuan-desktop 接入 外部已训练好的 嵌入模型。

## 接入流程

第一步。用户把自训练模型转 ONNX 格式。

```python
from optimum.onnxruntime import ORTModelForFeatureExtraction
model = ORTModelForFeatureExtraction.from_pretrained("./my_finetuned_model", export=True)
model.save_pretrained("./my_finetuned_model_onnx")
```

第二步。把 ONNX 模型放到 ~/.chayuan/models/embeddings/my_finetuned/。

第三步。chayuan-desktop 启动时扫描，识别新模型。

第四步。配置模型卡片。

```yaml
id: my-medical-embed
display_name: 医疗领域嵌入 v1
description: 基于 bge-m3 在 100 万医疗语料上微调
context_window: 8192
embedding_dim: 1024
custom: true
```

第五步。在 KB 设置里选这个模型作为默认嵌入。新建 KB 时用它。

## 跨模型的对比

chayuan-desktop 的评测能力让用户对比。

跑 100 题医疗领域查询。

bge-m3 通用：准确率 75%。

my-medical-embed 微调：准确率 88%。

差 13 个百分点，明显提升。值得用。

## 维度兼容

自训练模型的维度可能跟通用模型不一样。

如果保持 1024 维（推荐），能直接替代 bge-m3。所有索引代码不变。

如果改成其他维度（比如 768），KB 配置时要明确，sqlite-vec 表的维度也要相应。

## 模型分发

某行业的 5 家公司都在做医疗嵌入微调。重复劳动浪费。

chayuan-desktop 路线图含 行业模型市场。某行业用户上传微调模型，其他用户能下载用。

商业模式上面临挑战（谁愿意公开自家微调模型）。但开源行业语料的微调模型已经存在（医疗有 PubMedBERT 衍生、法律有 LegalBERT 衍生）。

## 微调的版本迭代

自训练模型经常迭代（每次新增语料就重训）。chayuan-desktop 的版本管理（前面文章讲）适用。

每个版本独立 ID，KB 记录版本。升级时按 KB 重建。

## 国产化场景

党政军场景特殊语料（公文、政策、案件）。微调嵌入很有价值。chayuan-desktop 支持接入是这种场景的硬需求。

某些机构有自己的 公文嵌入模型。chayuan-desktop 接入后员工电脑上能用。

## chayuan-server 的对应

chayuan-server 模式下自训练模型部署在服务器跑（GPU）。员工 chayuan-desktop 通过远程嵌入 API 调（如果模型不敏感能上服务器）或本地下载（如果敏感）。

## WPS 加载项

chayuan-wps 在 WPS 里检索时走 chayuan-desktop 配置的嵌入模型。员工写专业报告时享受微调精度提升。

## 总结

自训练嵌入模型的接入是 chayuan-desktop 在行业适应性上的工程能力。免费开源的AI软件 不锁定通用模型，让行业用户能用自家模型。chayuan-desktop 的 ONNX 接入 + 模型卡片 + 评测对比让 自训练模型 在桌面端能落地见效。
