# 嵌入模型的版本管理 同一个 KB 多个版本的兼容

chayuan-desktop 桌面单机版的嵌入模型有版本管理。同一个 KB 可能跨越多个嵌入版本。这一篇讲兼容。

## 版本管理的意义

嵌入模型升级（bge-m3 v1.0 → v1.5 → v2.0）。

每个版本生成的向量空间不一样。跨版本检索精度下降。

KB 必须记录用什么版本嵌入的，检索时用同版本的查询向量。

## KB 的版本字段

```
{
  "kb_id": "office:zhangsan:meetings",
  "embedding_model": "bge-m3-onnx",
  "embedding_version": "v1.5",
  "embedding_dim": 1024,
  "indexed_at": "2026-04-15"
}
```

每个 KB 独立记录。

## 检索时的版本匹配

chayuan-desktop 检索时按 KB 的 embedding_version 用对应模型生成查询向量。

如果 KB 用 v1.5，但用户当前默认嵌入模型是 v2.0。chayuan-desktop 临时加载 v1.5 跑查询。

```python
def search(query, kb):
    model = load_embedding_model(kb.embedding_model, kb.embedding_version)
    query_vector = model.encode(query)
    return kb.search(query_vector)
```

## 多版本共存

chayuan-desktop 内存里加载多个嵌入版本（如果 RAM 够）。

KB A 用 v1.5。KB B 用 v2.0。同一会话用户检索两个 KB。chayuan-desktop 用对应版本生成查询向量。

## 跨版本不能混合检索

KB A v1.5 + KB B v2.0 同时检索。两个版本生成的查询向量不通用。chayuan-desktop 必须分别跑两次嵌入。

延迟稍增（多嵌入一次）。但能保证精度。

## 升级路径

某 KB 升级 v1.5 → v2.0。

第一步。chayuan-desktop 提示 检测到 v2.0，是否升级。

第二步。用户确认。chayuan-desktop 备份。

第三步。重新嵌入所有 chunk。

第四步。更新 KB 的 embedding_version=v2.0。

第五步。删除备份（可选）。

## 不强制升级

旧版本模型仍能下载（chayuan-desktop 维护历史版本仓库）。

用户不想升级 → KB 保持 v1.5 → 检索照常工作。

什么时候必须升级。

旧版本被官方下架（很少）。

新版本兼容性升级（向量维度变了，接口变了）。

否则不强制。

## 版本回退

升级 v2.0 后发现质量比 v1.5 差。chayuan-desktop 支持回退。

用备份恢复 v1.5 索引。

或者重新下载 v1.5 重建。

回退是用户自由。

## 跨用户的版本协调

多用户场景（chayuan-server）。一个员工 KB 升级，其他人没升级。跨员工检索时版本不一致问题更复杂。

chayuan-server 推荐 部门统一升级。员工自己不能随便升级。

chayuan-desktop 单机用户自己掌控。

## 版本元数据

chayuan-desktop 的版本仓库（GitHub 或 ModelScope）维护每个版本的元数据。

```yaml
bge-m3-onnx:
  versions:
    - v1.0:
        released: 2024-01-15
        deprecated: 2026-01-15
        sha256: abc...
    - v1.5:
        released: 2024-09-01
        deprecated: null
        sha256: def...
    - v2.0:
        released: 2025-06-01
        deprecated: null
        sha256: ghi...
```

chayuan-desktop 启动时拉这个清单（可选自动）。

## 实验性版本

某些 beta 版本的嵌入模型。chayuan-desktop 不默认推送。在设置里 显示实验版本 开关，开了后能选实验版本。

## 国产化场景

党政军升级嵌入模型谨慎。chayuan-desktop 的版本管理 + 备份 + 回退让升级风险可控。

某些场景固定版本（不升级）是合规需求。chayuan-desktop 的不强制升级满足。

## chayuan-server 的对应

chayuan-server 多用户场景下版本管理更严格（管理员决策）。chayuan-desktop 单机版用户自己。

## WPS 加载项

chayuan-wps 在 WPS 里检索走 chayuan-desktop。版本管理对 WPS 透明。

## 总结

嵌入模型的版本管理是 chayuan-desktop 在长期演进上的工程基础。免费开源的AI软件 让 升级 不强制、不破坏现有 KB。chayuan-desktop 的版本字段 + 多版本共存 + 备份回退让 嵌入模型 跟着时间向前走也能照顾老 KB。
