# 嵌入失败的兜底 模型不可用时的降级

chayuan-desktop 桌面单机版在嵌入模型不可用时有降级方案。这一篇讲。

## 嵌入失败的场景

场景一：模型文件损坏。SHA256 校验失败。

场景二：内存不足。模型加载 OOM。

场景三：CUDA 错误。GPU 路径出问题。

场景四：远程嵌入网络断开。

场景五：嵌入服务超时。

每种都需要兜底。

## 默认降级链

```
chayuan-desktop 嵌入降级链：
  1. bge-m3-onnx-q8 (本地默认)
  2. bce-embedding-onnx (本地备选)
  3. bge-m3-onnx-q4 (更小，更快)
  4. 远程嵌入 (OpenAI / 智谱，如果用户配了)
  5. 简易 BoW（基于词袋，最后兜底）
```

按顺序尝试。失败一个降下一个。

## 模型损坏的恢复

启动时检测主嵌入模型损坏。

第一步。chayuan-desktop 提示 嵌入模型损坏，正在重新下载。

第二步。从默认源（modelscope 或 hf-mirror）拉模型。

第三步。下载完成校验通过 → 加载使用。

第四步。下载失败 → 降级链下一项。

## OOM 的应对

加载某模型 OOM。chayuan-desktop 切到更小模型。

bge-m3-onnx-q8（200MB）OOM → bge-m3-onnx-q4（120MB）。

如果 q4 也 OOM → 简易 BoW（不需要模型）。

提示用户 内存不足，已切换到轻量嵌入，精度降低。

## 远程嵌入网络断开

如果 KB 配置使用 OpenAI 嵌入。突然网络断。

chayuan-desktop 检测到几次连续失败。提示用户 远程嵌入不可用。

降级到本地 bge-m3-onnx。但是。这个 KB 索引时用 OpenAI 嵌入。本地 bge-m3 的查询向量跟它不在同一空间。检索精度会很差。

chayuan-desktop 在 UI 上明确警告 当前 KB 用的是 OpenAI 嵌入，本地兜底精度有限。建议恢复网络后再用。

## 简易 BoW 兜底

最后兜底。基于词袋的简单嵌入。

```python
def simple_embed(text):
    words = jieba.cut(text)  # 中文分词
    vocab = ["..."]  # 预设 1024 词
    vec = np.zeros(1024)
    for word in words:
        if word in vocab:
            vec[vocab.index(word)] += 1
    return vec / np.linalg.norm(vec)  # 归一化
```

精度极低。但能保证 chayuan-desktop 不挂掉。基本能命中关键词。

## 用户感知的提示

每次降级 chayuan-desktop UI 提示。

```
⚠ 嵌入服务异常，已切换到备用模型。
当前精度约为正常的 80%。
[查看详情] [尝试恢复]
```

让用户知情。

## 自动恢复

降级后 chayuan-desktop 后台每 5 分钟尝试恢复主模型。成功后切回主模型并提示。

## 检索时的失败

检索时调嵌入。失败。

如果是 临时失败（网络抖动）。重试 1 次。

如果是 持续失败。降级链。

如果整个降级链都失败（极少）。chayuan-desktop 直接拒绝检索，提示用户检查嵌入服务。

## 重排失败的兜底

重排独立于嵌入。重排模型不可用时。

chayuan-desktop 跳过重排。直接用召回 score 排序。

精度降但能用。

## 降级的可观测

每次降级写日志。

```
[2026-05-10 14:23] embedding fallback: bge-m3-onnx-q8 failed (OOM) → bge-m3-onnx-q4
```

便于排查长期问题。

## 国产化场景

党政军内网部署。chayuan-desktop 的本地嵌入是主路径。远程兜底基本不用。降级主要在本地模型损坏 / OOM 场景。

## chayuan-server 的对应

chayuan-server 模式下嵌入服务集中。降级可能影响多用户。chayuan-server 有更完善的高可用设计。chayuan-desktop 单机简化。

## WPS 加载项

chayuan-wps 在 WPS 里检索时如果 chayuan-desktop 嵌入降级，WPS 收到精度降低提示。员工知情。

## 总结

嵌入失败的兜底是 chayuan-desktop 在工程鲁棒性上的设计。免费开源的AI软件 不能因为模型挂掉就整个用不了。chayuan-desktop 的多层降级链 + 自动恢复 + 用户提示让 嵌入服务 在工程上稳。
