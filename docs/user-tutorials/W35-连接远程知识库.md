## 一句话说明

除了本机直连，察元AI文档助手还能连部署在服务器上的**远程知识库（chayuan-server）**：三种鉴权方式按需选——「账号密码（JWT）」个人账号、「应用接入（APPID + AppKey）」部门/服务级、「单机本机直连（无认证）」单机版游客；密码/密钥经 AES-GCM 设备绑定加密后才落盘，保存前可一键「测试连通」做三步体检。

## 适用场景

- 单位把知识库部署在内网服务器上，多人从各自 WPS 里连同一个库；
- 以部门/应用身份接入（管理员发了一对 APPID/AppKey），而不是个人账号；
- 想知道凭据存在哪、会不会明文写在配置里。

典型提问（chabot 语料视角）：

- 「WPS 插件连远程知识库要怎么配？三种鉴权选哪个？」
- 「提示『凭据校验失败』/『今日额度已用完』是什么意思？」
- 「知识库的密码是明文保存的吗？换电脑还能用吗？」

## 前置条件

- 已启用加载项并配置对话模型（见 W02/W03）；
- 远程 chayuan-server 服务地址可达，且你手里有对应凭据：个人账号（用户名/密码）、或管理员发放的应用凭据（APPID/AppKey）、或单机版后端已关鉴权（`AUTH_REQUIRED=false`）；
- 功能开关 `kbRemoteIntegration` 默认开启（灰度回滚开关），无需操作。

## 操作步骤

**1. 打开新增连接表单**

- 在哪：设置 → 常规设置 → **知识库设置**。已有连接时点左栏「知识库连接」标题行的「**＋**」（悬停「**新增连接**」）；一条连接都没有时整个面板是拓扑空态页，点右上「**＋ 新建连接**」。
- 看到什么：弹窗「**新增知识库连接**」（编辑已有连接时标题为「**编辑连接**」）。

**2. 填连接名称与服务地址**

- 「**连接名称**\*」：必填，显示在左侧连接列表里的名字（提示：在左侧"知识库连接"列表里显示的名字）。
- 「**服务地址**\*」：填 chayuan-server 的**根地址**（不含具体路径），如 `https://kb.example.com` 或 `192.168.x.x`。失焦时自动规范化：**没写协议默认补 http；本机地址（localhost/IPv4/IPv6）没写端口默认补 62581**，域名保持原样走 80/443。本机同时跑着 chayuan-harness 时也可点「**⌖ 自动发现本机 Harness**」免手填（见 W34）。

**3. 选鉴权方式并填凭据（逐字段）**

「**鉴权方式**」下拉三项：

- 「**单机本机直连（无认证）— 察元单机版**」：不需要任何账号密钥，连本机察元单机版后端（127.0.0.1:62581）使用，后端 `AUTH_REQUIRED=false` 时自动放行游客。只需名称 + 地址即可保存。
- 「**账号密码（JWT）— 个人账号**」：填「**用户名**\*」和「**密码**\*」；走 `POST /auth/login` 登录取 token，token 过期自动用 refresh token 续期一次，续期失败自动重新登录。
- 「**应用接入（APPID + AppKey）— 部门/服务级**」：填「**APPID**\*」（32 位 hex 应用 ID）和「**AppKey / AppSecret**\*」；每个请求带 `x-app-id`/`x-timestamp`/`x-sign` 三个头，签名算法为 HMAC-SHA256（服务端允许约 ±300 秒时钟偏差——本机时间差太多会报错，见 FAQ Q3）。接口路径自动从 `/knowledge_base/*` 切到 `/openapi/v1/kb/*`，无需手填。
- 编辑已有连接时，密码/密钥框留空表示「**保留空白则使用上次保存的值**」。

**4. 「测试连通」三步体检**

- 做什么：表单里点「**测试连通**」（测试中显示「**测试中…**」；表单上方有提示「**保存前可先测试,失败也可以保存(便于离线配置)**」），或保存后在设置面板左栏选中连接、点闪电图标（悬停「**测试连通**」）。
- 看到什么：三步逐条打 ✓/✗ 并带耗时——「**服务地址**」（GET /healthz，查网络可达）→「**凭据**」（JWT 探 /auth/me；HMAC 探 /openapi/v1/ping；none 探 /healthz）→「**知识库通路**」（拉知识库列表，✓ 时表单里显示「**已授权 N 个知识库**」）。任一步 ✗ 下方给具体原因（错误码含义见 FAQ Q2）。
- HMAC 应用连通但 0 授权时（设置面板里的测试结果），还会亮黄色提示「**APP「…」已连通,但未被授权任何知识库。请联系管理员调用 POST /openapi/apps/{id}/kb_grants**」，旁边「**复制管理员授权命令**」按钮可复制一条现成的授权 curl 发给管理员执行（toast「**管理员授权命令已复制**」）。

**5. 保存与管理连接**

- 点「**创建连接**」（保存中「**保存中…**」）/编辑态「**保存修改**」，成功后 toast「**已创建连接**」/「**已保存修改**」，右栏「**可访问知识库**」列出该连接下可见的库（带角色角标：悬停见「所有者(Owner)/可编辑(Editor)/只读(Reader)/管理员(Admin)」；公开库带「公」角标；空列表时提示「先点左栏的"测试连通"或"刷新",或联系管理员授权。」）。
- 连接条目上的操作（选中展开）：星形「**设为当前连接**」（toast「已设为当前连接」，对话检索用的就是当前连接）、闪电「**测试连通**」、铅笔「**编辑连接**」、垃圾桶「**删除连接**」（确认卡「确认删除连接「…」？此操作不可恢复。」→「**删除**」）。
- 凭据落盘形态：密码/AppKey 经 **AES-GCM（256 位）+ HKDF** 加密后才写入连接配置，加密 key 由浏览器设备指纹 + 本地私有文件系统里的随机盐派生、**每次启动重派生不落盘**——配置文件里只有密文，没有明文。

### 验证

1. `curl http://<服务地址>/healthz`：HTTP 200 即第 1 步「服务地址」可达（三步体检的第 1 步就是它）。
2. 设置 → 常规设置 → 知识库设置：新连接在列表里且可标为「当前」，右栏「可访问知识库」能列出该账号/该 APP 被授权的库，数量与「测试连通」第三步显示的「已授权 N 个知识库」一致。
3. 对话输入区点书本按钮（见 W36）：弹窗树里能看到远程库，勾选后发消息可正常检索引用。

## 常见问题

**Q1：三种鉴权方式到底选哪个？**
个人用自己的账号 → 「账号密码（JWT）」；管理员发了一对 APPID/AppKey（部门/服务级接入）→ 「应用接入（APPID + AppKey）」；连的是本机察元单机版且没开鉴权 → 「单机本机直连（无认证）」。拿不准就看管理员发给你的是账号密码还是 AppKey。

**Q2：测试连通报的中文错误都什么意思？**
第 1 步失败提示「**请检查服务地址、防火墙、HTTPS 证书**」；凭据类：4011「凭据校验失败,请检查 APPID/AppKey」、4012「本地时钟与服务端偏差过大,请校准系统时间」、4013「APPID 不存在或已被禁用,请联系管理员」、4014「AppKey 已被轮换,请重新输入新的 AppKey」、4015「登录已过期,请重新登录」、4031「当前账号没有该知识库的访问权限」、4032「APP 未被授权访问该知识库(…)」、4033「该知识库为公开类型,但当前 APP 未启用公开访问…」、4292「APP 今日额度已用完」、4293「你今日的搜索额度已用完」、404「服务地址正确,但接口不存在(请确认服务端版本 ≥ v0.3.6)」。按提示找对应的人处理即可。

**Q3：HMAC 连接报「本地时钟与服务端偏差过大」？**
签名带时间戳，服务端只容忍约 ±300 秒偏差。校准本机系统时间后重新「测试连通」。

**Q4：换了电脑 / 清了浏览器数据后，连接还在但密码失效？**
这是加密机制的预期行为：加密 key 与本机设备指纹 + 本地私有存储的盐绑定，换设备或清掉本地数据后密文解不开，**需要重新输入一次密码/AppKey**（打开「编辑连接」重填后保存即可，其它配置不受影响）。

**Q5：密码会明文存在配置文件里吗？**
不会。凭据是唯一必须走 `connectionCipher` 加密通道落盘的数据，配置里保存的是「初始向量:密文」形态的 AES-GCM 密文；表单里编辑时留空即沿用旧密文。

## 形态差异

- 远程连接行为与平台无关（Windows/macOS/Linux 的 WPS 加载项同一套代码）；内网环境注意服务地址要从 WPS 所在机器可达，HTTPS 自签证书可能被 WPS 内嵌浏览器拦截（第 1 步体检会如实报「请检查服务地址、防火墙、HTTPS 证书」）。
