## 一句话说明

「任务清单」是一个独立弹窗，集中列出本机插件产生的一切后台任务——拼写与语法检查、助手执行、文档脱密、表单审计、工作流、多模态生成等——支持按状态/范围/根因/风险筛选，并为保密检查任务提供「高危/中危/关键词命中」风险概览卡。

## 适用场景

- 同时跑过多个检查/助手任务，想找「上次那次保密检查」的结果与命中项；
- WPS 重启后想确认：上次没跑完的任务到底完成了没有；
- 想批量清理历史任务，或把某次检查的全部结果导出成 Markdown/JSON 存档。

典型提问（chabot 语料视角）：

- 「保密检查的结果在哪里看？」
- 「任务清单里那个『异常结束』是什么意思？」
- 「怎么把任务检查结果导出来？」

## 前置条件

- 察元 AI 文档助手已启用，且当前在 WPS **文字**端：入口按钮在「察元AI编审」选项卡，表格端/演示端的功能区没有这个按钮。
- 任务清单本身不产生任务；先由任一功能（如「拼写与语法检查」「保密检查」、助手执行）发起任务后，这里才有内容。

## 操作步骤

1. **打开任务清单**：点击功能区「察元AI编审」选项卡 → 「察元设置」组 → 「任务清单」。插件会弹出一个标题为「任务清单」的独立窗口；再次点击按钮时，若窗口已打开则直接聚焦到已开窗口，不会重复弹。
2. **认识空状态**：从未跑过任务时显示「暂无任务」，并提示「点击「检查全部」或「检查当前选中」开始拼写与语法检查，任务将显示在此处」。
3. **看保密检查风险概览卡**：跑过保密类任务（保密检查、涉密关键词提取等，功能本身见 W20）后，列表上方出现概览区。左上是统计范围切换：「统计全部任务」/「仅统计当前筛选结果」；下方一排五张卡：「高危任务」「中危任务」「关键词命中任务」「未见明显风险」「最近保密检查」（显示最近一次检查时间，无则显示「暂无」）。点前四张卡会把下方列表筛到对应风险，再点一次取消；点「最近保密检查」会定位到最近一次保密检查任务。高危/中危计数取自任务结果里的「高风险项」「中风险项」小节，关键词计数取自「可疑关键词汇总」小节。
4. **用筛选栏缩小范围**（一行控件，从左到右）：
   - 搜索框：占位「搜索任务标题、根因、摘要」；
   - 状态下拉：「全部状态 / 进行中 / 已完成 / 失败 / 已取消 / 异常结束」；
   - 范围下拉：「全部范围 / 全文 / 选中文本」；
   - 根因下拉：「全部根因」+ 按当前任务动态生成的根因项；
   - 审查结论下拉：「全部审查结论」+ 动态结论项（如「高风险」「未见明显AI痕迹」「已占位脱密」等）；
   - 风险视图下拉：「全部风险视图 / 仅高危任务 / 仅中危任务 / 仅关键词命中 / 仅未见明显风险」；
   - 定位质量下拉：「全部定位质量 / 仅精确命中 / 包含整句回退 / 包含定位失败 / 高风险任务」；
   - 排序下拉：「最新更新时间 / 最早更新时间 / 按状态 / 按分块数降序」。
5. **批量导出与清理**（筛选栏右侧，按条件出现）：「清理筛选结果（N）」删除当前筛出的可清理任务；「复制汇总 Markdown（N）」把筛选结果汇总为 Markdown 复制到剪贴板；「下载汇总 JSON（N）」下载 JSON 文件。
6. **读一条任务**：每行显示状态图标（⏳ 待执行 / 🔄 进行中 / ⏸ 已暂停 / ✅ 已完成 / ❌ 失败 / ⊘ 已停止 / ⚠ 异常结束）、标题、进度「当前/总数」，下方一排标签：范围（全文/选区）、分块数、定位质量（精确/回退/失败/跳过）、高危/中危计数、高疑似/中疑似计数、关键词计数、结论徽章、根因。进行中的任务行有进度条和「停止」按钮（悬停提示「停止任务」）；每行右侧有「详情」按钮。
7. **看详情**：点「详情」（或点任务行展开）在窗口内展开详情区：范围、分块数、定位汇总（精确/回退/失败/跳过 各多少）、根因与说明、创建/开始时间等；助手类任务还有「结论摘要」卡（文档写入、任务结论、重点提示、可疑关键词）。详情区自带搜索框（占位「搜索原片段 / 建议 / 根因 / 诊断 / 输出」）和「复制搜索摘要」「下载搜索摘要」按钮，可对逐条命中项再过滤。
8. **看工作流任务**：工作流任务行内展开「工作流任务树」，逐节点显示状态与耗时；点节点可跳到对应子任务详情。
9. **清理**：窗口右上角按需出现「清空失败与异常」「清空已完成」两个按钮，点击即移除对应任务（正在执行/待执行的不受影响）。

### 验证

1. 发起一次「拼写与语法检查」或「保密检查」，打开任务清单，应能看到对应任务行，进行中时进度条会前进。
2. 跑一次保密检查后，概览区出现且「最近保密检查」显示本次时间；点「高危任务」卡后列表只剩含高危项的任务。
3. 点「复制汇总 Markdown（N）」，粘贴到任意文本编辑器，应能看到带任务状态与结论的汇总内容。
4. 关闭 WPS 再打开（等 20 秒以上），打开任务清单：上次遗留的「进行中」任务应已被判为「异常结束」，原因为「应用已退出或重启，任务执行中断」。

## 常见问题

**Q1：上次明明在跑的任务，重开 WPS 后显示「异常结束」？**
任务执行时由运行窗口每 4 秒写一次心跳；WPS 关闭后心跳停止，任务清单打开时会把心跳超过约 20 秒的非终态任务判为中断（状态「异常结束」，原因「应用已退出或重启，任务执行中断」）。这是预期行为，重新发起该任务即可。

**Q2：为什么我没有看到风险概览卡？**
概览区只在存在保密类任务（保密检查、涉密关键词提取等）时出现。纯拼写检查/翻译/摘要任务不会触发它；跑一次「保密检查」即可看到。

**Q3：关掉任务清单窗口，任务还在跑吗？**
在跑。任务清单只是查看器，任务由各功能窗口执行（进行中的任务在任务进度窗中可见，见 W18）；关闭清单不影响执行，再次点「任务清单」会聚焦已开窗口或重开。

**Q4：「清空已完成」会不会误删正在跑的任务？**
不会。清空只移除已结束（完成/失败/已取消/异常）的任务，且工作流任务的子任务会随父任务一起清理。被清空的任务快照仍保留在本地归档（最多 200 条）供详情回查，但清单界面没有恢复入口，清理前请确认不再需要。

**Q5：表格/演示里怎么找不到「任务清单」按钮？**
该按钮目前只在文字端的「察元AI编审」选项卡提供；表格端、演示端功能区没有这个入口。

## 形态差异

- **文字端（WPS 文字）**：「察元AI编审」选项卡有「任务清单」按钮，本篇全部功能可用。
- **表格端/演示端**：功能区无「任务清单」按钮（ribbon-et.xml / ribbon-wpp.xml 未包含）。
