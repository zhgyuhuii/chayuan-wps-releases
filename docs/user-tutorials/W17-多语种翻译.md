## 一句话说明

顶部工具栏「翻译」▾ 按钮下拉出 52 个目标语种（中文、English、日本語、Français、العربية 等，选项直接用对应语言标注），点任一语种即发起后台翻译任务并弹出任务进度窗；默认把选中/全文替换为译文，长文档自动分块逐段安全替换并保护编号与段落样式。

## 适用场景

- 把合同、公文、说明书整体译成外文，或把外文资料译成中文；
- 只想翻译选中的几段；
- 关心专有名词、机构名、日期数字不被译错。

典型提问（chabot 语料视角）：

- 「翻译功能支持哪些语言？菜单在哪里？」
- 「翻译完原文怎么没了？能保留原文对照吗？」
- 「长文档翻译为什么是分段进行的？」

## 前置条件

- 已配置对话模型（见 W03）；
- 文档已打开；有选中内容时翻译选中，无选中时确认后翻译全文。

## 操作步骤

**1. 展开语种菜单**

- 在哪：顶部工具栏「AI 助手」分组 → 「**翻译**」▾。
- 看到什么：菜单内容在点开时动态生成，共 **52 个语种**按钮，标签用对应语言书写：中文、English、日本語、한국어、Français、Deutsch、Español、Italiano、Português、Русский、العربية、हिन्दी、ไทย、Tiếng Việt、Bahasa Indonesia、Türkçe、Polski、Nederlands、Svenska、Dansk、Norsk、Suomi、Čeština、Magyar、Ελληνικά、עברית、Українська、Română、Български、Hrvatski、Slovenčina、Slovenščina、Lietuvių、Latviešu、Eesti、Bahasa Melayu、Filipino、বাংলা、தமிழ்、తెలుగు、मराठी、ગુજરાતી、ಕನ್ನಡ、മലയാളം、ਪੰਜਾਬੀ、فارسی、اردو、Kiswahili、Afrikaans、Català、Euskara、Galego。

**2. 选语种发起任务**

- 做什么：先选中要翻译的文字（推荐），再点目标语种。
- 看到什么：无选中时弹确认框「**当前未选中文档内容，将对全文执行“翻译 - <语种>”。\n\n点击“确定”后开始处理全文。**」；确认后弹出任务进度窗，标题「翻译 - <语种>」（如「翻译 - English」），显示分块/批次进度。
- 翻译要求（内置提示词）：忠实原文、保持结构与编号、专有名词/政策名称/机构名/时间数字优先用标准译法、原文已是目标语言时做忠实润色。

**3. 看结果：默认替换为译文**

- 看到什么：翻译助手默认文档动作是「**替换文档内容**」——选中翻译时选中区域被替换为译文，全文翻译时全文替换。
- 长文档（超过分块长度，默认约 4000 字/块、块间带重叠）自动分块逐批翻译，写回时逐段**安全替换**：段落编号前缀保持不动、输出段落数对不上时不硬替换（降级为批注建议）、低质量批次自动改为批注提示（详见 W14 的替换保护与 W18 的任务窗操作）。
- 分块参数在哪调：设置 → 默认设置 → 「**段落截取设置**」——「**截取长度（字符）**」（默认 4000，界面建议 2000–8000）、「**上下重叠长度（字符）**」（默认 200，避免分界处语义断裂）、「**分段策略**」（按段落/按句子/按字符）。

**4. 想保留原文？改写回动作**

- 在哪：设置 → 助手设置 → 「翻译」→「**文档动作**」下拉。
- 翻译助手允许的动作：「替换文档内容」「插入到光标处」「添加批注」「批注 + 替换」「追加到文末」「仅生成结果，不写回文档」。改成「仅生成结果」或「插入到光标处」即可避免覆盖原文。

**5. 译文重跑/换模型**

- 在哪：任务进度窗标题栏（见 W18）。
- 做什么：对译文不满意点「**重试**」按原参数再跑，或从模型下拉换一个模型点「**用新模型重跑**」。

### 验证

1. 「翻译」▾ 展开：语种按钮共 52 个，标签与第 1 步清单一致（混排多语言书写）。
2. 选中一句中文 → 点「English」：任务窗跑完后选中位置变成英文译文，任务窗「文档动作：已替换文档内容」。
3. 设置 → 助手设置 → 翻译：文档动作下拉只有上表 6 个选项。

## 常见问题

**Q1：点完翻译，原文被译文覆盖了，怎么找回？**
默认动作就是替换。刚替换完可立即 Ctrl+Z 撤销；若任务卡勾选了「写回前备份源文件」，用「一键撤销」卡的「撤销本次修改」整体恢复（见 W14）。之后想保留原文，先按第 4 步把文档动作改成「仅生成结果」或「插入到光标处」。

**Q2：长文档翻译要多久？为什么分了几批？**
超过分块长度（默认约 4000 字，可在设置 → 默认设置 → 段落截取设置里调整）会按段落切块、带重叠上下文逐批翻译，批数越多耗时越长。进度窗能看到「第 N 批」推进，中途可「停止处理」。

**Q3：机构名、政策名被译错了怎么办？**
内置提示词已要求专有名词优先用标准译法，但模型仍可能出错。建议对术语敏感的文档：先跑一遍后用「重试/用新模型重跑」换模型对比；或在 AI 对话里附上术语表再让翻译（文档智能体链路）。

**Q4：菜单里没有我要的语种？**
当前内置 52 个语种，菜单为动态生成但语种清单固定，暂无自定义语种入口。可退而在 AI 对话里直接说「把这段翻译成 xx 语」由模型完成。
