# 察元 AI 文档助手（chayuan-wps）用户功能点清单（user-tutorials 教程底稿）

> **用途**：本清单是 `docs/user-tutorials/` 教程集的纲——每个功能点对应一篇独立教程 md，最终整库喂给 chabot 项目作客服/问答语料。写作前必读同目录 `01-写作规范.md`。
>
> **产出方式（2026-10-30）**：由两个只读代码盘点代理全库扫描产出（ribbon 三 XML 逐按钮 + 44 条路由逐页 + 14 个核心能力域），事实全部以 main 代码为准；与 `用户手册.md`（v3.0.10 口径）、`docs/user-manual.zh-CN.md`（v4.1.1 口径）、README.md 的不一致处已在各篇「事实来源」节标注，教程一律按代码写。
> **编号规则**：W 前缀单层连续编号（W01-W44），与察元OS 教程（chayuan-harness docs/user-tutorials，M/P/C/K 域字母）不冲突；chabot 侧按 `wps-tutorials/` 目录区分。

## 产品一句话

察元 AI 文档助手（Chayuan AI Document Assistant）——WPS 文字 / 表格 / 演示三端智能加载项：内嵌智能体在编辑器内完成 AI 对话、文本处理、批量操作、表单填报、模板编制与正文写回；本机 MCP 文档智能体服务可被 Claude Code、Codex、Cursor 等外部智能体调用读写 WPS 文档；优先支持离线/内网模型。

## 事实纪律要点（写作代理必读）

- 产品 UI **无 i18n 框架**：按钮/提示文案以 `public/ribbon.xml` label 属性与各 `.vue` 组件模板内中文字符串为准，引号引原文。
- `src/components/TaskPane.vue`、`Root.vue`、`Dialog.vue`、`TaskPaneTop/Bottom/Left.vue` 均为 **WPS 官方模板遗留 demo**，非产品 UI；真实主对话窗格 = `src/components/AIAssistantDialog.vue`；真实停靠面板由 `ribbon.js showTaskPane(position, route)` 动态挂任意路由。
- 现网 UI 无「牛档」字样（历史名仅存死代码）；「清除图像格式」为占位未上线（ribbon.js:3538）；任务编排 ribbon 直达钮已注释，入口在任务中心。
- 端口/发现链/写锁/隔离等机制类事实以域盘点报告路径为准（各篇「事实来源」引用具体文件）。
