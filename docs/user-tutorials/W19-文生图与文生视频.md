## 一句话说明

顶部工具栏「文本转图像」「文本转视频」两个按钮，把当前文档/选中内容预填成画图或视频提示词并发送到 AI 助手对话，由已启用的图像/视频生成模型生成文件，结果以可下载附件形式出现在对话和任务进度窗里。

## 适用场景

- 想给文档配一张插图、封面图或示意图；
- 把文案变成一段短视频；
- 不确定自己的模型配置能不能生图/生视频。

典型提问（chabot 语料视角）：

- 「文本转图像按钮点了没反应/报未找到图片模型怎么办？」
- 「生成的图片保存在哪？怎么插到文档里？」
- 「为什么生成的是图片文件而不是直接嵌进正文？」

## 前置条件

- 已在模型设置里添加并**启用**能生成图像/视频的模型：程序按模型名自动识别类型（如 `qwen-image`、`dall-e`、`flux`、`stable-diffusion` 等识别为图像生成，`kling`、`sora`、`runway`、`wanx` 视频等识别为视频生成），识别结果可在 设置 → 默认设置 的「**图像生成模型**」「**视频生成模型**」分类清单里确认；
- 任务取该类型下**第一个已启用**的模型执行；
- 没有对应模型时任务报「**未找到可用的图片模型，请先在设置中配置并启用图片模型**」（视频为「未找到可用的视频模型…」）。

## 操作步骤

**1. 一键发起（ribbon 入口）**

- 在哪：顶部工具栏「AI 助手」分组 → 大按钮「**文本转图像**」或「**文本转视频**」。
- 看到什么：AI 助手窗格自动打开，输入框已预填提示词并自动发送：
  - 图像：「**请根据当前内容生成一张图片，如有必要先让我确认画幅比例等参数。**」
  - 视频：「**请根据当前内容生成视频，如有必要先让我确认时长和画幅比例等参数。**」

**2. 模型识别意图并启动生成任务**

- 看到什么：对话模型先判定这是生图/生视频请求，自动带上上下文（画幅比例默认 16:9，视频时长默认 8 秒；你在对话里说过「竖版」「1:1」「15 秒」等会被采纳），随后消息里出现生成任务进度卡，正在调用对应模型。
- 生成的提示词可在对话里继续修改：直接说「换成横版」「主体改成…」再生成。

**3. 拿结果：可下载附件**

- 看到什么：完成后消息变为「**已生成图片文件，点击下方即可下载。**」或「**已生成视频文件，点击下方即可下载。**」，消息下方是生成的媒体文件卡（可下载；未命名时默认文件名为「生成图片」/「生成视频」加扩展名）。
- 任务进度窗/任务清单的「**生成附件**」卡里同时列出附件名与本地保存路径；结果汇总行显示「生成附件：N 个」。

**4. 对话里直接说也可以**

- 在哪：AI 助手窗格（无需 ribbon 按钮）。
- 做什么：直接说「根据这篇文档生成一张封面图」「把这段文案生成视频」。模型按同样链路识别并生成；说「导出文档里的图片」走的是附件导出而不是生图。

**5. 生成失败时看什么**

- 看到什么：任务报错并附分类建议，常见类别：未配置模型（见前置条件）、密钥/权限（「请检查接口地址、API 密钥和当前账号权限。」）、额度（「请检查模型额度、计费状态或稍后重试。」）、网络（「请检查网络连通性、服务状态、CORS、证书和代理配置。」）、超时（「请稍后重试，或改用更短文本、更简单提示词。」）。
- 做什么：按建议处理后重新发起（再点一次 ribbon 按钮，或在对话里重说需求）；任务运行中可随时「停止处理」。

**6. 与三级生图链（配图）的关系**

- 本篇是「点按钮 → 生成文件」的手动生图入口；文档智能体在自动配图场景走三级链——Tier1 模型生图（逐个尝试已启用的图像生成模型，最多 3 个，产物经本机服务落盘）→ Tier2 网络搜图 → Tier3 SVG 兜底，详见 W33。

### 验证

1. 设置 → 默认设置 里能看到「图像生成模型」（生图前）或「视频生成模型」（生视频前）分类且有已启用模型。
2. 打开一篇有内容的文档点「文本转图像」：AI 助手自动发送预填提示词，随后出现生成任务进度卡；完成后消息显示「已生成图片文件，点击下方即可下载。」并可下载。
3. 未启用任何图像模型时点「文本转图像」：报「未找到可用的图片模型，请先在设置中配置并启用图片模型」。

## 常见问题

**Q1：点了「文本转图像」没生成图片，提示未找到模型？**
说明模型设置里还没有能识别为图像生成的已启用模型。到设置 → 模型设置添加支持生图的厂商模型并启用（模型名需能被识别为图像生成，见前置条件），再重新发起。

**Q2：生成结果为什么是文件，不是直接插进文档？**
对话链路的生图/生视频产物以可下载附件交付（图片/视频文件保存在本地并可从「生成附件」卡看到路径），是否插入文档由你决定。文档智能体的配图链路才会把图片自动插入正文（见 W33 与 W14 的图片写回动作）。

**Q3：视频生成一直转圈很久？**
视频合成天然比图片慢（按秒级到分钟级计）。超时会给出「请稍后重试，或改用更短文本、更简单提示词。」的建议；也可先把时长要求说短一些（如 5 秒）再生成。

**Q4：能指定画幅比例和时长吗？**
能。预填提示词本身就说「如有必要先让我确认画幅比例等参数」，任务启动时默认 16:9、视频 8 秒；在对话里直接说明「竖版 9:16」「10 秒」会被识别并传给模型。

**Q5：「文本转语音」按钮怎么找不到？**
顶部 ribbon 当前只放出了「文本转图像」「文本转视频」两个按钮，语音按钮未放出；需要在 AI 对话里直接说「生成语音/朗读这段」走语音生成任务。
