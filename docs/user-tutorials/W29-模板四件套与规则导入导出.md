## 一句话说明

「模板管理」四件套维护一份**本机文档模板库**：把当前文档连同表单规则一起另存登记（导出模板）、把外部文件收进库（导入模板）、从库中复制一份开新文档（从模板新建）、把库中模板拷出到任意位置（下载模板）；「规则管理」的「规则导入／导出规则」则把表单规则集单独存成 `.aidooo` 文件在同事间流转。

## 适用场景

- 做好一份带规则库的公文/合同模板，要登记进模板库供日常「从模板新建」；
- 拿到同事发来的模板文件或 `.aidooo` 规则文件，要收进自己的库；
- 模板存到共享盘给别人当母本（下载模板），或只共享字段规则不共享文档。

典型提问（chabot 语料视角）：

- 「导出模板和导出规则有什么区别？」
- 「怎么把做好的模板给同事用？」
- 「从模板新建的文档保存时为什么老让我另存？」

## 前置条件

- WPS **文字**端，「察元AI编审」选项卡（表格/演示端另有「从模板新建」入口按钮，对话框内按宿主过滤模板）；加载项已启用（W02）；
- 全部为本地功能，不需要模型；规则集落盘位置由 设置 → 数据设置 决定（W44）。

## 操作步骤

**1. 「导出模板」：当前文档另存并登记**

- 在哪：「模板管理」组点「**导出模板**」。
- 看到什么：**先静默把当前规则库写入本文档**，再弹出「**另存文档**」对话框（默认文件名 = 当前文档名 + `.aidocx`，筛选「察元文档 (*.aidocx)」「Word文档 (*.docx)」，扩展名缺省自动补 `.aidocx`）。
- 选好位置保存后：弹「**文档已另存为：**」+ 完整路径；同时该文件**自动登记进本地模板库**（按文件名去扩展名登记，登记失败不影响导出）。之后「从模板新建」里直接能选到它。没打开文档时提示「**请先打开文档**」；另存失败提示「**另存文档失败：**+原因」。

**2. 「导入模板」：把文件收进模板库**

- 在哪：点「**导入模板**」。
- 看到什么：弹窗「**导入模板**」（420×420），说明文字「**选择模板文件（.docx / .xlsx / .pptx / .aidocx），将添加到本地模板库；从模板新建与 AI 生成时可从此处选择，模板类型须与当前文档类型一致。**」
- 做什么：点「**选择模板文件**」（执行中显示「添加中...」）选文件（支持 `.aidocx/.docx/.doc/.xlsx/.xlsm/.et/.pptx/.ppsx/.dps`）。成功提示「**模板已添加到本地模板库**」；下方「**已保存的模板（共 N 个）**」清单逐条显示类型徽章（文字/表格/演示）、名称与「×」删除（删的是登记项，不删磁盘文件）。库为空时显示「**暂无模板，请点击上方按钮添加**」。

**3. 「从模板新建」：复制一份开新文档**

- 在哪：点「**从模板新建**」（表格/演示端为各自选项卡上的同名入口）。
- 看到什么：弹窗「**从模板新建文档**」（表格端「…新建表格」、演示端「…新建演示」；420×480），说明「**选择模板将复制一份打开并标记为新建；保存时会提示另存为新文件**」。清单只显示**与当前宿主同类**的模板，末尾固定一项「**空白文档／空白表格／空白演示**」；没有同类模板时提示「**暂无本类模板，可直接创建空白文档，或在「导入模板」中添加**」。
- 做什么：点选一个模板（或空白项）→ 点「**新建**」（执行中「创建中...」）。产品行为：复制模板副本再打开、写「新建未保存」标记——**绝不留空的新文档**；成功提示「**已创建：**〈名称〉」（经系统级打开时追加「**（系统打开，请点击该文档继续）**」）。类型不匹配的模板会被同宿主闸门拦下并给出切换宿主指引。之后点保存会自动弹另存为，避免覆盖模板母本。

**4. 「下载模板」：把库中模板拷出去**

- 在哪：点「**下载模板**」。
- 看到什么：弹窗「**下载模板**」（420×500），说明「**从列表中选择一个模板，点击确定后选择保存位置**」；清单即本地模板库（与「导入模板」同一份），空时提示「**暂无模板，请先在「导入模板」中添加 .aidocx 模板**」。
- 做什么：选中模板 → 点「**确定**」（执行中「下载中...」）→ 弹系统另存对话框（筛选「Word文档 (*.docx)」，默认名 = 模板名 + `.docx`）→ 模板文件被复制到你选的位置。取消另存则不做任何事。

**5. 「导出规则」：规则集存成 .aidooo 文件**

- 在哪：「规则管理」组点「**导出规则**」。
- 看到什么：弹窗「**导出规则**」（420×480）：顶部搜索框（占位「按名称、标签搜索...」）、「**全选**」勾选框与「**已选 N 项**」计数、规则清单（每行名称 + 标签）；底部「**保存文件名：**」输入框（默认 `chayuan_template_年-月-日.aidooo`，尾注「**（将保存为 .aidooo 格式）**」）。
- 做什么：勾选要共享的规则（可搜索过滤）→ 点「**确定导出**」（执行中「导出中...」，未勾选时置灰）→ 另存对话框（筛选「察元规则 (*.aidooo)」）。文件为带 `format: aidooo` 头的 JSON。库为空时显示「**暂无规则项，请先在规则制作中添加**」。

**6. 「规则导入」：把 .aidooo 文件并回规则库**

- 在哪：点「**规则导入**」。
- 看到什么：弹窗「**规则导入**」（400×320），说明「**选择 .aidooo 格式的规则文件，将导入其中的规则项。ID 与现有规则重复的项将被跳过。**」
- 做什么：点「**从本机选择文件**」（执行中「导入中...」）选 `.aidooo`（或 JSON）文件。完成后显示「**导入完成**」：「**成功：N 项**」「**失败（ID重复跳过）：M 项**」。文件格式不对时提示「**文件格式无效，请选择正确的 .aidooo 规则文件**」。导入的规则立即出现在「规则制作」列表里。

### 验证

1. 「导出模板」后打开「导入模板」：清单里出现刚另存的文件名；
2. 点「从模板新建」选它 → 新窗口打开同款文档，点保存弹出另存为；「规则制作」里规则齐全（规则随文档走）；
3. 「导出规则」的 `.aidooo` 文件发给同事，对方「规则导入」后显示「成功：N 项」，其「规则制作」列表多出这些规则。

## 常见问题

**Q1：「导出模板」和「导出规则」到底差在哪？**
「导出模板」把**整份文档**（正文 + 内嵌规则库）另存为 `.aidocx/.docx` 并登记进模板库，适合交付完整模板；「导出规则」只把**字段规则清单**存成 `.aidooo` 小文件，适合同事之间只共享表单口径、不传文档。

**Q2：从模板新建出来的文档，保存时总弹另存为？**
这是刻意设计：从模板新建的副本带「新建未保存」标记，保存时强制另存为新文件，防止顺手把模板母本覆盖掉。第一次另存之后标记即清除，后续保存正常。

**Q3：模板清单里的「×」删除会把文件删掉吗？**
不会。删除的只是模板库登记项，磁盘上的模板文件原样保留；需要时重新「导入模板」即可。

**Q4：为什么「从模板新建」里看不到我导入的表格模板？**
清单按宿主过滤：文字端只列文字（doc）类模板，表格/演示端同理。把 Excel 模板带进文字端会被拦截并提示去对应宿主使用——先把文件在对应端「导入模板」登记，或直接在对应对话/入口使用。

**Q5：「规则导入」说我文件格式无效？**
「规则导入」只认 `.aidooo` 规则文件（JSON，含 rules 数组）。`.aidocx` 模板文件请走「导入模板」；想看规则内容，`.aidooo` 本质是 JSON，文本编辑器可直接打开。

**Q6：模板登记信息存在哪？换机器会丢吗？**
模板清单存在本机（设置了数据路径时为数据路径下的 `chayuan_document_templates.json`，详见 W44），不随文档走。换机器请重新「导入模板」登记一次，规则集用「导出规则/规则导入」迁移。
