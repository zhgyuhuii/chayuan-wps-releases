## 一句话说明

「表单内容」把文档里全部表单书签列成一张表（名称/内容/填写提示），可就地改值、删除、双击定位；「文档审计」按规则库对每个书签做**本地规则校验 + AI 审计**，给出高/中/低风险分级、逐书签审计意见和一份可复制的审计报告。

## 适用场景

- 交接前想快速核对模板里都有哪些填空位、各处当前填了什么；
- 合同填完要交审：查必填漏填、金额越界、日期先后颠倒、身份证/电话格式错、敏感词、多处「甲方」口径不一致；
- 审完要一份能贴进邮件/纪要的书面报告。

典型提问（chabot 语料视角）：

- 「文档审计怎么用？能查出什么问题？」
- 「表单内容窗口是干什么的？」
- 「审计报告怎么导出/复制？」

## 前置条件

- WPS 文字端打开**已插好书签**的文档（插书签见 W26）；「表单内容」「文档审计」都是整弹窗，不要求处于表单模式；
- 「表单内容」为纯本地功能，不需要模型；「文档审计」= 本地规则校验 + 内置「**文档审计助手**」的 AI 审计，**需要已配置对话模型**（W03）；
- 审计依赖规则库：没有任何规则时会直接报错（见 FAQ Q1）。

## 操作步骤

**1. 「表单内容」：全量书签一览**

- 在哪：「表单辅助」组点「**表单内容**」。
- 看到什么：弹窗「**表单内容**」（520×420）。文档里没有书签时显示「**文档中暂无表单标签（书签）**」和「**请先在「规则制作」中创建表单项并插入标签到文档**」；没有打开任何文档时提示「**当前没有打开任何文档**」。
- 有书签时列出四列表格：「**名称**」（书签显示名）「**内容**」（书签当前文字，空则「(空)」）「**填写提示**」（取自对应规则的填写提示）「**操作**」。
- 做什么：
  - **双击**某行「内容」格（行悬停提示「双击进入编辑并定位到文档」）→ 格内变输入框，改完回车或点别处保存，正文里对应书签内容同步更新；
  - 点行尾「**删除**」（悬停提示「删除标签及内容」）删除该书签；
  - 看完点右下「**关闭**」。

**2. 「文档审计」：选规则**

- 在哪：「表单辅助」组点「**文档审计**」。
- 看到什么：大弹窗「**文档审计**」（880×760），顶部筛选条：搜索框（占位「**搜索规则名称、标签、审计规则**」）、「**风险**」下拉（全部/高/中/低）、「**数据类型**」下拉（全部 + 12 类）与「**重置筛选**」「**刷新**」「**全选**」「**清空**」按钮。规则表八列：「**选择**」（勾选框）「**规则名称**」「**必填**」「**审计规则**」「**数据类型**」「**异常问题数**」「**问题内容**」「**详情**」。底部「**开始审计**」（未勾选任何行时置灰）与「**关闭**」。
- 做什么：规则行**默认全部勾选**，可用「全选」「清空」调整；清单按「审计优先级」（小号在前）排序。点规则名展开「**关联书签**」面板（头行「共 N 处」「异常问题 N 项」），逐书签列出「书签名称／值／值类型／问题详情／风险级别／原因／建议」（审计后有「审查意见」列），书签名可点击定位到正文。规则较多时底部有分页（10/20/50/100 条/页，上一页/下一页）。搜索框与「风险」「数据类型」筛选随时可用；规则或书签被改动后点「**刷新**」重载，筛选失手点「**重置筛选**」复原。

**3. 执行审计**

- 在哪：点「**开始审计**」。
- 看到什么：按钮变「**审计中...**」。审计分两层：先对每个书签跑**本地规则校验**（必填、类型约束、正则/范围/枚举、敏感词，以及派生检查——同类字段格式不一致、开始日期晚于结束日期、金额≤0、编号不含字母数字），再把规则、书签值、上下文与本地问题一起交给「文档审计助手」做 AI 审查，最后合并去重。任务同时进入任务清单（W40），可中途停止。
- 结果区从上到下：
  - 「**审计摘要**」卡：总体结论 +「问题数：N」「批注数：M」（批注数即成功写入书签的审计批注条数）；
  - 「**书签审计意见**」：每个书签一条（字段名、风险徽章、审计意见、问题数）；
  - 「**改进建议**」列表；
  - 「**问题列表**」：每条含「书签／字段值／问题类型／判断依据／改进建议」，无问题时显示「**未发现明显问题**」；
  - 「**报告预览**」：AI 生成的正式审计报告（执行摘要/关键发现/问题分析/结论/建议与行动项等章节），右上「**复制报告**」把 Markdown 全文复制到剪贴板；
  - 规则表里每个规则/书签行也会亮起风险徽章与问题数（可点开看异常书签）。
- 助手配置的写回动作为批注类时，审计意见会以「【文档审计】」批注写入对应书签（W14 批注写回语义）。

### 验证

1. 建一个「金额」规则（小数、范围 0–1000000）并插书签，在正文填「-5」→ 文档审计后问题列表出现高风险「金额应大于 0」类条目；
2. 清空一个必填书签再审计 → 该书签风险级别「高」（必填为空）；
3. 「复制报告」后粘贴到任意文本编辑器，应得到带一级标题的 Markdown 报告。

## 常见问题

**Q1：点「开始审计」报「没有可审计的规则」/「当前文档未找到对应书签实例」？**
前者：规则库里没有任何启用审计的规则——先去「规则制作」建规则（W26/W27）。后者：勾选的规则在文档里一个书签都没插——回「规则制作」把规则「应用」到文档，或勾选别的规则。

**Q2：报「文档审计助手已被关闭」或「未找到可用模型」？**
审计用内置助手「文档审计助手」：到 设置 → 助手设置 里把它启用；模型未配置时到模型设置配好对话模型（W03），或在助手上单独指定模型。

**Q3：审计会改我的文档吗？**
审计本身只读；唯一会写文档的动作是按助手写回动作给书签**加批注**（内容为「【文档审计】」+ 审计意见），不改正文。不想要批注，把助手的写回动作设为「无」即可（助手配置见 W12）。

**Q4：AI 说没问题，但我总觉得哪里不对（或反过来）？**
两层结论是合并的：本地规则校验（确定性，占位残留等以机器为权威）+ AI 审查（语义与规则外风险）。每条问题都带「判断依据」与定位书签，请按依据人工复核；证据不足处 AI 会写「需人工复核」。

**Q5：报告想存成文件怎么办？**
点「报告预览」右上「**复制报告**」得到 Markdown 全文，粘贴到 WPS/记事本保存即可；审计结果也会随任务留在任务清单（W40）里，重开文档审计窗口可回看最近一次结果。

**Q6：表单内容里改了内容，规则表/审计里的值会跟着变吗？**
会。「表单内容」直接改的是文档书签里的文字，审计每次开始都重新读取书签当前值；筛选条上的「刷新」可重载列表。
