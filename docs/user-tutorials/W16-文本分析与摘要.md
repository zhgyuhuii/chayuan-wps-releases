## 一句话说明

顶部工具栏「生成摘要」按钮和「文本分析」▾ 菜单提供九个文本处理件：换种方式重写、扩写、缩写、检查段落序号格式、AI 痕迹检查、批注解释、超链接解释、纠正拼写和语法、提炼关键词。点任意一项即发起后台任务并弹出任务进度窗，结果按该项默认的写回动作落进文档（多数是批注或插入，不动原文）。

## 适用场景

- 写完一段想换个说法、扩充或精简；
- 公文排版前检查序号层级是否规范；
- 拿到一篇「疑似 AI 写的」文稿，想标出可疑片段人工复核；
- 想快速提炼一份材料的关键词或摘要。

典型提问（chabot 语料视角）：

- 「文本分析菜单里九个功能都是干什么的？」
- 「AI 痕迹检查能证明这篇文章是 AI 写的吗？」
- 「点了『换种方式重写』，结果写到哪里去了？」

## 前置条件

- 已配置对话模型（见 W03），否则任务启动时报「未找到可用模型，请先在设置中配置并启用对应模型」；
- 文档已打开；有选中内容时处理选中，无选中时确认后处理全文。

## 操作步骤

**1. 入口与九项菜单**

- 在哪：顶部工具栏「AI 助手」分组 → 「**文本分析**」▾ 按钮（下拉菜单动态展开，九项标签原文）：
  「换种方式重写」「扩写」「缩写」「检查段落序号格式」「AI 痕迹检查」「批注解释」「超链接解释」「纠正拼写和语法」「提炼关键词」。
- 旁边的独立大按钮「**生成摘要**」是第十件（摘要单独成钮）。
- 做什么：先选中要处理的文字（推荐），再点菜单项。

**2. 确认处理范围**

- 看到什么：无选中时弹确认框「**当前未选中文档内容，将对全文执行“<功能名>”。\n\n点击“确定”后开始处理全文。**」（全文较长时追加等待提示）；点「确定」继续，「取消」退出。

**3. 等任务跑完：任务进度窗**

- 看到什么：自动弹出任务进度窗（窗口标题即功能名，如「AI 痕迹检查」），显示进行中/已完成状态徽章、进度条、结果汇总与结果预览；窗口操作（确认写回/换模型重跑等）见 W18。
- 超长文档会自动分块逐批调用模型，进度窗里能看到「第 N 批」的推进。

**4. 各项的默认写回动作（结果落在哪）**

| 菜单项 | 默认文档动作 | 结果位置 |
|---|---|---|
| 换种方式重写 | 替换文档内容 | 替换选中/全文（编号与段落样式受保护，不安全自动降级批注，见 W14） |
| 扩写 | 插入到光标处 | 插在选区后面/光标处，原文保留 |
| 缩写 | 替换文档内容 | 同「换种方式重写」 |
| 检查段落序号格式 | 链接形式批注 | 按定位加批注，正文不动；批注末尾提示可去任务清单看完整结果 |
| AI 痕迹检查 | 添加批注 | 在命中的原文片段上加批注，正文不动 |
| 批注解释 | 链接形式批注 | 批注式解释挂在选中文本上 |
| 超链接解释 | 链接形式批注 | 解释链接/引用指向关系 |
| 纠正拼写和语法 | 添加批注 | 以批注形式给出修正说明，可在助手里改成替换等动作 |
| 提炼关键词 | 插入到光标处 | 项目符号列表插在选区后/光标处 |
| 生成摘要 | 仅生成结果，不写回文档 | 摘要只在任务窗/任务清单里看，不动文档 |

- 想改某项的写回动作：设置 → 助手设置 → 选中该项 → 「文档动作」下拉（可选范围见 W14）。

**5. AI 痕迹检查怎么用、结论怎么读**

- 定位：它是「文档鉴伪与文风分析」的**辅助人工复核**工具，不是鉴定结论。检查维度包括套话与过渡堆砌、结构过度工整、空洞概括、解释性元话语、英译腔、免责声明式收尾、前后文风格断裂七类。
- 看到什么：每条疑似项都带「命中片段」（可直接在原文里逐字搜索的短片段）＋痕迹类型＋疑似程度（高/中/低）＋判断依据＋改写或复核建议；命中片段必须与原文逐字一致，程序不会编造。
- 结论口径：疑似不等于定论——提示词明确要求不武断断言「一定由 AI 撰写」，纯法规引用、固定公文表述会标为低疑似或待人工复核；没有发现时会明确写「**未发现明显 AI 痕迹**」。

**6. 生成摘要**

- 在哪：「AI 助手」分组的大按钮「**生成摘要**」。
- 看到什么：默认「仅生成结果」——摘要（一句话结论 + 分主题要点）出现在任务进度窗和任务清单里，文档不动；可在助手里把文档动作改成「追加到文末」等写回方式，或开启「报告模式」走分段结构化报告。

### 验证

1. 选一段文字点「换种方式重写」：任务窗完成后原文被替换为改写版本，且「文档动作：已替换文档内容」。
2. 选一段文字点「批注解释」：正文不变，选中文本上多一条批注。
3. 点「生成摘要」：文档无变化，任务窗/任务清单里能看到完整摘要。
4. 「文本分析」▾ 展开可见九项，名称与本篇第 1 步清单一致。

## 常见问题

**Q1：点「换种方式重写」后正文被改了，能撤销吗？**
能。勾选过「写回前备份源文件」的任务可用任务卡「一键撤销」回退（见 W14）；也可以直接用 WPS 自己的撤销（Ctrl+Z）。批量分块任务建议先备份再跑。

**Q2：AI 痕迹检查说「高疑似」，能作为处分/鉴定的依据吗？**
不能。它的定位是协助人工复核的文风分析，提示词层面就要求保守研判、疑似 ≠ 定论、命中片段逐字可查。请把结果当作「值得人工复核的线索清单」，结合写作过程证据综合判断。

**Q3：为什么「纠正拼写和语法」只给了批注没有改正文？**
它的默认文档动作就是「添加批注」——先让你看到修正建议再决定。要自动改正：可在设置 → 助手设置 → 纠正拼写和语法里把文档动作改成「替换文档内容」；或用更精细的「拼写与语法检查」（见 W15）＋对话链路「直接改正正文」。

**Q4：菜单里这些功能和「更多」菜单里的助手是什么关系？**
「文本分析」九项是固定入口；「更多」菜单还会列出全部内置与自定义助手（含分析类其它项，如「润色优化」「正式化改写」等），入口管理见 W05/W10。
