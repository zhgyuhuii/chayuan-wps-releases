## 一句话说明

「文档批量」分组的三件套把文档「瘦身」变成三步：扫描并列出没人用的样式勾选清除、把已用样式按页码列成可跳转的统计表、一键删除全文空白行（表格内空白段不动）。

## 适用场景

- 接手别人排版的文档，样式面板里堆了几十个从没用过的「样式1」「Heading 4」，想一次清掉；
- 交审前想知道「正文」「标题 2」都散布在哪些页，逐处核查格式一致性；
- 网页复制来的材料满篇空行，要一键清空再排版；
- 文档里夹着大量「看起来是空的、其实藏了空格」的段落，想一并清掉。

典型提问（chabot 语料视角）：

- 「清理未使用的样式会不会把正文格式弄乱？」
- 「统计已使用样式的表怎么跳到某一页去看？」
- 「删除空白行会不会把表格里的空行也删掉？」

## 前置条件

- WPS **文字**端打开文档（「察元AI助理」选项卡仅文字端显示）；
- 已启用加载项（见 W02）。三件套均为纯本地批处理，**不依赖模型配置**；
- 「清理未使用的样式」「统计已使用样式」逐段扫描全文，几百页大文档扫描期间界面显示进度，耐心等进度走完。

## 操作步骤

入口：顶部「**察元AI助理**」选项卡 → 「**文档批量**」分组，三个大按钮从左到右依次为「**清理未使用的样式**」「**统计已使用样式**」「**删除空白行**」。

**1. 「清理未使用的样式」**

- 在哪：点「清理未使用的样式」，弹出「**未使用样式清理**」窗口。
- 看到什么：窗口打开即自动扫描，显示「**正在扫描未使用的样式...**」和进度「已扫描段落 X/Y」。
- 做什么：扫描完成后列出所有未被任何段落使用的**段落样式**，页面提示「**以下样式在文档中未被任何段落使用，可勾选后清除。**」；每项前面有勾选框，**默认全部勾选**，顶部有「**全选**」框和「**已选 N / M**」计数；可逐项取消勾选保留个别样式。
- 点「**确定清除**」（一项都没勾时按钮置灰；执行中显示「清除中...」）。
- 看到什么：清除完成弹「**已删除 N 个样式。**」；若有删不掉的会追加「**有 X 个样式无法删除（可能为内置样式）。**」；清单清空后窗口自动关闭。一个未使用样式都没有时列表处显示「**未发现未使用的样式**」。不想清理时点「**取消**」或右上角「**×**」关闭窗口。

**2. 「统计已使用样式」**

- 在哪：点「统计已使用样式」，弹出「**样式使用统计**」窗口。
- 看到什么：窗口打开即扫描，显示「**正在统计样式...**」和进度「已处理 X/Y 个段落 (N%)」；段落数少于 10000 时会先对文档重新分页再统计，保证页码准确。
- 做什么：扫描完自动生成两列表格：「**样式名称**」「**页码**」。每个样式一行合并单元格，右侧列出它出现过的所有页（同一页去重、按页码升序），页码单元格显示「**第 N 页**」。
- 想看某处：**双击**对应「第 N 页」单元格，正文会跳到该页并选中该样式的段落，窗口保持打开可继续跳（页码格悬停提示「双击跳转到第 N 页」）。
- 看完点右下「**关闭**」。文档没有任何段落样式可统计时显示「**文档中未找到使用的样式**」。扫描期间你在正文里的光标选区会被临时保存、统计完成后自动恢复，不需要自己找回位置。

**3. 「删除空白行」**

- 做什么：点「删除空白行」即执行，**无确认弹窗**。从文末往前逐段检查，段落内容去掉段落符、换行、制表符、空格（含不间断空格）后为空的整段删除；**表格内部的段落全部跳过**，不影响表格结构。
- 看到什么：完成弹「**已删除 N 个空白行**」；没有空白行弹「**文档中没有找到空白行**」。

### 验证

1. 「文档批量」分组三个按钮名称与本篇引号内文案一致。
2. 新建文档 → 样式面板随意新建一个不用的段落样式 → 点「清理未使用的样式」→ 该样式出现在勾选清单中，点「确定清除」后弹「已删除 1 个样式。」，样式面板里它消失。
3. 在文档不同页用「标题 1」→ 点「统计已使用样式」→ 表格出现「标题 1」一行，页码列出对应页；双击页码格正文跳转选中。
4. 连敲几次回车制造空行 → 点「删除空白行」→ 弹「已删除 N 个空白行」，表格内空段保留。

## 常见问题

**Q1：清理未使用的样式，会不会把正文正在用的格式删乱？**
不会。清单只收录「全部段落扫一遍后没有任何段落引用」的段落样式，正在使用的样式不进清单；勾选默认全选，但可以逐项取消勾选再清除。被清掉的样式没有任何段落在用，正文外观不变。

**Q2：为什么有的样式明明没用却删不掉？**
内置样式（如「正文」「标题 1」等程序内置项）受 WPS 保护，删除接口对其无效。代码会把这些计入失败并在完成提示里显示「有 X 个样式无法删除（可能为内置样式）。」，属正常现象。

**Q3：统计表里页码看起来不对？**
统计前段落数少于 10000 时会先重新分页再取页码；超过 10000 段的超大文档为性能跳过重新分页，页码按当前分页计算。改过内容后重新点一次「统计已使用样式」即可刷新。

**Q4：「删除空白行」会把表格里用来占位的空段删掉吗？**
不会。删除逻辑明确跳过表格内段落，只处理正文中的空段；表格行列数与结构不变。

**Q5：清理/统计窗口一直显示「正在扫描」？**
两份扫描都按批次逐段处理并显示「已扫描段落 X/Y」「已处理 X/Y 个段落 (N%)」，大文档需要等待；若弹出「当前没有打开任何文档」，先确认文档仍处于打开状态；「清理未使用的样式」失败显示「扫描失败：…」、「统计已使用样式」失败显示「加载样式统计失败：…」，重开窗口再试即可。

**Q6：字符样式、表格样式为什么不在清单/统计表里？**
两个窗口都只处理**段落样式**：「清理未使用的样式」扫描时直接跳过非段落类型，「统计已使用样式」统计的是各段落的段落样式。字符样式、表格样式、列表样式暂不在治理范围内，需在样式面板手工管理。

**Q7：只含空格的段落会被删吗？全角空格呢？**
半角空格、不间断空格、制表符与换行/段落符都在空白判定剔除范围内，只含这些的段落会按空白行删除；**全角空格不在剔除范围**，只含全角空格的段落不会被当作空白行删掉。
