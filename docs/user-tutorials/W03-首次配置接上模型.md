## 一句话说明

助手能对话的前提是接上一个对话大模型。首次打开助手窗格会提示「先配置模型，再开启智能写作。」：到设置 → 模型设置里选一家供应商，填 API 密钥（云端）或自动探测本机 Ollama / LM Studio（离线），刷新模型清单后发第一条消息验证连通。

## 适用场景

- 新装察元，欢迎页提示未检测到可用模型，不知道从哪配起；
- 内网 / 涉密环境没有公网 API Key，想用本机 Ollama、LM Studio 等离线端点；
- 配了密钥但「检测连接」报错、或模型下拉是空的。

典型提问（chabot 语料视角）：

- 「第一次用怎么配置模型？必须要 API Key 吗？」
- 「Ollama 已经装好了，察元里怎么连上？」
- 「检测连接报 401 / 404 是什么意思？」

## 前置条件

- 已启用加载项并打开 AI 助手窗格（见 [W02](./W02-在WPS中启用加载项.md)）。
- 云端路线：能访问所选供应商并已有 API Key（设置内「获取秘钥」链接直达各家密钥管理页）。
- 离线路线：本机已安装并启动 Ollama（默认端口 11434）或 LM Studio（默认端口 1234）；没装也可在设置内点「一键安装」引导。

## 操作步骤

**第 1 步 · 从助手窗格进入模型设置**

- 在哪：AI 助手窗格。三种等价入口：
  1. 欢迎页标题「**先配置模型，再开启智能写作。**」下方的「**立即配置模型**」按钮；
  2. 输入区模型下拉（此时显示「配置模型」）展开后的空态提示「**请先在设置中配置模型：开启提供商、填写 API 地址与密钥、刷新模型清单**」→ 点「**立即配置模型**」；
  3. 侧栏左下角「**设置**」齿轮按钮（悬停提示「设置」）。
- 看到什么：独立的设置窗口（默认 1120×820），左栏默认选中「**模型设置**」。

**第 2 步 · 在供应商清单里选一家**

- 在哪：设置窗口第二列（厂商清单）。
- 看到什么：清单按五个分组折叠展示——「**自定义 / 国内平台 / 国际平台 / 本地与自建 / API 聚合**」；顶部有「**全部 / 免Key / 免费**」筛选下拉和搜索框。每行有标签徽标：「**免Key**」（本地 / 自建或无需 API Key 即可使用）、「**免费**」（注册即得免费 Key）、「**免费额度**」，以及状态徽标「**已开启 / 已配置 / 未配置 / 异常**」。
- 默认已开启五家（「已开启」= 显示在察元AI助理的模型下拉中）：**OpenAI、Ollama、DeepSeek、百度云千帆、阿里百炼**。
- 做什么：云端路线点 **DeepSeek**（或其它云端厂商）；离线路线在「本地与自建」组点 **Ollama**（或 LM Studio）。

**第 3 步 · 填密钥与地址（云端，以 DeepSeek 为例）**

- 在哪：第三列厂商配置面板，标题为厂商名，右侧有启用开关。
- 看到什么：「**API 密钥**」输入框（占位「请输入 API 密钥」，行尾三个小按钮：粘贴、显隐眼睛、检测图标）；「**API 地址**」输入框——选中厂商时已按官方地址预填（DeepSeek 为 `https://api.deepseek.com/v1`，下方显示「对话接口预览: …」实时预览）；「**模型**」区初始显示「暂无模型」和提示「配置 API 地址后，点击"刷新模型"按钮获取可用模型」。
- 做什么：
  1. 在「API 密钥」粘贴 Key（提示「多个密钥使用逗号分隔」；没有 Key 时点提示行里的「**获取秘钥**」链接直达该厂商密钥管理页）；
  2. 确认「API 地址」为预填的官方地址；
  3. 点「**刷新模型**」拉取模型清单（「**管理**」按钮可增删）；
  4. 点密钥行的**检测图标按钮**（悬停提示「**检测 API 密钥和地址是否可用**」）。
- 看到什么：先提示「**正在检测连接...**」，成功后提示「**连接成功，API 可用**」；失败给具体原因（见 FAQ Q2）。
- 注意：Ollama 类免密钥供应商（Ollama、LM Studio、Xinference、One API、FastChat、New API）可以不填密钥，检测时也不会被要求先填 Key。

**第 4 步 · 离线路线：连接本机 Ollama / LM Studio**

- 在哪：同上面板，选中 Ollama（或 LM Studio）后，配置面板顶部多出一条**本地引擎状态条**。
- 看到什么（状态条自动探测，三种结果）：
  - 「**✅ Ollama 已安装并运行（<版本>）**」；
  - 「**⚠️ 未检测到 Ollama（未安装或未启动）**」＋「**一键安装**」按钮——点击后自动择优打开 Ollama 官网或 ModelScope 镜像的下载页（按钮变为「正在打开…」；macOS / Linux 还会把官方安装命令复制到剪贴板备用），装好启动后回到此页即自动识别；
  - 「**⏳ 正在检测 Ollama…**」。
- 做什么：选中 Ollama 后「API 地址」已预填默认地址 `http://localhost:11434`，一般无需手填；若该框被清空且探测到服务在运行，状态条会提示「**检测到本地服务运行于 127.0.0.1:11434，点击「填入地址」自动完成配置。**」并出现「**填入地址**」按钮——点击一键补回默认地址。
- 看到什么：补填后提示「**已填入 Ollama 默认地址 http://localhost:11434，可点击「刷新模型」获取本地模型列表**」。LM Studio 同理（默认地址 `http://localhost:1234`，预填形式 `http://localhost:1234/v1`）。地址已配好时，状态条改为显示拉取模型的网络提示（如建议从 ModelScope 下载 GGUF 导入或配置国内镜像加速）。
- 收尾：点「**刷新模型**」列出本机已拉取的模型。

**第 5 步 · 设为默认对话模型**

- 在哪：设置窗口左栏「**默认设置**」→ 第二列「模型设置项」→「**对话模型**」。
- 做什么：右侧「**默认模型**」下拉里选一个刚配好的模型。下拉为空时显示「请先在模型设置中配置：开启提供商、填写 API 地址与密钥、刷新模型清单」；提示「**仅显示在模型设置中已开启且已配置的对应类型模型（对话/图像/视频/语音）**」。

**第 6 步 · 用第一条回复确认连通**

回到助手窗格，输入一句话发送。**以对话第一条回复成功为准**判断连通——WPS 沙箱的网络策略与 curl 探活结果未必一致（用户手册 FAQ 口径），检测通过不代表对话链路必通，反之检测失败也可按报错修正后以对话验证。

### 验证

1. 输入区模型下拉能展开并看到刚刷新的模型（按厂商分组显示）。
2. 发送一句话收到流式回复；输入区占位文案从「请先配置模型后再开始对话」恢复为「输入消息，Enter 发送，Ctrl+Enter 或 Alt+Enter 换行」。
3. 供应商面板检测图标点击后提示「连接成功，API 可用」，且该厂商清单行状态徽标正常（不再出现「异常」）。

## 常见问题

**Q1：检测时提示「请先填写 API 地址」/「请先填写 API 密钥」？**
检测依赖地址＋密钥：地址必填；密钥对 Ollama 类免密钥供应商可空，云端厂商必填。补齐后再点检测图标。

**Q2：检测报「连接失败： 401 / 403 / 404 …」怎么处理？**
- 「**401 未授权：请检查 API 密钥是否正确、是否已过期，或该密钥是否有访问权限**」→ 核对 / 重贴密钥；
- 「**403 禁止访问：API 密钥可能无权限访问此接口**」→ 检查该 Key 的接口权限；
- 「**404 未找到接口（探测 <地址>）：请确认服务已启动、地址正确**」→ 地址写错（多 / 少了 `/v1`）或本地服务没启动。
失败后该厂商清单行会挂「**异常**」徽标（悬停显示「最近检测失败：<原因>」）；修复后重新检测成功即自动清除。

**Q3：Ollama 显示「未检测到（未安装或未启动）」？**
本机 11434 端口无响应。先确认 Ollama 服务已启动（终端能执行 `ollama list`）；没装就点「**一键安装**」，察元会自动择优打开官网 / ModelScope 镜像下载页；装好启动后回到该面板即自动识别。

**Q4：模型下拉一直是空的？**
三个条件缺一不可：供应商开关已启用、API 地址与密钥已配置、点过「**刷新模型**」。另外下拉按类型过滤——只有「对话」类型模型会出现在对话下拉中，图像 / 视频 / 语音模型要在对应助手里选。

**Q5：检测通过，对话却发不出去？**
以第一条回复为准继续排查：核对「API 地址」与厂商文档一致、本机代理 / 内网防火墙是否放行该域名；离线模型确认服务进程在跑、显存足够。改完在对话里再发一条验证。
