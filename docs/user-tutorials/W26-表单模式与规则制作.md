## 一句话说明

「规则制作」在右侧停靠面板里维护一份**表单规则库**（每个规则定义一个表单项：名称、类型、约束、审查方式），把规则「应用」到文档就生成书签标签；「表单模式」把全文锁定、只留书签区域可填——两者配合，把一份普通文档变成「只能填空、不能动正文」的表单模板。

## 适用场景

- 制作合同、公文、审批单等模板：正文措辞不能被填表人改动，只留姓名、日期、金额这些空位；
- 想给每个填空位定规矩（必填、长度、数值范围、身份证/电话格式），后续交给「文档审计」自动查错（见 W28）；
- 一套字段规则（甲方、乙方、金额……）想在多份文档里反复用——规则库随文档保存，也能整体导入导出（见 W29）。

典型提问（chabot 语料视角）：

- 「怎么做一份只能填空不能改正文的合同模板？」
- 「规则制作里的书签是什么格式？怎么插到文档里？」
- 「表单模式怎么进、怎么退？进了之后哪里填内容？」

## 前置条件

- WPS **文字**端打开一份文档。「察元AI编审」选项卡仅文字端显示（表格/演示端没有本篇功能）；
- 加载项已启用（见 W02）；
- 本篇的规则制作与表单模式均为**本地功能，不需要配置模型**；规则库里的「智能提取」按钮要用 AI 抽字段，需已配对话模型（见 W27）。

## 操作步骤

入口：顶部「**察元AI编审**」选项卡。与本篇相关的三个分组：

- 「**表单辅助**」组：「表单模式」（动态按钮，进入后变「退出表单模式」）、「表单内容」「文档审计」（后两者见 W28）；
- 「**模板管理**」组：导出模板／导入模板／从模板新建／下载模板（见 W29）；
- 「**规则管理**」组：「**规则制作**」「规则导入」「导出规则」（导入导出见 W29）。

**1. 打开规则库面板**

- 在哪：点「**规则制作**」。
- 看到什么：WPS **右侧**停靠出规则库面板（不是弹窗）。顶部是搜索框（占位「**按名称、标签搜索...**」），下面一排按钮：「**+ 添加**」「**智能提取**」（见 W27）、「**修改**」「**删除**」（后两个需先单击选中一行才可用）。主体是规则表，四列：「**应用**」「**书签名称**」「**必填**」「**标签**」。还没有规则时表体显示「**暂无规则，点击「添加」创建**」。

**2. 新建一个表单项规则**

- 在哪：点「**+ 添加**」。
- 看到什么：弹出「**添加表单项**」窗口（高度自适应屏幕，约 420–800）。
- 逐字段填写：
  - 「**书签名称**」（带 \* 必填）：表单项显示名，如「姓名」「合同编号」，它将作为书签标签的一部分；
  - 「**语义键**」：稳定英文键，如 `partyA`、`contractAmount`，用于同类字段归并与跨项逻辑校验；
  - 「**填写提示**」：填表人看到的提示语，如「请输入合同甲方全称」；
  - 「**标签**」：分类用，多个用英文逗号分隔（如「合同, 客户」），供搜索；
  - 「**是否必填**」勾选后，审计时会校验该处不能为空；
  - 「**内容生成策略**」：保留内容／清空内容／样例内容（智能提取写入时按此处理原文）；「**样例内容**」配合样例策略使用；
  - 「**数据类型**」共 12 类：字符串、下拉选项、整数、小数、日期、时间、日期+时间、布尔、邮箱、电话、身份证号、网址。选类型后下方**动态出现**该类型的约束项：
    - 字符串 → 最小长度／最大长度／须包含／不许包含／正则匹配（均可留空不限制）；
    - 整数、小数 → 最小值（≥）／最大值（≤）／等于（精确值），小数多一项「小数位数」；
    - 日期、时间、日期+时间 → 不早于（≥）／不晚于（≤）／等于（精确值）；
    - 布尔 → 「允许的值」（默认「是,否」）；下拉选项 → 「下拉值」（英文逗号分隔）；
    - 邮箱／电话／身份证号／网址 → 无额外约束，页面提示「**此类格式由类型自动校验，仅需设置是否必填**」；
  - 「**审查方式**」10 种：无、正则审查、格式校验、范围校验、枚举校验、大模型审查、敏感词审查、格式一致性、逻辑关系、跨项校验；配合「**审查规则**」文本框（如正则 `^1[3-9]\d{9}$`、范围「0,1000000」、枚举「是,否」）与「**审查提示**」（校验不通过时显示的提示语）；
  - 「**实例处理方式**」（语义合并／逐实例处理）、「**是否参与审计**」「**审计优先级**」（1–100）、「**备注**」「**智能提取提示**」为进阶项，可留空。
- 填完点「**确定**」（「取消」放弃）。书签名称留空会提示「**请输入书签名称**」。规则立即出现在右侧规则表中。

**3. 把规则应用为文档书签**

- 在哪：先在正文里把光标放到要留空的位置，再回右侧规则表点该行「**应用**」按钮（或**双击**规则行——行悬停提示「单击选中，双击在当前文档位置创建书签」）。
- 看到什么：光标/选区处插入一个书签，名称格式为「**名称_id_序号**」，如 `姓名_fmx81k2a_1`——`id` 是规则唯一标识（自动生成的 `f` 开头串），序号自动递增，同一规则可在文档多处插标签。当前插入点已有书签时会拦截：「**已存在书签，不能重复添加。**」（按光标状态显示「当前选区」或「当前光标位置」开头）并列出冲突书签名。
- 展开关联书签树：点行首箭头或书签名称链接，行下展开「**关联书签**」面板——「共 N 处」，每处显示「第 N 处」、书签名链接、位置、内容（空则「（空）」），提供「**定位**」（正文跳转选中该书签）和「**删除书签**」；面板头还有「**删除规则**」。选中规则后点顶部「**删除**」同样删规则，文档已有关联书签时会提醒「**文档中已存在 N 个关联书签，删除规则不会自动删除这些书签，它们将保留在文档中。**」

**4. 进入／退出表单模式**

- 在哪：「表单辅助」组点「**表单模式**」。
- 看到什么：弹提示「**已进入表单模式，仅可编辑书签区域、表单域、内容控件，其他内容已锁定。**」——书签区域已自动包成内容控件（提示里带「**已将 N 个书签区域设为可编辑。**」）；一个书签都没有时追加「**提示：可先插入书签，或在文档中使用表单域/内容控件作为可编辑区域。**」。同时**右侧自动打开表单编辑窗格**；按钮文字变为「**退出表单模式**」（按钮文字随文档状态动态变化）。
- 再点「**退出表单模式**」：提示「**已退出表单模式，文档全部内容可编辑**」，书签外包裹的临时内容控件被移除、保护解除，正文恢复可编辑。没打开文档就点按钮会提示「**请先打开文档**」。

**5. 在表单模式里填写**

- 在哪：正文里把光标点进某个书签区域。
- 看到什么：右侧窗格显示该处表单编辑卡：首行书签显示名与「**编辑规则**」按钮，下面列出「类型：」「语义键：」「填写提示：」「备注：」，再往下是按数据类型生成的输入控件（必填项带 \*）。光标不在任何书签内时显示「**将光标移入文档中的书签区域，此处将显示该处的表单编辑。**」。文档不处于表单模式时，右侧窗格回到默认内容「**规则库**」页并提示「**请先进入表单模式以使用表单编辑功能**」。

### 验证

1. 进入表单模式后，试着在书签外的正文打字——应无法输入；点进书签区域可正常填写；按钮显示「退出表单模式」。
2. 「表单内容」（W28）打开后能看到刚插的每个书签：名称、内容、填写提示。
3. 关闭 WPS 重开该文档再点「规则制作」：规则列表还在——规则随文档变量保存，并同步落盘到数据路径下的 `relus.aidooo` 文件（路径见 W44）。

## 常见问题

**Q1：文档里一个书签都没插，能开表单模式吗？**
能。会提示「已进入表单模式……」并追加「提示：可先插入书签，或在文档中使用表单域/内容控件作为可编辑区域。」——此时文档里原有的表单域、内容控件仍可编辑；建议先回「规则制作」插好书签再填。

**Q2：右侧规则库面板不小心关了，怎么再打开？**
再点一次「察元AI编审」→「规则制作」即可重新停靠。进入表单模式也会自动打开右侧窗格。

**Q3：删了规则，文档里的书签会一起消失吗？**
不会。删除时会明确提示「文档中已存在 N 个关联书签，删除规则不会自动删除这些书签，它们将保留在文档中。」要清理书签，可在展开的「关联书签」面板里逐个「删除书签」，或在「表单内容」（W28）里删除。

**Q4：书签名为什么是「姓名_f开头串_1」这样的乱码样子？**
这是刻意设计：名称_id_序号 三段式让程序能从书签名反查出对应规则（审查时按 id 匹配规则校验内容），序号保证同一规则多处插标签不重名。手工在 WPS 里插的同名书签请勿模仿此格式拼接。

**Q5：同一个位置插不了第二个书签？**
当前选区/光标处已有书签时会提示「已存在书签，不能重复添加。」（「当前选区」或「当前光标位置」开头）并列出冲突书签名——先把光标移到别的位置，或先删除旧书签。

**Q6：表单模式会加密或改坏文档吗？**
不会。它用的是 WPS 的「仅允许填写窗格」保护 + 把书签区域包成内容控件，退出表单模式即还原；表单模式状态记在文档变量里，随文档保存，下次打开按钮仍显示正确状态。
