## 一句话说明

察元的全部配置集中在一个独立设置窗口里：左栏四大项「模型设置 / 默认设置 / 助手设置 / 常规设置」，其中「常规设置」下再分「数据设置 / 知识库设置 / MCP 服务管理」三个子页。本篇是总览地图，告诉你每一页管什么、从哪进。

## 适用场景

- 想改默认模型、配置厂商、管理助手，但不知道在哪个页签；
- 要接知识库、管理 MCP 服务、改数据落盘路径；
- 打开设置后看到三列布局，不清楚列与列的关系。

典型提问（chabot 语料视角）：

- 「察元的设置在哪里？都有哪些配置项？」
- 「默认模型 / 数据路径 / 知识库分别在哪里设置？」
- 「设置里的 MCP 服务管理是干什么的？」

## 前置条件

- 已启用加载项（见 [W02](./W02-在WPS中启用加载项.md)）；模型配置的具体操作见 [W03](./W03-首次配置接上模型.md)，本篇只讲地图不展开。

## 操作步骤

**第 1 步 · 打开设置窗口**

在哪：三个等价入口——

1. AI 助手窗格侧栏左下角「**设置**」齿轮按钮（悬停提示「设置」）；
2. 「察元AI编审」选项卡 →「察元设置」分组 →「**设置**」按钮；
3. 表格端 / 演示端「察元AI助理」选项卡上的「**设置**」按钮。

看到什么：弹出独立设置窗口（默认 1120×820，三列布局）。设置窗口是单实例的——已开着时再点「设置」，只会把已有窗口带到前台，不会开第二个。

**第 2 步 · 左栏四大项（第一列主菜单）**

| 菜单项 | 管什么 |
|---|---|
| 「**模型设置**」 | 打开设置默认落在这页：配置各家模型供应商 |
| 「**默认设置**」 | 按模型类型设默认模型；网络资源搜索；段落截取 |
| 「**助手设置**」 | 内置 / 自定义助手的管理与参数 |
| 「**常规设置**」 | 点开后在第二列出现三个子页：数据设置 / 知识库设置 / MCP 服务管理 |

**第 3 步 · 模型设置页**

- 第二列：厂商清单，按「**自定义 / 国内平台 / 国际平台 / 本地与自建 / API 聚合**」五组折叠分组，顶部「**全部 / 免Key / 免费**」筛选＋搜索框；每行带「免Key / 免费 / 免费额度」标签与「已开启 / 已配置 / 未配置 / 异常」状态徽标；清单支持拖拽排序，右键「自定义」厂商可编辑 / 删除。
- 第三列：选中厂商的配置面板——启用开关、「API 密钥」「API 地址」「模型」清单（「刷新模型」「管理」）与检测按钮。详见 [W03](./W03-首次配置接上模型.md)。

**第 4 步 · 默认设置页**

第二列标题「**模型设置项**」，共六项：前四项为模型分类——「**对话模型**」「**图像生成模型**」「**视频生成模型**」「**语音转换模型**」，外加「**网络资源搜索**」「**段落截取设置**」。选中后在右侧设置：

- 模型分类项：右侧「**默认模型**」下拉，按厂商分组选择；提示「仅显示在模型设置中已开启且已配置的对应类型模型（对话/图像/视频/语音）」。
- 「段落截取设置」：大文档分批处理的参数——「**截取长度（字符）**」（建议 2000–8000，默认 4000）、「**上下重叠长度（字符）**」（默认 200）、「**分段策略**」（按段落 / 按句子 / 按字符），以及「**建议复核问题写入批注**」开关。
- 「网络资源搜索」：内嵌网络资源搜索面板（配图 / 搜图资源清单，见 W33 教程）。

**第 5 步 · 助手设置页**

第二列标题「**助手设置项**」：按分组折叠的助手清单（每组标题行可展开，显示数量；底部提示「可拖拽排序，右键菜单可复制、删除、上移、下移」），工具栏按钮：「**导入助手**」「**新建分组**」「**从智能空间同步**」（宿主助手模式下为「**新建助手**」）。选中单个助手后右侧编辑其参数。详见 W11 / W12 教程。

**第 6 步 · 常规设置 → 数据设置**

- 在哪：左栏「常规设置」→ 第二列「**数据设置**」。
- 看到什么：标题「**数据路径设置**」，说明原文：「**设置后，规则数据（relus.aidooo）、导入的文档模板等本地数据将统一保存到此路径下。留空则规则不写入本地文件。**」
- 做什么：在路径输入框直接填，或点「**选择文件夹**」；下方显示「默认路径：…」和只读的「错误日志目录（只读）：…」；「**使用默认路径**」按钮一键还原。页面下方还有「**多模态服务端 Fallback**」开关与「服务端接口地址 / 接口密钥」输入框（长视频或本地抽帧能力不足时的服务端分析兜底）。改完点窗口底部「**保存**」。

**第 7 步 · 常规设置 → 知识库设置**

内嵌完整的知识库设置面板（本机发现与远程连接三鉴权），详见 [W34](./W34-连接本机察元知识库.md) / [W35](./W35-连接远程知识库.md)。

**第 8 步 · 常规设置 → MCP 服务管理**

- 看到什么：标题「**MCP 服务管理**」＋状态行（形如「本机在线 · Agent 已注册」），右上「**刷新**」「**添加**」按钮。
- 做什么：「刷新」重新探测全部服务状态；「添加」弹出添加 MCP 服务表单（名称 / 地址 / 请求头 / 启用开关）；点列表中的服务条目进详情（在线状态、工具清单、编辑 / 删除）。

### 验证

1. 逐项点过左栏四项：每项的第二列清单与第三列表单都能正常显示（第一屏加载失败会显示「加载失败：…」与「请刷新或重新打开设置」）。
2. 在「数据设置」改路径 → 点「保存」→ 关闭重开设置，路径保持。
3. 已配置过模型时，「模型设置」里对应厂商行显示「已开启」或「已配置」徽标。

## 常见问题

**Q1：左栏为什么只有四项？听说还有历史版本 / 评测历史 / 能力审计页？**
这三页（历史版本列表、评测历史、能力审计）在代码中属隐藏主菜单：左栏不显示，点击入口会被拦回「模型设置」，带这些页参数的深链打开时也会被重定向。当前版本没有常规入口，属预留页面，日常配置用不到。

**Q2：设置窗口打不开，或点了没反应？**
设置是单实例窗口：已有一个设置窗口（可能被挡在后面）时，再点「设置」只是把它带到前台。关掉旧窗口或切换过去即可。

**Q3：数据路径留空会怎样？**
按面板原文：「留空则规则不写入本地文件。」错误日志也会落到各系统默认位置，不影响其它功能使用。

**Q4：模型设置 / 默认设置里看到的模型对不上？**
「默认设置」的下拉只列「已开启且已配置」的对应类型模型；模型下拉是空的先回「模型设置」完成供应商配置与「刷新模型」（见 [W03](./W03-首次配置接上模型.md) FAQ Q4）。
