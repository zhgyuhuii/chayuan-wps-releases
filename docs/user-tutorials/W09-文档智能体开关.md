## 一句话说明

机器人图标打开「文档智能体」下拉：一个总开关决定发消息走 MCP 文档智能体链路还是内置助手链路，旁边健康灯显示本机文档服务状态；下方可设「表单自动继续 N 秒」、勾选其它 MCP 服务，并可一键「刷新」状态或跳「管理」页。执行多步文档任务时，消息区右上还有任务清单漂浮卡实时显示 n/m 进度。

## 适用场景

- 想让 AI 真正动手改文档（多步规划、写回、表单填报），而不只是给文本建议；
- 本机 MCP 文档服务没起，发消息提示走了内置助手，想知道怎么拉起来；
- 接了别的 MCP server，想在 WPS 里启用/停用它们。

典型提问（chabot 语料视角）：

- 「输入框旁边的机器人图标是什么？怎么开关文档智能体？」
- 「提示『本机文档服务未就绪，发送将使用内置助手』怎么办？」
- 「消息右上角转圈的小圆点 n/m 是什么？」

## 前置条件

- 已打开 AI 助手窗格（见 W05）。
- 文档智能体走本机 MCP 服务（`127.0.0.1:62588`，路径 `/mcp`）。该服务由设置页/启动脚本手动或按需拉起（启动方法见 W37）；未运行时加载项自动回落内置助手链路，不影响基本对话。

## 操作步骤

**1. 认识机器人按钮与健康灯**

- 在哪：输入区工具条上的**机器人图标**按钮，图标右下角有一颗**健康灯小圆点**（绿/黄/灰），启用了 MCP 时按钮上还有已启用服务数徽标。
- 悬停提示：「**文档智能体（已启用 N 个 MCP）· <健康说明>**」；关闭时为「**文档智能体（已关闭）· 点击选择 MCP**」。

**2. 打开下拉、开/关总开关**

- 做什么：点机器人按钮展开下拉。
- 看到什么（自上而下）：
  - 总开关行：复选框 +「**文档智能体**」+ 右侧状态字「**就绪**」（绿）/「**部分可用**」（黄）/「**未就绪**」（灰）/「**已关闭**」，悬停状态字可见完整健康说明（如「察元 MCP 与 Agent 可用」「sidecar 未运行（心跳文件无响应）」「环回被拦截…」）；
  - 「**表单自动继续**」行：数字输入框（默认 **5**，范围 1–120）+ 单位「秒」——参数收集类表单卡等待你确认的秒数，倒计时结束自动继续；
  - 分隔线后是**其它 MCP server** 勾选列表（内置察元AI文档服务不在此列、始终自动启用）；一个都没加时显示「**暂无其它服务——内置察元AI文档服务自动启用**」，且勾选项在总开关关闭时置灰；
  - 底部两个文字按钮：「**刷新**」（深探测一次健康状态）和「**管理**」（打开设置页的 MCP 服务管理，见 W37）。
- 做什么：勾/去勾「文档智能体」即开/关总开关；开关会记忆，下次打开窗格保持。

**3. 本机服务未就绪时的一键启动**

- 看到什么：总开关开着但本机服务没起时，消息区顶部出现软横幅「**本机文档服务未就绪，发送将使用内置助手**」，横幅右侧带「**一键启动**」按钮（点击后变「**正在启动…**」）。
- 做什么：点「**一键启动**」拉起本机 MCP 服务（与设置页「启动本机服务」同一条链路）。
- 看到什么：成功后横幅消失，健康说明变为「**本机文档服务已启动**」。
- 特殊情况：横幅若为「**本机服务在运行，但应用安全层拦截了加载项的连接——请在设置中信任察元AI加载项（或确认安全弹窗）后重启应用**」，说明服务活着但连接被 WPS 安全层拦了，按提示信任后重启应用（此横幅没有一键启动按钮，拉起解决不了拦截）。点过一次「一键启动」后，本会话内后续探活失败会静默自动重拉一次。

**4. 看任务清单漂浮卡（执行中）**

- 看到什么：文档智能体执行多步任务时，消息区右上角先出现一个小圆点带轨道转圈动画和「**任务清单 n/m**」进度与「**展开 ▴**」；点它展开完整漂浮卡——标题行「**任务清单**」+ 转圈图标 + 「n/m」（模型尚未规划完时显示「**规划中**」），下面逐条列出步骤：完成的打 ✓、进行中的带转圈、待办的为空心圆。
- 做什么：点卡片标题行可再收起/展开；任务随执行实时推进。
- 补充两处执行痕迹：
  - 智能体消息底部有「**执行过程**」折叠条（显示「N 步」和最近一步的名称），点开逐条查看每个步骤及其明细；
  - 消息底部会标出「**文档智能体**」徽章和「**已识别为：…**」的路由说明，表示这轮确实走了智能体链路。

**5. 健康状态何时刷新**

- 被动刷新时机：打开助手窗格、展开本下拉、切换总开关、发送消息、点「刷新」——这些都只做健康探活，**不会**自动拉起本机服务（避免反复弹 WPS 安全提示）；要启动服务用横幅「一键启动」或设置页「启动本机服务」。

### 验证

1. 展开下拉：总开关、健康状态字、「表单自动继续」默认值 5、「刷新」「管理」都在。
2. 停掉本机服务（或未安装）时展开下拉/发消息：健康灯灰、状态字「未就绪」，消息区顶部出现「本机文档服务未就绪，发送将使用内置助手」横幅；点「一键启动」后横幅消失。
3. 终端访问 `http://127.0.0.1:62588/healthz`（服务已启动时）：返回健康响应；给智能体发一个多步任务，右上角出现任务清单漂浮卡且 n/m 随步骤推进。

## 常见问题

**Q1：关闭总开关后会怎样？**
发消息不再走 MCP 文档智能体，改用内置助手链路；MCP 任务清单漂浮卡、执行过程等智能体专属 UI 随之不出现。再勾上总开关即恢复（会立即刷新一次健康状态）。

**Q2：健康灯是黄色「部分可用」是什么意思？**
即外接 MCP 服务可达、但察元文档通道未就绪（悬停状态字可看完整说明「仅外服可用（n/m），察元文档通道未就绪」）。先点「刷新」复查；仍黄则按 W37 排查本机服务。

**Q3：一键启动也起不来？**
启动走与设置页「启动本机服务」相同链路，失败常见于部署机未装 Node.js 或被安全软件拦截——改用 W37 的启动脚本/预编译二进制方式启动，或到 设置-常规设置-MCP 服务管理 页查看详情。

**Q4：表单自动继续 5 秒太短，来不及填参数？**
把「表单自动继续」的秒数调大（1–120 之间，改动立即记忆）。它只影响参数收集类表单卡的自动继续等待，不影响普通对话。

**Q5：怎么添加其它 MCP server？**
点下拉底部「管理」进设置页的 MCP 服务管理添加（见 W37）；添加后回到下拉勾选即可启用，徽标数字只统计你手动添加且已启用的服务。
