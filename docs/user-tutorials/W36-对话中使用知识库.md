## 一句话说明

给会话绑定知识库后照常发消息：发送链路自动「多查询检索 → 去重合并 → 可信度打分 → 注入提示词」，回答按 [^cN] 标注出处，消息下方折叠条「**知识来源**」可展开看每条来源的片段、星级信任度并下载原文；也可以选中一段文字用右键「察元AI知识库」的三个动作（核对/总结/问答本段）一键发起。

## 适用场景

- 写材料时想让 AI 回答「以库内文档为准」并给得出处，而不是凭模型记忆自由发挥；
- 拿到一份文档，想核对其中说法与单位知识库是否一致；
- 看到回答下面的「知识来源」条，想知道星级、片段、📎 文件名分别是什么。

典型提问（chabot 语料视角）：

- 「回答里的来源怎么展开？星级是什么意思？」
- 「为什么绑定了知识库回答里还是 0 条来源？」
- 「右键的『知识库核对本段』是怎么工作的？」

## 前置条件

- 已连上至少一条知识库连接（本机见 W34、远程见 W35）；
- 已配置对话模型（见 W03）——检索结果注入后由它作答；
- 功能开关 `kbRemoteIntegration` 为开（默认开；关闭时绑定仍在但不触发检索，见 W34 步骤 1）。

## 操作步骤

**1. 给会话绑定知识库**

- 在哪：对话输入区工具条的书本图标按钮（模型芯片、机器人按钮旁边）；未绑定时悬停「**选择知识库**」，已绑定时「**已绑定 N 个知识库 · 点击编辑**」且按钮高亮。
- 做什么：点开「**选择知识库**」弹窗——知识库按分组排列（本机连接显示「**察元 Harness(本机)**」分组，远程连接按服务端返回的分组）；顶部搜索框「**搜索知识库名称...**」可过滤；组头有「**全选**」；每行勾选框 + 📚 + 库名 + 角色角标（悬停见「所有者/可编辑/只读/管理员」），公开库带「公开」角标，过期的授权行带「已过期」角标且不可勾。
- 「**检索配置**」区（可不改）：「**topK / 每条查询**」默认 5（1–20）、「**融合方式**」默认「**RRF（推荐）**」（另一项 Weighted）、「**启用 hybrid（向量+关键词）**」默认勾选、「**启用 rerank**」默认不勾。
- 底部显示「**已选 N 个知识库**」（可点「**清空**」），点「**确定 (N)**」保存。绑定是**会话级**的：不同会话可绑不同库组合，随会话历史保存。

**2. 发消息：自动检索与引用回答**

- 做什么：绑定后照常提问发送。
- 看到什么：识别为知识类提问时，处理进度会提示「**已选择知识库，本轮将先搜索知识库并结合当前材料回答。**」；回答正文按引用约束在关键事实处标注 **[^cN]**（N 对应来源卡编号），并要求不编造来源、知识库未覆盖时明说。
- 背后发生什么（理解用）：发送链路对绑定库自动执行「**计划 → 批量检索 → 去重 → 打分**」——先把你的消息做**四层漏斗**多查询拆解（T1+T2 结构切分与自适应归并；长文本再加 T3 ngram 向量层次聚类、T4 LLM 关键短语蒸馏；自动按长度选档：≤200 字单查询，≤800/≤4 千字跳过聚类蒸馏，≤2 万字起启用 T3，≤10 万字全启），再逐库检索（本机库 `GET /search` 按查询×库受限并发、按名次折算得分；远程库走 `search_batch` 批量接口），合并去重后按**可信度**排序注入。
- 可信度：6 个信号加权（检索得分、标题命中、章节命中、查询召回、来源质量、跨查询一致，另对过期内容轻惩罚）折算成 1–5 星（≥0.85 五星、≥0.70 四星、≥0.55 三星、≥0.40 两星、其余一星）。

**3. 看「知识来源」折叠条**

- 在哪：AI 回答气泡下方（默认折叠），标题行「**📚 知识来源 · N 条 · 〈所绑库名〉**」；点击展开。
- 每条来源卡：`[cN]` 编号 + **五星信任度**（悬停显示「信任度: 0.xx」）+ 所属库名 + 类型（文档/结构化/向量/办公）+「**📎 文件名**」下载链接（悬停「下载附件: 文件名」，点击取回原文；下载失败会给中文原因，如「下载链接已失效,请重新发起搜索以获取新的链接」）。
- 点卡片行首箭头「**展开片段详情**」：显示命中片段文本（截前 280 字）、§章节路径、「命中查询: …」词标签。
- 悬停某张来源卡，回答正文里对应的 [cN] 引用会高亮，方便对照。
- 空态与异常：没命中时标题「**知识库已检索 · 0 条**」+「**已检索所选知识库，但没有命中可引用内容。**」；检索出错时标题「**知识库检索异常**」+「**⚠ 检索异常**」标记，展开见「检索失败：〈原因〉」。绑定的库被删除/收回权限时会提示重新在侧栏选择。

**4. 右键三动作：核对 / 总结 / 问答本段**

- 在哪：文档里**选中一段文字**后右键 →「**察元AI知识库**」菜单（表格单元格右键同款）；或功能区「察元AI助理」选项卡 →「**知识库**」菜单，同样三个按钮。
- 三个动作：「**知识库核对本段**」（逐句对照知识库判 ✓/✗/未覆盖，给整体一致率）、「**知识库总结本段**」（区分原文要点与知识库补充背景的简明摘要）、「**知识库问答本段**」（选中是问题就直接答，是陈述就追问相关知识）。
- 做什么：点任一动作——自动取当前选中文字套上对应提示词模板，打开 AI 助手窗格并**自动发送**（选区超 1500 字自动截断并注明「（已截断）」）。
- 没选中就点：弹提示「**请先选中需要 核对/总结/问答 的内容**」。
- 相关能力：助手里还有「**知识库对比**」类助手（kb-verify 域，20 个，按行业领域分类），执行时会先检索绑定知识库、把命中片段注入工作上下文，适合成批的对照查验任务。

### 验证

1. 绑定一个库后，问一个只在该库文档里有明确答案的问题：回答带 [c1] 等引用标记，气泡下方「知识来源 · N 条」展开可见对应文档片段。
2. 选中一段含具体事实的文字，右键「察元AI知识库」→「知识库核对本段」：助手窗格自动发出核对请求，回答逐句给出 ✓/✗/未覆盖与 [^cN] 依据。
3. 点来源卡的「📎 文件名」：开始下载该来源的原文文件（远程库经服务端下发的短期下载链接取回）。

## 常见问题

**Q1：绑定了知识库，为什么回答下面显示「知识库已检索 · 0 条」？**
检索正常但没命中：换个更贴近库内文档用语的问题再问；也确认库里文档已加载就绪（察元OS 侧教程《上传文档与加载索引》）。注意此时回答没有库内依据，别当引用看。

**Q2：回答里的 [cN] 和来源条怎么对应？星级代表内容一定正确吗？**
一一对应：[cN] 就是来源条第 N 张卡，悬停卡片时正文对应引用高亮。星级是检索可信度（命中质量+多查询一致度等 6 信号折算），**不是内容正确性保证**，核对内容请展开片段详情看原文。

**Q3：为什么提示「绑定的知识库已被删除或权限被收回」？**
绑定的库在服务端已不存在或权限被收回（发送前会按最新目录预检）。在侧栏「选择知识库」里重新勾选可用的库即可。

**Q4：右键里没有「察元AI知识库」菜单？**
先在文档里选中文字再右键（该菜单按选区上下文显示）；表格里请用单元格内右键。也可改用功能区「察元AI助理」→「知识库」菜单，三动作完全一致。

**Q5：检索出来的分数/星级每次不一样？**
会。星级由本次检索的多查询命中情况动态折算（含跨查询一致信号），同一问题改写后命中组合变化，星级随之浮动；以片段详情里的原文为准。

## 形态差异

- 本篇操作在 WPS 文字端描述；表格/演示端右键与「知识库」菜单的三动作同款（表格单元格右键菜单为同一处理链）。
- 本机库与远程库在「选择知识库」弹窗和来源条上交互一致，仅分组名与下载链路不同（远程库下载走服务端短期 token 链接）。
