## 一句话说明

内置助手是产品预先配好的「提示词 + 输入来源 + 输出格式 + 写回动作」组合：在 AI 助手窗格侧栏、右键菜单或功能区点一下「执行」，就把当前选中内容或整篇文档交给模型按预设流程处理，结果按配置写回文档或在任务窗里查看。文字（文档）端内置 4526 个领域助手（覆盖 228 个行业领域）外加系统助手、文本分析、工具助手三组；表格端内置 66 个配方助手、演示端内置 81 个配方助手。

## 适用场景

- 文档写完想做一次校对/摘要/翻译/改写，不想自己想提示词，点一个现成助手就出结果；
- 属于某个行业（政务、法律、医疗、教育、电商等），想要本行业的成套公文/文案/审查助手；
- 想把某个常用助手固定到功能区或右键菜单，随手一点就执行。

典型提问（chabot 语料视角）：

- 「内置的 4526 个领域助手在哪里，怎么一键运行？」
- 「右键菜单里的『察元AI文本分析』是干什么的，怎么用？」
- 「为什么表格里看不到文档端那 4526 个助手？」

## 前置条件

- 已在 WPS 中启用加载项（见 [W02](./W02-在WPS中启用加载项.md)），并完成模型配置（见 [W03](./W03-首次配置接上模型.md)）——助手执行要调用模型。
- 文字端入口在「察元AI助理」功能区选项卡与 AI 助手窗格侧栏；表格端、演示端只显示各自宿主的配方助手（66 / 81 个），详见「形态差异」。

## 操作步骤

### 1. 打开 AI 助手窗格，切到「助手」页签

1. 在 WPS 功能区点「察元AI助理」选项卡 →「AI助手」组 →「AI助手」按钮，打开 AI 助手窗格。
2. 窗格左侧边栏顶部有两个页签：「助手」「对话」，各带数量徽标。点「**助手**」，进入助手列表；页签工具栏上是一个「**添加助手**」加号按钮和一个「**搜索助手**」输入框。
3. 列表按分组显示，每个分组行有展开箭头 ▾、组名和数量。文字端默认展开「⭐ 收藏」「系统助手功能」「文本分析分组」「自定义智能助手」，其余 228 个行业领域组默认折叠。

### 2. 找到想要的助手

- **搜索**：在「搜索助手」输入框输入名称/描述/分组关键词，列表实时过滤。
- **展开领域组**：点组名展开。领域组采用「先出分组、点开再加载」机制——未展开时只显示组名与该领域助手数（如「政务 / 公文 24」），第一次展开时会短暂显示「加载中…」，随后该领域助手全部就位；再次浏览不重复加载。
- **收藏**：点条目上的星形按钮（悬停提示「收藏到顶部」），该助手进入「⭐ 收藏」分组置顶显示（原领域分组里仍保留）；再点一次（提示「取消收藏」）移出。
- 每个条目显示：图标、名称、右侧「**内置**」或「**自定义**」标记、一句功能描述（自定义助手还有创建时间）。条目右侧的操作按钮依次是：收藏星标、**执行助手**（▶ 播放键）、**使用说明**（? 问号，仅带说明书的助手显示）、**编辑助手**（铅笔）、**删除助手**（垃圾桶，仅自定义助手显示）。

### 3. 点「▶」执行

1. 点条目上的**执行助手**按钮（执行中按钮暂停键显示「执行中」，再点无效，防重复启动）。
2. 按助手类型走不同分支：
   - **全文档输入的助手**：处理既有正文且输入落全文时（输入范围为「始终处理全文」，或「优先选中，无选中时回退全文」且此刻没有选区），先弹确认框「“<助手名>”将处理全文内容（约 <N> 字），是否继续执行？」，点「继续」才执行；写回动作是「插入到光标处」「追加到文末」「插入到文档最前面」这类新增内容的助手不弹此确认；
   - **需要补参数的助手**：先在对话里出现参数收集气泡，补充后回车继续；
   - **工具助手**（如条形码批量生成）：不进对话，直接在窗格主区打开工具面板；
   - **普通文档处理助手**：立即启动任务。
3. 任务启动后会弹出独立的**任务进度窗**，显示「正在处理：第 X / Y 段」等进度；任务在后台执行，关掉进度窗不中断，状态与结果见 [W18](./W18-任务进度窗确认写回与撤销.md)。写回动作（替换/批注/插入等九种）的语义见 [W14](./W14-写回动作九种对照.md)。

### 4. 用功能区固定按钮执行（文字端）

「察元AI助理」选项卡「AI助手」组里的这些按钮本身就是内置助手的一键入口：「拼写与语法检查」「生成摘要」「文本分析」菜单（换种方式重写/扩写/缩写/检查段落序号格式/AI 痕迹检查/批注解释/超链接解释/纠正拼写和语法/提炼关键词）、「翻译」菜单（20 语种）、「文本转图像」「文本转视频」「知识库」菜单。点击后走与侧栏执行相同的任务链。

「AI助手」组里还有 4 个**智能助手槽位**按钮：你把某助手的「显示位置」勾选了「顶部主菜单」，它就会占一个槽位，按钮文字直接显示助手名；未配置的槽位自动隐藏。点槽位按钮即执行对应助手。

### 5. 用右键菜单执行

在正文选中一段文字后右键，菜单里有这些察元入口：

- 「**察元AI文本分析**」：文本分析类助手子菜单；
- 「**察元AI翻译**」：20 语种翻译子菜单；
- 「**察元AI知识库**」：「知识库核对本段」「知识库总结本段」「知识库问答本段」（需已绑定知识库，见 [W36](./W36-对话中使用知识库.md)）；
- 「**智能助手**」×4：与功能区槽位同源的右键槽位，显示已配置到右键菜单的助手名，点击即执行；
- 「**更多智能助手**」：其余配置到右键的助手；
- 「**添加到察元**」：把选中内容作为上下文送进 AI 助手对话（未选中内容会提示「请先选择要添加的内容」）。

表格单元格内右键有对应的一套（「添加到察元AI助手」等）。

### 验证

1. 侧栏「助手」页签页签名右侧的数字徽标 = 当前可用助手总数；文字端全量加载后应与 4526 + 系统/分析/工具/自定义数量一致（领域组未展开时以组行上的计数显示）。
2. 任意执行一个只读类助手（如「生成摘要」，文档动作默认「仅生成结果，不写回文档」），任务进度窗出现且最终状态为完成，结果可在窗内查看。
3. 把某助手「显示位置」勾选「右键菜单」并保存后，选中正文右键应能看到以该助手命名的菜单项。

## 常见问题

**Q1：领域分组点开后一直显示「加载中…」或数量对不上？**
领域包按需懒加载：展开组名那一刻才去加载该领域的助手包，一般片刻即完成；若刚展开就搜索，列表以已加载内容为准。收起再展开一次即可触发加载。

**Q2：点「执行助手」提示「文档智能体正在写文档，请等待完成或停止后再执行助手。」？**
文档智能体（MCP 开关开启时的智能体回合）正在写文档，写入期间禁止并发执行助手。等写入完成或停止该回合后再点执行（MCP 开关见 [W09](./W09-文档智能体开关.md)）。

**Q3：为什么执行前弹「将处理全文内容（约 N 字）」的确认？**
该助手的输入范围是全文档，长文档耗时与 token 消耗都更大，产品在执行前让你确认一次。点「继续」执行、点「取消」放弃；只想处理片段可先选中文字，或把该助手的「输入范围」改为按选中处理（见 [W12](./W12-创建自定义助手.md)）。

**Q4：表格/演示里怎么找不到那 4526 个领域助手？**
助手按宿主分流：文字端显示文档助手全集；表格端只显示 66 个表格配方、演示端只显示 81 个演示配方（侧栏与「察元AI助理」选项卡一键按钮同源）。这是设计行为，避免行业文档助手淹没表格/演示配方。

**Q5：功能区出现 4 个一模一样的「智能助手」按钮？**
槽位按钮未配置助手时本应隐藏；若看到重复占位，多半是显示配置刚改过未刷新。到「助手管理」（见 [W11](./W11-助手管理.md)）检查各助手的「显示位置」，保存一次触发功能区刷新即可。

## 形态差异

- **表格端（ET）**：侧栏只列表格配方 66 个（通用高频 8 + 行业包 58）；「察元AI助理」选项卡一键按钮为「公式助手」「数据洞察」「一键图表」「数据清洗」「报表结论」「一键美化」「文档安全」（保密检查/加密工作簿/解密工作簿），「更多表格助手」菜单含排序汇总、多表合并汇总、两表对比差异、表格翻译、敏感信息脱敏、智能分列、按列拆表、文档抽取成表、数据战报页。配方点按行为分两种：「点击后立即发送」或「点击后预填输入框，补充要求后发送」。
- **演示端（WPP）**：侧栏只列演示配方 81 个；一键按钮为「生成PPT」「整套摘要」「美化统一」「口播稿」「整套校对」「结构诊断」，「更多演示助手」菜单含结构件补齐、整套翻译、转讲义文档、页码页脚、数据战报页、课件生成、习题互动页。
