## 一句话说明

助手配置可以打包成 JSON 文件在同事间传阅导入，也可以右键一键「复制为新助手」做变体；接入智能空间（chayuan-server）后还能整批拉取团队发布的文档助手。另有 18 个增强助手（8 通用 + 8 领域 + 2 补充）已内置在产品里，可在控制台查看与管理其旧自动安装副本。

## 适用场景

- 把自己调好的助手发给同事，或拿到别人的 `.json` 助手文件想装进来；
- 想基于现有助手改一个变体，不动原件；
- 团队用 chayuan-server 智能空间统一管理文档助手，想在 WPS 里一键同步；
- 听说有 18 个新助手，想确认装没装、怎么重装或卸载。

典型提问（chabot 语料视角）：

- 「怎么把助手发给同事？导入 json 报『导入文件不是有效的助手配置』怎么办？」
- 「『从智能空间同步』要填什么地址和 token？」
- 「18 个自动安装的助手在哪里管理，卸载了会复活吗？」

## 前置条件

- 导出/导入/复制在设置窗口「助手设置」页操作（入口见 [W11](./W11-助手管理.md)）；
- 智能空间同步需要可访问的 chayuan-server 地址和账号 token（从 chayuan-client 登录后获取）；
- 18 个内置增强助手随产品自带，无需安装包。

## 操作步骤

### 1. 导出助手（分享给别人）

1. 打开设置窗口「**助手设置**」页，在左栏「助手设置项」里找到要分享的助手。
2. 在该助手条目上**右键** → 「**导出助手**」。
3. 浏览器下载一份 `<助手名>.json` 文件（内容含 `type: "chayuan-assistant"`、`version: 1`、导出时间和完整助手配置），消息条提示「已导出助手“<助手名>”」。
4. 把这个 json 文件发给同事即可——它就是助手的全部配置。

### 2. 导入助手

1. 在「助手设置」页左栏工具栏点「**导入助手**」，选择一个 `.json` 文件。
2. 产品读取并校验：标准导出文件（`type: "chayuan-assistant"`，也兼容旧 `niudang-assistant` 包装）取其中的 assistant 配置；格式不对会报「**导入文件不是有效的助手配置**」。
3. 校验通过即入库：重名自动追加序号，归入其声明的分组（分组不存在会自动创建），消息条提示「已导入助手“<助手名>”」，左栏自动选中它，可立即微调后点「保存」。
4. 另一条路：右键已有助手 → 「**复制为新助手**」，在本机快速做一个可改的副本（同样自动去重命名）。

### 3. 从智能空间同步（团队批量分发）

1. 「助手设置」页工具栏点「**从智能空间同步**」。
2. 首次使用会依次弹两次输入框：
   - 「请输入智能空间(chayuan-server)地址,例如:http://localhost:7861」（必填，服务器根地址）；
   - 「请输入访问 token(从 chayuan-client 登录后获取)」（必填，JWT 访问令牌）。
   两项会保存到本机设置，下次同步不再询问。
3. 同步过程消息条实时显示「同步中(N/M):<助手名>」。拉取范围是服务器上的「文档助手」类应用（按 `scope` 取 mine/shared/public/all，默认 all）。
4. 合并规则：与本机已有助手按 `custom_cy_<appId>` 标识匹配——已存在则**覆盖更新**，不存在则**追加**；本机自建的其他自定义助手不受影响。
5. 完成后提示「同步完成:新增 X 个,更新 Y 个,共 Z 个」。若地址或 token 不对，报「同步失败,请检查智能空间地址 / token 是否正确」。

### 4. 管理 18 个内置增强助手

1. 8 个通用增强（语气调整、通俗化、列表→段落、段落→列表、纪要、引文核查、表格→MD、时间线）+ 8 个领域助手（法务审核、学术摘要、出题、公文规范、医学术语、数字核对、术语对照、抽代码）+ 2 个补充（表格统计、笔记整理），共 18 个，**现已直接注册为产品内置助手**，在面板侧栏即可使用。
2. 旧版本曾把它们作为「自动安装」副本写进自定义助手列表；当前版本启动时会自动把这些旧副本迁移清理。管理入口在**控制台**（`/control`）：「**自动安装助手**」页签显示「已自动安装」「总可安装数」两个统计与已安装清单，提供「**立即安装(force=true)**」「**全部卸载**」「**清理卸载标记(允许重新安装)**」三个按钮；页面提示原文：「18 个新助手(P3 extra 8 + P5 领域 8 + P5+ 补 2)在首次启动时自动注入到 customAssistants。可在此重新安装或全部卸载;卸载后不会"复活"(用 _uninstallMarker 标记)。」（控制台其余页签见 [W43](./W43-控制台软配置.md)）。

### 验证

1. 导出的 json 用文本编辑器打开，应看到 `"type": "chayuan-assistant"` 与助手名称、提示词等字段。
2. 导入（或同步）后回到面板侧栏「助手」页签：新助手出现在对应分组，带「自定义」标记；点「▶」可正常执行。
3. 控制台「自动安装助手」页签：全部卸载后「已自动安装」计数归零；点「立即安装(force=true)」后恢复。

## 常见问题

**Q1：导入报「导入文件不是有效的助手配置」？**
文件内容不是产品认的助手 JSON——可能是导出时被改动、截断，或拿错了别的配置文件。用文本编辑器确认文件里有 `"type": "chayuan-assistant"`（或旧版 `niudang-assistant` 包装）和 assistant 字段后重试。

**Q2：导入后名字多了个数字后缀？**
本机已有同名助手时自动去重（原名后追加序号），避免覆盖；可在导入后直接改名。

**Q3：「从智能空间同步」一直失败？**
按顺序检查：地址是否能访问（浏览器打开 `http://<服务器>:7861`）、token 是否过期（到 chayuan-client 重新登录复制）、账号对该批文档助手是否有权限（scope 覆盖 mine/shared/public）。修正后重新点「从智能空间同步」。

**Q4：全部卸载后这 18 个助手还会自动装回来吗？**
不会。卸载时写入了卸载标记，启动迁移不会恢复它们；想再要回来，到控制台点「清理卸载标记(允许重新安装)」再「立即安装(force=true)」，或直接用面板侧栏的内置助手（这 18 个能力本身已内置注册）。

**Q5：导出的助手文件里会不会带我的密钥？**
导出内容是助手配置（名称/提示词/参数等），不包含模型厂商的 API Key；收到的同事使用时走他自己配置的模型。

## 形态差异

- 「导入助手」「新建分组」「从智能空间同步」工具栏按钮与右键菜单（复制为新助手/导出助手/上移/下移/删除）为**文字端**助手设置页形态；表格/演示宿主的助手设置工具栏只有「**新建助手**」，不提供 JSON 导入导出与智能空间同步。
- 控制台「自动安装助手」页签在 `/control` 独立页面内操作。
