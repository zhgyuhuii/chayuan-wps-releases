## 一句话说明

「助手管理」是设置窗口里的「助手设置」页：在这里统一启停内置助手、编辑助手参数、按分组整理排序、复制/删除/导出自定义助手；改完保存会同步刷新顶部菜单与右键菜单的助手入口。

## 适用场景

- 某个内置助手用不上（或执行按钮碍事），想停用；后来又想恢复；
- 想调整助手在分组里的顺序、把常用助手挪到前面；
- 想批量看一眼都装了哪些助手、各归哪个分组；
- 想给同事发一个助手配置，或把别人给的助手装进来（导出/导入见 [W13](./W13-助手导入导出与分享.md)）。

典型提问（chabot 语料视角）：

- 「助手管理入口在哪里，怎么把不用的助手关掉？」
- 「停用的助手怎么恢复？」
- 「顶部菜单同步失败是什么意思，要紧吗？」

## 前置条件

- 已启用加载项并打开过 WPS 文档；「助手管理」按钮在文字端「察元AI助理」选项卡的「AI助手」分组里。
- 表格/演示端没有这个大按钮，从各自「设置」进入设置窗口后选「助手设置」页签即可，内容按宿主分流（表格端只列表格配方助手，演示端同理）。

## 操作步骤

### 1. 打开助手管理

- **入口一（功能区）**：「察元AI助理」选项卡 →「AI助手」组 →「**助手管理**」按钮。弹出独立设置窗口（窗口标题「助手管理」，约 1000×680），左导航自动定位到「**助手设置**」页签。
- **入口二（面板）**：AI 助手窗格侧栏底部齿轮「**设置**」按钮 → 左导航点「**助手设置**」（左导航依次为：模型设置/默认设置/助手设置/常规设置，常规设置下还有数据设置、知识库设置、MCP 服务管理三个子页）。

### 2. 认识「助手设置」页布局

- **左栏「助手设置项」**：按分组折叠列出全部助手，组名右侧有数量；工具栏按钮（文字端）从左到右是「**导入助手**」「**新建分组**」「**从智能空间同步**」。分组标题行有一行提示：「可拖拽排序，右键菜单可复制、删除、上移、下移」。空分组里显示「将自定义助手拖到这里，或点击新建分组后在右侧创建助手」。
- **右栏「助手设置」**：点左栏任一助手后显示它的完整配置（头部为图标+名称+功能说明，正文为各参数字段，字段含义见 [W12](./W12-创建自定义助手.md)）。

### 3. 启用 / 停用助手

1. 在左栏点选一个**系统助手**（如「拼写与语法检查设置」）；右栏头部右侧有一个**开关**。
2. 关掉开关并保存：该助手从功能区顶部菜单与右键菜单的入口消失（文档端侧栏「助手」页签清单仍会列出它，方便以后重新启用）；再打开开关即恢复。表格/演示宿主的配方助手停用后还会从面板侧栏隐藏——「停用后该助手将从面板隐藏」（设置页原文提示）。
3. 自定义助手没有启用开关，不想要就右键「删除」。

### 4. 编辑、排序与整理

- **编辑参数**：左栏点选助手 → 右栏改字段 → 点窗口底部「**保存**」。内置助手可改后用「**恢复默认模板**」一键还原。
- **组内排序**：直接**拖拽**助手条目到目标位置，也可右键用「**上移**」「**下移**」微调。
- **复制为新助手**：右键 →「**复制为新助手**」，生成一个副本进入编辑，重名会自动追加序号。
- **删除**：右键 →「**删除**」（仅自定义助手可删；内置助手不可删）。
- **新建分组**：点「**新建分组**」输入组名；在助手配置里把「所属分组」填成新组名也可以创建分组。

### 5. 保存与顶部菜单同步

保存助手配置后，产品会同步刷新顶部菜单/右键菜单的助手入口。如果个别同步动作失败，会给出单独提示（如「智能助手已删除，但顶部菜单同步失败，请稍后点击保存重试」「助手已导入，但同步到顶部菜单失败，请稍后点击保存重试」）——配置本身已保存，按提示再点一次「保存」即可补齐刷新。

### 验证

1. 停用某助手并保存后，选中正文右键、打开功能区菜单核对该助手入口已消失（文档端侧栏「助手」页签仍列其条目属正常）；重新开启并保存后入口恢复。
2. 拖拽排序保存后，面板侧栏里分组内顺序与设置页一致。
3. 删除/新建自定义助手后，功能区「更多」菜单与右键菜单的助手项随之增减（以该助手「显示位置」勾选为准）。

## 常见问题

**Q1：停用的助手去哪了？会不会丢配置？**
停用只是隐藏入口，配置原样保留；回到助手管理把开关打开再保存即可恢复。

**Q2：提示「顶部菜单同步失败，请稍后点击保存重试」怎么办？**
这是功能区（另一个 webview）刷新动作偶发失败，助手数据已经存上。回到设置窗口再点一次「保存」，让菜单刷新补做一遍；仍不生效就关掉 WPS 文档重开。

**Q3：设置窗口里的「助手市场」页能一键安装助手吗？**
不能。「助手市场」（/marketplace，独立页面）目前是**纯展示页**：按「内置/扩展/领域/第三方」四类来源汇总助手清单，支持按名称/标签/描述搜索、按分组与来源过滤，卡片上只有信息没有安装按钮。要新增助手请走「导入助手」（JSON 文件）或「从智能空间同步」（见 [W13](./W13-助手导入导出与分享.md)）。

**Q4：为什么我的助手管理里字段比别人的少？**
设置页按宿主分流：表格/演示端只管理各自的配方助手，可编辑字段也少（名称、说明、配方提示词、触发方式）；4526 个文档领域助手与完整字段要在文字（文档）端打开。

## 形态差异

- **表格端（ET）/演示端（WPP）**：助手设置左栏只列本宿主配方助手，工具栏按钮变为「**新建助手**」；右栏字段为显示名称/功能说明/配方提示词/触发方式，头部有「使用说明」按钮与启停开关。
- 本篇所述「导入助手/新建分组/从智能空间同步/拖拽排序」等完整工具栏为**文字端**形态。
