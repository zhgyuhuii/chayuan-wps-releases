## 一句话说明

「保密检查」用 AI 对当前文档做一次只读的涉密与敏感信息审查：按密级标识、涉军涉装、单位身份、人员联络、内部编号、商业敏感等类别逐项排查，按高/中风险与待人工复核分级，命中片段以批注锚定到原文，完整报告进任务清单并汇总成风险概览。它只给意见，不改你的正文。

## 适用场景

- 文档外发、上报、公开前的自查：想知道里面有没有密级标识、部队/单位敏感表述、内部编号、联系人信息等；
- 收到一份「要脱密处理」的文档，先摸清楚有哪些风险点，再决定用「文档脱密」遮盖哪些词（见 [W21](./W21-文档脱密.md)）；
- 表格/演示稿外发前快速过一遍敏感数据。

典型提问（chabot 语料视角）：

- 「保密检查能查出来什么？」
- 「文档外发前怎么自查敏感信息？」
- 「保密检查发现问题后会改我的文档吗？」

## 前置条件

- 已在 WPS 中启用加载项，三端 Ribbon 出现「察元AI助理」（见 W02）；
- 已配置可用的对话模型（见 W03）：保密检查走模型语义研判，未配置模型无法执行；
- 保密检查属付费专属能力（涉密类：脱密/复原/保密检查/涉密关键词提取均为付费专属，无免费额度），未购买时点击会弹「购买授权」窗（见 [W42](./W42-购买授权与能力门禁.md)）。

## 操作步骤

### 文字端（WPS 文字）

1. 打开要检查的文档，在 Ribbon「察元AI助理」选项卡找到「安全保密」组，点「保密检查」（按钮标题取该助手的显示标题，默认即「保密检查」）。
2. 系统弹出标题为「保密检查」的任务进度窗，助手以全文为输入，按分块交给模型逐块研判，再汇总执行计划把结果锚定回原文。检查聚焦八大类风险：
   - **密级与保密标识**：绝密、机密、秘密、内部资料、不得外传、商密等；
   - **涉军涉装涉训信息**：部队、战区、装备、型号、演训、战备、部署等；
   - **组织身份与单位名称**：机关名称、部队番号、院所名称、公司全称、供应商、客户名称等；
   - **人员与联络信息**：联系人姓名、职务、手机号、邮箱、证件号、内部通讯录等；
   - **时间、地点、部署和流转安排**：时间节点、路线、会议安排、库房位置、交付计划等；
   - **内部编号与项目标识**：项目代号、型号代号、合同编号、文号、图号、批次号等；
   - **经营与商业敏感信息**：报价、成本、投标方案、采购清单、客户名单、未发布经营数据等；
   - **军工/政企文档高频敏感线索**：机场、阵地、雷达站、研究所、专项任务、技术指标等。
3. 等待完成。结果分两级落地：
   - **批注**：每条命中的「命中片段」按结构化锚点策略定位到原文，以链接批注形式写在该片段处；锚点要求命中片段与正文逐字一致，定位失败时跳过该条、不做整篇兜底批注，并提示「未能将批注锚定到原文……已跳过全文单条批注。请查看任务清单对照修改后重试。」；
   - **任务清单**：完整审查报告存入任务记录，小节固定为「总体结论 / 高风险项 / 中风险项 / 低风险或待人工复核 / 建议处理 / 可疑关键词汇总」，每条命中项含命中片段、命中关键词、风险类别、判断依据、建议处理。进度窗内的查看、换模型重跑、撤销等操作见 [W18](./W18-任务进度窗确认写回与撤销.md)。
4. 打开任务清单：「察元AI编审」选项卡 →「察元设置」组 →「任务清单」。存在保密检查任务时，清单顶部出现风险概览区，五张卡：「高危任务」「中危任务」「关键词命中任务」「未见明显风险」「最近保密检查」，可用「统计全部任务 / 仅统计当前筛选结果」切换统计口径；点任一张卡即按该风险筛选任务列表（详见 [W40](./W40-任务清单.md)）。高危/中危计数取自报告「高风险项」「中风险项」小节的条数，「关键词命中任务」看「可疑关键词汇总」小节。
5. 筛查定位：任务列表上方还有「全部定位质量 / 仅精确命中 / 包含整句回退 / 包含定位失败 / 高风险任务」下拉，可按批注锚定质量过滤任务，快速找出需要人工对照的报告。
6. 逐条核对批注与报告，按「建议处理」修改文档（删除或模糊密级标识、单位全称泛化为「有关单位」、隐去具体时间地点联系人编号等）。保密检查本身不改正文，改不改、怎么改由你决定。

说明：检查结果的锚点批注与「AI 痕迹检查」共用同一套「命中片段」抽取规则（见 [W16](./W16-文本分析与摘要.md)）。默认写回动作为链接批注，要换成普通批注或不写回可在 设置 → 助手设置 中修改该助手配置。

### 表格端 / 演示端

1. 在表格（ET）或演示（WPP）的「察元AI助理」选项卡，点「文档安全」▾菜单 →「保密检查」。
2. 系统打开 AI 助手窗格并自动发送预填的检查指令，要求「只读不改」：
   - 表格端：扫描已用区域，识别手机号/身份证号/银行卡号/邮箱/工资薪酬列等敏感数据，输出「位置+类型+样例脱敏展示（如 138****1234）」的问题清单，不修改任何单元格；
   - 演示端：逐页检查敏感词/密级表述/内部代号/客户名与金额等，输出「页码+内容摘要+风险级别」的问题清单，不修改任何文字。
3. 在对话窗格查看智能体返回的问题清单，按条目人工处理。

### 验证

- 文字端：检查完成后，原文命中片段旁应出现批注；打开「察元AI编审」→「察元设置」→「任务清单」，能看到该保密检查任务，顶部风险概览区的高危/中危/关键词计数与报告小节条数一致。
- 全文无风险时，报告「总体结论」应写明「未发现明显保密风险」，任务在概览中计入「未见明显风险」。
- 表格/演示端：AI 助手窗格中出现自动发送的保密检查指令及智能体输出的问题清单。

## 常见问题

**Q1：点「保密检查」弹出「购买授权」窗口？**
保密检查是付费专属能力，未购买时点击直接拦截并弹「购买授权」窗。按窗口指引购买或输入序列号后重试（见 W42）。

**Q2：检查完了文档里没有批注？**
批注只锚定「命中片段」且要求与正文逐字一致；模型输出的片段若与原文对不上，该条会被跳过（不做整篇兜底批注），界面会有相应提示。打开任务清单看完整报告，对照「命中片段」手工定位即可；也可用「包含定位失败」筛选快速找到这类任务。

**Q3：高危/中危的数字是怎么统计的？**
任务清单从报告正文的「高风险项」「中风险项」小节解析条数，「关键词命中任务」看「可疑关键词汇总」小节。概览计数与报告内容一一对应，报告为空或写「无」的小节不计入。

**Q4：会不会误报或者漏报？**
助手的研判原则是「关键词只是线索，是否涉密由语义+实体+上下文决定」：高/中风险按证据分级，拿不准的归入「待人工复核」而非静默放过，同时对公开、教材、泛指语境降噪避免机械误报。它是辅助筛查，最终结论请以人工保密审查为准。

**Q5：和「文档脱密」是什么关系？**
保密检查是「查」——只读分析、批注标注；文档脱密是「盖」——把确认要遮盖的关键词替换为占位符（见 W21）。常见流程是先保密检查摸清风险点，再用文档脱密统一遮盖。

**Q6：检查涉及把全文发给模型，涉密文档安全吗？**
检查会把文档内容送给你在「模型设置」里选定的模型服务。涉密程度高的文档，建议先在设置里切换到本机离线模型（如 Ollama/LM Studio，配置见 W03）再执行保密检查与脱密。
