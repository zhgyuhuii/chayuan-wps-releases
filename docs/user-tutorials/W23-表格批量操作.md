## 一句话说明

「表格批量操作」▾ 下拉菜单把 14 个表格整理动作做成一键批处理：导出/删除全部表格、行宽三式、按关键词删行删列（两步确认）、全部表格查找替换/追加文字、首列序号、统一列宽、首列首行套样式、批量添加/删除表格题注——一次操作吃掉整篇文档的全部表格。

## 适用场景

- 交接来的文档里几十张表格式各异，要统一行宽、列宽、首行首列样式；
- 要给全文所有表格补「表1、表2…」题注，或把已有题注整体清掉重新编号；
- 表格里混着旧数据行/列，要按关键词批量删除，或把某个词全文表格内批量替换/追加。

典型提问（chabot 语料视角）：

- 「怎么给文档里所有表格统一设置列宽？」
- 「删除文字所在行是怎么确认的，会误删吗？」
- 「能一次给所有表格加上『表1 表2』的题注吗？」

## 前置条件

- WPS **文字**端打开文档（「察元AI助理」选项卡仅文字端显示，表格/演示端没有本菜单）；
- 已启用加载项（见 W02）。本组功能为纯本地批处理，**不依赖模型配置**；
- 文档中无表格时，直接批处理类会弹「文档中没有表格」提示后结束。

## 操作步骤

入口：顶部「**察元AI助理**」选项卡 → 「**批量操作**」分组 → 「**表格批量操作**」▾，下拉共 14 项。以下按菜单顺序逐项说明。

**1. 「导出全部表格」**

- 做什么：点击后先弹文件另存为对话框（标题「**导出表格到Excel**」，默认文件名「文档名_表格导出.xlsx」，可选 .xlsx 或 .xls），选好保存位置。
- 看到什么：每张表导出为 Excel 里的一张工作表（名为「表格1」「表格2」…）。成功后弹「**成功导出N个表格到: <路径>**」；文档无表格先弹「**文档中没有表格**」。

**2. 「删除全部表格」**

- 做什么：点击即执行，**无确认弹窗**，从后往前逐表删除。
- 看到什么：完成后弹「**已删除 N 个表格**」。

**3. 「根据内容自动行宽」**

- 做什么：点击即对全部表格按内容自适应列宽。
- 看到什么：成功弹「**已完成：N 个表格已按内容自动调整列宽**」；个别表失败弹「**已处理 N 个表格，成功 X 个，失败 Y 个**」。

**4. 「根据窗口自动行宽」**

- 做什么：点击即对全部表格按页面窗口宽度平铺列宽。
- 看到什么：成功弹「**已完成：N 个表格已按窗口自动调整列宽**」，失败分支同第 3 项。

**5. 「根据第一表格刷新样式」**

- 做什么：点击即把**第 1 张表**的表格样式、样式选项（标题行/最后一行/首列/最后一列）与逐格格式（首行、首列、最后一行、最后一列、中间行按角色对应复制）刷到其余所有表格。
- 看到什么：成功弹「**已完成：N 个表格已与首表格样式完全一致（含首行、首列、最后一行、中间行等）**」（N 为除首表外的表数）；文档只有一张表时弹「**文档中仅有一个表格，无需刷新样式**」。

**6. 「删除文字所在行」／7. 「删除文字所在列」**（两步式对话框）

- 做什么：点击弹出「**删除文字所在行/列**」窗口（标题「删除文字所在行/列」，副标题「在文档全部表格中查找包含关键词的单元格，删除其所在行或列」）。菜单项已预选好「删除方式」（「删除行」/「删除列」单选，可改）；在「**关键词**」框输入要查找的文字，点「**确定**」。
- 看到什么：找到后进入确认页「**共找到 N 个相同的数据，是否删除每个文字所在的行/列？**」，提示「点击“确定删除”将执行删除并关闭窗口。」——点「**确定删除**」才真正删；点「取消」退回输入页。没输入关键词提示「**请输入关键词**」；没找到提示「**未找到包含“××”的文字**」。
- 执行后：显示绿色结果「**已删除 N 行**」（或「已删除 N 列」），点「**关闭**」退出。查找范围是全部表格的单元格文字（包含匹配）；同一行/列多个命中只删一次。

**8. 「追加替换文字」**

- 做什么：点击弹出「**追加或替换文字**」窗口（副标题「在文档全部表格中查找并替换或追加」）。填「**查找内容**」，选「**替换**」（默认）填「**替换内容**」，或选「**追加**」填「**追加内容**」，点「**确定**」。
- 看到什么：直接对全部表格所有单元格执行——替换把命中文字全部换成新文字；追加在每个命中文字后面接上追加内容。**成功后窗口自动关闭、无成功提示**，回正文核对即可；失败（如「文档中没有表格」）在窗口内红字提示，窗口不关。无确认步骤，建议先备份。

**9. 「首列添加序号」**

- 做什么：点击即给每张表**最左侧插入一列**（窄列，约 0.6 厘米/28 磅），逐行填入 1、2、3…并居中。
- 看到什么：成功弹「**已完成：N 个表格均已首列添加序号（1、2、3…）**」。**无确认、可重复叠加**——再点一次会再插一列序号列，已在第 9 条 FAQ 说明。

**10. 「手动列宽度」**

- 做什么：点击弹出「**手动列宽**」窗口，窗内标题「**统一表格列宽**」，副标题「列宽（磅，5～500）」；在「**列宽**」数值框填目标值（默认 60），点「**确定**」。
- 看到什么：所有表格的所有列统一设为该宽度，成功后窗口自动关闭；数值越界提示「**列宽须在 5～500 磅之间**」，未填提示「**请输入列宽数值**」。

**11. 「第一列指定样式」／12. 「第一行指定样式」**

- 做什么：点击弹出「**第一列指定样式**」（或「**第一行指定样式**」）窗口，副标题「选择一种样式，将应用于文档所有表格的第一列（类似开始菜单样式）」。窗口自动列出**文档中的段落样式**（卡片按样式字体预览），可用「**输入关键词筛选样式…**」框过滤（显示「共 N 个匹配」）；点卡片选中（显示「**已选中**」，默认选中第一个），点「**确定**」。
- 看到什么：进入完成页「**已应用到 N 个单元格，文档所有表格第一列已使用所选样式。**」（第一行模式文案为「第一行」），点「**关闭**」退出；关键词无匹配显示「**无匹配样式，请修改关键词**」。

**13. 「添加表格题注」**

- 做什么：点击弹出「**添加或修改题注**」窗口（副标题「在正文中表格的上一行或下一行插入题注，不进入表格内部，居中显示」）。逐项填写：
  - 「**标签**」：默认「表」，生成序号规则见下方提示「题注序号自动生成：表1、表2、表3…」；
  - 「**题注内容（可选）**」：接在序号后，无空格，如「表1说明」；
  - 位置单选「**上方**」（默认）/「**下方**」。
  点「**确定**」。
- 看到什么：按文档顺序给每张表生成「表1」「表2」…（表格上方/下方的空白段会被直接利用，否则插入新段，题注居中）；成功后窗口自动关闭、无弹窗提示。未填标签提示「**请输入标签（如：表）**」。

**14. 「删除表格题注」**

- 做什么：点击即执行，**无确认弹窗**。定位紧贴每张表上/下方（间隔 1～80 字符）且长得像表题注/标签的段落（「表1」「Table 1」「附表」等模式）删除；按位置没找到时再全文档按模式扫一遍。
- 看到什么：成功弹「**已删除 N 个表格题注（含标签）**」；没有可删的弹「**文档中没有找到表格题注**」。

### 验证

1. 「表格批量操作」▾ 展开，菜单项共 14 个，名称与本篇各步引号内文案一致。
2. 建一个含 2 张表的测试文档 → 点「首列添加序号」→ 弹「已完成：2 个表格均已首列添加序号（1、2、3…）」，两张表最左列出现居中序号。
3. 同一文档点「添加表格题注」（默认标签「表」、位置「上方」）→ 两张表上方分别出现居中的「表1」「表2」。
4. 点「删除表格题注」→ 弹「已删除 2 个表格题注（含标签）」，题注段落消失。
5. 点「根据第一表格刷新样式」前先把第 2 张表手工改乱，执行后第 2 张表边框底纹字体与第 1 张一致。

## 常见问题

**Q1：「删除全部表格」「首列添加序号」点了直接就执行，没有确认，做错了怎么挽回？**
这两类直接批处理均无确认弹窗、加载项本身也不提供撤销入口。手快了先试 WPS 自带的撤销（Ctrl+Z）；批量整理前建议先另存一份副本。

**Q2：「首列添加序号」点了两三次，表格前面多了好几列序号？**
该功能每次执行都会在首列前再插一列序号列，代码没有「已有序号列就跳过」的判断。多余的序号列可点「删除文字所在列」按关键词处理，或手工删列；以后执行一次即可。

**Q3：「追加替换文字」点确定后窗口直接关了，到底替换成功没有？**
成功即关窗、无成功提示是设计行为。回正文翻表格核对；若窗口没关并显示红字（如「文档中没有表格」），才是没执行。

**Q4：「删除文字所在行」会不会把别处同名的行一起删掉？**
查找范围就是全部表格的单元格，包含匹配即命中，命中行都在删除清单里——确认页会显示「共找到 N 个相同的数据」，把 N 与预期对一下再点「确定删除」；关键词尽量带上前缀后缀以缩小命中。

**Q5：「导出全部表格」在 Mac 上没弹出保存对话框？**
Windows 正常弹文件对话框；Mac 环境对话框可能不可用，代码会回退为把生成的 Excel 触发浏览器下载（弹「Excel文件已生成并触发下载！」并列出文件名）。按下载提示取文件即可。
