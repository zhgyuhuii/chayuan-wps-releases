## 一句话说明

v6.1 主线能力：在对话里丢给 AI 一个模板文件（PPT/Word/Excel）加一句话要求，它自动按扩展名路由到对应宿主，走「剖析模板 → 出计划 → 你点确认 → 槽位填充 → 多轮质检」五段式链，后台生成一份**保留模板母版、背景、字体的同框架新文档**并自动打开——不用手动逐页改。

## 适用场景

- 有一套公司标准 PPT 模板，要按本周材料快速产出一份正式汇报；
- 有 Word 公文红头/合同框架，要把新内容按原章节骨架灌进去；
- 有 Excel 台账/报表样式，要按新数据生成同款表格；
- 素材是另开的文档（或新窗口没带附件），想让 AI 记住上一次的模板与素材继续做。

典型提问（chabot 语料视角）：

- 「怎么按模板批量生成 PPT？」
- 「模板生成的计划确认卡是什么，怎么用？」
- 「生成会把我原来的模板改掉吗？」

## 前置条件

- 已配置可用的**对话模型**（W03）——剖析出的计划与多维审查都由它完成；无模型时管线在开副本之前即报错退出；
- 手头有模板文件（`.pptx/.ppsx/.dps`、`.docx/.doc/.aidocx`、`.xlsx/.xlsm/.et/.csv`，扩展名决定生成类型）与内容素材（素材可直接写在要求里，也可作为附件/知识库材料）；
- 该能力在对话窗格内完成，任务执行期间窗格内实时显示进度（模板生成不弹独立的任务进度窗）。

## 操作步骤

**1. 发起：模板文件 + 一句话要求**

- 在哪：打开 AI 助手对话窗格（W05），把模板文件拖入/添加为附件，输入要求，如「按这个模板生成年终总结 PPT，要点如下：……」。
- 看到什么：命中「Office 模板类附件 + 生成意图」即直接进模板生成管线，助手消息显示「**已识别模板生成请求，直接开始处理…**」（不弹参数表单，参数由你的话自动推断；确认职责由后段计划卡承担）。没有附件但提到「模板/上次/刚才」且 30 分钟内生成过，会显示「**已按上次的模板与素材开始处理…**」直接复用（见第 5 步）。

**2. 剖析与计划（两段式确认第一段）**

- 后台先做**文件级剖析**：逐页/逐段识别形状角色（标题/副标题/正文/装饰——LOGO、页码、章节号、隐形水印都判为装饰，永不改写）、字号、坐标；随后把剖析结果与你的要求交给对话模型产出**改写计划**。
- 看到什么：对话里出现计划卡，标题「**【改写计划】需求：**〈你的要求〉」，下面逐条列动作——PPT 逐页（「第 N 页 edit：〈标题〉」）、Excel 逐数据块/单元格、Word 逐段落（含「新增 N 段」），结尾一行「**确认无误请回复「确认执行」，将开始写入新文档。**」
- 计划同时携带**契约勾选卡**（按模板类型不同）：Word——「沿用模板章节骨架／沿用字体字号／沿用行距与缩进／文风跟随模板／保留固定文案／模板正文作范文参照」（末项默认不勾）；Excel——「沿用表头文字与结构／沿用列宽行高／沿用合并单元格／沿用数字格式」；PPT——「沿用配色方案／沿用字体方案／沿用背景图元／装饰元素保持不动／按页型复用版式／文案风格跟随模板／保留型文案不动」。改影响大纲/结构的勾选项会触发重新规划。
- 计划会话级缓存 **30 分钟**：30 分钟内都能确认；重载窗格即失效（重发一次即可）。

**3. 确认执行（两段式第二段）**

- 做什么：计划没问题就点卡片上「**确认执行**」按钮（或回复「确认执行」）；不想做了点卡片「**取消**」清掉待执行计划。执行中按钮显示「**执行中...**」。
- 看到什么：管线先复制一份模板副本（**原模板文件从头到尾不被修改**），再逐形状/逐段填充；窗格内实时滚动进度事件。

**4. 质检循环与交付**

- 每一轮质检 = **机器审计**（占位残留——Lorem ipsum/「输入标题」/「点击输入」等、文本溢出按形状容量、字体一致性）+ **自愈**（能机器修的当场修：残留再清扫、溢出按容量句读截断重写）+ **AI 多维审查**（需求符合性、文案质量、契约勾选项逐条核查）。默认 **3 轮**，可调，上限 **4 轮**；全部干净提前通过，有问题修到轮次上限为止。
- 交付：PPT 走文件级 ZIP 文本替换——只改文字内容，模板的母版/背景/字体字节级保留；Word/Excel 原地另存交付并清除「新建未保存」标记。当前开着未命名的空白文稿时直接替换交付（PPT 提示「**原空白文稿已关闭，生成结果已带完整模板设计打开。**」），否则自动在 WPS 打开产物。
- 看到什么：结果消息逐项汇报——「**已后台生成：**〈文件路径〉」「**执行：**改写 N 处（含内容底稿 M 处）／复制 X 页／新增 Y 页；共 Z 页」「**核对：**N 轮（内容 ✓／✗ 换行溢出 ✓／✗ 字体 ✓／✗ 占位残留 ✓／✗），勾选契约项已逐条核查，机器自愈 N 处——**全部通过／达轮次上限**」，未决问题最多列 3 条；自动打开失败时提示「**自动打开失败——请手动打开：**〈路径〉」。

**5. 跨文档对话跟随与记忆**

- **15 分钟会话交接**：生成完成后原窗格把会话快照写入全局交接键；你在新文档窗格里打开 AI 助手，会自动把刚才的生成会话过继为当前会话，接着说「把第 3 页改成……」即可继续。
- **30 分钟输入记忆**：模板路径与素材被记住 30 分钟，新窗口不带附件说「用上次的模板再做一版」也能复用。
- **30 天勾选偏好**：按模板内容 hash 记住你上次的契约勾选（偏好键 `chayuan_tpl_aspect_prefs`），同一模板下次生成自动预填。
- 同一能力也开放给外部智能体：MCP 工具 `template_generate`（模板路径 + 要求 + 素材，目标宿主离线会自动拉起 WPS 并等待就绪），见 W39。

### 验证

1. 对话发送一个 `.pptx` 模板并说「生成 5 页产品介绍」→ 应出现【改写计划】卡且逐页列出动作；点「确认执行」后进度推进，结束时消息含「已后台生成：」路径与「核对：N 轮（…✓）」；
2. 打开产物核对：版式/母版/背景与模板一致，正文已按你的素材改写，无「输入标题」「Lorem ipsum」残留；
3. 检查原模板文件修改时间未变（模板只读，产物是新文件）。

## 常见问题

**Q1：计划卡点「确认执行」没反应或提示过期？**
计划缓存只有 30 分钟，且重载窗格会清空。重新发一次请求生成新计划再确认即可；确认前改了契约勾选项（章节骨架、按页型复用版式等影响大纲的项）也会自动重新规划。

**Q2：会把我原来的模板文件改掉吗？**
不会。管线第一步就复制副本，一切写入都发生在副本/产物上；结果消息里的「已后台生成：路径」就是新文件，原模板仅作剖析与底版。

**Q3：结束时写「达轮次上限」还有未决问题？**
说明修满轮次（默认 3、上限 4）仍有未决项，消息会列出前 3 条。处理办法：把未决点补进要求重新生成；或在 MCP/能力参数里提高 qcRounds（最大 4）；「未命中模板原文 N 处（已跳过）」多因模板文字含特殊格式，可手动补改。

**Q4：生成完了原文档窗口没了？**
PPT 交付时会关闭你当前未命名的空白演示、自动打开成品（消息里写明「原空白文稿已关闭…」）；已命名的文档不会被关闭。成品路径在结果消息里，也可从资源管理器直接打开。

**Q5：想控制页数/篇幅？**
把页数写进要求（如「生成 5 页」）或 MCP 参数 pageTarget——计划按目标页数编排（新增页克隆模板内容页为底版）；Word 章节数同理写在要求里，勾选「沿用模板章节骨架」时按模板标题树映射成章。

**Q6：报「未配置该模型的 API 地址」或直接失败？**
模板生成依赖对话模型：到 设置 → 模型设置 确认默认对话模型可用（W03）。模型调用失败发生在复制副本之前，不会留下半开的临时文件，修好模型重发即可。
