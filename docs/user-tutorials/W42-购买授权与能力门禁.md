## 一句话说明

免费使用有每日额度；涉密类能力（文档脱密/脱密复原/保密检查/涉密关键词提取）为付费专属。额度用尽或触碰付费能力时自动弹出「购买授权」窗——扫码购买、分享得次数、输入序列号本地激活（验签离线完成，不联网）。

## 适用场景

- 执行助手或对话时弹出「购买授权」窗，想知道为什么弹、免费额度还剩多少；
- 已购买序列号，想激活或换机后疑惑为什么激活失败；
- 使用「文档脱密」「保密检查」时被拦，想了解哪些能力需要购买。

典型提问（chabot 语料视角）：

- 「弹出来的『购买授权』窗口是什么，必须买吗？」
- 「序列号怎么激活？激活时联网吗？」
- 「哪些功能是付费的？」

## 前置条件

- 加载项已启用。门禁与激活全部在本机完成：激活验签本地进行、不联网；购买下单需扫码到浏览器完成。

## 操作步骤

1. **理解门禁规则**（代码唯一检查入口 `capabilityGate.ensureCapability` 的行为）：
   - **未购买且有免费额度** → 计数放行，不弹窗；免费额度按天计数、次日重置（对话与助手各走独立额度池）；
   - **未购买且额度用尽** → 自动弹出「购买授权」窗，本次操作中止；
   - **已购「次数授权」且有剩余** → 每次执行扣 1 次，扣到 0 后回落免费门控；
   - **已购「时间授权」且在有效期内** → 直接放行，不弹、不计数、不限次；
   - **付费专属能力**（文档脱密、脱密复原、保密检查、涉密关键词提取）→ 未购买直接弹「购买授权」窗，零免费额度。检查点：AI 助手对话发送（`chat`）、助手任务执行（`startAssistantTask`）、功能区「文档脱密」「脱密复原」按钮、对话内脱密/复原入口。
2. **认识「购买授权」窗**：触发门禁后弹出的独立窗口（路由 `#/purchase-guide-dialog`，窗口尺寸 460×660，标题「购买授权」）。从上到下：
   - **说明区**：按触发原因显示标题与说明——额度用尽时是「还可用 X 次/已用完」类文案；付费专属时如「文档脱密需购买后使用」「涉密检查需购买后使用」等；
   - **二维码页签**：「支持我们」（购买二维码，下方有「在电脑浏览器中打开」链接与购买网址）/「分享获取次数」（分享二维码——好友扫码安装并首次使用后，你和好友各得该功能使用次数）；
   - **本机指纹条**：显示 16 位设备指纹和「复制」按钮（点后变「已复制」）——购买时需要提供它来签发与本机绑定的序列号；
   - **公众号折叠条**：「关注「智灵鸟科技」公众号查询序列号」，展开后显示公众号二维码，说明「购买后如未记录序列号，可凭本机指纹查询」；
   - **激活区**：「已购买？输入序列号激活：」输入框（占位 `XXXXX-XXXXX-XXXXX-XXXXX-X`）+「激活」按钮（验证中显示「验证中...」）；
   - **协议小字**：「购买即视为同意《察元 AI 购买与使用协议》」，点开可读全文（不退款、设备绑定、序列号保管等条款）。
3. **激活序列号**：在输入框粘贴序列号（带或不带横杠均可），点「激活」。激活在本机完成，不联网：
   - 通过 → 绿色提示「激活成功！授权已生效，窗口将自动关闭。」，窗口自动关闭；
   - 失败 → 显示具体原因（中文），见下「常见问题」Q2。
   激活采用「叠加」而非覆盖：时间授权累加到期天数、次数授权累加次数；序列号一经激活会记录，不能在同机重复刷。
4. **主动打开购买/激活窗**：不想等门禁拦截时，在 AI 助手窗格欢迎区底部点「获取支持凭证」，即以「激活授权」场景打开同一窗口（标题「激活授权」）。
5. **查看剩余权益**：AI 助手窗格欢迎区底部有权益面板——已购买时显示「已购买」徽标，时间授权显示「有效期至 <日期>」；免费额度与剩余次数以「购买授权」窗的提示文案为准。授权取消/过期后（如次数扣尽且无时间授权），记录会标记为过期，重新回落到免费门控。

### 验证

1. 触发一次付费专属能力（如点「文档脱密」但未购买）：应弹出「购买授权」窗，且说明区为「文档脱密需购买后使用」。
2. 在激活框粘贴一个错误序列号点「激活」：应显示红色错误文案（如「序列号长度不正确…」）而不是静默失败。
3. 激活成功后重新打开欢迎区权益面板：应出现「已购买」徽标；时间授权还应显示「有效期至」日期。
4. 断网状态下走一遍激活流程：本地验签不依赖网络——能否激活只取决于序列号与本机指纹是否匹配（购买下单仍需网络）。

## 常见问题

**Q1：每天免费能用多少次？**
免费额度按天计数、次日自动重置：对话与执行助手分别走独立的每日额度池。页面提示文案中的次数（如「免费版每日可对话 30 次」「每日 2 次共用」）与引擎配置可能存在口径差异，以「购买授权」窗当次提示为准；额度即将用尽或用尽时会明确弹窗。

**Q2：激活报错怎么看是什么问题？**
错误文案与原因一一对应：「序列号不能为空」；「序列号长度不正确，请检查是否完整」；「序列号格式错误，请检查输入」；「序列号校验失败，请核对每一位」；「序列号密钥版本不匹配，请更新到最新版本」；「序列号与本机不匹配，请核对购买时填写的本机指纹是否正确」；「该序列号已激活过」；「该序列号不包含「察元 AI 文档助手」授权」。最常见的是换机/重装系统后设备指纹变化——按协议需重新购买。

**Q3：激活时会把我的序列号传到网上吗？**
不会。激活采用本地验签（HMAC 签名核验，密钥随安装包内置），全程不联网；联网只发生在你扫码购买时（浏览器里完成）。

**Q4：时间授权和次数授权有什么区别？**
时间授权按天数计，有效期内不限次；次数授权按次数计，每次执行助手/付费功能扣 1 次，且有自签发起的有效期。两者可叠加共存：时间有效时优先不限次，时间过期后扣次数。

**Q5：分享给好友真的能得次数？**
「购买授权」窗的「分享获取次数」页签会生成带你设备指纹（mid 参数）的分享二维码/链接（分享页路径为 /share）；好友扫码安装并首次使用后，双方各得该功能使用次数。

**Q6：为什么我的「购买授权」窗里没有购买二维码？**
「支持我们」购买区只在未购买状态下显示；已购买后打开此窗（例如从「获取支持凭证」进入）时不再重复展示购买二维码，直接用下方输入框激活或管理序列号即可。控制台（W43）的「License」页签也提供同样的激活入口。
