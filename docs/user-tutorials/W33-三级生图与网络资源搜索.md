## 一句话说明

智能体给文档/PPT 配图时按「三级图源」自动降级：Tier 1 用你在设置里启用的图像生成模型生图（最多逐个尝试 3 个）→ 不通则 Tier 2 按你配置的「网络资源搜索」清单搜图下载 → 再不通由 Tier 3 对话模型直接绘制 SVG 矢量图形兜底。每一级只做自己份内的事，失败如实上报，绝不静默换一个可能计费的来源。

## 适用场景

- 想让 AI 生成/生成PPT 时自动配图，但不清楚该配生图模型还是搜图服务；
- 内网/离线环境想用免 Key 的必应图片/Openverse 搜图，或单位自建了 SearXNG；
- 配了多个生图模型，想知道坏了会发生什么、会不会乱扣费。

典型提问（chabot 语料视角）：

- 「配图的三级降级是什么？必须都配吗？」
- 「搜图的 API Key 安全吗？会传到你们服务器吗？」
- 「没配图像生成模型时让它配图会怎样？」

## 前置条件

- 已启用加载项并配置对话模型（见 W02/W03）：三级链由对话模型在回合里编排；
- Tier 1 需要：设置 → 默认设置 →「图像生成模型」分类下有**已启用**的生图模型；
- Tier 2 需要：设置 → 默认设置 →「网络资源搜索」里启用并配置资源（不配也能用内置免 Key 兜底：必应图片、Openverse）；
- Tier 3 无任何配置要求（对话模型直接画 SVG），前两级全不可用时的保底；
- 网络搜图/测活由本机 MCP 服务（127.0.0.1:62588）执行，需本机服务在运行（见 W37）。

## 操作步骤

### 一、配置 Tier 1：图像生成模型

1. 在哪：设置 → 默认设置，左侧设置项列表选「**图像生成模型**」（与「对话模型」「视频生成模型」「语音转换模型」并列）。
2. 做什么：添加/启用支持生图的厂商模型（填 API Key、启用开关），可启用多个。
3. 看到什么：运行时链路逐个尝试已启用的生图模型，**最多尝试 3 个**；某个模型失败会换下一个，全部失败才降级。产物图片经本机服务落盘到 WPS 容器可读的本地路径，插入工具直接可用。
4. 一个模型都没启用时：链路报「**未配置图像生成模型（设置 → 默认设置 → 图像生成）**」并进入降级。
5. 手动生图入口（点按钮生成文件、不自动插正文）见 [W19](./W19-文生图与文生视频.md)；本篇的三级链用于对话配图/生成PPT（见 W32）等自动插图场景。

### 二、配置 Tier 2：网络资源搜索

1. 在哪：设置 → 默认设置，左侧设置项列表选「**网络资源搜索**」。页首说明原文：「三级生图的中坚：生图模型不可用时按此清单网络搜图，搜图不通再由大模型绘制 SVG。Key 只保存在本机，搜索经本机服务执行。」
2. 清单分三组共 10 个内置资源，卡片上有「搜图」「需 Key/免 Key」标签：
   - **网页搜索**：Serper（免费额度 2500 次/月）、Tavily、Linkup（仅网页结果，不参与搜图）、SearXNG（自建元搜索，「API Key」输入框位置填的是**实例地址**，无需 Key）；
   - **图片图库**：Pexels、Pixabay、Unsplash（免费档 50 次/小时）；
   - **免 Key 兜底**：必应图片（国内可达，三级生图默认兜底）、Openverse（CC 授权图库，海外网络）、DuckDuckGo（免 Key 网页搜索）。
3. 做什么（逐卡操作）：点开关「启用」→ 展开的凭据框里粘贴 API Key（可点眼睛图标显示/隐藏）→ 点「**申请 Key ↗**」可跳转官方申请页 → 点「**测试**」发一次最小真实请求验证连通。SearXNG 卡片的输入框标签是「实例地址」。
4. 看到什么：测试通过显示「✓ <延迟>ms」，失败显示「✗ <原因>」；页首状态条实时显示「已启用 N / 已配 Key N / 免 Key 恒可用 N」与同步状态。
5. 关键一步——「**⇄ 同步本机服务**」：启用清单变更后会自动同步到本机服务（落盘 `dataDir/web-resources.json`，供 `image_search` 搜图工具消费）；本机服务离线时状态条显示「⚠ 本机服务未同步」（设置仍保存在本地），服务恢复后点该按钮手动补同步。
6. 页首「**⚡ 全部测活**」：对已启用与全部免 Key 资源逐个测试，弹toast「测活完成：N/M 连通」。

### 三、链路怎么跑（无需操作，理解用）

1. 对话里提出配图需求（或用 W32 的生成PPT/配图组配方），模型调用生图工具。
2. **Tier 1 模型生图**：按「图像生成模型」启用的模型逐个试（≤3 个）；未走通时任务进度提示「**模型生图未走通，尝试本机生图服务**」，回落到本机服务的原生生图通道（配置文件 `dataDir/image-gen.json`，未配置时报「**未配置生图模型（dataDir/image-gen.json），请改用 svg_add 矢量图形兜底**」）。
3. **Tier 2 网络搜图**：生图两级都不通，模型改调搜图工具——你在「网络资源搜索」启用的资源**按清单顺序**先试（要求已配好凭据），全不行再落内置免 Key 兜底（必应图片 → Openverse，无需启用恒可用）；搜到候选后逐张尝试下载（校验图片内容防止死链），成功返回本地路径交给插入工具。
4. **Tier 3 SVG 兜底**：搜图也不通时，对话模型直接生成 SVG 矢量图形源码，用演示/文档工具的 `svg_add` 画到页面（纯本地生成，不依赖图片模型与图库网络）。
5. **铁律「绝不静默替位」**：每一级失败都返回明确的 ok:false 与原因，由调用方决定降级，不会静默换一个可能计费的来源；每级用了哪个来源会在结果里注明（source/origin）。

`dataDir` 位置：Windows 为 `%LOCALAPPDATA%\chayuan-wps\mcp`，macOS/Linux 为 `~/.config/chayuan-wps/mcp`；下载与生图产物在其下 `tmp-images/`（macOS 优先落 WPS 沙盒容器内对应目录，保证容器内可读）。

### 验证

1. 设置 → 默认设置 →「网络资源搜索」：任一免 Key 卡片点「测试」应显示「✓」与延迟毫秒数；状态条「免 Key 恒可用 3」。
2. 配好 Key 后点「⇄ 同步本机服务」，状态条变「✓ 已同步本机服务」；`dataDir/web-resources.json` 出现且 providers 数组含你启用的资源 id。
3. 不启用任何生图模型、不配任何 Key（免 Key 兜底源无需配置），在对话里对当前文档说「给这篇文档配一张×××示意图」：模型应降级走搜图并插图成功，结果来源标注为 bing/openverse。
4. 生图两级与搜图全部失败时（例如本机无法访问外网且无生图模型）：模型按策略改用 `svg_add` 画矢量图，而不是静默失败或换计费来源。

## 常见问题

**Q1：必须三级都配置吗？**
不是。三级是「能配则配、按序降级」：只配 Tier 1 也能生图（生图全挂才需要 Tier 2）；完全什么都不配时，免 Key 搜图兜底（必应/Openverse）和 Tier 3 SVG 仍然可用——只是效果上限低一些。

**Q2：API Key 会泄露吗？**
Key 只保存在本机（加载项本地设置），搜图请求由本机 MCP 服务直接发往各资源官方接口，不经第三方服务器转发；同步到本机服务的配置文件也只落在本机 dataDir。

**Q3：点「测试」失败，显示 Key 无效/网络不可达？**
按状态条原因处理：「Key 无效」多为 401/403——核对 Key 是否复制完整、账号是否有该 API 权限；「网络不可达」多为代理/防火墙——Openverse 等海外源需可达外网；「超时」可稍后重试。改完再点「测试」，通过后记得确认状态条为「✓ 已同步本机服务」。

**Q4：为什么我启用了搜图资源，配图时却没用到？**
常见两个原因：① 修改后没同步——本机服务离线时启用清单没落盘，点「⇄ 同步本机服务」补同步；② 凭据不齐——启用了需 Key 的资源但没填 Key，链路会跳过它继续下一个，最终落到免 Key 兜底。

**Q5：Serper 免费额度用完会怎样？**
该资源请求失败并记录原因，链路按清单顺序换下一个启用资源，或落到免 Key 兜底——不会卡死也不会静默产生费用（每来源只做自己份内的事，失败如实上报）。额度以 Serper 官方口径为准（清单标注免费额度 2500 次/月）。

**Q6：Tier 3 的 SVG 图效果一般，能只用模型生图吗？**
可以：把「图像生成模型」配好且网络可用时，链路第一级就成功，不会走到 SVG。SVG 兜底是为离线/无 Key 环境保证「永远有图可用」的保底，不是首选。

## 形态差异

- 搜图/测活的执行与配置落盘都依赖本机 MCP 服务（127.0.0.1:62588）：服务未启动时设置仍可保存，但「测试/同步」会提示服务离线；启动方式见 [W37](./W37-启动本机MCP服务.md)。
