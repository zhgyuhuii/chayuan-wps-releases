## 一句话说明

WPS 演示端的「察元AI助理」选项卡把高频演示配方做成 Ribbon 一键钮：点一下自动打开 AI 助手面板并预填配方提示词（一键型直接自动发送），智能体按配方用演示稿工具生成/加工整套 PPT；全部 81 个演示配方（通用高频 + 配图 + 行业包）在助手面板侧栏可查可搜。

## 适用场景

- 从零出一套 PPT：点「生成PPT」，先大纲确认再逐页生成；
- 对已有演示稿做加工：整套摘要、排版美化统一、写口播稿、整套校对、结构诊断、补结构件、整套翻译、转讲义；
- 行业固定套路：年终总结、述职、开题/答辩、课件与习题、党建微课、大促战报等。

典型提问（chabot 语料视角）：

- 「演示端 Ribbon 上的 AI 按钮分别做什么？」
- 「点『生成PPT』后是直接出片吗？要不要先确认大纲？」
- 「演示稿怎么整体校对/统一字体？」

## 前置条件

- 已在 WPS 演示中启用加载项，Ribbon 出现「察元AI助理」选项卡（见 W02）；
- 已配置可用对话模型（见 W03）；配图需求还可在 设置 → 默认设置 启用图像生成模型或配置网络搜图（见 [W33](./W33-三级生图与网络资源搜索.md)，不配也有 SVG 矢量兜底）；
- 「AI演示助手」面板按上次形态打开（浮窗或停靠），机制与表格端相同。

## 操作步骤

入口都在演示端 Ribbon「察元AI助理」选项卡 →「AI助手」组（大按钮一排 →「文档安全」▾ →「更多演示助手」▾ →「设置」）。

**1. 「AI演示助手」：单开对话面板**

- 点「AI演示助手」：打开 AI 助手对话面板（单实例，已开则聚焦不重复开窗，形态按上次记忆）。

**2. 「生成PPT」：从主题到整套片子**

- 点「生成PPT」：面板打开，输入框预填「请为我生成一套演示稿：先给出大纲（页码+每页标题+要点），等我确认后逐页生成。主题与要求：」，在末尾补充主题、受众、页数、风格后发送；
- 智能体先给大纲，你回复「确认」或提修改意见，然后逐页生成（版式/标题/正文/演讲备注），写回走预览确认闸门（见 W18）；
- 需要配图时在要求里注明：配图走三级图源（模型生图→网络搜图→SVG 矢量，见 W33）；在 PPT 宿主里生图会自动按当前页面宽高比选 16:9/9:16，无需手动指定比例；
- 单位有统一模板时，不用本按钮：改走对话模板编制——在对话里直接给模板文件+要求，按模板版式出片（见 W30「对话生成整套文档（模板编制）」）；
- 侧栏还有面板专属的「文档转 PPT」（读 Word 提炼大纲逐页生成）、「大纲调整」「数据页」「项目进度汇报」「校对修复执行」「汇报压缩」「答辩问答预案」等。

**3. 一键直达钮：整套摘要 / 美化统一 / 口播稿 / 整套校对 / 结构诊断**

- 这五个全部是**立即执行型**（点完自动发送，无需补充）：
  - 「整套摘要」：通读全部页面，在第 1 页后新增一页「核心要点」摘要页（3-5 条要点）；
  - 「美化统一」：全部页面中文字体统一为微软雅黑、标题 28 号、正文 18 号，表格形状跳过，完成后报告触及页数与形状数；
  - 「口播稿」：逐页生成口语化演讲者备注（每页 3-5 句）写入对应页备注；
  - 「整套校对」：只读校对错别字/重复词/占位符文本（Lorem/TODO/示例）/标点问题，输出「页码+原文+修改建议」清单，不改文字；确认后想批量改，用侧栏「校对修复执行」；
  - 「结构诊断」：只读诊断故事线连贯性、单页要点数、封面/目录/过渡/结尾页缺失，给 3-5 条调整建议。

**4. 「文档安全」▾：保密检查 / 加密演示稿 / 解密演示稿**

- 「保密检查」：立即执行型，逐页只读检查敏感词/密级表述/内部代号/客户名与金额，输出「页码+内容摘要+风险级别」清单（能力全貌见 [W20](./W20-保密检查.md)）；
- 「加密演示稿」：预填型，智能体先在对话里向你询问密码，再用演示稿工具 `security_encrypt_save` 完成加密并报告保存路径；密码遗忘无法找回；
- 「解密演示稿」：预填型，先提醒备份，确认后 `security_decrypt_save` 移除打开密码。

**5. 「更多演示助手」▾：高频带参配方**

- 菜单项：结构件补齐（立即执行型：缺封面/目录/过渡/结尾页自动补齐并列出新页码）/ 整套翻译 / 转讲义文档 / 页码页脚 / 数据战报页 / 课件生成 / 习题互动页，除「结构件补齐」外均预填补充型；
- 「转讲义文档」需在 WPS 文字里打开目标文档（逐页整理成「页码+标题+要点」写入 Word）；「数据战报页」跨宿主读取打开的工作簿数据提炼大数字出战报页组；
- 菜单底部与分隔线后各有一个「设置」，都打开与文字端同一个设置窗口（见 W04）。

**6. 「模板新建」大按钮**

- 打开「从模板新建」对话框，按当前宿主列出已登记模板供新建演示稿（见 W29）。

**7. 助手面板侧栏：81 个演示配方全集**

- 在哪：AI 助手面板左侧栏「助手」页签，演示宿主只显示演示配方（Ribbon=高频直达，面板=全集）；
- 分组：通用高频、配图、科研学术、政务汇报、党务学习、教育培训、销售提案、咨询方案、通用职场、医疗健康、制造安环、金融、电商运营、房产置业、活动婚庆；「配图」组三条（搜图配图页/AI 生图配图/矢量图标装饰）对应三级图源，见 W33；
- 每条右侧：收藏（星标）、▶「执行助手」（立即执行型直接发送/预填型等补充）、?「使用说明」（演示端 81 条逐条编制了分步说明书：准备→分步操作→小贴士）；
- 配方的启用停用与编辑见 [W11](./W11-助手管理.md)。

### 验证

1. 点「生成PPT」并发送主题：先收到大纲（页码+每页标题+要点）而不是直接出片；回复确认后逐页生成；
2. 点「整套校对」：自动发送，对话返回只读问题清单且原稿文字未被改动；
3. 点「加密演示稿」并发送：智能体先问你要密码；加密后报告保存路径；
4. 打开侧栏「助手」页签：只看到演示配方（看不到文字/表格端助手），组名右侧有数量角标。

## 常见问题

**Q1：点了「生成PPT」没先给大纲就开始逐页出片？**
配方的设计是大纲先行——按钮预填的提示词原文就要求「先给出大纲（页码+每页标题+要点），等我确认后逐页生成」。若某次模型没有遵守，重新点一次「生成PPT」，在补充要求里明确「先出大纲等我确认再生成」再发送即可。

**Q2：「美化统一」会不会把表格样式也改了？**
不会。配方明确「表格形状跳过」，只统一字体字号；表格样式可用侧栏「表格样式统一」配方单独处理。

**Q3：生成的 PPT 里图片比例不对/铺不满页面？**
PPT 宿主生图会自动按页面宽高比选 16:9/9:16（生图模型默认 1:1 才会铺不满）。若仍异常，检查是否在对话里手动指定了比例；配图链路本身的问题见 W33。

**Q4：「整套翻译」翻到一半停了/个别页没翻？**
整套翻译逐页读取后用文本替换写回（数字、专有名词保持原样）；页数多时耗时长，可让模型从指定页继续。写回走预览确认闸门，可在任务进度窗核对每处替换（W18）。

**Q5：一键钮点了没反应？**
面板正在执行回合时不会被打断（等回合结束再点）；面板打开失败会弹「AI 助手面板打开失败（原因）」提示；模型未配置先完成 W03。同表格端机制，见 [W31](./W31-表格助手.md) 常见问题 Q1。

**Q6：侧栏怎么没有「添加助手」入口？**
演示端侧栏展示的是内置演示配方 + 演示宿主自定义助手；创建入口与字段说明见 [W12](./W12-创建自定义助手.md)（表格/演示宿主的自定义配方存宿主分桶，编辑走设置 → 助手设置）。
