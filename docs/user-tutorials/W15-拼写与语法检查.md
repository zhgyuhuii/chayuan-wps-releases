## 一句话说明

顶部工具栏「拼写与语法检查」按钮对全文或选中内容做错别字、语法、标点、搭配检查：有选中只查选中，无选中确认后查全文；检查在独立进度窗里分块并发执行，关掉进度窗任务照跑，结果以批注形式精确钉到原文问题处。

## 适用场景

- 公文、论文、报告发出去之前想查一遍错别字和标点；
- 长文档只想检查其中一章/一段；
- 检查到一半想关窗干别的，或想中途停下来。

典型提问（chabot 语料视角）：

- 「拼写与语法检查在哪里点？会改动我的正文吗？」
- 「校对进度窗关了任务还在跑吗？怎么中途停止？」
- 「检查结果在哪里看？为什么是批注？」

## 前置条件

- 已配置对话模型（见 W03）。检查优先用设置里指定的「拼写与语法检查模型」，未指定时回落到默认对话模型；两者都没有时任务报错；
- 建议先保存文档，便于配合备份/撤销（见 W14）。

## 操作步骤

**1. 发起检查**

- 在哪：顶部工具栏「AI 助手」分组的大按钮「**拼写与语法检查**」。
- 看到什么（按选区分流）：
  - **有选中**（不少于 2 个字符）：直接以「选中」模式启动，只检查选中内容；
  - **无选中**：弹确认框「**当前未选中文档内容，将对全文执行“拼写与语法检查”。\n\n点击“确定”后开始处理全文。**」——全文超过 12000 字时附加「当前内容较长，处理可能需要更久，请耐心等待。」，超过 30000 字时附加「当前内容很长，处理时间可能较久，并可能触发分段或较长响应，请确认后继续。」；点「确定」开始，「取消」不执行；
  - **文档没有正文**：提示「当前文档没有可检查的正文内容」。

**2. 读进度窗**

- 看到什么：独立提示窗，标题「**拼写与语法检查**」（选区模式为「**拼写与语法检查（选中）**」），标题旁状态徽章：准备中 / 进行中 / 已完成 / 失败 / 异常结束 / 已停止。
- 副标题固定一行：「**任务可关闭提示窗继续执行，只有点击停止才会中止任务。**」
- 进度区：「正在检查：第 x / y 段」+ 百分比进度条 +「当前检查内容」卡显示正在检查的原文片段。
- 右上按钮：「**停止任务**」（仅任务运行中显示）和「**关闭**」。
- 完成时显示「**已完成，共添加 N 处批注**」，随后提示「即将自动关闭」并自动关窗；停止后显示「任务已停止」。
- 底部提示：「可在「任务清单」中查看详细进度；关闭此提示窗不会停止任务。」

**3. 看结果：批注钉在原文上**

- 看到什么：每处问题在原文对应位置加一条批注。模型按结构化 JSON 返回每个问题的问题片段、建议改法、原因、所在整句和前后各最多 12 个字的锚定上下文；程序按「原文查找 → 范围复核」把批注精确钉到问题文字上（表格里的坐标漂移会自动重定位，钉不上就不硬挂）。
- 批注内容格式：「<原因>: 建议改为「<建议>」」（无建议时只写原因），例如「错别字: 建议改为「作业」」。

**4. 中途停止**

- 在哪：进度窗「**停止任务**」按钮（或任务清单里对应任务的停止入口）。
- 看到什么：任务状态变「已停止」。停止信号跨窗口生效——即使你关掉了进度窗，也能从任务清单里停掉它。

**5. 对话里也可以校对（MCP 链路）**

- 在哪：AI 助手窗格开启文档智能体（见 W09）后，直接对 AI 说「校对一下这篇文档」。
- 看到什么：模型跑校对任务后，消息里出现「**校对结果**」卡（汇总发现 N 处问题），下方两个按钮：「**写成批注**」和「**直接改正正文**」——选哪个由你决定，不会不打招呼就改正文；本轮修改前已创建快照时还有「**一键撤销**」卡（点「撤销本次修改」整体回退，见 W14）。

### 验证

1. 在文档里故意写一个错别字（如「做业」），选中它点「拼写与语法检查」：进度窗标题为「拼写与语法检查（选中）」，完成后原文「做业」处出现批注，内含建议「作业」。
2. 检查进行中点「关闭」关掉进度窗：批注仍在继续增加（任务未停）；再从任务清单停止该任务，进度状态变为「已停止」。
3. 全文模式启动时能看到「当前未选中文档内容，将对全文执行……」确认框。

## 常见问题

**Q1：关闭进度窗后任务还在跑吗？**
在跑。副标题写明「任务可关闭提示窗继续执行，只有点击停止才会中止任务。」关窗不影响检查；只有点「停止任务」（或任务清单里的停止）才会中止。

**Q2：为什么有些“病句”没被报出来？**
检查提示词只报「明确可证实的错别字、语法错误、标点误用、固定词误写、搭配错误」，明确排除风格偏好、口语化、语气优化等主观润色项，避免误报。需要文风润色请用「文本分析 ▾」里的相关功能（见 W16）。

**Q3：长文档检查很慢，能提速吗？**
检查按块分片进行，默认块长约 6000 字。从工具栏发起的检查要边查边写批注，逐块串行执行；通过文档智能体发起的校对（先出预览、你确认后再落笔）按并发设置执行（默认并发 3，可调 1–8，当前版本这两个参数暂无设置界面）。最有效的提速是给检查指定一个更快的「拼写与语法检查模型」。

**Q4：报「请先在设置中配置拼写与语法检查模型」？**
说明默认对话模型也没配好。到设置里配好对话模型（见 W03），或在设置里专门指定「拼写与语法检查模型」后重试。

**Q5：检查会直接改动我的正文吗？**
不会。检查结果只加批注；要把建议落到正文，用对话链路「校对结果」卡上的「直接改正正文」按钮（按定位逐处安全替换，定位不稳的自动降级为批注），或按批注手动修改。
