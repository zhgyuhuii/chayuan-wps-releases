## 一句话说明

输入区左侧的模型芯片按钮展开按厂商分组的对话模型下拉，点选即切换；选中的模型以「厂商ID|模型ID」复合 id 记忆（跨窗格/跨会话生效），从下一条消息开始使用，未配置任何模型时下拉直接给「立即配置模型」引导。

## 适用场景

- 配了多家厂商（或本地 Ollama/LM Studio），想在对话里随手换模型对比效果；
- 某个任务更适合别的模型（长文摘要用大杯、快问快答用小杯）；
- 新机器上还没配模型，点开下拉不知所以，需要被引导去配置。

典型提问（chabot 语料视角）：

- 「对话的时候怎么切换模型？换了以后哪条消息生效？」
- 「模型下拉是空的/提示先配置模型，怎么办？」
- 「我选的模型下次打开还在吗？」

## 前置条件

- 已打开 AI 助手窗格（见 W05）。
- 下拉里要能列出模型，需先在设置中启用厂商并填好 API 地址与密钥（本地 Ollama 类厂商可免密钥），且该厂商有模型清单——见 W03 首次配置。

## 操作步骤

**1. 认识模型按钮**

- 在哪：输入区工具条最左侧的**芯片图标**按钮（右边依次是机器人、知识库、回形针等工具钮）；已选模型时图标旁带厂商 logo 徽标（无已知 logo 的厂商显示模型名首字徽标），悬停提示当前模型名。
- 未配置任何对话模型时悬停提示为「**配置模型**」。

**2. 展开下拉并选择**

- 做什么：点芯片按钮展开下拉。
- 看到什么：
  - 模型按**厂商分组**排列：每组头是「▾ 箭头 + 厂商 logo/首字徽标 + 厂商名」，点组头可折叠/展开该组；有已知 logo 的厂商显示 logo，没有的显示厂商名首字徽标；
  - 已配置「察元桌面版」时，末尾多出「**察元桌面版 · 本地模型**」等镜像分组，镜像察元桌面版里已配置的对话模型——选这类模型聊天经桌面版的模型代理（本机 62581 端口）转发；
  - 当前选中的模型行高亮（active 态）。
- 做什么：点目标模型行即完成切换，下拉自动收起。
- 未配置任何模型时，下拉显示引导文案「**请先在设置中配置模型：开启提供商、填写 API 地址与密钥、刷新模型清单**」和按钮「**立即配置模型**」，点它打开设置页（见 W03）。

**3. 生效时机与记忆**

- 生效：模型在**发送时**解析——切换后**下一条消息**即用新模型；已经在执行中的回合不受影响，任务窗的「换模型重跑」也会取当前选中的模型（见 W18）。
- 记忆：选择立即写入加载项共享存储（复合 id 形如 `DEEPSEEK|deepseek-chat`），同时作为默认对话模型（`defaultModelId`/`defaultModelsByCategory.chat`）同步——重开窗格、重启 WPS 后仍保持；设置页与智能体链路读同一份默认值。
- 作用范围：模型选择是**全局的**，不按会话单独记忆——切换后所有会话（含其它文档的会话）的下一条消息都用新模型。
- 模型清单在窗口重新聚焦时自动刷新：刚在设置页增删了厂商/模型，回到助手窗格点一下任意处即可刷新下拉。

### 验证

1. 点芯片按钮：下拉按厂商分组出现，当前模型行高亮。
2. 选另一家厂商的模型，发一条消息：回复正常返回（模型切换生效）；重开 AI 助手窗格，悬停芯片按钮显示的仍是刚选的模型名。
3. 清空配置（或在未配置的机器上）展开下拉：出现「请先在设置中配置模型…」引导与「立即配置模型」按钮。

## 常见问题

**Q1：下拉里没有我刚在设置里加的厂商？**
下拉只列「已启用 + 已填 API 地址 + 有模型清单」的厂商（Ollama 类本地厂商可免密钥）。回设置-模型设置确认该厂商已启用、地址正确并刷新过模型清单；模型清单在窗口重新聚焦时自动刷新（刚关掉设置页时点一下助手窗格即可），仍没有就重开 AI 助手窗格。

**Q2：切换模型后，正在生成的回答会换吗？**
不会。模型在发送时读取，切换只影响下一条消息；要换模型重跑可用任务窗的「换模型重跑」（见 W18）。

**Q3：重启 WPS 后模型变回第一个了？**
选择按复合 id 记忆并校验存在性：若该厂商被停用或模型清单里已无此模型，会回落到列表第一个。恢复启用该厂商即可找回原选择。

**Q4：对话里选的模型会影响助手执行用的模型吗？**
会参与。助手模型按优先级解析：助手显式配置的模型 > 对话框当前选中 > 助手分类默认 > 对话默认（跟随）；且对话选择会同步写入默认对话模型。要给单个助手固定模型，在助手编辑里单独设置（见 W12）。

**Q5：「察元桌面版 · 本地模型」分组是怎么来的？**
运行察元桌面版后，加载项会镜像桌面版里已配置的对话模型，按平台分组显示在下拉末尾；选这些模型聊天都经桌面版的模型代理（本机 62581 端口）转发。桌面版未在线时该分组无内容、不显示。

**Q6：模型行前面显示的是首字方块而不是厂商 logo？**
只有确有内置 logo 的厂商才显示 logo；没有已知 logo 的厂商/模型直接渲染名称首字徽标，不会去请求不存在的图片。属正常显示，不影响选用。
